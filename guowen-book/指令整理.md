# 科學班國文歷屆試題詳解集｜指令整理

本檔整理兩種「指令」：
**一、需求指令**——這本書是依哪些要求做出來的（可直接複製，下次請 AI 製作其他科目或其他學校時沿用）；
**二、操作指令**——如何在電腦上重新排版、修改內容、增加年度。

---

### 2. 可重複使用的完整指令（Prompt）

把下面整段貼給 AI，並附上試題與解答檔案（或官網網址）即可。〔 〕內換成自己的內容。

```text
請製作一套「〔國立嘉義高級中學科學班甄選入學〕〔國文科〕歷屆試題詳解集」，輸出為 A4 的 PDF。

【取材】
- 試題與參考答案使用我附上的檔案（〔100–115 學年度試題與解答〕），不足的再到學校官網〔https://www.cysh.cy.edu.tw/p/412-1008-888.php〕下載。
- 答案一律以官方公布的參考答案為準（有修正版用修正版）。你若認為官方答案有疑義，仍採官方答案，另外客觀說明。

【分冊】
- 五個學年度一本，共分三冊（〔101–105／106–110／111–115〕），多出來的年度列為特別收錄。
- 每冊都要有：封面、編輯說明（資料來源）、使用說明（記號圖例）、可點選且有頁碼的目錄、各年度章名頁與試卷總覽、書末附錄。

【每一題必須包含，順序固定】
1. 原題完整重現：題幹、引文、選項、出處一字不漏；題目中的圖表也要放上；原卷若有誤植，照錄並註明。
2. 彩色手寫筆記畫重點：直接在原題上用螢光筆、圈、波浪線、刪除線、字上小註標出題眼與關鍵詞，旁邊另有手寫風格的筆記欄，像資優生畫過重點的考卷。
3. 答案，加上一句話破題。
4. 解題邏輯：分步驟寫出「怎麼想」（審題 → 定位依據 → 刪去 → 結論）。
5. 詳解：四個選項逐一說明，錯誤選項要指出錯在哪個詞、應如何改；成語典故給出處與本義；文言文與詩詞附白話語譯；題組另附文本導讀（結構、主旨、比較表）。
6. 易錯提醒：常見誤判，或官方答案的疑義說明。
7. 延伸知識點：與考點直接相關、可以帶走的知識表，要「完整成體系」（例如考到年齡代稱，就給由襁褓到期頤的完整年齡代稱表，附出處與例句），每題 2–4 則。
8. 加深加廣（接軌學測難度）：每題 1–3 則，內容包括高中課文連結、學測常見考法與作答要領、進階概念辨析、文學史與國學脈絡、學測難度的自編進階演練（附答案與解析）。不要寫無法查證的「某年學測第幾題」。

【每個年度】
- 試卷總覽：官方答案速查、題型配比、難度分布、命題趨勢分析、備考建議、題目一覽表（考點、類別、難度、答案、頁碼）。

【書末附錄】
- 歷年答案總表、歷年題型分布統計、延伸知識點索引（附頁碼）。

【品質】
- 詳解的細節程度比照市售出版社詳解。
- 每一回（每個學年度）排版後約 100 頁，靠完整而有深度的延伸內容達成，不可灌水或重複。
- 字音、字義、成語出處以教育部《重編國語辭典》查證；沒有把握的出處、年代、作者寧可不寫，不可杜撰。
- 使用臺灣繁體中文與臺灣課綱用語。

【版面】
- 非常精美、編排細節清楚；全書字體使用「芫荽（Iansui）」。
- 題頭顯示題號、考點名稱、類別、難度星等與配分。

【交付】
- 三冊 PDF。
- 一份「指令整理.md」：整理我下過的需求指令（含這份 prompt），以及重新排版、修改內容、增加年度的操作指令。
- 可重新排版的原始檔（內容檔、排版程式、樣式）。
```

## 二、操作指令

### 0. 專案結構

```
guowen-book/
├── content/            各年度內容檔（111.txt … 115.txt）← 要改詳解就改這裡
├── figs/               題目中的圖（由試卷 PDF 裁切）
├── source/text/        試卷轉出的文字檔＋官方答案（撰稿參考用）
├── build.py            內容檔 → HTML 的排版引擎（含格式檢查）
├── frontmatter.py      封面、編輯說明、使用說明、目錄、附錄
├── style.css           全書版面樣式（顏色、字體、間距）
├── render.js           HTML → PDF（Chromium / Playwright）
├── make.py             一鍵產生全書 PDF
├── fonts-bold.css      粗體字設定（芫荽無粗體，改用霞鶩文楷 TC Bold）
├── tools/              小工具（預覽、裁圖、查辭典、試卷轉文字、跨年度重複檢查）
├── FORMAT.md           內容檔格式與品質規範
└── dist/科學班國文歷屆試題詳解集_第X冊_起-迄.pdf   ← 成品（三冊）
```

### 1. 環境準備（只需一次）

需要 Python 3、Node.js、Playwright（Chromium）與 poppler-utils（`pdftoppm`、`pdfinfo`、`pdftotext`）。

```bash
cd guowen-book
```

```bash
npm install
```

```bash
npm install playwright && npx playwright install chromium
```

（第三行只有在電腦尚未安裝 Playwright 時才需要。）

### 2. 產生全書 PDF

```bash
python3 make.py
```

只產生某一冊（例如第三冊）：

```bash
python3 make.py 3
```

只產生單一年度（不含封面、目錄、附錄）：

```bash
python3 make.py --year 115
```

- 會自動執行兩階段排版：先排一次取得各題頁碼，回填目錄、題目一覽與索引後再排一次。
- 成品：`dist/科學班國文歷屆試題詳解集_第一冊_101-105.pdf`、`…_第二冊_106-110.pdf`、`…_第三冊_111-115.pdf`。
- 各冊收錄哪些年度，寫在 `build.py` 最上方的 `VOLUMES`。
- 結尾顯示「頁數一致 ✓」表示目錄頁碼正確；若顯示頁數不同，再執行一次即可。

### 3. 只排某一年（改稿時用）

```bash
python3 build.py --check 115
```

檢查 115 學年度內容檔：題數、必填欄位、行內標記是否配對，並自動比對官方答案。

```bash
tools/preview.sh 115
```

排出單一年度樣張 `dist/sample-115.pdf`，並把每頁轉成圖片放在 `dist/prev/`。

### 4. 修改內容

所有文字都在 `content/年度.txt`，用純文字編輯器即可修改。最常用的寫法：

| 想做的事 | 寫法 |
| --- | --- |
| 黃／綠／藍／粉／橘 螢光筆 | `{y:文字}` `{g:文字}` `{b:文字}` `{p:文字}` `{o:文字}` |
| 螢光筆＋字上方手寫小註 | `{y:文字|小註}` |
| 紅筆圈、波浪線、刪除線 | `{c:文字}` `{u:文字}` `{x:文字}` |
| 直接寫上紅／藍手寫字 | `{n:文字}` `{nb:文字}` |
| 邊欄手寫筆記 | 在題幹或選項後加 `@note red`（或 blue、green、purple、orange），下一行寫筆記 |
| 詳解中的重點粗體 | `{k:關鍵詞}` |
| 延伸知識點卡片 | `@know 標題`，下一行起寫內容 |
| 加深加廣卡片 | `@adv 標題`，下一行起寫內容 |
| 表格 | `| 欄1 | 欄2 |`（第一列為表頭） |

完整欄位說明見 [`FORMAT.md`](FORMAT.md)，範例見 `content/115.txt`。改完後依序執行第 3、第 2 節的指令。

### 5. 查證字音字義

```bash
tools/moe.sh 輕佻 越俎代庖 白圭之玷
```

查詢教育部《重編國語辭典》（透過萌典），列出注音與釋義。

### 6. 調整版面

| 想調整 | 修改位置 |
| --- | --- |
| 字體 | `style.css` 最上方 `:root` 的 `--serif`、`--sans`、`--kai`、`--hand`（目前皆為 Iansui）。芫荽沒有粗體字重，粗體由 `fonts-bold.css` 指定為同源的霞鶩文楷 TC Bold（若用瀏覽器合成的假粗體，PDF 會大三倍） |
| 主色、螢光筆與筆色 | `style.css` 的 `:root` 變數與 `.hl-y` 等 |
| 筆記欄寬度 | `style.css` 的 `.row>.margin{width:53mm}` |
| 紙張與邊界、頁眉頁碼 | `style.css` 的 `@page` |
| 封面、使用說明、附錄文字 | `frontmatter.py` |
| 類別名稱與代表色 | `build.py` 的 `CATS`、`CAT_COLOR` |

若只想讓「手寫筆記」用芫荽、內文改用其他字體，把 `--serif`、`--sans` 改成想要的字體名稱，並在 `build.py` 的 `fonts` 清單加入對應的字體 CSS 即可。

### 7. 新增其他年度（例如 116 學年度）

嘉義高中歷屆甄選試題頁：<https://www.cysh.cy.edu.tw/p/412-1008-888.php>

1. 到上列頁面下載該年度「國文科能力檢定試題」與「參考答案」PDF，存成：
   `source/pdf/116_q.pdf`、`source/pdf/116_ans.pdf`（有修正版答案時另存 `116_ans_fix.pdf`）。
2. 轉成文字與頁面圖片：

```bash
tools/extract.sh 116
```

3. 題目有圖時，用頁面比例座標（0–1）裁圖到 `figs/`：

```bash
python3 tools/crop.py 116 2 0.05 0.30 0.48 0.62 116_q07.png
```

4. 依 `FORMAT.md` 撰寫 `content/116.txt`（可把 `FORMAT.md`、`content/115.txt` 與 `source/text/116.txt` 交給 AI 撰寫）。
5. 把新年度加入 `build.py` 的 `VOLUMES`（決定放在哪一冊），執行第 3 節的檢查與預覽，再執行第 2 節。封面年度、目錄、附錄統計會自動更新。

### 8. 常見問題

| 狀況 | 處理 |
| --- | --- |
| `--check` 顯示「行內標記未配對」 | 檢查該處 `{ }` 是否成對、是否巢狀（不可巢狀）、標記內是否含 `|` |
| 顯示「@answer 與官方答案不符」 | 核對 `=== META` 的 `@answers` 與該題 `@answer` |
| 某個字顯示成不同字體 | 芫荽缺該字，已自動以霞鶩文楷 TC 或全字庫正楷體（TW-Kai）補字；屬正常現象 |
| 字上小註擠在一起 | 小註控制在 10 字內，較長的說明改寫到 `@note` 邊欄筆記 |
| 目錄頁碼為「—」 | 重新執行 `python3 make.py` |

### 9. 定稿前的檢查清單

```bash
for y in 100 101 102 103 104 105 106 107 108 109 110 111 112 113 114 115; do python3 build.py --check $y | tail -1; done
```

每個年度都應顯示「✓ 格式檢查通過」（題數、必填欄位、官方答案比對、每題是否有加深加廣）。

```bash
python3 tools/dupcheck.py
```

檢查是否有卡片被誤放到別的年度（應顯示「重複 0 組」）。

```bash
python3 make.py
```

三冊結尾都應顯示「頁數一致 ✓」。

### 10. 本書的已知限制

- 詳解、延伸知識與加深加廣由 AI 撰寫，字音字義以教育部辭典查證，但課文引句、作家生平、題辭與書信用語等無法全數以工具核對，建議由老師抽核。
- 標示「本書自編」的進階演練未經第二人驗題。
- 官方答案有討論空間的題目，一律依官方答案（或指定的解答版本）作答，疑義寫在該題「易錯提醒」。
- 100 學年度第 5 題：依指示採打字版解答 C；學校原始答案卷為 A，書中已並陳兩者依據。
- 少數極罕用字（如 110 學年度第 14 題的「𡙸」）撰稿時因缺字改用通行字並在筆記欄註明。
- 延伸卡片不跨頁，部分頁面底部會有留白。
