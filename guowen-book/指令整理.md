# 科學班國文歷屆試題詳解集｜指令整理

本檔整理兩種「指令」：
**一、需求指令**——這本書是依哪些要求做出來的（可直接複製，下次請 AI 製作其他科目或其他學校時沿用）；
**二、操作指令**——如何在電腦上重新排版、修改內容、增加年度。

---

## 一、需求指令彙整

### 1. 製作過程中下達的指令（依時間順序）

| # | 指令原文 | 落實方式 |
| --- | --- | --- |
| 1 | 製作一本非常精美且編排細節清楚的科學班入學考國文考題詳解集，題目取自網路 | 以 A4 書籍版面排版成 PDF；試題取自學校官網公開檔案 |
| 2 | 詳解要依照出版社等級的細節程度，主要是嘉義高中 | 改以嘉義高中科學班甄選「科學能力檢定—國文科」111–115 學年度為主；每題含考點、難度、逐選項詳解、延伸知識 |
| 3 | 要附上原完整題，彩色手寫筆記畫重點注記，衍伸的知識點，解題邏輯以及詳解，答案 | 每題固定六區塊：原題重現（筆記版）→ 答案＋一句破題 →（語譯）→ 解題邏輯 → 選項詳解 → 易錯提醒 → 延伸知識點 |
| 4 | 字體改成芫荽就好 | 全書統一使用「芫荽 Iansui」字體（缺字時以霞鶩文楷 TC 補） |
| 5 | 最後整理指令 md | 即本檔 |

### 2. 可重複使用的完整指令（範本）

> 請製作一本 **〔學校／考試名稱〕〔科目〕歷屆試題詳解集**（PDF，A4）。
>
> **取材**：題目與參考答案取自〔學校官網網址〕公開的歷屆試題，收錄〔起訖年度〕。答案一律以官方公布（含修正）為準，官方答案若有疑義，仍採官方答案並另外說明。
>
> **每一題都要包含**：
> 1. **原題完整重現**：題幹、引文、選項、出處一字不漏；原卷誤植照錄並註明。
> 2. **彩色手寫筆記畫重點**：直接在原題上用螢光筆、圈、波浪線、刪除線、字上小註標出題眼與關鍵詞，旁邊有手寫風格的筆記欄。
> 3. **答案**與一句話破題。
> 4. **解題邏輯**：分步驟寫出「怎麼想」（審題 → 定位 → 刪去 → 結論）。
> 5. **詳解**：四個選項逐一說明，錯誤選項要指出錯在哪個詞、應如何修正；文言文與詩詞附白話語譯。
> 6. **延伸知識點**：與考點直接相關的比較表、典故、文學常識，每題 2–3 則。
>
> **細節程度**：比照市售出版社詳解；題組另附文本導讀；每個年度附試卷總覽（答案速查、題型配比、難度分布、命題趨勢、題目一覽）；書末附歷年答案總表、題型統計與知識點索引。
>
> **版面**：非常精美、編排細節清楚；字體使用芫荽（Iansui）；有封面、使用說明、可點選的目錄與頁碼。
>
> **正確性**：字音、字義、成語出處以教育部《重編國語辭典》查證；沒有把握的出處不寫。
>
> **最後**：整理一份指令說明 md（需求指令＋操作指令）。

### 3. 內容品質規範

撰寫每一題時遵守的細則（筆記怎麼畫、每個欄位寫什麼、字數）寫在 [`FORMAT.md`](FORMAT.md)。

## 二、操作指令

### 0. 專案結構

```
guowen-book/
├── content/            各年度內容檔（111.txt … 115.txt）← 要改詳解就改這裡
├── figs/               題目中的圖（由試卷 PDF 裁切）
├── source/text/        試卷轉出的文字檔＋官方答案（撰稿參考用）
├── build.py            內容檔 → HTML 的排版引擎（含格式檢查）
├── frontmatter.py      封面、編輯說明、使用說明、目錄、附錄
├── style.css           全書版面樣式（顏色、字體、間距）
├── render.js           HTML → PDF（Chromium / Playwright）
├── make.py             一鍵產生全書 PDF
├── tools/              小工具（預覽、裁圖、查辭典、試卷轉文字）
├── FORMAT.md           內容檔格式與品質規範
└── dist/科學班國文歷屆試題詳解集.pdf   ← 成品
```

### 1. 環境準備（只需一次）

需要 Python 3、Node.js、Playwright（Chromium）與 poppler-utils（`pdftoppm`、`pdfinfo`、`pdftotext`）。

```bash
cd guowen-book
```

```bash
npm install
```

```bash
npm install playwright && npx playwright install chromium
```

（第三行只有在電腦尚未安裝 Playwright 時才需要。）

### 2. 產生全書 PDF

```bash
python3 make.py
```

- 會自動執行兩階段排版：先排一次取得各題頁碼，回填目錄、題目一覽與索引後再排一次。
- 成品：`dist/科學班國文歷屆試題詳解集.pdf`。
- 結尾顯示「頁數一致 ✓」表示目錄頁碼正確；若顯示頁數不同，再執行一次即可。

### 3. 只排某一年（改稿時用）

```bash
python3 build.py --check 115
```

檢查 115 學年度內容檔：題數、必填欄位、行內標記是否配對，並自動比對官方答案。

```bash
tools/preview.sh 115
```

排出單一年度樣張 `dist/sample-115.pdf`，並把每頁轉成圖片放在 `dist/prev/`。

### 4. 修改內容

所有文字都在 `content/年度.txt`，用純文字編輯器即可修改。最常用的寫法：

| 想做的事 | 寫法 |
| --- | --- |
| 黃／綠／藍／粉／橘 螢光筆 | `{y:文字}` `{g:文字}` `{b:文字}` `{p:文字}` `{o:文字}` |
| 螢光筆＋字上方手寫小註 | `{y:文字|小註}` |
| 紅筆圈、波浪線、刪除線 | `{c:文字}` `{u:文字}` `{x:文字}` |
| 直接寫上紅／藍手寫字 | `{n:文字}` `{nb:文字}` |
| 邊欄手寫筆記 | 在題幹或選項後加 `@note red`（或 blue、green、purple、orange），下一行寫筆記 |
| 詳解中的重點粗體 | `{k:關鍵詞}` |
| 表格 | `| 欄1 | 欄2 |`（第一列為表頭） |

完整欄位說明見 [`FORMAT.md`](FORMAT.md)，範例見 `content/115.txt`。改完後依序執行第 3、第 2 節的指令。

### 5. 查證字音字義

```bash
tools/moe.sh 輕佻 越俎代庖 白圭之玷
```

查詢教育部《重編國語辭典》（透過萌典），列出注音與釋義。

### 6. 調整版面

| 想調整 | 修改位置 |
| --- | --- |
| 字體 | `style.css` 最上方 `:root` 的 `--serif`、`--sans`、`--kai`、`--hand`（目前皆為 Iansui） |
| 主色、螢光筆與筆色 | `style.css` 的 `:root` 變數與 `.hl-y` 等 |
| 筆記欄寬度 | `style.css` 的 `.row>.margin{width:53mm}` |
| 紙張與邊界、頁眉頁碼 | `style.css` 的 `@page` |
| 封面、使用說明、附錄文字 | `frontmatter.py` |
| 類別名稱與代表色 | `build.py` 的 `CATS`、`CAT_COLOR` |

若只想讓「手寫筆記」用芫荽、內文改用其他字體，把 `--serif`、`--sans` 改成想要的字體名稱，並在 `build.py` 的 `fonts` 清單加入對應的字體 CSS 即可。

### 7. 新增其他年度（例如 108–110 學年度）

嘉義高中歷屆甄選試題頁：<https://www.cysh.cy.edu.tw/p/412-1008-888.php>

1. 到上列頁面下載該年度「國文科能力檢定試題」與「參考答案」PDF，存成：
   `source/pdf/110_q.pdf`、`source/pdf/110_ans.pdf`（有修正版答案時另存 `110_ans_fix.pdf`）。
2. 轉成文字與頁面圖片：

```bash
tools/extract.sh 110
```

3. 題目有圖時，用頁面比例座標（0–1）裁圖到 `figs/`：

```bash
python3 tools/crop.py 110 2 0.05 0.30 0.48 0.62 110_q07.png
```

4. 依 `FORMAT.md` 撰寫 `content/110.txt`（可把 `FORMAT.md`、`content/115.txt` 與 `source/text/110.txt` 交給 AI 撰寫）。
5. 執行第 3 節的檢查與預覽，再執行第 2 節產生全書。封面年度、目錄、附錄統計會自動更新。

### 8. 常見問題

| 狀況 | 處理 |
| --- | --- |
| `--check` 顯示「行內標記未配對」 | 檢查該處 `{ }` 是否成對、是否巢狀（不可巢狀）、標記內是否含 `|` |
| 顯示「@answer 與官方答案不符」 | 核對 `=== META` 的 `@answers` 與該題 `@answer` |
| 某個字顯示成不同字體 | 芫荽缺該字，已自動以霞鶩文楷補字；屬正常現象 |
| 字上小註擠在一起 | 小註控制在 10 字內，較長的說明改寫到 `@note` 邊欄筆記 |
| 目錄頁碼為「—」 | 重新執行 `python3 make.py` |
