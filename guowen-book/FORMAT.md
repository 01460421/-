# 內容檔格式規範（content/年度.txt）

每個年度一個純文字檔，由排版引擎 `build.py` 轉成 HTML/PDF。**完整範例請讀 `content/115.txt`**（第 1–7 題即是品質標竿）。

## 一、檔案結構

```
=== META                 ← 年度資訊（一個）
=== Q 1                  ← 單題
=== GROUP g15            ← 題組文本（放在該題組第一題之前）
=== Q 15
...
```

- `=== 種類 參數` 開啟一個區塊；區塊內以 `@欄位 參數` 開啟欄位，欄位內容寫在後續各行，直到下一個 `@` 或 `===`。
- 內文任何一行都不可以用 `@` 或 `=== ` 開頭。

## 二、META 欄位

| 欄位 | 說明 |
| --- | --- |
| `@total 35` | 總題數 |
| `@scoring 1-10=2.5 11-35=3` | 配分規則（依試卷說明） |
| `@scoretext …` | 配分說明文字（顯示於章名頁） |
| `@answers CAADC DABCD …` | **官方參考答案**（有「修正」版時用修正後的），供自動比對 |
| `@source URL` | 嘉義高中官網公告頁（不確定就填 https://www.cysh.cy.edu.tw/p/412-1008-888.php） |
| `@examname 甲｜乙` | 該年度考試名稱，依試卷抬頭填寫，以全形直線 `｜` 分兩行，如 `第一階段甄選｜國文成就測驗`；未填時預設「科學能力檢定｜國文科能力檢定」 |
| `@bonus 1` | （僅 100 學年度）標示為特別收錄 |
| `@fixnote` | （選填）若官方曾修正答案，說明哪一題由什麼改成什麼 |
| `@trend` | 命題趨勢分析（4–6 個條列，每條以 `- **小標**：` 起頭） |
| `@tips` | 備考建議（3 個條列） |

## 三、Q（單題）欄位

| 欄位 | 必填 | 說明 |
| --- | --- | --- |
| `@type` | ✓ | 考點名稱（6–12 字，如「近體詩格律與詩意推敲」） |
| `@cat` | ✓ | 只能是：`形音義`、`詞語成語`、`語文應用`、`國學常識`、`白話閱讀`、`文言閱讀`、`詩詞曲賞析` |
| `@tags` | ✓ | 2–4 個標籤，逗號分隔 |
| `@diff` | ✓ | 難度 1–5 |
| `@answer` | ✓ | 官方答案（A–D）。官方公布兩個答案皆給分時寫 `B/C`，META 的 `@answers` 該題也寫 `B/C` |
| `@stem` | ✓ | 題幹（**原題一字不漏**；不含題號，題號自動加） |
| `@box` | | 題目中的引文框；`@box poem` 為詩歌（逐行保留換行）；`@box label=甲` 可加標籤 |
| `@table` | | 題目中的表格（用 `| a | b |` 語法，第一列為表頭） |
| `@fig 檔名.png w=70` | | 題目中的圖（先用 `tools/crop.py` 裁到 `figs/`）；w 為寬度百分比 |
| `@opt A`…`@opt D` | ✓ | 四個選項原文 |
| `@note 顏色` | | **手寫邊欄筆記**，附著在「前一個」stem/box/table/fig/opt 旁。顏色：red blue green purple orange |
| `@cols 1` | | （選填）強制選項欄數 1/2/4；預設依長度自動 |
| `@key` | ✓ | 一句破題（40–70 字，直接講出解題關鍵） |
| `@translation` | | 文言文／詩詞的白話語譯（文言題必附） |
| `@logic` | ✓ | 解題邏輯：3–5 步，每步一行 `1. 【步驟名】說明` |
| `@ana A x` / `@ana C o` | ✓ | 四個選項逐一詳解。`o`＝該敘述正確，`x`＝該敘述錯誤（與是否為答案無關；答案由 @answer 決定） |
| `@trap` | | 易錯提醒（有常見誤判、或官方答案有疑義時必寫） |
| `@know 標題` | ✓ | 延伸知識點，每題 2–4 則，表格務求**完整**（見第九節） |
| `@adv 標題` | ✓ | 加深加廣・接軌學測，每題 1–3 則（見第九節）；題組的 GROUP 也可加 |

`@stem`、`@box` 可出現多次，依出現順序排版（如：題幹 → 引文框 → 選項）。

## 四、GROUP（題組文本）欄位

```
=== GROUP g15
@range 15-17
@intro 15-17 為題組。閱讀下列二段文字，回答 15-17 題。
@p label=甲
發鳩之山，其上多{y:柘木}……（一個 @p 可含多行，每行是一個自然段）
@note red
精衛＝炎帝之女所化
@p label=乙
……
@src
（劉義慶《宣驗記》）
@translation
【甲】……
【乙】……
@guide
文本導讀：結構、主旨、兩文比較表等
@know 標題
……
```

- `@p` 為文本段落，`@p poem` 為詩歌（保留換行），`@note` 附著在前一個 `@p`。
- 題組內各題照常用 `=== Q n` 書寫（不需再重複文本）。題組文本若為文言，`@translation` 必附；`@guide` 必寫。

## 五、行內標記（題幹、選項、文本、詳解皆可用）

| 寫法 | 效果 |
| --- | --- |
| `{y:文字}` `{p:文字}` `{g:文字}` `{b:文字}` `{o:文字}` | 黃／粉／綠／藍／橘 螢光筆 |
| `{u:文字}` `{ub:文字}` | 紅／藍 波浪底線 |
| `{c:文字}` `{cb:文字}` | 紅／藍 手繪圈（限 2–6 字） |
| `{x:文字}` | 紅筆刪除線（錯字、錯誤敘述） |
| `{y:文字|手寫註}` | 以上任一種加上「字上方的手寫小註」（註 ≤ 10 字） |
| `{n:手寫字}` `{nb:…}` `{ng:…}` `{np:…}` | 直接插入紅／藍／綠／紫 手寫字（如填入空格的答案、注音、訂正字） |
| `{k:關鍵詞}` | 詳解內文的重點粗體（紅褐色） |
| `__文字__` | 原試卷的底線（題目畫線處） |
| `**文字**` | 粗體 |

**不可巢狀**（`{y:…{c:…}…}` 會出錯）；標記內不可出現 `{ } |`。

區塊內文（logic 以外的詳解欄位）支援：`- ` 條列、`| a | b |` 表格、`> ` 引文（楷體）、`## ` 小標；每一行是一個段落。

## 六、筆記版原題的畫法（重點！）

「原題重現・筆記版」要像資優生在考卷上畫重點：

1. **題幹**：用黃色螢光筆畫出「題目要求」（如「讀音相同」「使用錯誤」「不包括」），並加上方小註；否定型題幹一定要標。
2. **選項**：錯誤處用 `{x:}` 或 `{u:}` 標出並以 `{n:}`／邊欄筆記訂正；正確關鍵用綠色或黃色標出。形音義題直接用 `{n:}` 寫出國字／注音。
3. **文本**：關鍵句（對應各題答案的依據）畫螢光筆；文言難詞用 `{u:難詞|字義}` 加註；轉折詞、主旨句用圈或不同顏色。顏色分工建議：黃＝題眼／主旨，綠＝正確依據，藍＝結構／韻腳／補充，粉／橘＝對比或情感。
4. **邊欄筆記**（`@note`）：每題 3–6 則，每則 1–2 行、每行 ≤ 14 字，口吻像手寫筆記（「刪！主語錯」「→ 對應第二段」）。紅＝解題關鍵，藍＝字詞知識，綠＝正確依據，紫／橘＝延伸提醒。
5. 一題的標記量要適中：題幹 1–2 處、每個選項 0–2 處；題組文本每段 2–5 處。
6. 版面注意：字上小註的字數不要超過底字字數加 2（過長會把底字撐開），較長的說明改寫到邊欄筆記；`{n:}` 手寫插入字不可斷行，超過 8 字請拆開或移到邊欄；選項折行不好看時用 `@cols 1` 或 `@cols 2` 指定欄數。

## 七、內容品質要求（出版社等級）

- **原題完整**：題幹、引文、選項、出處一字不漏照原卷（含原卷的書名號、標點）。原卷若有誤植，照錄並在邊欄筆記註明「原卷誤植，應為…」。
- **答案**：一律以官方（修正後）參考答案為準。若你認為官方答案有疑義，仍採官方答案，並在 `@trap` 中客觀說明疑義所在。
- **解題邏輯**：寫「怎麼想」——審題 → 定位／判斷依據 → 刪去 → 結論；不是重述詳解。
- **選項詳解**：四個選項都要解釋。錯誤選項要指出「錯在哪個詞、應如何改」；成語、典故要給出處與本義；文言選項要對應原文句子。
- **延伸知識點**：必須與本題考點直接相關，且「可帶走」——比較表、同類字詞整理、作家作品常識、文體知識、課文連結等。每題 2–3 則。
- **正確性**：字音、字義、成語出處務必查證——執行 `tools/moe.sh 詞語1 詞語2 …` 可查教育部《重編國語辭典》。出處、年代、作者沒有把握時寧可不寫，**不可杜撰**。
- 用語為臺灣繁體中文、臺灣教育部審定字音與課綱用語。
- 篇幅：**每個年度排版後約 100 頁（95–110 頁）**，靠完整而有深度的延伸內容達成，不可灌水、不可重複。25 題的年度平均每題約 4 頁，35 題的年度平均每題約 2.8 頁。以 `tools/preview.sh 年度` 顯示的頁數為準。

## 八、工作流程

1. 讀 `source/text/年度.txt`（已依左右欄順序轉出的試卷文字＋官方答案），並用 Read 工具看 `source/img/年度_p-N.png` 核對版面：底線、方框、圖表、空格等文字檔看不出來的資訊。
2. 有圖的題目用 `python3 tools/crop.py …` 裁圖後以 `@fig` 置入，並用 Read 看裁切結果是否完整。原卷的純文字表格請改用 `@table` 重打。
3. 撰寫 `content/年度.txt`。
4. `python3 build.py --check 年度` 檢查格式（會自動比對官方答案、題數、必填欄位）。
5. `tools/preview.sh 年度` 排出樣張，用 Read 看 `dist/prev/年度-NN.png` 抽查至少 6 頁：手寫註是否擠壓、表格是否過寬、圖是否清楚。
6. 不要修改 `build.py`、`style.css` 與其他年度的檔案；排版引擎若有不足，在最後回報。

## 九、加深加廣：接軌學測難度（重要）

使用者要求「每一題的加深加廣要更完整及詳細，以接軌學測難度」，例如考到年齡代稱，就要給**完整的**年齡代稱表。請這樣做：

### 1. `@know`（延伸知識點）要「完整成體系」

- 不要只列與本題選項有關的三五項，要把**整個知識系統**整理出來，讓讀者不必再查別的書。例：
  - 年齡代稱 → 由襁褓、孩提、垂髫、總角、豆蔻、及笄、束髮、弱冠、而立、不惑、知命、花甲、古稀、耄耋到期頤，附年齡、出處與例句，男女有別者分列。
  - 題辭 → 依婚嫁、壽誕、喬遷、開業、教育、醫界、哀輓（男、女、師長、軍警）等完整分類。
  - 六書、修辭、文體、詩詞曲體制、書信用語、借代詞、通同字、一字多音／多義等，皆比照辦理。
- 表格要有「出處／例句／辨析」欄，不只是名詞清單。一張表太長時拆成兩三張（如「上：幼年至成年」「下：中年至老年」）。

### 2. `@adv`（加深加廣・接軌學測）每題 1–3 則

每則是一張獨立的卡片，內容從下列方向擇要撰寫（標題自訂，要具體）：

| 方向 | 寫什麼 |
| --- | --- |
| 高中課文連結 | 本題考點在高中國文（含教育部推薦選文十五篇、常見選文）中的對應篇章、名句與考點，例：〈師說〉〈赤壁賦〉〈出師表〉〈鴻門宴〉〈桃花源記〉〈岳陽樓記〉〈醉翁亭記〉〈項脊軒志〉〈廉恥〉〈勸學〉〈諫逐客書〉〈大同與小康〉〈晚遊六橋待月記〉〈鹿港乘桴記〉〈畫菊自序〉等 |
| 學測怎麼考 | 同一概念在學測國綜的常見題型與問法（單選、多選、混合題的表格填答與短答、跨文本比較、圖表判讀），以及作答要領。**只描述題型與考法，不要寫「某某年學測第幾題」這類無法查證的資訊** |
| 進階辨析 | 更細的概念區分（如借代與借喻、轉品與轉化、互文與錯綜、樂府與古詩、傳奇三義、文言虛詞的進階用法、詞類活用與特殊句式：判斷句、被動句、倒裝句、省略句） |
| 文學史與國學脈絡 | 把本題的作者、作品放進完整的流變系統（韻文流變、散文流變、小說流變、學術思想流派），用表格呈現 |
| 進階演練（本書自編） | 1 題學測難度的自編小題（單選或多選），附答案與 2–4 行解析；標題務必含「本書自編」四字；題目與答案必須確實無誤 |

- 每題至少一則 `@adv`；基礎題（字音、字形）也要寫，可寫「學測如何把形音義融入閱讀題」「高中課文中的同類字詞」。
- 內容必須正確：課文句子、作者、出處沒有把握就不寫；用 `tools/moe.sh` 查證字詞。
- 全年度寫完後看頁數：不足 95 頁，優先補「知識體系表」與「高中課文連結」；超過 110 頁則精簡重複處。
