@logic
1. 【審題】題目比的是「讀音」，四組字兩兩形近（同聲符），命題重點就是{k:「有邊讀邊」會出錯}的字。
2. 【逐組標音】把每個字放回成語念一遍：喟（ㄎㄨㄟˋ）然而嘆／涇渭（ㄨㄟˋ）分明；裨（ㄅㄧˋ）補闕漏／睥（ㄅㄧˋ）睨群雄；垂髫（ㄊㄧㄠˊ）／續貂（ㄉㄧㄠ）；卓犖（ㄌㄨㄛˋ）／夢縈（ㄧㄥˊ）。
3. 【刪去】(A) 聲母不同、(C) 聲母聲調皆不同、(D) 整個音節都不同，全部刪去。
4. 【確認】「裨」作「補益」解讀ㄅㄧˋ（另有ㄆㄧˊ一音，用於「裨將」），「睥睨」讀ㄅㄧˋ ㄋㄧˋ，兩字同音，選 (B)。
@ana A x
「{k:喟}」然而嘆：喟，ㄎㄨㄟˋ，嘆氣的樣子。《論語‧子罕》：「顏淵喟然歎曰：『仰之彌高，鑽之彌堅。』」
涇「{k:渭}」分明：渭，ㄨㄟˋ，渭水。涇水流入渭水時清濁不混，比喻是非、好壞界限分明，語本《詩經‧邶風‧谷風》「涇以渭濁」。
→ ㄎㄨㄟˋ ≠ ㄨㄟˋ。
@ana B o
「{k:裨}」補闕漏：裨，ㄅㄧˋ，增益、補助；闕，同「缺」。指補救缺失疏漏，語出諸葛亮〈出師表〉：「必能裨補闕漏，有所廣益。」
「{k:睥}」睨群雄：睥睨，ㄅㄧˋ ㄋㄧˋ，斜著眼睛看，表示高傲、不把對方放在眼裡。
→ 同讀ㄅㄧˋ，為正解。
@ana C x
黃髮垂「{k:髫}」：髫，ㄊㄧㄠˊ，小孩額前垂下的頭髮。「黃髮」指老人，「垂髫」指兒童，語出陶淵明〈桃花源記〉：「黃髮垂髫，並怡然自樂。」
狗尾續「{k:貂}」：貂，ㄉㄧㄠ，毛皮珍貴的獸類。古代近侍官員以貂尾為冠飾，封官太濫時貂尾不夠，只好用狗尾代替；比喻以壞續好、前後不相稱，典出《晉書‧趙王倫傳》「貂不足，狗尾續」。
→ ㄊㄧㄠˊ ≠ ㄉㄧㄠ。
@ana D x
卓「{k:犖}」不群：犖，ㄌㄨㄛˋ，分明、顯著；「卓犖」是卓絕超群的意思。
魂牽夢「{k:縈}」：縈，ㄧㄥˊ，圍繞、纏繞。形容十分掛念。
→ ㄌㄨㄛˋ ≠ ㄧㄥˊ。
@trap
「裨」是多音字：作「增益、補助」解時讀ㄅㄧˋ（裨益、裨補、無裨於事），作「副的、小的」解時讀ㄆㄧˊ（裨將）。本題「裨補闕漏」取「補益」義，讀ㄅㄧˋ；若誤讀成ㄆㄧˊ，就會以為四個選項都不同音。

@type 錯別字辨正
@cat 形音義
@tags 錯別字, 同音字, 形近字
@diff 2
@answer C
@stem
下列文句，**__完全沒有__**{y:錯別字|找全對的}的是：
@note red
錯字常躲在{c:雙音詞}裡
一句一句圈出可疑詞
@opt A
種種超前部署的措施成功{x:厄}{n:遏}止了疫情的蔓延
@note blue
遏＝阻止；厄＝災難
「部署」沒錯（非佈署）
@opt B
若未配合檢疫作業，有觸犯{x:防}{n:妨}害公務罪之虞
@note blue
妨＝阻礙（女部）
防＝戒備
@opt C
這場室內講座要求所有參與者皆{g:須}{g:佩戴}口罩
@note red
須＝必須 ✓
佩戴 ✓ 全句無誤
@opt D
小明提出用烤箱消毒衣物的想法，引人發{x:劇}{n:噱}。
@note blue
發噱ㄐㄩㄝˊ＝發笑
@cols 1
@key
(A)「厄止」應作「遏止」、(B)「防害」應作「妨害」、(D)「發劇」應作「發噱」；(C)「皆須」「佩戴」用字全對。
@logic
1. 【定位】錯別字多半出現在{k:同音或形近的雙音詞}。先把每句的關鍵詞圈出來：部署、厄止、蔓延／防害公務、之虞／皆須、佩戴／消毒、發劇。
2. 【以義辨字】用詞義回推用字：「阻止」疫情→遏（辵部，與行進受阻有關）；「阻礙」公務→妨（妨礙、妨害）；引人「發笑」→噱（口部，大笑）。
3. 【檢核正解】(C)「皆須」是「都必須」，助動詞用「須」正確；「佩戴口罩」指把物品繫掛、穿戴在身上，用字正確。
4. 【結論】(A)(B)(D) 各錯一字，選 (C)。
@ana A x
「厄止」→「{k:遏}止」。遏，ㄜˋ，阻止、禁絕，如「遏止」「遏阻」「怒不可遏」。厄，ㄜˋ，災難、困窮，如「厄運」「困厄」。兩字同音，但意義不同。
另外，句中「超前部署」的「部署」是正確寫法（布置、安排），不可寫作「佈署」。
@ana B x
「防害」→「{k:妨}害」。妨，ㄈㄤˊ，損害、阻礙；「妨害公務」是法律用語，指妨礙公務員執行職務。防，戒備、防備，如「防範」「防疫」。句末「之虞」的「虞」是憂慮、可能的意思，用字正確。
@ana C o
全句無錯別字。「須」表示「必須、應當」，後接動詞（須佩戴）；「佩戴」指把物品繫掛或穿戴在身上，如佩戴口罩、佩戴名牌、佩戴勳章。
@ana D x
「發劇」→「發{k:噱}」。噱，ㄐㄩㄝˊ，大笑；「發噱」即發笑，「引人發噱」指惹人發笑。「劇」是戲劇或劇烈之意，與笑無關。
@trap
(C) 有兩個常被懷疑的地方：一是「須／需」——「須」是助動詞「必須」（務須、必須、須知），「需」是動詞或名詞「需要、需求」（需款孔急、軍需）；二是「佩戴／配戴」——教育部辭典兩詞皆收，「佩戴」為繫掛物品在身上，「配戴」為搭配佩戴，用於口罩皆無不可。不要因為「好像見過另一種寫法」就誤刪正解。
@know 「遏／厄／扼／軛」辨析（皆讀ㄜˋ）
| 字 | 意義 | 例詞 |
| 遏 | 阻止、禁絕 | 遏止、遏阻、怒不可遏、響遏行雲 |
| 厄 | 災難、困窮 | 厄運、困厄、厄難 |
| 扼 | 用力握住；據守 | 扼腕、扼殺、扼要、扼守 |
| 軛 | 套在牛馬頸上的曲木 | 牛軛 |
@know 「須」與「需」的分工
| 字 | 詞性 | 意義 | 例詞 |
| 須 | 助動詞 | 必須、應當 | 必須、務須、無須、須知 |
| 須 | 名詞 | 鬍鬚（本義）；片刻 | 須眉、須臾 |
| 需 | 動詞／名詞 | 需要；需用的東西 | 需要、需求、急需、軍需、不時之需 |
- 口訣：後面接{k:動詞}多用「須」（須努力），後面接{k:名詞}多用「需」（需人手）。
@know 「噱」的兩個讀音
- ㄐㄩㄝˊ：大笑。如「發噱」「令人發噱」。
- ㄒㄩㄝ：引人發笑的花招。如「噱頭」。
- 同樣常被寫錯的「笑」字詞：捧{k:腹}大笑（非「捧復」）、忍{k:俊}不禁（非「忍峻」）、{k:莞}爾一笑（ㄨㄢˇ，非「菀」）、{k:哄}堂大笑（非「轟堂」）。

@logic
1. 【審題】每個選項有兩個成語，且句末都有{k:情感線索}（欣羨、喜歡、景仰、真是……），先用線索判斷句子要「褒」還是「貶」。
2. 【A】「令人欣羨」需要褒義詞，「貌合神離」卻是感情不睦，與「鶼鰈情深」自相矛盾 → 刪。

4. 【D】「令人景仰」需要褒義，「好行小慧」是愛賣弄小聰明 → 刪。

@ana A x
{k:鶼鰈情深}：鶼，ㄐㄧㄢ，比翼鳥；鰈，ㄉㄧㄝˊ，比目魚。比喻夫妻感情深厚，用法正確。
{k:貌合神離}：表面上關係密切，實際上心思不一。與「鶼鰈情深」矛盾，更不可能「令人欣羨」。可改為「相敬如賓」「琴瑟和鳴」。

@logic
1. 【翻譯題幹】「得之於人者太多」＝從別人那裡得來的太多。「於」引出{k:來源}，可代換成「從、自」。
2. 【代換法】把「從」代入四個選項：(A) 法「從」民？不通；(B) 不憂愁「從」貧賤？不通；(C) 舜「從」田野中興起，通順；(D) 一生之計在「從」勤？不通。
3. 【確認其他用法】(A) 表被動「被」、(B) 表對象「對於」、(D) 與「在」結合表「決定於」。

@ana A x

@ana B x
語出陶淵明〈五柳先生傳〉：「不戚戚於貧賤，不汲汲於富貴。」意思是：{k:對於}貧賤不憂愁，對於富貴不急切追求。「於」引出動作涉及的對象。
@ana C o
語出《孟子‧告子下》：「舜發於畎畝之中，傅說舉於版築之間。」發，興起、被起用；畎畝，ㄑㄩㄢˇ ㄇㄨˇ，田間。意思是：舜是{k:從}田野耕作之中被起用的。「於」引出來源、起點，與題幹「得之於人」用法相同。
@ana D x
俗諺「一年之計在於春，一日之計在於晨，一生之計在於勤」。「在於」表示「取決於、關鍵在」，「於」與「在」連用，引出事情的關鍵所在，並非「從」。
@trap

| 用法 | 可代換為 | 例句 |
| 表處所、時間 | 在 | 戰「於」長勺（《左傳‧曹劌論戰》） |

## 一、這篇文章在說什麼？
本文節自徐復觀討論中國山水畫起源的論文。作者要回答的問題是：中國人與自然的關係，為什麼到了魏晉會發生轉變？他的答案是——魏晉以前，人與自然只是「比興」的關係；莊子思想則開啟了人「歸向自然」的另一種關係。
## 二、兩種「人與自然」關係的對照
| 比較 | 比興的關係 | 莊子式的關係 |
| 時代／代表 | 魏晉以前為主流；《詩經》、孔子 | 莊子開啟，影響魏晉以後 |

| 作用方向 | 只把自然人格化 | 自然人格化、人格自然化皆可 |
| 人生的安頓 | 不在自然中求安頓 | 可在自然中求得安頓 |
## 三、兩個關鍵術語
- {k:自然人格化}：把人的性情、感受投射到自然物上，讓山水花鳥「像人一樣」。主角仍然是人，自然只是用來比擬或引發人的感情。
- {k:人格自然化}：人把自己歸向自然、化入自然，讓自己的人格以自然的樣貌呈現，並在其中安頓生命。

1. 【釐清概念】依題組文本：比興關係中「只賦予自然以人格化」；莊子的物化精神則「亦可賦予人格以自然化」。兩者方向相反——前者是{k:自然→像人}，後者是{k:人格→化為自然}。
2. 【先刪「自然人格化」】(B) 青山「嫵媚」、還會「見我」，是把山當人看；(C) 花會濺淚、鳥會驚心，是「感時」「恨別」之情投射於物。兩者都以人的感情為主體，屬比興。
3. 【比較 A、D】(D) 清風明月化為耳目所得的聲與色，寫的是人{k:享用}自然，沒有涉及「人格」；(A) 柳宗元登西山，發現此山高峻特立、不與小土丘同類，正是他自己不與世俗同流的人格寫照——{k:人格以山的形象呈現}。
4. 【結論】最符合「人格自然化」的是 (A)。
@ana A o
出自柳宗元〈始得西山宴遊記〉。培塿，ㄆㄡˇ ㄌㄡˇ，小土丘。柳宗元被貶永州後主動尋訪山水，登上西山，才知道此山卓然特立，不和小土丘同列。西山的「特出」就是作者人格的化身；下文更寫「悠悠乎與顥氣俱」「心凝形釋，與萬化冥合」，自己與天地自然融為一體，並在其中得到安頓——合乎文本所說「主動追尋自然」「賦予人格以自然化」。
@ana B x
出自辛棄疾〈賀新郎‧甚矣吾衰矣〉。詞人覺得青山嫵媚可愛，又設想青山看我也是如此。青山能「見」、有「嫵媚」之態，是把人的情感與眼光賦予青山，屬{k:自然人格化}（擬人）。
@ana C x
出自杜甫〈春望〉。因為感傷時局、怨恨離別，所以見花而落淚、聞鳥鳴而心驚（或解為花也濺淚、鳥也驚心）。無論哪一種解讀，都是以人的家國之痛為主體，自然景物只是觸發或承載感情的媒介，屬比興的關係。
@ana D x
出自蘇軾〈赤壁賦〉。清風入耳成為聲音，明月入目成為景色，是造物者「取之無禁，用之不竭」的寶藏。此句寫人以感官領受自然之美，自然仍是自然、人仍是人，既未把自然人格化，也談不上把人格自然化。
@trap
本題是全卷最抽象的一題，(A)(D) 之間容易猶豫。有人認為 (D) 蘇軾在清風明月中得到寬慰，也算「在自然中安頓人生」；也有人認為 (A) 以山自比，其實近於「比」。官方答案為 (A)。較穩當的作法是{k:刪去法}：(B)(C) 明顯是自然人格化；(D) 的引句只描寫耳目感受，沒有「人格」可言；(A) 的「特出」「不與培塿為類」則同時指山也指人，最能對應「人格」與「自然」合一。作答時以{k:選項引文本身}為準，不要過度延伸到全篇。
@know 四則文例出處與語譯

@ana A x

@ana B x

@ana C o
作者以「魏晉」為分界：之前，文學中人與自然的關係就是比興；之後，比興仍在，但人開始主動追尋自然、把人格自然化。新的書寫方式出現並成為重點，以比興寫自然的情形自然相對減少。敘述與文意相符。
@ana D x

@trap
(C) 的「較少」在原文沒有直接對應的字句，原文甚至說比興「當然會繼續存在」，因此有人會覺得 (C) 也不夠精確。但四個選項中，(A)(B)(D) 都與原文明顯{k:相反}，(C) 則是可由「以前是唯一的關係、以後多了新的關係」推得的{k:相對說法}。學術性文本的題目，正解常是「溫和的推論」，而誘答常帶有「習慣」「最大」這類絕對化的字眼。
@know 轉折複句的閱讀法
- 原句：「人通過比興而與自然相接觸的情形，{k:雖然}魏晉時代及其以後，當然會繼續存在，{k:但}自然向人生所發生的比興的作用，是片斷地、偶然地關係。」

- 長句拆解三步驟：①找關聯詞（雖然、但、所以、而）②刪去插入語 ③留下主幹：「比興關係是片斷、偶然的」。

@ana A x

@ana B x
詞的格律其實比近體詩更繁複：每個詞牌都有固定的句數、每句字數與平仄，所謂「調有定句，句有定字，字有定聲」。李清照〈詞論〉甚至主張詞要分五音、五聲、清濁輕重。說它「沒有一定限制」「比近體詩自由」是錯的；詞只是{k:句式}長短不一，並非格律寬鬆。
@ana C o

@ana D x

@trap

## 二、甲文的論證路線
- 蜣螂至濁、蟬至清 → 蜣螂能「化」為蟬 → 可見濁者能求為清 → 類推到人：貪夫可化為廉。

## 三、對讀的重點：古人的觀察 vs. 現代的知識
- 甲文的事實基礎（蜣螂化蟬）已被乙文否定：那只是糞金龜的{k:蛹}。

| 類型 | 生活史 | 代表昆蟲 |

- {k:孵化}：卵變成幼蟲；{k:蛹化}（化蛹）：幼蟲變成蛹；{k:羽化}：蛹（或末齡若蟲）變為成蟲。
- 蟬屬於不完全變態，若蟲在土中吸食樹根汁液多年後才鑽出地面羽化；糞金龜是完全變態，兩者根本不同類，蜣螂當然不可能「化為蟬」。

## 一、文章結構
| 層次 | 原文 | 重點 |
| 釋疑 | 有疑陶淵明詩篇篇有酒……寄酒為跡者也 | 陶詩寫酒，其實是借酒寄託心志 |
| 評文 | 其文章不群……論懷抱則曠而且真 | 文章卓絕出眾，氣勢高昂，內容真切 |
| 評人 | 加以貞志不休……孰能如此乎 | 志節堅貞，安貧樂道，是大賢 |

## 二、閱讀重點
- 全文是{k:讚美}的語氣，由「文」寫到「人」，最後歸結到作者自己的感受。
- 「橫素波而傍流，干青雲而直上」是用{k:譬喻}形容文章的氣勢，不是寫陶淵明的經歷。陶淵明一生仕途不顯，最後辭官歸隱，絕非「飛黃騰達」。
- 「恨不同時」的「恨」是{k:遺憾}，不是怨恨；「同時」是「同一個時代」。
## 三、句式提醒
- 「莫之與京」是否定句中代詞賓語前置的{k:倒裝句}，還原為「莫與之京」：沒有人能與他並列。
- 「不以躬耕為恥，不以無財為病」：「以……為……」即「把……當作……」。
- 「自非……孰能……」：如果不是……誰能……？是{k:反問}句，用來加強肯定。
@know 蕭統與〈陶淵明集序〉
- 蕭統：南朝梁武帝長子，未即位而卒，諡「昭明」，世稱{k:昭明太子}。
- 主編《{k:文選}》（又稱《昭明文選》），是現存最早的詩文總集，選文標準為「事出於沉思，義歸乎翰藻」。
- 他是歷史上第一位為陶淵明編集、作序、寫傳的人。在陶淵明仍不受重視的南朝，蕭統的推崇可謂獨具慧眼。

@ana C x

## 二、乙文：蔣勳怎麼解讀「嘯」
- 嘯＝{k:孤獨者}在{k:巨大壓抑}下的{k:吶喊}，不是唱歌，更不是歡笑。

1. 【A】第二段：「竹林七賢一生{k:沒有}完成什麼偉大的事業，他們{k:沒有}達成儒家文化的要求」→ 選項相反。
2. 【B】第三段：「沒有人告訴我們為什麼阮籍會跑到山林裡大叫？」原因文中未說明；第一段還說孤獨者「相約到山林比賽」→「找不到對手」無據。
3. 【C】第一段末：「嘯」是極其孤獨的字，保留在《嘯傲江湖》中；訛傳為「笑傲」後，就看不到悲憤與傲氣了 → 反過來說，「嘯傲」才能表現孤獨與傲氣，正確。
4. 【D】「偉大的思想」指的是「為天地立心……」等儒家經典；父母師長「都不覺得阮籍在歷史裡是重要的人物」，並沒有教小孩讀《世說新語》→ 錯。
@ana A x
「為天地立心，為生民立命，為往聖繼絕學，為萬世開太平」是儒家文化對讀書人的要求，作者明說竹林七賢「沒有達成」。選項把否定說成肯定。
@ana B x
作者只提出疑問「為什麼阮籍會跑到山林裡大叫」，感嘆沒有人解釋，並未給出「找不到對手」的答案。依作者的理解，嘯是出於孤獨與壓抑，與對手無關。
@ana C o
原文：「『嘯』其實是一個極其孤獨的字，後來保留在武俠小說《嘯傲江湖》中，但後人都以諧音字訛傳為『笑傲江湖』，不復見從心底嘶叫吶喊出的悲憤與傲氣。」作者認為「嘯」字才帶有孤獨、悲憤與傲氣，換成「笑」就失去了這層意義。選項是此句的正面改寫。
@ana D x
錯誤有二：①父母師長重視的是儒家經典（作者五歲就開始背誦），而「不覺得阮籍在歷史裡是重要的人物」，沒有教導閱讀《世說新語》的敘述；②「這些經典是偉大的思想」指儒家經典，不是《世說新語》。選項把兩件事接錯了。
@trap
(C) 需要一步「{k:反向推論}」：原文說「改成笑傲 → 看不到悲憤與傲氣」，選項說「嘯傲 → 才能表現孤獨和傲氣」。兩者是同一件事的正反兩面，屬於合理推論。相對地，(B) 的「找不到對手」可能來自對武俠小說或第 7 題成吉思汗「寂寞」的聯想，在本文中毫無依據——{k:不要把別篇文章的印象帶進來}。
@know 成語：笑傲江湖／嘯傲山林
- {k:嘯傲}：曠達任性，不受拘束。常見搭配有「嘯傲山林」「嘯傲林泉」，多用來形容隱士。
- {k:笑傲}：傲然優游自得。金庸小說名為《笑傲江湖》。
- 兩詞古書中皆有用例；乙文是作者從「孤獨」的角度提出的個人見解。閱讀題作答時{k:以文本為準}，但自己寫作時可兩者並存、依語境選用。
@know 橫渠四句
> 為天地立心，為生民立命，為往聖繼絕學，為萬世開太平。
- 作者：北宋{k:張載}，字子厚，世稱橫渠先生，與周敦頤、程顥、程頤、邵雍合稱「北宋五子」。
- 意思：為天地確立精神價值，為百姓安頓生命，為古代聖人接續將要中斷的學問，為千秋萬世開創太平。
- 在乙文中，這四句代表「儒家對人的宏大要求」，用來對照竹林七賢的「一事無成」，以及青春期孩子真實的內心需求。
@know 細節題的「原文對照」習慣
- 選項中的{k:動詞}和{k:肯定／否定}最容易被動手腳：完成 ↔ 沒有完成、重視 ↔ 不覺得重要。
- 作法：在選項關鍵動詞下畫線，回原文找到同一件事，看是肯定還是否定。本題 (A)(D) 都能用這個方法在十秒內刪去。

=== Q 35
@type 古今文本的比較統整
@cat 白話閱讀
@tags 文本比較, 統整判斷, 古今對讀
@diff 4
@answer C
@stem
{y:比較甲、乙二文|「皆」要兩文都成立}，下列說明正確的是：
@note red
比較題：
把選項拆成「甲如何」
「乙如何」分別檢查
@opt A
二文皆提及阮籍擅嘯，{x:嘯時山鳴谷應}
@note blue
甲文林谷傳響的
是「真人」的嘯
@opt B
二文{x:皆}以人物事蹟來{x:探討「嘯」字的深刻意涵}
@note blue
甲文只記事，不探討
@opt C
乙文作者認為甲文阮籍的嘯音傳遞出{g:對孤獨的領略}
@note red
乙：嘯＝孤獨者的吶喊
並引《世說新語》阮籍 ✓
@opt D
乙文作者認為甲文的{x:阮步兵和阮籍}都是「{x:笑傲江湖}」的代表人物。
@note blue
同一人；且作者認為
「笑傲」是訛傳
@cols 1
@key
乙文作者以《世說新語》中阮籍的長嘯為例，說明「嘯」是孤獨者從壓抑中發出的吶喊，亦即阮籍的嘯傳達了孤獨，(C) 正確。
@logic
1. 【A】乙文說「當阮籍長嘯時，山鳴谷應」；但甲文對阮籍只說「聞數百步」，「林谷傳響」的是真人的嘯 → 並非「二文皆」。
2. 【B】甲文是客觀記事，全篇沒有一句解釋「嘯」的意義；探討意涵的只有乙文 → 並非「二文皆」。
3. 【D】阮步兵就是阮籍；而且乙文作者認為「笑傲江湖」是訛傳，失去了嘯的悲憤與傲氣，不會以此稱許阮籍 → 錯。
4. 【C】乙文把阮籍等竹林七賢的嘯解讀為「孤獨的人」的吶喊，並引《世說新語》為證 → 作者認為阮籍的嘯傳達了對孤獨的體會，正確。
@ana A x
甲文：阮籍的嘯「聞數百步」；真人的嘯「如數部鼓吹，林谷傳響」。乙文：「當阮籍長嘯時，山鳴谷應，震驚了所有的人」。可見「山鳴谷應」在甲文中屬於真人，只有乙文把它歸給阮籍。「二文皆提及阮籍擅嘯」可以成立，但後半句不成立。
@ana B x
甲文只敘述阮籍訪真人、兩人以嘯相應的經過，沒有任何議論；「嘯」的深刻意涵是乙文作者的闡釋。且乙文主要是從字形、情感來說解，並舉竹林七賢為例，與甲文的寫法不同。
@ana C o
乙文稱竹林七賢為「這些孤獨者」，說嘯是「一個孤獨的人……張開口大叫出來的模樣」「極其孤獨的字」，並以《世說新語》所記阮籍長嘯為例。因此在作者看來，阮籍的嘯聲正是孤獨心境的表達。說明正確。
@ana D x
錯誤有二：①「阮步兵」「阮籍」是同一人的兩種稱呼，不能並列為兩人；②乙文認為「嘯傲江湖」被訛傳為「笑傲江湖」後，「不復見……悲憤與傲氣」，作者對「笑傲」一詞是否定的，不會拿來稱讚阮籍。
@trap
(A) 是整個題組最精巧的陷阱：只讀乙文會覺得它完全正確，因為乙文確實說阮籍長嘯時山鳴谷應。必須回到甲文原典核對，才會發現「林谷傳響」寫的是真人。{k:比較題不能用一篇文章的說法去代替另一篇}；乙文是作者的轉述與詮釋，未必與原典字字相符。
@know 原典與詮釋的落差
| 項目 | 甲文（原典） | 乙文（詮釋） |
| 阮籍的嘯 | 聞數百步 | 山鳴谷應，震驚了所有的人 |
| 嘯的場合 | 阮籍獨訪真人，兩人先後而嘯 | 孤獨者相約到山林比賽 |
| 嘯的情感 | 未說明（真人聞嘯而「笑」） | 悲憤、壓抑、孤獨 |
- 現代散文引用古書時，常依作者的理解加以發揮。閱讀時可以欣賞其見解，同時保持{k:查證原典}的習慣——這也是本題組把兩文並列的用意。

@know 魏晉名士為何「痛苦不堪」？
- 司馬氏以「名教」（儒家禮法）為名，行奪權之實，並藉以誅除異己；嵇康即因不肯合作而被殺，臨刑前彈奏〈廣陵散〉。
- 阮籍為求自保，「口不臧否人物」（從不評論他人好壞），只能以醉酒、長嘯、窮途痛哭來宣洩。
- 因此他們對禮教的反抗，並非單純的放蕩，而是{k:不願同流合汙又無力改變}的苦悶——這是理解乙文「孤獨」二字的歷史背景。
