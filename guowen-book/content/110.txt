@key
殲ㄐㄧㄢ／讖ㄔㄣˋ、絢ㄒㄩㄢˋ／徇ㄒㄩㄣˋ、憚ㄉㄢˋ／殫ㄉㄢ 都不同音；只有「渝」「逾」同讀ㄩˊ。
@logic
1. 【審題】比的是「讀音」，聲母、韻母、聲調三者全同才算相同。四組都是{k:同聲符的形近字}，命題陷阱就是「有邊讀邊」。
2. 【逐字標音】(A) 殲ㄐㄧㄢ／讖ㄔㄣˋ；(B) 絢ㄒㄩㄢˋ／徇ㄒㄩㄣˋ；(C) 渝ㄩˊ／逾ㄩˊ；(D) 憚ㄉㄢˋ／殫ㄉㄢ。
3. 【抓最細微的差異】(B) 只差韻母（ㄩㄢ／ㄩㄣ），(D) 只差聲調（四聲／一聲），是最容易看走眼的兩組；(A) 則聲、韻、調全不同。
4. 【結論】只有 (C) 完全同音，選 (C)。
@ana A x
「{k:殲}」敵無數：殲，ㄐㄧㄢ，殺盡、消滅，如「殲滅」。
一語成「{k:讖}」：讖，ㄔㄣˋ，預言。指原本無心的一句話，竟然像預言一樣應驗了，多用於不好的事被說中。
→ ㄐㄧㄢ ≠ ㄔㄣˋ。
@ana B x
「{k:絢}」麗無比：絢，ㄒㄩㄢˋ，色彩華麗，如「絢爛」「絢麗」。
「{k:徇}」私枉法：徇，ㄒㄩㄣˋ，曲從、順從。指為了私情而歪曲法律。
→ 韻母一為ㄩㄢ、一為ㄩㄣ，讀音不同。
@ana C o
始終不「{k:渝}」：渝，ㄩˊ，改變。自始至終都不改變，形容意志堅定。
年「{k:逾}」古稀：逾，ㄩˊ，超過。古稀指七十歲，語本杜甫〈曲江〉「人生七十古來稀」；年逾古稀即年紀超過七十歲。
→ 同讀ㄩˊ，為正解。
@ana D x
肆無忌「{k:憚}」：憚，ㄉㄢˋ，害怕、畏懼。指任意妄為，毫無顧忌。
「{k:殫}」精竭慮：殫，ㄉㄢ，竭盡。指用盡精力與心思，也作「殫心竭慮」。
→ 一為四聲、一為一聲，讀音不同。
@trap
「徇」字教科書多依教育部審訂音讀ㄒㄩㄣˋ；《重編國語辭典》則把「徇私」一詞標作ㄒㄩㄣˊ ㄙ。但不論取哪一讀，韻母都是ㄩㄣ，與「絢」的ㄩㄢ不同，不影響本題判斷。另外「殫」不可受「憚、彈」影響而讀成四聲。

=== Q 2
@type 錯別字訂正
@cat 形音義
@tags 錯別字, 同音字, 成語用字
@diff 2
@answer C
@stem
下列文句，{y:__完全沒有__錯別字|找全對的一句}的是：
@note red
錯字多藏在{c:四字格}
用「字義」檢查
@opt A
每到年節，外地民眾迫不{x:急}{n:及}待地趕回家團聚，往往造成高速公路壅塞
@note blue
及＝來得及；急到「來不及」等
@opt B
只要按部就班，循序漸進學習知識，終有金榜{x:提}{n:題}名、夢想成真的一天
@note blue
題＝寫上（題字）
名字「寫」在榜上
@opt C
身為體育迷，有幸獲贈奧運賽入場券，得以{g:躬逢其盛}，真是人生樂事
@note red
躬＝親自 ✓ 全句無誤
@opt D
儘管快要按{x:耐}{n:捺}不住胸中的怒氣，作為母親的她也只能無奈地接受現實
@note blue
捺ㄋㄚˋ＝用手按住
@key
(A) 迫不「及」待、(B) 金榜「題」名、(D) 按「捺」不住 各錯一字；(C)「躬逢其盛」「入場券」用字全對。
@logic
1. 【定位】錯別字題的錯字九成藏在{k:成語或固定詞語}裡，先圈出每句的四字格：迫不急待、按部就班、循序漸進、金榜提名、躬逢其盛、按耐不住。
2. 【以義辨形】用詞義檢查用字：急迫得「來不及」等待 → 及；名字被「寫」上金榜 → 題；用手「按住」怒氣 → 捺。
3. 【別被干擾字騙】「壅塞」「按部就班」「儘管」「入場券」都是常被寫錯的詞，但題目中寫的是正確的，不要多疑。
4. 【結論】(C) 全句無誤，選 (C)。
@ana A x
迫不「急」待 → 迫不「{k:及}」待。及，趕上、來得及；成語指情況急迫，不能再等待。因為意思與「急」有關，最容易寫成「急」。同類的「措手不及」「望塵莫及」也都用「及」。句中「壅塞」（ㄩㄥ ㄙㄜˋ，淤滯不通）用字正確。
@ana B x
金榜「提」名 → 金榜「{k:題}」名。金榜是科舉時代殿試揭曉的榜單；題，書寫。名字被寫在金榜上，指考試被錄取。「提名」則是選舉時推舉候選人，意思完全不同。句中「按部就班」「循序漸進」皆正確。
@ana C o
全句無錯別字。「{k:躬逢其盛}」：躬，親自；指親身參與盛會或遇上盛況。王勃〈滕王閣序〉有「童子何知，躬逢勝餞」之語。「入場券」的「券」（ㄑㄩㄢˋ）下面是「刀」，不可寫成「卷」。
@ana D x
按「耐」不住 → 按「{k:捺}」不住。捺，ㄋㄚˋ，用手重按，引申為抑制。「按捺」是抑止、忍耐的意思，因為詞義接近「忍耐」而常被誤寫為「耐」。句中「儘管」（即使、雖然）用字正確。
@know 本題三組同音字辨析
| 正確用字 | 字義 | 例詞 | 常見錯誤 |
| 及 | 趕上、到達 | 迫不及待、措手不及、過猶不及 | 迫不「急」待 |
| 急 | 焦躁、迅速 | 急不可待、當務之急、操之過急 | — |
| 題 | 書寫、簽署 | 金榜題名、題字、題詩 | 金榜「提」名 |
| 提 | 拿起、舉出 | 提名、提議、提綱挈領 | — |
| 捺 | 用手按；抑制 | 按捺不住、一撇一捺 | 按「耐」不住 |
| 耐 | 忍受 | 忍耐、耐人尋味、俗不可耐 | — |
- 「迫不及待」與「急不可待」意思相近，一用「及」、一用「急」，要連同整個詞一起記。
@know 句中沒錯、卻常被寫錯的詞
- {k:按部就班}：語本陸機〈文賦〉「選義按部，考辭就班」，部、班指門類與次序；不可寫成「按步就班」。
- {k:入場券}：券是票據、憑證（獎券、禮券、穩操勝券）；「卷」是書本、考卷。
- {k:壅塞}：壅，堵塞；也可寫作「擁塞」（ㄩㄥˇ ㄙㄜˋ），但不可寫成「雍塞」「臃塞」。
- {k:儘管}：儘，任憑、即使；「盡」則是完畢、全部（盡力、盡頭）。
- {k:躬逢其盛}：躬是「親自」，如「事必躬親」「躬耕」；不可寫成「恭逢其盛」。
@know 錯別字題的檢查口訣
- 一圈：圈出成語與固定詞語。
- 二拆：把詞拆開問「這個字在這裡是什麼意思」。
- 三換：想一個同義詞代換，看用字合不合理（按捺＝按住，不是「按耐」＝按忍耐）。

=== Q 3
@type 疊字詞的一詞多義
@cat 形音義
@tags 詞義, 疊字, 文言詞語
@diff 3
@answer A
@stem
下列各組「 」內的詞語，{y:意義前後相同|同一個解釋代入兩句}的是：
@note red
疊字常「一詞多義」
看它在{c:形容什麼}
@opt A
「亭亭」{n:高聳直立}淨植，不蔓不枝／青青陵上松，「亭亭」{n:高聳直立}高山柏
@note red
蓮莖、柏樹都「挺立」✓
@opt B
念天地之「悠悠」{nb:遼遠長久}，獨愴然而涕下／蘭橈畫舸「悠悠」{nb:悠閒緩慢}去，疑是神仙
@note blue
形容天地 vs. 形容船行
@opt C
不「戚戚」{nb:憂愁}於貧賤，不汲汲於富貴／夫子言之，於我心有「戚戚」{nb:心有所動}焉
@note blue
憂貧 vs. 被說中而感動
@opt D
吾年未四十，而視「茫茫」{nb:模糊不清}，而髮蒼蒼／風吹花片片，春動水「茫茫」{nb:浩大無邊}
@note blue
形容視力 vs. 形容水勢
@cols 1
@key
蓮的「亭亭淨植」與柏的「亭亭高山柏」都是「高聳直立」；悠悠、戚戚、茫茫在兩句中所形容的對象不同，意義也不同。
@translation
(A) 蓮莖筆直潔淨地挺立著，不蔓生也不旁生枝節。／山陵上的松樹青翠茂盛，高山上的柏樹高聳挺立。
(B) 想到天地的遼闊久遠，獨自悲傷得流下眼淚。／華美的遊船悠閒地緩緩划去，讓人懷疑船上的是神仙。
(C) 不因為貧賤而憂愁，不急切地追求富貴。／先生說的這番話，使我心中有所觸動。
(D) 我年紀還不到四十歲，視力卻已模糊，頭髮也已花白。／風吹得花瓣片片飄落，春水湧動，一片浩大無邊。
@logic
1. 【審題】比的是「詞義」。疊字詞常常一詞多義，判斷的關鍵是看它在句中{k:形容的對象}。
2. 【找對象】亭亭 → 蓮莖／柏樹；悠悠 → 天地／船行；戚戚 → 對貧賤的心情／聽了話之後的心情；茫茫 → 視力／春水。
3. 【代換檢驗】用同一個解釋代入前後兩句：(A)「高聳直立」兩句都通；(B)「遼遠」不能形容船去；(C)「憂愁」代入「於我心有憂愁焉」不合文意；(D)「模糊」不能形容水勢。
4. 【結論】選 (A)。
@ana A o
前句出自周敦頤〈愛蓮說〉：「中通外直，不蔓不枝，香遠益清，亭亭淨植。」亭亭，挺直聳立的樣子，形容蓮莖。
後句出自晉代何劭〈遊仙詩〉：「青青陵上松，亭亭高山柏。」亭亭，高聳直立的樣子，形容柏樹。教育部《重編國語辭典》「亭亭」條「高聳直立」義即以此句為例。
→ 兩者皆為「高聳直立」，正解。
@ana B x
前句出自陳子昂〈登幽州臺歌〉：悠悠，遼闊久遠、無窮無盡，形容天地時空。
後句出自歐陽脩〈采桑子〉（春深雨過西湖好）：悠悠，安閒自在、從容緩慢，形容畫船緩緩划去。蘭橈（ㄖㄠˊ）、畫舸（ㄍㄜˇ）都是對船的美稱。
→ 遼遠長久 ≠ 悠閒緩慢。
@ana C x
前句見陶淵明〈五柳先生傳〉贊語所引黔婁之妻的話：戚戚，憂愁、憂懼的樣子；汲汲，急切追求的樣子。

@know 「汲汲」與「戚戚」
- {k:汲汲}（ㄐㄧˊ ㄐㄧˊ）：急切追求的樣子，如「汲汲營營」；注意與「岌岌可危」的「岌岌」（危險貌）區別。
- {k:戚戚}：除了疊用，「戚」單用可指憂愁（休戚與共）或親屬（親戚、外戚）。
- 「不戚戚於貧賤，不汲汲於富貴」是互文式的對偶句：對貧賤不憂、對富貴不求，合起來即「安貧樂道」。

@opt A

@opt B

@key

@logic
1. 【找固定搭配】戊「當…的情況下」是條件，要接結果句乙「就會使人…」；甲以「…者」結尾，是一個主語，後面要接謂語丙「反而愈容易想離開」，且「越…愈…」前後呼應。
2. 【定位轉折詞】丁「另外，和原本預期不同」：「另外」表示這是第二項發現，不可能放在最前面；「和預期不同」要緊接一個出人意料的結果——正是甲丙（知識高的人反而想離開）。
3. 【看尾句】引文最後「推測可能是認為自身感染可能性低、有能力自我保護」，是在解釋「為什麼知識高的人反而想離開」，所以甲丙必須放在最後。
4. 【組合】戊乙／丁／甲丙 → (B)。
@ana A x

@ana B o
戊乙：「當負面情緒湧現、缺乏社會責任意識的情況下，就會使人傾向於不服從」——第一項發現（條件 → 結果）。丁甲丙：「另外，和原本預期不同，防疫公衛知識程度越高……者，反而愈容易想離開」——第二項發現（出乎意料）。末句再推測原因，文意完整。
@ana C x

@ana D x

@know 排序題常用的關聯詞配對
| 關係 | 常見配對 | 本題例子 |
| 條件 | 只要…就…／當…（的情況下），就會… | 戊 → 乙 |
| 倚變 | 越…越…／愈…愈… | 甲「越高」→ 丙「愈容易」 |
| 轉折 | 雖然…但是…／…，反而… | 甲 → 丙「反而」 |

- 「另外」「此外」「同時」開頭的句子{k:絕不會是第一句}；「…者」「…的人」結尾的句子後面一定要接謂語。
@know 排序題四步驟
- 一、看頭尾：題目若已給首句、尾句，先想它們「需要接什麼」。
- 二、找配對：把有關聯詞、指示代詞（這、此、其）的句子兩兩綁定。
- 三、排區塊：把綁好的小組依「總說 → 分說」「現象 → 原因」排序。
- 四、順讀檢驗：把答案完整默唸一遍，檢查主語是否一貫、語氣是否通順。
@know 讀懂這則研究：知識高 ≠ 配合度高
- 一般預期「公衛知識越充足，越願意配合隔離」，研究結果卻相反；報導推測原因是這些人{k:自認感染機率低、有能力保護自己}。

「耳環」正確；但「瑪瑙」無法承接後文的「一串」「滴落」——詩句寫的是思念時落下的淚；「晨曦」是清晨的陽光，給人明朗、希望之感，無法形容「嗔人」（生氣）的神情。
@ana B o
耳環：在髮叢邊叮叮作響，像霧中行船時敲響的鐘聲，在濃霧（濃髮）裡尋找航路。
珍珠：子午線劃分時間，兩人被時間、空間分隔，思念時淚珠成串滴落，如一串暗藍的珍珠。
晚雲：與「迎人的編貝」（笑時露出的潔白牙齒）相對，寫戀人嗔怒時的臉色。
三處皆合，為正解。
@ana C x
「風鈴」不是人身上的飾物，無法「在濃密的髮叢找航路」；「瑪瑙」亦與「滴落」不合。只有「晚雲」正確。
@ana D x
「珍珠」正確；但「風鈴」「晨曦」兩處皆不合詩意。
@trap
第三格最容易猶豫：晨曦、晚雲都是天象。判斷關鍵是修飾語「嗔人的」——嗔（ㄔㄣ）是生氣、責怪；上一個意象「迎人的編貝」寫笑，這裡寫怒，一迎一嗔形成對比。晨曦的明亮只適合寫笑容，不適合寫怒容。其實只要前兩格確定是「耳環」「珍珠」，答案就已經鎖定 (B)。

@know 作家常識：鄭愁予

=== Q 7
@type 移覺（通感）修辭判斷
@cat 語文應用
@tags 修辭, 移覺, 感官摹寫, 否定題
@diff 3
@answer A
@stem
行文時，將視覺、聽覺、嗅覺、味覺、觸覺等感官知覺互相轉化，把{y:某個感官上的感受移到另一個感官|定義：A 感官 → B 感官}的修辭法，稱之為「移覺」。例如：「微風過處，送來縷縷{b:清香}，彷彿遠處高樓上緲茫的{b:歌聲}似的。」(朱自清〈荷塘月色〉)即是將嗅覺轉化為聽覺。下列文句{y:__沒有__|否定題！}使用「移覺」修辭法的是：
@note red
每句問兩件事：
原本是哪種感官？
後來變成哪種感官？
@note blue
例句：清香（嗅）→ 歌聲（聽）
@opt A
{g:黑壓壓}的，滿天{g:烏雲}，盤旋著，自上而下，直要捲到地面
@note red
從頭到尾都是{c:視覺}
沒有轉換 → 答案
@opt B
三粒{b:苦松子}／沿著路標一直滾到我的腳前／伸手抓起／竟是一把{b:鳥聲}
@note blue
看得見、抓得到的松子
→ 聽覺的鳥聲
@opt C
{b:馬蹄聲}，孤獨又憂鬱的自遠至近，灑落在沉默的街上成{b:白色的小花朵}
@note blue
聽覺 → 視覺
@opt D
{b:聲音}初不甚大，只覺入耳有說不出來的妙境，五臟六腑裡像{b:熨斗熨過}，無一處不伏貼
@note blue
聽覺 → 觸覺
@key
(A) 寫烏雲的顏色與動態，自始至終都是視覺，沒有感官的轉移；(B)(C)(D) 分別把松子變成鳥聲、把馬蹄聲變成花朵、把歌聲變成熨斗熨過的觸感。
@logic
1. 【讀懂定義】移覺必須有「兩種感官」：原本屬於甲感官的感受，被寫成乙感官的感受。只有一種感官的摹寫不算。
2. 【否定題】題幹問「沒有使用」，要找只有單一感官的句子。
3. 【逐句標感官】(A) 黑壓壓、烏雲、盤旋、捲到地面 → 全是視覺；(B) 松子（視、觸）→ 鳥聲（聽）；(C) 馬蹄聲（聽）→ 白色小花朵（視）；(D) 聲音（聽）→ 熨斗熨過（觸）。
4. 【結論】只有 (A) 沒有感官轉換，選 (A)。
@ana A x
「黑壓壓」寫顏色與濃密，「盤旋」「自上而下」「捲到地面」寫烏雲翻湧的動態，都是眼睛所見。句中把烏雲寫得像會盤旋、席捲的活物，可說有轉化與誇飾的效果，但{k:感官始終是視覺}，沒有移覺。本項為答案。
@ana B o
出自洛夫〈隨雨聲入山而不見雨〉。滾到腳前的松子是看得見、抓得起的實物，伸手一抓卻成了「一把鳥聲」——把{k:視覺、觸覺的對象轉成聽覺}，並用量詞「一把」讓聲音變得可以握在手中，是移覺的名句。
@ana C o
出自何其芳〈黃昏〉。馬蹄聲本屬聽覺，卻說它「灑落在街上成白色的小花朵」，把一聲聲清脆的蹄聲寫成{k:看得見的花朵}，是聽覺轉為視覺；「孤獨又憂鬱」另有擬人的效果。
@ana D o
出自劉鶚《老殘遊記》第二回〈明湖居聽書〉，寫王小玉說書的歌聲。把聽覺的享受寫成「五臟六腑裡像熨斗熨過」的{k:觸覺感受}，是聽覺轉為觸覺；句中有喻詞「像」，同時是譬喻。
@trap
移覺常和譬喻、轉化一起出現，不要因為 (A) 的烏雲寫得很生動、(D) 有「像」字，就用「有沒有比喻」來判斷。唯一的判準是：{k:有沒有從一種感官跨到另一種感官}。另外，(A) 是四個選項裡最「樸素」的一句，否定題的答案往往就是這種看起來沒什麼技巧的句子。

@know 摹寫、移覺、譬喻怎麼分
| 修辭 | 定義 | 判斷重點 | 例句 |

@know 課文連結：〈明湖居聽書〉的聽覺描寫

「儉、節用」是墨家；「博、重君臣父子夫婦長幼之禮」是儒家；「嚴而少恩、正上下之分」是法家。
@translation
甲：墨家過於儉嗇而難以遵行，因此他們的主張不能全部照辦；但是他們強調加強根本（農業生產）、節約用度，是不可廢棄的。
乙：儒家學說廣博卻少能抓住要領，花費力氣多而功效少，因此他們的主張難以全部遵從；但是他們排定君臣、父子之間的禮節，分別夫婦、長幼之間的次序，是不可改變的。
丙：法家嚴苛而缺少恩情；但是他們端正君臣上下的名分，是不可更改的。
@logic
1. 【看句型】三句都是「缺點；然＋優點」。學派的{k:核心主張}通常寫在「然」字後面的優點裡。
2. 【甲】缺點「儉而難遵」、優點「彊本節用」：主張節用、節葬、非樂，刻苦到一般人做不到的是{k:墨家} → 刪 (C)(D)。
3. 【乙】優點「序君臣、父子之禮，列夫婦、長幼之別」：講禮、講人倫的是{k:儒家}；缺點「博而寡要」指儒家經傳繁多 → 刪 (A)。
4. 【丙驗證】「嚴而少恩」「正君臣、上下之分」：以嚴刑峻法治國、強調尊君的是{k:法家}。選 (B)。
@ana A x
甲填「墨者」正確。但乙句講「禮」與人倫次序，不是法家；丙句「嚴而少恩」才是法家。名家的特色是辨析「名」與「實」，原文對名家的評語是「使人儉而善失真；然其正名實，不可不察也」。
@ana B o
墨家：節用、節葬，生活刻苦，故「儉而難遵」；儒家：六藝經傳繁多，故「博而寡要，勞而少功」，但重視禮制人倫；法家：一切斷之以法，故「嚴而少恩」，但能端正尊卑名分。三處皆合。
@ana C x
乙、丙正確，但甲不可填道家：道家主張清靜無為，並非以「儉」「節用」為號召；且司馬談最推崇道家，在〈論六家要旨〉中只稱讚道家「指約而易操，事少而功多」，並未像對其他五家那樣先指出缺點。
@ana D x
三處全錯：甲非道家，乙非法家，丙非名家。
@trap
原文的寫法是「儒者」「墨者」「法家」「名家」「道家」，稱呼並不一致，所以選項中「儒者／儒家」的差異不是判斷重點，重點在甲句是墨或道。另外，「儉」字容易讓人聯想到老子的「三寶」（一曰慈，二曰儉，三曰不敢為天下先）而誤選道家——要連同「彊本節用」「難遵」一起看，才知道指的是墨家的刻苦作風。
@know 司馬談〈論六家要旨〉對六家的評價

@know 文言詞語：本題的關鍵實詞
- {k:彊本節用}：彊同「強」；本，根本，古代指農業。語本《荀子‧天論》「彊本而節用，則天不能貧」。
- {k:寡要}：寡，少；要，要領。
- {k:遍循}：全部遵循。「不可遍循」「難盡從」都是「無法全部照做」的意思。
- {k:易}：改變。「不可易」「不可改」「不可廢」三句同義換字，避免重複。

@stem
清代文學家鄭板橋曾經為自己寫過一副對聯：
@box
「常如作客，何問康寧。但使囊有餘錢，甕有餘釀，釜有餘糧。取數頁賞心舊紙，放浪吟哦。興要闊，皮要頑，五官靈動勝千官，{y:過到六旬猶少}；
定欲成仙，空生煩惱。只令耳無俗聲，眼無俗物，胸無俗事。將幾枝隨意新花，縱橫穿插。睡得遲，起得早，一日清閒似兩日，{y:算來百歲已多}。」

@key
由「過到六旬猶少」「算來百歲已多」可知這是六十歲的自壽聯，應送祝壽題辭「松柏常（長）春」。
@translation
上聯：常把自己當成人世間的過客，何必去問身體是否安康。只要口袋裡有多餘的錢，酒甕裡有喝不完的酒，鍋裡有吃不完的糧食；拿幾頁自己喜愛的舊書稿，無拘無束地吟詠。興致要開闊，皮骨要頑健耐磨，五官靈活自在，勝過當什麼大官，活到六十歲還算年輕。
下聯：一心想要成仙，只是平白生出煩惱。只要耳朵不聽庸俗的聲音，眼睛不看庸俗的事物，胸中不放庸俗的事；拿幾枝隨手摘來的鮮花，縱橫交錯地插著。睡得晚，起得早，清閒的一天抵得上兩天，這樣算來，我已經活了一百多歲了。
@logic
1. 【找出場合】題辭題的關鍵是「場合」。聯中「過到六旬猶少」點出年齡六十，「算來百歲已多」是對壽命的幽默計算 → 這是一副{k:六十歲生日時寫給自己的壽聯}。
2. 【對應題辭】祝壽 → 找祝壽用語。
3. 【逐項判斷】松柏常春（祝壽）、五世其昌（賀結婚）、眾望所歸（賀當選）、道範長存（輓喪）。
4. 【結論】選 (A)。
@ana A o
{k:松柏常春}（通行寫作「松柏長春」）：松柏四季常青，比喻人長壽不老，是男女通用的祝壽題辭。與自壽聯的場合相符。
@ana B x
{k:五世其昌}：語出《左傳‧莊公二十二年》「五世其昌，並於正卿」，原指陳敬仲的後代到第五代將會昌盛；後用為{k:賀人新婚}的題辭，祝福子孫昌盛。
@ana C x
{k:眾望所歸}：深得眾人擁護、愛戴，用於{k:賀人當選}（民意代表、首長等）。
@ana D x
{k:道範長存}：道德風範永遠留存人間，是{k:哀輓男性長者}的輓辭。把輓辭送給過生日的人，是最嚴重的誤用。
@trap
聯中有「定欲成仙」「百歲」等字眼，粗心的考生可能誤以為與喪事有關而選 (D)。其實下聯是說「一心想成仙只會自尋煩惱」，強調的是活在當下的清閒。題辭題最忌{k:喜喪不分}：凡有「長存」「千古」「安仰」「其萎」等字眼的，一律是輓辭。

@know 對聯的基本規則
- 字數相等、詞性相對、平仄相反、內容相關。
- {k:上聯末字為仄聲、下聯末字為平聲}（仄起平收）：本聯上聯末字「少」（ㄕㄠˋ，年輕，仄聲）、下聯末字「多」（平聲），可據此判斷哪一聯是上聯。
- 張貼時，以面對大門為準，上聯在右、下聯在左。
- 本聯在長句中還有工整的句中對：囊有餘錢／甕有餘釀／釜有餘糧 對 耳無俗聲／眼無俗物／胸無俗事；「有餘」對「無俗」。
@know 作家常識：鄭板橋
- 鄭燮（ㄒㄧㄝˋ），字克柔，號板橋，江蘇興化人，清代書畫家、文學家，為「{k:揚州八怪}」之一。
- 自稱「康熙秀才、雍正舉人、乾隆進士」，曾任山東范縣、濰縣知縣，後辭官回揚州賣畫為生。
- 詩、書、畫皆有名，擅畫蘭、竹、石；書法自創「六分半書」；「難得糊塗」是他流傳最廣的題字。
- 國中常見選文〈寄弟墨書〉即出自《鄭板橋集》的家書。本聯為他的{k:六十自壽聯}，見清代梁章鉅《楹聯叢話》。
