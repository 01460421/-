@type 同音字形辨識
@cat 形音義
@tags 字形, 成語用字, 形近音同
@diff 2
@answer C
@stem
下列「」內的字，{y:字形前後相同|看清：考「字形」}的是：
@note red
作法：把每個注音{c:還原成國字}再比對
@opt A
一丘之「ㄏㄜˊ」{n:貉}／被「ㄏㄜˊ」{n:褐}懷玉
@note blue
貉＝獸名；褐＝粗布衣
@opt B
「ㄅㄧˋ」{n:髀}肉復生／失之交「ㄅㄧˋ」{n:臂}
@note blue
髀＝大腿；臂＝胳膊
@opt C
「ㄅㄧㄥˇ」{n:秉}筆直書／「ㄅㄧㄥˇ」{n:秉}性善良
@note red
兩個都是「秉」✓
秉＝執持 → 引申為「秉受」
@opt D
奉為圭「ㄋㄧㄝˋ」{n:臬}／「ㄋㄧㄝˋ」{n:涅}槃重生
@note blue
臬＝箭靶；涅槃＝梵語音譯
@key
把注音逐一「還原成國字」：貉／褐、髀／臂、秉／秉、臬／涅，只有 (C) 前後同為「秉」。
@logic
1. 【審題】題目問的是「字形」前後相同，不是字音（字音本來就相同），所以每個選項都要寫出國字。
2. 【還原】利用成語的{k:典故與字義}推回國字：「一丘之貉」是同一山丘上的貉（獸名，犬部旁邊是「豸」）；「被褐懷玉」是穿著粗布衣（褐，衣部）而懷藏美玉。
3. 【比對】(A) 貉／褐、(B) 髀／臂、(D) 臬／涅 皆為同音異字；(C)「秉筆直書」「秉性善良」同為「秉」。
4. 【檢核】「秉性」亦可寫作「稟性」，但其餘三項確定不同，故 (C) 為唯一可能的答案。
@ana A x
一丘之「{k:貉}」：貉，音ㄏㄜˊ，外形似狐的野獸。成語比喻彼此同類、沒有差別（多用於貶義），語出《漢書‧楊惲傳》「古與今如一丘之貉」。
被「{k:褐}」懷玉：褐，粗布衣服。成語比喻懷有真才實學而不為人知，語出《老子》第七十章「知我者希，則我者貴，是以聖人被褐懷玉」。此處「被」音ㄆㄧ，通「披」。
→ 貉 ≠ 褐。
@ana B x
「{k:髀}」肉復生：髀，大腿。指因久處安逸、不再騎馬，大腿上的肉又長了出來，比喻久處安逸、壯志未酬。典出《三國志‧蜀書‧先主傳》裴松之注引《九州春秋》，劉備如廁見髀裡肉生而慨然流涕。
失之交「{k:臂}」：臂，胳膊。兩人擦肩而過，比喻錯過好機會，語本《莊子‧田子方》「吾終身與汝交一臂而失之」。
→ 髀 ≠ 臂。
@ana C o
「{k:秉}」筆直書：秉，執持、拿著。指寫史者握筆據實記錄，毫不隱諱。
「{k:秉}」性善良：秉性，天賦的本性。「秉」由「執持」引申為「承受、稟受」。
→ 前後皆為「秉」，字形相同，為正解。
@ana D x
奉為圭「{k:臬}」：圭是測日影的儀器，臬是射箭的靶子，「圭臬」合指標準、準則。
「{k:涅}」槃重生：涅槃為梵語 nirvāṇa 的音譯，佛教指超脫生死的境界；「涅槃重生」常與「浴火鳳凰」連用，指歷經磨難後獲得新生。
→ 臬 ≠ 涅。
@trap
「稟性」與「秉性」在教育部《重編國語辭典》中皆有收錄、意義相通（天賦的本性）。若把第二個詞寫成「稟性」，會誤以為 (C) 前後不同而找不到答案。遇到這種「兩寫皆可」的情況，要回頭用{k:刪去法}：其餘三項絕對不同字，(C) 就是命題者設定的答案。
@know 「秉」與「稟」的分工
| 字 | 本義 | 常見詞語 | 記憶法 |
| 秉 | 手持禾束 → 執持、掌握 | 秉筆直書、秉燭夜遊、秉公處理、秉持 | 「手拿」的動作多用秉 |
| 稟 | 穀倉賜穀 → 承受；對上報告 | 稟告、稟報、稟賦、天稟 | 「向上報告」只能用稟 |
- 「秉性／稟性」「秉承／稟承」兩組為通用寫法；「稟告」「稟賦」不可寫作「秉」。

@key

@logic
1. 【審題】比的是讀音。四組都是「同聲符的形近字」，命題重點在{k:聲符相同未必同音}。
2. 【抓多音字】「刨」有二音：作「挖掘」解讀ㄆㄠˊ（刨土、刨根究底）；作「削刮」解讀ㄅㄠˋ（刨冰、刨木）。「刨根究底」是把根挖出來追究到底，讀ㄆㄠˊ，與「庖」同音。
3. 【抓通假字】「矜寡孤獨」的「矜」通「鰥」，讀ㄍㄨㄢ，不可讀ㄐㄧㄣ。
4. 【刪去】(C) 艟ㄊㄨㄥˊ（又讀ㄔㄨㄥ）≠ 幢ㄔㄨㄤˊ；(D) ㄍㄨㄢ ≠ ㄐㄧㄣ。(A) 確定同音，選 (A)。
@ana A o
越俎代「庖」：庖，ㄆㄠˊ，廚師。語本《莊子‧逍遙遊》「庖人雖不治庖，尸祝不越樽俎而代之矣」，比喻踰越本分、代人做事。
「刨」根究底：刨，ㄆㄠˊ，挖掘。指查問根由、追究底細，也作「追根究柢」。
→ 同讀ㄆㄠˊ，為正解。
@ana B x
舉止輕「佻」：教育部《重編國語辭典》標音為ㄑㄧㄥ ㄊㄧㄠ（佻，輕薄不莊重）。
「挑」肥揀瘦：挑，ㄊㄧㄠ，選擇。
依現行辭典兩字其實同為ㄊㄧㄠ。命題者設定本項「讀音不同」，應是取「佻」的另一讀ㄊㄧㄠˊ（如《詩經‧小雅‧大東》「佻佻公子」）。本書依官方公布答案 (A) 作答，並於「易錯提醒」說明此項疑義。
@ana C x
海「艟」止泊：艟，ㄊㄨㄥˊ（坊間亦見讀ㄔㄨㄥ），「艨艟」為古代戰船。
鬼影「幢幢」：ㄔㄨㄤˊ ㄔㄨㄤˊ，搖曳晃動的樣子。
→ 讀音不同。
@ana D x
「矜」寡孤獨：矜，通「鰥」，ㄍㄨㄢ，老而無妻者。語出《禮記‧禮運》「矜寡孤獨廢疾者皆有所養」。
青青子「衿」：衿，ㄐㄧㄣ，衣領，同「襟」。語出《詩經‧鄭風‧子衿》，「青衿」後借指讀書人。
→ ㄍㄨㄢ ≠ ㄐㄧㄣ。
@trap
本題 (B) 有討論空間：查教育部《重編國語辭典修訂本》，「輕佻」注音ㄑㄧㄥ ㄊㄧㄠ、「挑肥揀瘦」注音ㄊㄧㄠ ㄈㄟˊ ㄐㄧㄢˇ ㄕㄡˋ，兩字同音。官方參考答案僅公布 (A)。應考策略：字音題若出現兩個「似乎都對」的選項，優先選{k:各版辭典皆無異讀}的那一項（本題的庖／刨），並在試後依簡章規定提出試題疑義。

=== Q 3
@type 一字多義辨析
@cat 形音義
@tags 字義, 詞性, 古今義
@diff 3
@answer A
@stem
下列各組「」內的字，{y:意義前後相同|字義比較}的是：
@note red
方法：{c:代換法}——找一個詞同時代入前後兩句
@opt A
白手「起」家{n:建立}／平地「起」高樓{n:建造}
@note red
都是「興建、建立」✓
@opt B
人生如「寄」{nb:寄居}／「寄」書長不達{nb:寄送}
@opt C
眾望所「歸」{nb:歸向}／這事不「歸」我管{nb:屬於}
@opt D
「施」比受更有福{nb:給予(動)}／受「施」慎勿忘{nb:恩惠(名)}
@note blue
詞性不同，意義就不同
@cols 1
@key
「白手起家」「平地起高樓」的「起」都是「興建、建立」；其餘三組或義項不同，或詞性不同。
@logic
1. 【審題】比較字義，常用{k:代換法}：用同一個解釋代入前後兩句，都通順才算相同。
2. 【代換】(A) 以「建立」代入：白手「建立」家業、平地「建起」高樓，皆通。
3. 【驗證其他】(B) 寄居／寄送；(C) 歸向／屬於；(D) 動詞「給予」／名詞「恩惠」，均不相同。
4. 【提醒】字義題除了看義項，還要看{k:詞性}：(D) 兩個「施」意思相關，但一為動詞、一為名詞，仍判為不同。
@ana A o
白手「起」家：起，興建、創立。指沒有憑藉而獨力創立家業。
平地「起」高樓：起，建造。俗諺「萬丈高樓平地起」，比喻事物由基礎逐步建立。
→ 皆為「建立、興建」，正解。
@ana B x
人生如「寄」：寄，暫時託身、寄居。語出《古詩十九首‧驅車上東門》「人生忽如寄，壽無金石固」，感嘆人生短暫如旅居。
「寄」書長不達：寄，託人傳送。語出杜甫〈月夜憶舍弟〉「寄書長不達，況乃未休兵」。
→ 寄居 ≠ 寄送。
@ana C x
眾望所「歸」：歸，歸向、趨附。指眾人所期望、敬仰的對象。
這事不「歸」我管：歸，屬於、由（表示職責歸屬）。
→ 歸向 ≠ 屬於。
@ana D x
「施」比受更有福：施，動詞，給予。語出《新約聖經‧使徒行傳》。
受「施」慎勿忘：施，名詞，別人給的恩惠。語出東漢崔瑗〈座右銘〉「施人慎勿念，受施慎勿忘」。
→ 給予（動詞）≠ 恩惠（名詞）。

| 站立、起身 | 項莊拔劍「起」舞 | 《史記‧項羽本紀》 |
| 興建、建立 | 平地「起」高樓、白手「起」家 | 本題 |
| 發動、興起 | 「起」兵、揭竿而「起」 | — |
| 出身、發跡 | 「起」於布衣、「起」自寒微 | — |
| 啟發 | 「起」予者商也 | 《論語‧八佾》 |
| 治癒、使復活 | 「起」死回生 | — |
@know 「歸」的常見義項
- 返回：「歸」去來兮（陶淵明）
- 女子出嫁：之子于「歸」（《詩經‧桃夭》）、後五年吾妻來「歸」（歸有光〈項脊軒志〉）
- 歸附、歸向：眾望所「歸」、天下「歸」仁
- 歸還：完璧「歸」趙、久假不「歸」
- 屬於：「歸」我管

三處皆合，為正解。
@ana B x

@ana C x
「離離」（草木茂盛或分明貌）不押ㄤ韻，光憑格律即可刪去。
@ana D x

@box lines
「在抗倭戰爭中功績最為卓著的戚繼光，

@note red
「不是…而是…」→ 戊丁相連
@note blue
首句主語「戚繼光，」後面要接謂語 → 戊開頭
@note green
末句「這…方案」指甲乙的做法 → 乙收尾
@opt A
甲乙丙戊丁
@opt B
戊丁丙甲乙
@opt C
戊丁甲丙乙
@opt D
甲戊乙丙丁
@key
「不是…而是…」鎖定戊→丁；「現實感」（丙，總說）帶出「看清並適應政治、以軍事為輔」（甲→乙，分說），乙再接末句「這是…方案」。
@logic
1. 【找固定句式】(戊)「不是…的將領」與 (丁)「而是…的將領」是並列的{k:否定—肯定}句式，必為「戊丁」相連 → 刪 (A)(D)。
2. 【定開頭】首句「戚繼光，」是主語，後面須接判斷句的謂語，「不是…將領」正好承接；若接 (甲)「他看清…」則主語重複。確定以戊開頭。
3. 【比較 B、C】差別在「丙甲乙」或「甲丙乙」。(乙) 以連詞「而」開頭，必須緊接在 (甲) 之後：「看清並適應政治，{k:而}把軍事技術作為輔助」；若中間插入 (丙) 則語氣斷裂 → 刪 (C)。

@ana A x
以 (甲) 開頭，主語「戚繼光，他看清…」重複累贅；且「戊丁」放在最後，緊接「這是…方案」，「方案」沒有指涉對象（將領不是方案）。
@ana B o
戊丁（他是哪一種將領）→ 丙（成功的原因：現實感）→ 甲乙（現實感的具體表現）→ 末句（評價此一做法）。由{k:定位人物 → 提出原因 → 具體說明 → 總結評價}，層次分明。
@ana C x
「戊丁」正確，但「甲丙乙」把 (丙) 插在甲、乙之間，使 (乙) 的「而把…」失去上文，變成「在於他清醒的現實感，而把軍事技術作為輔助」，語意不通。
@ana D x
「甲戊乙丙丁」拆散了「不是…而是…」（戊丁）與「…政治，而把…」（甲乙）兩組固定搭配。
@know 排序題四步驟
| 步驟 | 做法 | 本題應用 |
| ① 找關聯詞 | 不是…而是、雖然…但是、因為…所以、不但…而且 | 戊→丁 |
| ② 找指代詞 | 他、這、此、其 的指涉對象必須出現在前面 | 末句「這…方案」←甲乙 |
| ③ 定首尾 | 與題幹首句、末句銜接 | 「戚繼光，」＋戊；乙＋「這是…」 |
| ④ 看層次 | 總說→分說、原因→結果、時間先後 | 丙（總）→甲乙（分） |

## 什麼是「翻案」？
- 對歷史定論提出相反的新見解。傳統說法（《西京雜記》）：昭君不肯賄賂畫工毛延壽，被畫醜而不得見幸，元帝事後怒殺毛延壽。王安石卻說「意態由來畫不成」——美人的神韻本來就畫不出，毛延壽是冤死的。
- 這正是第 20–22 題所說宋詩「{k:以議論為詩}」「自出己意」的典型。

@know 樂府詩 vs. 古詩 vs. 近體詩
- 樂府：原為漢代音樂官署，後指其所採集、可入樂的詩；多敘事，題目常有「歌、行、引、曲、吟」。王安石〈明妃曲〉題為「曲」，屬{k:歌行體}的文人古詩。
- 古詩（古體詩）：不講平仄對仗，句數不限，可換韻。
- 近體詩：絕句四句、律詩八句，講究平仄、押韻（律詩並須對仗）。

2. 【找相似點】上文說桂花的缺點是「滿樹齊開，不留餘地」，結果「三日都狼藉」——來得猛、去得快。

@ana B x

@ana C o

@ana D x

@know 文言句式：「A 之為 B」
- 「之」置於主謂之間，取消句子獨立性；「為」＝作為、對於。
- 「玉蘭之為春光」直譯：玉蘭作為春天的風光（那樣盛極一時）。
- 同類句式：「大道之行也，天下為公」「師道之不傳也久矣」。
@know 成語：一蹴而至／一蹴可幾
- 蹴（ㄘㄨˋ）：踏、踩。「一蹴而至」「一蹴而就」「一蹴可幾」都是踏一步就到達，比喻事情輕易成功。

@ana B x

@ana C o

@ana D x

2. 【看上下文】「待的日子一久，便讓那裡成為了家」「屬於我父母親的那支飛鏢射中了『條通』」「靶面上盡是不太牢靠的飛鏢」——強調落腳地點並非精心規劃，而是碰巧。
3. 【對應選項】(A)「倚靠機運」即偶然性。(B)(C)(D) 的「跟不上步調」「蜂擁」「從眾」都不是飛鏢這個譬喻的相似點。
@ana A o
飛鏢射中何處有運氣成分；移民北上，在哪裡找到落腳處也多憑機緣，日久便成了家。符合文意。
@ana B x
文中寫移民「待的日子一久，便讓那裡成為了家」，並未提到他們跟不上都市步調。
@ana C x
首句「外地北上的移民」確實點出遷徙潮，但「射飛鏢」這個譬喻著眼於「落點如何決定」，不是形容人數眾多。若要形容蜂擁，應是「如潮水般湧入」之類。
@ana D x
隨波逐流是跟著別人走；射飛鏢卻是各人各自擲出、落點各異，文中也無惋惜從眾之意。
@know 譬喻題的解法：找「相似點」
| 步驟 | 本題 |
| ① 找本體 | 移民決定落腳地點 |
| ② 找喻體 | 射飛鏢 |
| ③ 找相似點 | 落點帶有偶然、運氣 |
| ④ 回上下文驗證 | 「那支飛鏢射中了條通」「不太牢靠的飛鏢」 |
- 譬喻三要素：{k:喻體、喻詞、喻依}。有喻詞「像、如、彷彿」為明喻；用「是、成為」為隱喻（暗喻）；省略喻詞為略喻；只剩喻依為借喻。
@know 延伸意象：「不太牢靠的飛鏢」
- 第二段以「靶面上盡是不太牢靠的飛鏢」形容一條通的違建居民——他們隨時可能被迫遷離，為第三段「在地圖上被抹去」埋下伏筆。同一個譬喻前後呼應，稱為{k:意象的延續}。

=== Q 34
@type 文句涵義與作者情感
@cat 白話閱讀
@tags 現代散文, 句意解讀, 修辭
@diff 3
@answer A
@stem
關於上文文句的{y:解讀}，說明最適當的是：
@note red
引號內是原文（一定對）
要檢查的是{c:引號後的解讀}
@opt A
「鐵路旁連棟的矮房子成了公園綠地，栽上溫良恭儉讓的綠化樹」表現作者對{g:整齊規劃後失去多元樣貌}的感慨
@note red
↔ 南腔北調、百家爭鳴 ✓
@opt B
「於幼齡的我，鐵軌、車廂、貨櫃交織的節拍，毋寧像是一首搖籃曲」作者指出{x:厭倦}童年時二條通吵雜刺耳的金屬碰撞聲
@note blue
搖籃曲＝親切、安心
@opt C
「一到三條通一度南腔北調、百家爭鳴的春秋時代，至此告一段落」呈現條通因現代化，不得不遭受{x:廢棄且閒置}的悲劇命運
@note blue
變成綠地、大道，不是閒置
@opt D
「臺北市區鐵路也全面地下化後，我發現自己反而越睡越淺，即使是闃靜的夜裡，也時常難以成眠」敘述即使鐵路地下化，作者{x:仍對火車噪音不堪其擾}
@note blue
是「沒有聲音」才睡不好
@key
「溫良恭儉讓的綠化樹」整齊溫馴，對比過去「南腔北調、百家爭鳴」的熱鬧——作者感慨的是多元樣貌的消失。
@logic
1. 【鎖定檢查範圍】每個選項前半是原文引句，後半才是命題者的解讀，只需判斷後半。
2. 【抓情感方向】(B) 搖籃曲 → 正面情感；選項說「厭倦」→ 方向相反。(D)「反而越睡越淺」的原因是少了催眠的節拍；選項說「仍受噪音之擾」→ 因果顛倒。
3. 【抓事實】(C) 原文說鐵道成了市民大道、矮房成了公園綠地，是「改建」，不是「廢棄閒置」。
4. 【確認】(A)「溫良恭儉讓」與下一句「南腔北調、百家爭鳴」對照，可知作者感慨的是整齊劃一取代了多元喧鬧。
@ana A o
以形容君子德行的「溫良恭儉讓」寫綠化樹，暗示規劃後的街景乖順而單調；緊接「南腔北調、百家爭鳴的春秋時代，至此告一段落」，惋惜之情明顯。解讀正確。
@ana B x
「毋寧」意為「不如說、寧可說」。作者說那節拍不如說是一首搖籃曲，伴他入睡，是溫暖的童年記憶，並無厭倦。厭惡噪音的是「成年人」。
@ana C x
「告一段落」指那個各省移民雜處、充滿活力的時期結束了。空間並未被廢棄閒置，而是改建為交通幹道與公園綠地。
@ana D x
鐵路地下化後已無火車噪音。作者「越睡越淺」是因為從小聽慣的「搖籃曲」消失了，前文以「職是之故」（因此）明確交代因果。
@trap
(D) 的原文引句本身沒有問題，錯在解讀把「因為安靜而失眠」說成「因為噪音而失眠」。作答「文句解讀」題時，務必回到引句的{k:前一句}看因果——此處關鍵是連接詞「職是之故」。
@know 易混連接詞與副詞
| 詞語 | 意義 | 例句 |
| 毋寧 | 不如、寧可說（表示選擇後者） | 與其說是噪音，毋寧說是搖籃曲 |
| 無寧 | 同「毋寧」 | 不自由，毋寧死 |
| 職是之故 | 因此、因為這個緣故（職：由於） | 職是之故，我難以成眠 |
| 職此 | 因此 | 職此之由 |
| 闃靜 | 寂靜無聲（闃，ㄑㄩˋ） | 闃靜的夜裡、闃無一人 |
@know 借古喻今的詞語：春秋時代、百家爭鳴、楚河漢界
- {k:百家爭鳴}：春秋戰國時儒、道、墨、法等各家學說並起、互相論辯。文中借指各地移民帶來不同口音與生活方式。
- {k:楚河漢界}：楚漢相爭時，項羽、劉邦以鴻溝為界中分天下；後為象棋棋盤中界，比喻界線分明。
- {k:南腔北調}：口音混雜，南北方言皆有。

=== Q 35

@cat 白話閱讀

@diff 3
@answer D
@stem
關於{y:條通的變化}，敘述最適當的是：
@note red
回第三、四段
每個逗號都要對
@opt A
鐵路成{x:廢墟}，政府強拆矮房，條通{x:至此而沒落}

@key

@logic
1. 【定位】「變化」相關訊息在第三段（鐵道與矮房的去向）與第四段（南北兩個世界）。
2. 【核對第三段】鐵道 → 市民大道（交通幹道）；矮房 → 公園綠地。據此刪 (A)「廢墟」、(B)「重新修建、住宅區」。
3. 【核對第四段】南：「暫厝安身、但求溫飽」＝貧；北：「紙醉金迷」「銷金窟」＝奢。(C)「沒落」「治安混亂」無據。
4. 【結論】(D) 三個分句皆與第四段相符。
@ana A x
鐵道拆除後成為「以市民大道為名的交通幹道」，並非廢墟；違建確遭拆除，但作者只說一到三條通的「春秋時代告一段落」，北段條通反而「豔名遠播」，不能說條通就此沒落。
@ana B x

@ana C x

@ana D o

@know 統整題的檢核法：一個逗號一個勾
