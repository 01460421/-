1. 【審題】題幹問「錯別字{k:最多}」，不是「有沒有錯」。四個選項都藏有錯字，必須每一組都訂正完再比數量，不能看到第一個錯字就選。

- 「潰」不成軍：ㄎㄨㄟˋ，潰散。形容軍隊慘敗，散亂得不成隊伍。
- → 三字同讀ㄎㄨㄟˋ，為正解。
@ana C x

- 「揭」竿而起：ㄐㄧㄝ，高舉。原指陳勝、吳廣舉竹竿為旗起事（《史記‧陳涉世家》），後泛指起義。

@ana D x

- 「贍」養父母：ㄕㄢˋ，供給生活所需。

@trap
- 「偈」最常被誤讀為ㄐㄧㄝˊ。教育部辭典中「偈」作佛經頌詞解讀{k:ㄐㄧˋ}；ㄐㄧㄝˊ是「疾馳、勇武」之義，極少用。

1. 【審題】比較字義用{k:代換法}：找一個解釋同時代入前後兩句，兩句都通順才是相同。
2. 【看位置與詞性】(B) 的「顧」一在動詞位置（四顧）、一在句首（顧自……以來）；(D) 的「之」一在動詞前、一在名詞前——位置不同，詞性多半不同，可先存疑。
3. 【代入檢驗】(C) 以「如果沒有」代入：「如果沒有這種人，我要跟誰同道呢」「如果沒有管仲，我們恐怕要披頭散髮、衣襟左開了」，兩句皆通。

@ana A x

@ana B x
- 四「顧」蒼茫：顧，{k:看、環視}，動詞。

@ana C o
- 「微」斯人，吾誰與歸：語出范仲淹〈岳陽樓記〉。微，{k:無、如果沒有}；斯人，指「先天下之憂而憂，後天下之樂而樂」的古仁人。「吾誰與歸」是「吾與誰歸」的倒裝。

@ana D x

@translation

@ana B o

@ana C x
路隔山川，神馳絳帳：絳帳，紅色的紗帳。《後漢書‧馬融傳》記馬融「常坐高堂，施絳紗帳，前授生徒」，後世遂以「絳帳」為{k:師長講席}的美稱。此語是說「雖然山川阻隔，心神卻飛往老師的講席」，對象應為{k:師長}，不可用於同學。對同學、平輩可說「別後縈思，無時或釋」等。
@ana D o
前覆手函，想早收閱：手函，親筆信；意為「先前回覆的信，想必早已收到看過了」。措辭平直，不用「諒蒙垂察」「諒邀尊鑒」一類敬語，適用於{k:晚輩}（或關係親近的平輩）。對長輩則會改用敬辭，如「前肅蕪函，諒邀鈞鑒」。使用對象無誤。
@trap
「絳帳」「門牆」「杏壇」「函丈」「立雪」都是與{k:老師}有關的典故；與同學有關的常用字則是「硯」（硯右、硯席、同硯）、「窗」（同窗）、「學」（學安）。看到「帳」字不要誤想成同學共處的「營帳」。

=== Q 9
@type 使動用法與意動用法
@cat 語文應用
@tags 文法, 詞類活用, 使動, 意動
@diff 4
@answer D
@stem
在文句之中，如果動詞與賓語（受詞）的關係含有「{b:使賓語如何如何}」即是「使…… 怎麼樣」的意思，就稱為「使動用法」，其動詞則稱之為「致使動詞」。例如王安石〈泊船瓜洲〉「春風又綠江南岸」之「綠」解為「使……變綠」，下列動詞何者{y:__**並非致使動詞**__|找「認為…」的那個}：
@note red
先用題幹的定義：
{c:使＋賓語＋怎樣}
@note blue
檢驗：賓語{u:真的變了}嗎？
真的變＝使動
只是覺得＝意動
@opt A
大孝「尊」{nb:使…受尊敬}親，其次不辱，其下能養
@opt B
心猶未死杯中物，春不能「朱」{nb:使…變紅}鏡裡顏
@note blue
朱：紅色 → 使紅潤
@opt C
日思「高」{nb:使…升高}其位，「大」{nb:使…增多}其祿，而貪取滋甚
@note blue
想讓官位更高、俸祿更多
@opt D
孔子登東山而「小」{n:認為…小}魯，登泰山而「小」{n:認為…小}天下。
@note red
魯國沒有真的變小
→ {y:意動}，不是使動 ✓
@cols 1
@key
「小魯」「小天下」是登高後「覺得」魯國、天下變小，屬意動用法（以……為小）；尊親、朱顏、高其位、大其祿都是「使……怎樣」的使動用法。
@logic
1. 【讀懂定義】使動用法＝主語{k:使}賓語產生某種變化或狀態，可還原為「使＋賓語＋動詞／形容詞」。
2. 【逐項還原】(A) 尊親＝使雙親受尊敬；(B) 朱顏＝使容顏紅潤；(C) 高其位、大其祿＝使官位升高、使俸祿增多。三者的賓語都（被期待）發生實際變化。
3. 【找出例外】(D)「小魯」若還原成「使魯國變小」顯然不通——孔子登山不可能讓魯國縮小；合理的理解是「{k:認為}魯國小」，這是{k:意動用法}。
4. 【結論】並非致使動詞的是 (D)。
@ana A x
語本《禮記‧祭義》曾子語：「孝有三：大孝尊親，其次弗辱，其下能養。」尊親，{k:使雙親受到尊敬}（因子女的德行成就而尊榮）；其次是不使父母蒙羞；最下一等只是能奉養。「尊」為使動用法，是致使動詞。
@ana B x
語出黃庭堅〈次韻柳通叟寄王文通〉。朱，紅色，本為形容詞（名詞），此處帶賓語「鏡裡顏」，意為{k:使鏡中的容顏紅潤}。全句說：心還沒有對杯中酒死心，春天卻已無法讓鏡中衰老的容顏恢復紅潤。「朱」為使動用法，與「春風又綠江南岸」的「綠」結構相同。
@ana C x
語出柳宗元〈蝜蝂傳〉，諷刺貪得無厭的人「日思高其位，大其祿，而貪取滋甚，以近於危墜」。高其位，{k:使自己的官位升高}；大其祿，{k:使自己的俸祿增多}。「高」「大」皆形容詞作使動用法。
@ana D o
語出《孟子‧盡心上》。小魯、小天下：{k:認為魯國小、認為天下小}（以魯為小、以天下為小）。孔子登上東山、泰山，眼界開闊，主觀上覺得魯國、天下變小了，客觀上魯國、天下並沒有改變。這是{k:意動用法}，「小」是意謂動詞而非致使動詞，為本題答案。
@translation
- (A) 最大的孝是使父母受人尊敬，其次是不讓父母蒙受羞辱，最下等的只是能夠奉養父母。
- (B) 我的心對杯中酒仍未死心，但春天已不能讓鏡中的容顏再紅潤起來。
- (C) 每天想著提高自己的官位，增加自己的俸祿，貪求索取越來越厲害。
- (D) 孔子登上東山就覺得魯國小了，登上泰山就覺得天下小了。
@trap
使動與意動的外形完全相同（形容詞＋賓語），差別只在{k:客觀改變}或{k:主觀認定}。口訣：「使動真的變，意動心裡想。」把句子改寫成「使＿＿＿」與「認為＿＿＿」各念一遍，哪個合理就是哪一種。
@know 使動用法與意動用法比較
| 項目 | 使動用法 | 意動用法 |
| 意義 | 主語使賓語「怎麼樣」 | 主語認為賓語「怎麼樣」／把賓語當作什麼 |
| 還原 | 使＋賓語＋動詞（形容詞） | 以＋賓語＋為…… |
| 賓語是否改變 | 客觀上改變 | 只是主觀看法 |
| 本題 | 綠江南岸、尊親、朱顏、高其位、大其祿 | 小魯、小天下 |
| 例一 | 項伯殺人，臣{k:活}之（《史記‧項羽本紀》）：使他活 | 漁人甚{k:異}之（〈桃花源記〉）：認為它奇異 |
| 例二 | 既來之，則{k:安}之（《論語‧季氏》）：使他們安定 | 吾妻之{k:美}我者，私我也（《戰國策》）：認為我美 |
| 例三 | {k:舞}幽壑之潛蛟，{k:泣}孤舟之嫠婦（〈赤壁賦〉）：使蛟龍起舞、使寡婦哭泣 | {k:侶}魚蝦而{k:友}麋鹿（〈赤壁賦〉）：把魚蝦當伴侶、把麋鹿當朋友 |
| 例四 | 富國{k:強}兵：使兵力強大 | 不獨{k:親}其親，不獨{k:子}其子（《禮記‧禮運》）：以……為親、以……為子 |
@know 「春風又綠江南岸」的鍊字故事
- 南宋洪邁《容齋續筆》記載，王安石這句詩的草稿最初作「又{k:到}江南岸」，圈去改為「過」，再改「入」、改「滿」，前後換了十來個字，最後才定為「{k:綠}」。
- 「到、過、入、滿」只寫出春風的動作；「綠」字由形容詞轉為使動，既有顏色，又寫出春風吹過、草木轉青的{k:動態變化}，一字兼有視覺與時間感。
- 這種改變詞性以增加表現力的手法，修辭學稱為{k:轉品}（轉類）。

=== Q 10
@type 「相」字的單向與雙向
@cat 語文應用
@tags 文法, 相, 偏指副詞, 唐詩宋詞
@diff 3
@answer D
@stem
動詞前加「相」字，有表示其動作、事況、情態是{b:雙向}的，如「相見{u:實}難別亦難」﹔也有表示{b:單向}的，如「山中相送罷，日暮掩柴扉」。下列文句「」內的「相」字，{y:__**表示「雙向」**__|問：誰對誰？}的是：
@note purple
原卷作「相見實難」
李商隱〈無題〉通行本作
「相見{y:時}難別亦難」
@note red
判斷法：畫箭頭
甲→乙 且 乙→甲＝雙向
只有甲→乙＝單向
@opt A
深林人不知，明月來「相」{nb:月→我}照
@note blue
月照我，我不照月
@opt B
洛陽親友如「相」{nb:親友→我}問，一片冰心在玉壺
@note blue
親友問起我
@opt C
煮豆燃豆萁，豆在釜中泣，本是同根生，「相」{nb:萁→豆}煎何太急
@note blue
豆萁煎豆（兄逼弟）
@opt D
都門帳飲無緒，留戀處，蘭舟催發。{g:執手}「相」{n:你⇄我}看淚眼，竟無語凝噎。
@note red
兩人牽手互看 ✓
@cols 1
@key
「執手相看淚眼」是離別的兩人牽著手、互相凝望對方的淚眼，動作是雙向的；明月照我、親友問我、豆萁煎豆都只是一方對另一方。
@logic
1. 【讀懂定義】雙向＝「互相」，甲對乙、乙也對甲；單向＝偏指一方，「相」字相當於代詞「我、你、他」。例句「山中相送罷」是我送朋友，朋友並沒有送我。
2. 【畫箭頭】每一句都問「誰對誰做這個動作」：(A) 明月→我；(B) 親友→我；(C) 豆萁→豆；(D) 你⇄我。
3. 【代換檢驗】把「相」換成「互相」：明月和我互相照？親友和我互相問？都不通。只有「互相看著淚眼」通順。
4. 【結論】選 (D)。
@ana A x
語出王維〈竹里館〉。幽深的竹林裡無人知曉，只有明月前來照著我。動作由明月發出、指向詩人，「相」偏指「我」，是{k:單向}。
@ana B x
語出王昌齡〈芙蓉樓送辛漸〉。洛陽的親友如果問起我，「相問」即「問我」，「相」偏指說話者自己，是{k:單向}。
@ana C x
相傳為曹植〈七步詩〉。豆萁在鍋下燃燒，煎熬鍋中的豆子——是豆萁（比喻兄長曹丕）煎豆（比喻曹植），「相煎」即「煎我」，是{k:單向}。若解為互相煎熬，則與「豆在釜中泣」的受害者口吻不合。
@ana D o
語出柳永〈雨霖鈴〉。在京城門外設帳餞別，正依依不捨時，船家已催促出發；兩人緊握著手、{k:彼此}望著對方含淚的雙眼，哽咽得說不出話。「執手」已點明是兩人共同的動作，「相看」是互相看，為{k:雙向}，正解。
@translation
- (A) 幽深的竹林中沒有人知道我在這裡，只有明月來照著我。
- (B) 洛陽的親友如果問起我的近況，（請告訴他們）我的心像玉壺裡的冰一樣純潔。
- (C) 煮豆子時燒的是豆萁，豆子在鍋裡哭泣：我們本是同一條根上長出來的，你為何煎熬我這樣急迫？
- (D) 在京城門外設帳飲酒餞別，卻毫無心緒；正在依依不捨的時候，船家已催著出發。握著手互相望著淚眼，竟哽咽得一句話也說不出來。
@trap
(C)「相煎」因為後世常說「兄弟相煎」「同室操戈」，容易誤以為是互相傷害。回到原詩：加害者是「萁」，受害者是「豆」，是{k:單方面}的迫害。判斷時要以{k:原文語境}為準，不要用後起的成語意義回推。

@key
「除了……（吵醒你的）應該是……」鎖定甲→丁；末句「不過是……沉澱吧」需要主語，只有（乙）「童年、少年」能接；中間「然後在桌上→面對雛菊」為戊→丙。
@logic
1. 【找關聯詞】（甲）「除了鳥叫與太陽，」語意未完，必須接「還有什麼」；（丁）「吵醒你的應該是……黑咖啡」正好補足——清晨把人喚醒的，除了鳥叫與陽光，還有咖啡香。甲丁相連，且「露重的清晨，」後面接「醒來」最自然 → 甲丁在最前。
2. 【接末句】末句「不過是把臂之間／杯底咖啡的沉澱吧」是「A 不過是 B」的後半，前面要有名詞性的主語。（乙）「愚騃的童年，動盪的少年，」正是主語 → 乙在最後。此時只剩 (A)(D)。
3. 【排中段】（戊）以「然後」開頭，承接「被咖啡喚醒」之後；「在圓形的玻璃桌上」是地點，後接（丙）「面對……雛菊」的動作 → 戊丙。
4. 【驗證】(D) 丁丙甲戊乙：「除了鳥叫與太陽，然後在……玻璃桌上」語意中斷，「除了」沒有下文。答案為 (A)。
@ana A o
全段為：「露重的清晨，／除了鳥叫與太陽，／吵醒你的應該是一壺香濃的黑咖啡，／然後在圓形的玻璃桌上，／面對一叢窗外淡紫而柔怯的雛菊，／愚騃的童年，動盪的少年，／不過是把臂之間／杯底咖啡的沉澱吧。」脈絡是{k:清晨醒來 → 桌前坐定 → 望見雛菊 → 回想往事}，由外在景物轉入內心感懷，順序最自然。
@ana B x
以（乙）開頭，「露重的清晨，愚騃的童年……」時間詞與回憶直接相撞；又以（戊）「然後在圓形的玻璃桌上，」接末句「不過是……沉澱吧」，「不過是」前面是地點而非主語，語意不通。
@ana C x
以（丁）收尾，變成「吵醒你的應該是一壺香濃的黑咖啡，不過是……杯底咖啡的沉澱吧」，前句才說「應該是」，後句又說「不過是」，自相矛盾；且（甲）「除了」前面隔著（戊），句意被拆散。
@ana D x
頭尾（丁開頭、乙收尾）看似合理，但中段「（丙）面對……雛菊，（甲）除了鳥叫與太陽，（戊）然後在……玻璃桌上」把「除了……應該是……」的固定搭配拆開，「除了」懸空、「然後」之前也沒有可承接的動作。
@trap
(D) 是最強的誘答，因為它和正解一樣以（乙）收尾。兩者的差別在於「除了」的位置：「除了 A，（還有／應該是）B」中，A 必須在 B 的{k:前面}。先鎖定「甲丁」再看選項，就不會被 (D) 迷惑。
@know 排序題四步驟（新詩也適用）
| 步驟 | 做法 | 本題應用 |
| ① 找關聯詞 | 除了…還有、不是…而是、雖然…但是、然後、於是 | 除了（甲）→ 應該是（丁）；然後（戊） |

@know 詩句賞析：咖啡的沉澱
- 「愚騃」音ㄩˊ ㄞˊ，愚昧無知；「把臂」是互相握著手臂，表示親密，「把臂之間」指老友相聚談笑的片刻。

@logic
1. 【第一格看句式】「□我以孤獨」是「動詞＋我＋以＋名詞」，即「把孤獨□給我」。上一句是「我孤獨地{k:投}身在人群中」，下一句用同一個動詞回應最有張力：我把自己投給人群，人群卻只回報我孤獨。「視我以」「離我以」不合語法 → 刪 (C)(D)。
2. 【第二格看主語】主語是「細雨」。「霏霏」形容雨雪細密紛飛；「霪」是久下不停的大雨，與「細」矛盾，且一般只說「霪雨」不說「霪霪」→ 刪 (A)。

@ana A x

@translation
君子可以把心意寄託在外物上，卻不可以把心思留滯在外物上。把心意寄託在外物上，即使是微小的東西也足以帶來快樂，即使是珍奇的東西也不足以成為禍害；把心思留滯在外物上，即使是微小的東西也足以成為禍害，即使是珍奇的東西也不足以帶來快樂。老子說：「繽紛的色彩使人眼花，紛雜的音樂使人耳聾，豐美的滋味使人味覺敗壞，縱馬打獵使人心神狂蕩。」然而聖人並沒有廢棄這四樣東西，也只是姑且藉它們寄託心意罷了。劉備有雄才大略，卻喜歡編織毛物；嵇康曠達，卻喜歡打鐵；阮孚放達，卻喜歡給木屐上蠟。這些事難道有什麼聲色滋味嗎？他們卻樂在其中，終身不厭倦。
大凡可喜的事物，足以使人愉悅卻不足以改變人心志的，沒有比得上書法和繪畫的了。然而到了沉迷其中而放不下的地步，那禍害就說也說不完了。鍾繇甚至為此吐血、挖人墳墓；宋孝武帝和王僧虔甚至為此互相猜忌……，都是因為兒戲般的事情危害了國家、禍及自身。這就是「留意」的禍害。
當初我年輕的時候，曾經喜好這兩樣東西，家裡有的，唯恐失去；別人有的，唯恐人家不給我。後來自己笑自己說：我看輕富貴卻看重書法，輕視生死卻看重繪畫，豈不是顛倒錯亂、喪失本心了嗎？從此不再沉迷。看到喜歡的雖然有時也還收藏，但被人拿走了，也不再覺得可惜。就好比煙雲從眼前飄過、百鳥的鳴聲傳入耳中，怎會不欣然接受呢？然而它們離去了，也就不再掛念。於是書和畫這兩樣東西，常常成為我的快樂，卻不能成為我的禍患。

| 劉備好結髦 | 劉備喜歡用犛牛尾編織飾物，見《三國志‧諸葛亮傳》裴松之注引《魏略》 |
| 嵇康好鍛鍊 | 竹林七賢之一，性好打鐵，見《晉書‧嵇康傳》 |
| 阮孚好蠟屐 | 阮孚愛木屐，親自吹火上蠟，嘆「未知一生當著幾量屐」，見《世說新語‧雅量》 |
| 鍾繇嘔血發塚 | 相傳鍾繇向韋誕求蔡邕筆法不得，捶胸嘔血；韋誕死後竟盜其墓以取之 |
| 宋孝武、王僧虔相忌 | 宋孝武帝想獨享書法盛名，王僧虔不敢顯露真工夫，常用拙筆寫字以求自保，見《南齊書‧王僧虔傳》 |
- 鍾繇是三國魏的書法家，後世尊為「楷書之祖」；他也是本卷第 17–18 題中鍾毓、鍾會的父親。
@know 出自本文與相關的成語
- {k:過眼雲煙}（煙雲過眼）：比喻事物很快消逝，不留痕跡；也指身外之物不必看重。即出自本文「譬之煙雲之過眼」。
- {k:玩物喪志}：沉迷於所喜好的事物而喪失志氣，語出《尚書‧旅獒》「玩人喪德，玩物喪志」——正是「留意於物」的結果。
- {k:尤物移人}：《左傳‧昭公二十八年》「夫有尤物，足以移人」，蘇軾反用其語，說書畫「足以悅人而不足以移人」。
@know 蘇軾的「超然」思想
- 〈超然臺記〉：「凡物皆有可觀。苟有可觀，皆有可樂，非必怪奇瑋麗者也。」又說人之所以不樂，是因為「遊於物之內，而不遊於物之外」。
- 〈寶繪堂記〉的「寓意而不留意」與此一脈相承：{k:不被外物的得失牽動}，才能隨遇而樂。
- 蘇軾以「記」為題的名篇：〈喜雨亭記〉、〈超然臺記〉、〈石鐘山記〉、〈記承天寺夜遊〉。宋人的「記」常{k:藉事說理}，不只是記錄建築或遊蹤。

=== Q 13
@type 文言文對比句式填空
@cat 文言閱讀
@tags 蘇軾, 對比, 對偶, 文意推斷
@diff 3
@answer B
@stem
請依照文意推斷，選出□□中{y:__**依序應填**__|四格都要對}字詞的恰當選項：
@note red
填空題：用{c:下文}回推上文
用{c:對偶}找反義詞
@opt A
{x:留意／寓意}／吾／尚
@opt B
{g:寓意／留意／人／厚}
@opt C
{x:留意／寓意}／朝／求
@opt D
寓意／留意／世／{x:賤}。
@note red
可以→樂→寓意
不可以→病→留意
@note blue
「薄」的反義＝厚
賤與薄同義，不成對比
@cols 2
@key
下文「寓意於物……為樂」「留意於物……為病」決定前兩格為「寓意／留意」；「薄富貴而□於書，輕死生而重於畫」以「薄↔厚、輕↔重」成對，末格為「厚」。
@logic
1. 【前兩格：看緊接的解釋】首句說「可以□□」「不可以□□」，下文立刻解釋：「寓意於物」→ 足以為樂、不足以為病（好）；「留意於物」→ 足以為病（壞）。好的配「可以」，壞的配「不可以」→ 寓意／留意。刪 (A)(C)。
2. 【第四格：看對偶】「吾薄富貴而□於書，輕死生而重於畫」兩句結構相同：輕↔重是反義，所以「薄」也要配反義詞 →「厚」。(D) 的「賤」與「薄」同為輕視之意，無法構成「顛倒錯繆」的對比。刪 (D)。
3. 【第三格：驗證】「家之所有，惟恐其失之；□之所有，惟恐其不吾予也」——「家」指自己家，相對的是別{k:人}；「不吾予」是「不給我」，東西在別人手上才說得通。
4. 【結論】寓意／留意／人／厚，選 (B)。
@ana A x
前兩格填反了：若作「可以留意於物，不可以寓意於物」，就與下文「留意於物，雖微物足以為病」「此留意之禍也」完全矛盾。第三格「吾之所有」又與上句「家之所有」重複；第四格「尚於書」不成詞。
@ana B o
- 寓意／留意：與下文兩組對比句及第二段「留意之禍」一致。
- 人：「家之所有」對「人之所有」，自己有的怕失去，別人有的怕得不到，寫出年少時患得患失的貪戀。
- 厚：「薄富貴而厚於書」與「輕死生而重於畫」對偶，意為看輕富貴卻看重書法。
- 四格皆合，為正解。
@ana C x
前兩格同樣填反。第三格「朝之所有」（朝廷所有）與個人收藏的語境不合；第四格「求於書」無法與「薄」構成反義對比。
@ana D x
前三格大致可通（「世之所有」雖不如「人」與「家」對得工整），但第四格「賤於書」是「輕視書法」，與「薄富貴」同方向，句子變成「看輕富貴也看輕書法」，就談不上「顛倒錯繆失其本心」了。
@trap
容易只做前兩格就在 (B)(D) 之間憑感覺選。兩者的決勝點在第四格：{k:對偶句中相對位置的詞，詞性相同、意義相反（或相近）}。「輕／重」已示範了反義，所以「薄」必配「厚」。
@know 文言填空的三個線索
| 線索 | 說明 | 本題應用 |
| 下文解釋 | 作者提出主張後，通常緊接著說明 | 「寓意於物……」「留意於物……」兩句 |
| 對偶互文 | 相對位置的字詞，意義相反或相近 | 薄↔厚、輕↔重；家↔人 |
| 關鍵詞重現 | 同一概念會在後文反覆出現 | 「留意而不釋」「留意之禍」 |
@know 否定句的賓語前置：「不吾予」
- 文言否定句中，若賓語是代詞（吾、我、己、之），常提到動詞前面。「不吾予」＝「不予吾」（不給我）。
| 例句 | 還原 | 出處 |
| 不吾知也 | 不知吾也 | 《論語‧先進》 |
| 歲不我與 | 歲不與我 | 《論語‧陽貨》 |
| 莫我知也夫 | 莫知我也夫 | 《論語‧憲問》 |
| 不患人之不己知 | 不知己 | 《論語‧學而》 |
- 成語「時不我與」「人莫予毒」都是這種句式的遺留。
@know 文言常見的反義對舉
- 厚／薄：厚此薄彼、厚古薄今、厚積薄發。
- 輕／重：輕重緩急、避重就輕、舉足輕重。
- 貴／賤：「是故無貴無賤，無長無少」（韓愈〈師說〉）。
- 作動詞用時，「薄」「輕」「賤」都有「看不起」的意思，「厚」「重」「貴」則是「看重」，如「貴古賤今」「重男輕女」。

=== Q 14
@type 文言實詞字義判斷
@cat 文言閱讀
@tags 字義, 古今異義, 病, 勝, 去
@diff 3
@answer D
@stem
請依照文意推斷，判斷畫線部分字義{y:__**解釋錯誤**__|把解釋代回原句}者：
@note red
選「錯的」！
方法：{c:代入法}
@opt A
雖尤物不足以為「__病__」：{g:禍害}
@opt B
足以悅人而不足以「__移__」人者：{g:改變}
@opt C
則其禍有不可「__勝__」言者：{g:盡}
@opt D
然「__去__」而不復念也：{x:歸去}{n:離去、消逝}。
@note blue
病↔樂（對比）
移＝改變心志
不可勝言＝說不完
@note red
煙雲、鳥聲「離開」了
古義「去」＝離開
@cols 2
@key
「然去而不復念也」的「去」是離去、消逝——煙雲飄過、鳥聲遠去，並不是「回去」；病（禍害）、移（改變）、勝（盡）三項解釋皆正確。
@logic
1. 【審題】選「解釋錯誤」者。把每個解釋代回原句，看通不通。
2. 【A】「雖尤物不足以為病」與上句「足以為樂」相對，樂的反面是禍患 →「禍害」可通。
3. 【B、C】「足以悅人而不足以移人」：能讓人喜悅卻不至於改變人的心志 →「改變」可通；「其禍有不可勝言者」＝禍害多到說不盡 →「盡」可通。
4. 【D】主語是「煙雲」「百鳥（之聲）」，它們經過眼前耳畔之後是「離開、消失」，無所謂「歸去」。文言的「去」本義就是{k:離開}，選項解為「歸去」是添字誤釋。
@ana A o
病：禍害、憂患。此句與「雖微物足以為樂」相對——樂是好處，病是壞處。文末「常為吾樂而不能為吾病」同義。解釋正確。
@ana B o
移：改變、動搖（人的心志）。如《孟子‧滕文公下》「貧賤不能移」。蘇軾此句化用《左傳》「夫有尤物，足以移人」，意思是書畫能使人愉悅，卻不像聲色之類足以改變人的性情。解釋正確。
@ana C o
勝：音ㄕㄥ，盡、完全。「不可勝言」即說不完，同「不可勝數」「不勝枚舉」。解釋正確。
@ana D x
去：{k:離去、消逝}。原句說煙雲從眼前飄過、鳥鳴傳入耳中，當下欣然接受；等它們離開了，也就不再掛念。「去」是「離開此處」，沒有「回到原處」的意思，解為「歸去」不當，為本題答案。
@trap
「去」是典型的{k:古今異義}字：現代說「去學校」是「前往」；文言的「去」多是「離開」。「歸去」雖然也含「離開」，但多了「返回」的方向，用在煙雲、鳥聲上並不通。字義題常用這種「看似相近、其實多了或少了一層意思」的解釋設陷。
