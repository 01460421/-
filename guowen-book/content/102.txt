@logic
1. 【審題】題幹問「錯別字{k:最多}」，不是「有沒有錯」。四個選項都藏有錯字，必須每一組都訂正完再比數量，不能看到第一個錯字就選。
2. 【以義辨形】成語的用字跟著意思走：切「磋」是磨治骨角（石部）、「孺」慕是幼兒依戀父母（子部）、「罄」竹是把竹子用盡（缶部，器皿空了）、粗製「濫」造是浮濫不講究（水部，氾濫）。
3. 【逐組計數】(A) 四詞各錯一字，共 4 個；(B)「卓」→灼、「跚」→珊，2 個；(C)「杆」→扞、「究」→咎，2 個；(D) 只有「估」→沽，1 個。
4. 【結論】4 ＞ 2 ＝ 2 ＞ 1，選 (A)。
@ana A o
共 {k:4} 個錯字，為全題最多，是本題答案。
- 切「蹉」琢磨 → 切「{k:磋}」琢磨：語出《詩經‧衛風‧淇奧》「如切如磋，如琢如磨」，切、磋、琢、磨原是加工骨、角、玉、石的工夫，比喻互相研究討論。「蹉」用於「蹉跎」（虛度光陰）。
- 「儒」慕之情 → 「{k:孺}」慕之情：孺，幼兒；孺慕本指小兒愛慕父母，後指對人深切的依戀敬慕。
- 「磬」竹難書 → 「{k:罄}」竹難書：罄，盡。把竹子用盡做成竹簡也寫不完，形容罪狀極多。「磬」是玉石製的打擊樂器。
- 粗製「爛」造 → 粗製「{k:濫}」造：濫，浮泛、不加節制。指製作粗劣，只求數量不講品質。
@ana B x
共 {k:2} 個錯字。
- 真知「卓」見 → 真知「{k:灼}」見：灼，明白、透徹。成語固定作「真知灼見」，指正確而透徹的見解。
- 意興闌「跚」→ 意興闌「{k:珊}」：闌珊，衰落、將盡。形容興致低落。「跚」用於「蹣跚」（走路歪斜不穩）。
- 瓦釜雷鳴（《楚辭‧卜居》「黃鐘毀棄，瓦釜雷鳴」，比喻平庸者居於高位）、一蹴可幾（一舉腳就能到達，比喻輕易成功）二詞無誤。
@ana C x
共 {k:2} 個錯字。
- 「杆」格不入 → 「{k:扞}」格不入：扞，音ㄏㄢˋ，抵禦、牴觸；扞格，互相牴觸。形容彼此意見完全不合。「杆」是木棍（欄杆、旗杆）。
- 既往不「究」→ 既往不「{k:咎}」：咎，責怪。語出《論語‧八佾》「成事不說，遂事不諫，既往不咎」，指對過去的錯誤不再責備。
- 緣木求魚（《孟子‧梁惠王上》）、改弦易轍二詞無誤。
@ana D x
只有 {k:1} 個錯字。
- 「估」名釣譽 → 「{k:沽}」名釣譽：沽，買，引申為謀取；釣，用手段獵取。指故意做作以謀取名聲。
- 揠苗助長（《孟子‧公孫丑上》）、劍及履及（形容行動果決迅速）、不忮不求（《詩經‧邶風‧雄雉》，忮音ㄓˋ，嫉妒）三詞無誤。
@trap
- 「卓見」本身是正確的詞（高超的見解，如「遠見卓識」），所以「真知卓見」很容易看漏；但四字成語固定寫作「真知{k:灼}見」。
- 「既往不究」因「追究」一詞而看似合理，但成語出自《論語》，用的是責怪義的「{k:咎}」。

## 自編小題
下列文句，完全沒有錯別字的選項是：
- (A) 他做事向來按步就班，從不投機取巧
- (B) 這項政策朝令夕改，早已為人垢病
- (C) 兩隊實力相當，比賽一度陷入膠著
- (D) 面對各方質疑，他仍一昧否認到底
{k:答案：(C)}
- (A) 按「步」就班 → 按「{k:部}」就班：部、班都指門類、次序，語本陸機〈文賦〉「選義按部，考辭就班」。
- (B) 「垢」病 → 「{k:詬}」病：詬，辱罵、指責；垢是汙穢。
- (D) 一「昧」→ 一「{k:味}」：一味，一直、總是；昧是昏暗、隱藏（愚昧、拾金不昧）。

@note red

{c:有邊讀邊}最危險
@opt A
言行荒「謬」{nb:ㄇㄧㄡˋ}／未雨綢「繆」{nb:ㄇㄡˊ}／待罪「僇」{nb:ㄌㄨˋ}人

@opt C

@note blue

@opt D
有礙觀「瞻」{nb:ㄓㄢ}／「贍」{nb:ㄕㄢˋ}養父母／風「簷」{nb:ㄧㄢˊ}展書讀。
@note blue
贍養≠瞻仰
簷＝屋簷
@cols 1
@key
四組各是「翏、貴、曷、詹」聲符的形近字；只有 (B) 饋、簣、潰三字同讀ㄎㄨㄟˋ，其餘三組三個字的讀音全不相同。
@logic
1. 【審題】題幹要求「讀音{k:完全}相同」，一組三個字只要有一個不同音就要刪去。
2. 【看出命題手法】每組三字聲符相同（謬繆僇、饋簣潰、遏偈揭、瞻贍簷），專考「有邊讀邊」會讀錯的字。
3. 【逐字標音】(A) ㄇㄧㄡˋ／ㄇㄡˊ／ㄌㄨˋ；(B) ㄎㄨㄟˋ／ㄎㄨㄟˋ／ㄎㄨㄟˋ；(C) ㄜˋ／ㄐㄧˋ／ㄐㄧㄝ；(D) ㄓㄢ／ㄕㄢˋ／ㄧㄢˊ。
4. 【結論】只有 (B) 三字同音。注意「功虧一簣」的「虧」讀ㄎㄨㄟ（一聲）、「簣」讀ㄎㄨㄟˋ（四聲），題目考的是「簣」。
@ana A x
- 言行荒「謬」：ㄇㄧㄡˋ，錯誤。
- 未雨綢「繆」：ㄇㄡˊ，綢繆是緊密纏縛。語本《詩經‧豳風‧鴟鴞》「迨天之未陰雨，徹彼桑土，綢繆牖戶」，鳥兒趁未下雨先修補窩巢，比喻事先預防。
- 待罪「僇」人：ㄌㄨˋ，僇人即罪人。柳宗元〈始得西山宴遊記〉：「自余為僇人，居是州，恆惴慄。」
- → 三字讀音各不相同。
@ana B o
- 中「饋」猶虛：ㄎㄨㄟˋ。中饋原指婦女在家主持飲食之事，借指妻子；「中饋猶虛」比喻男子尚未娶妻。
- 功虧一「簣」：ㄎㄨㄟˋ，盛土的竹筐。語出《尚書‧旅獒》「為山九仞，功虧一簣」，比喻事情只差最後一步而未能完成。
- 「潰」不成軍：ㄎㄨㄟˋ，潰散。形容軍隊慘敗，散亂得不成隊伍。
- → 三字同讀ㄎㄨㄟˋ，為正解。
@ana C x
- 莫可阻「遏」：ㄜˋ，阻止。連橫〈臺灣通史序〉：「運會之趨，莫可阻遏。」
- 佛門「偈」語：ㄐㄧˋ，梵語 gāthā 的音譯，佛經中的頌詞，多為四句一偈。
- 「揭」竿而起：ㄐㄧㄝ，高舉。原指陳勝、吳廣舉竹竿為旗起事（《史記‧陳涉世家》），後泛指起義。
- → 三字讀音各不相同。

@stem
下列文句「 」中的字詞，{y:__**意義相同**__|代換法檢驗}的選項是：
@note red
方法：{c:代換法}
同一個解釋代入兩句都通才算
@opt A
至若春和「景」{nb:日光}明，波瀾不驚／高山仰止，「景」{nb:大}行行止
@note blue
景行＝大道
→ 比喻崇高德行
@opt B

@note blue
句首的「顧」多是轉折連詞
@opt C
「微」{n:如果沒有}斯人，吾誰與歸／「微」{n:如果沒有}管仲，吾其被髮左衽矣
@note red
微＋人名，句首
＝假設否定 ✓
@opt D

@note blue
唯…之…＝賓語提前
之子＝這位女子
@cols 1
@key
兩個「微」都放在句首、後接人物，表示「如果沒有」；景（日光／大）、顧（看／但是）、之（助詞／這）前後意義皆不同。
@logic
1. 【審題】比較字義用{k:代換法}：找一個解釋同時代入前後兩句，兩句都通順才是相同。
2. 【看位置與詞性】(B) 的「顧」一在動詞位置（四顧）、一在句首（顧自……以來）；(D) 的「之」一在動詞前、一在名詞前——位置不同，詞性多半不同，可先存疑。
3. 【代入檢驗】(C) 以「如果沒有」代入：「如果沒有這種人，我要跟誰同道呢」「如果沒有管仲，我們恐怕要披頭散髮、衣襟左開了」，兩句皆通。
4. 【確認其他】(A) 春和景明的「景」是日光，景行的「景」是大；(B) 看／但是；(D) 結構助詞／指示代詞。答案為 (C)。
@ana A x
- 至若春和「景」明：語出范仲淹〈岳陽樓記〉。景，{k:日光}（一說景物）；全句指春風和煦、陽光明媚。
- 高山仰止，「景」行行止：語出《詩經‧小雅‧車舝》。景，{k:大}；景行，大路，比喻光明正大的德行。全句以仰望高山、行走大道比喻對崇高品德的仰慕，「景仰」一詞即由此而來。
- → 日光 ≠ 大。
@ana B x
- 四「顧」蒼茫：顧，{k:看、環視}，動詞。
- 「顧」自海通以來，西力東漸：語出連橫〈臺灣通史序〉。顧，{k:但是、不過}，表轉折的連詞。
- → 看 ≠ 但是。
@ana C o
- 「微」斯人，吾誰與歸：語出范仲淹〈岳陽樓記〉。微，{k:無、如果沒有}；斯人，指「先天下之憂而憂，後天下之樂而樂」的古仁人。「吾誰與歸」是「吾與誰歸」的倒裝。
- 「微」管仲，吾其被髮左衽矣：語出《論語‧憲問》。孔子說如果沒有管仲輔佐齊桓公尊王攘夷，中原人民恐怕早已淪為夷狄（被髮左衽是夷狄的裝束；被，通「披」）。
- → 皆為「如果沒有」，正解。
@ana D x
- 父母唯其疾「之」憂：語出《論語‧為政》，孟武伯問孝，孔子的回答。之，{k:賓語提前的結構助詞}，無實義；原句語序為「父母唯憂其疾」。
- 「之」子于歸，宜其家室：語出《詩經‧周南‧桃夭》。之，{k:這、此}，指示代詞；之子，這位女子；于歸，出嫁。
- → 助詞 ≠ 指示代詞。
@translation
- (A) 到了春風和煦、陽光明媚的時候，湖面平靜，沒有驚濤駭浪。／高山令人仰望，大道讓人遵行。
- (B) 但是自從海運開通以來，西方勢力逐漸向東擴張。
- (C) 如果沒有這樣的人，我要和誰同道呢？／如果沒有管仲，我們恐怕要披散頭髮、衣襟向左開（淪為夷狄）了。
- (D) 讓父母只為子女的疾病擔憂（其餘不必操心，就是孝了）。／這位姑娘出嫁了，定能使夫家和順美滿。
@trap
(D) 的兩個「之」都不是最常見的「的」或代詞「他」，容易誤以為「反正都很特別，應該相同」。判斷訣竅：「唯……之（是）……」是固定的{k:賓語提前句式}（唯利是圖、唯命是從同理）；「之子」「之二蟲」的「之」後面緊跟名詞，是{k:指示代詞「這」}。

- (C) 兩個「之」都是動詞「往、到」：我想到南海去（〈為學一首示子姪〉）／停止耕作，走到田埂上（《史記‧陳涉世家》）。判斷訣竅：「之」後面接{k:處所}，前面又沒有別的動詞，就是動詞「往」。

@ana B o

## 自編小題
下列文句「」內成語的運用，最恰當的選項是：
- (A) 這家老店的招牌菜遠近馳名，每到假日總是「門可羅雀」
- (B) 他初次登臺就技驚四座，前輩們都讚嘆「後生可畏」
- (C) 王教授學識淵博，演講時「信口開河」，令人獲益良多
- (D) 這本小說情節鬆散、結局草率，實在令人「不忍卒讀」
{k:答案：(B)}
- (A) 門可羅雀：門前可以張網捕雀，形容賓客稀少；應改「門庭若市」。
- (B) 後生可畏：語出《論語‧子罕》，稱讚年輕人有成就、值得敬畏，使用恰當。
- (C) 信口開河：隨口亂說（貶）；應改「旁徵博引」「口若懸河」。

@key

@logic
1. 【善用題幹】題幹已提供「六十為周期」與「卯時＝上午五至七點」兩條線索，足以推算 (A) 與 (D)。
2. 【推算 A】2013－1954＝59 年。六十年一循環，所以 1953 年與 2013 年同為癸巳；1954 是 1953 的下一年：天干「癸」之後回到「甲」，地支「巳」之後是「午」→ 甲午；午對應馬。(A) 正確。

4. 【常識判斷 B、C】「甲子」一循環六十年，「甲子花」即花甲之年（六十歲）；「寅吃卯糧」是今年吃掉明年的糧，表示入不敷出。
@ana A o
干支紀年六十年一循環，2013－60＝1953，故 1953 年亦為癸巳年。1954 年為其次年：十天干「……壬、癸」之後重新從「{k:甲}」起；十二地支「……辰、巳」之後為「{k:午}」，故為甲午年。地支午對應生肖馬。歷史上的印證：甲午戰爭發生於 1894 年，1894＋60＝1954。敘述正確。
@ana B x
「甲子」為干支之首，一輪六十年，故以「花甲」「甲子」稱六十歲。聯中「紀算新開甲子花」是說年歲的計算又開始新的一輪甲子，為{k:六十歲}的壽聯。七十歲稱「古稀」（杜甫〈曲江〉「人生七十古來稀」），應改為「六十歲」。
@ana C x
寅吃卯糧：寅年就吃掉了卯年的糧食，比喻{k:入不敷出}，預先支用以後的進項。意思與「糧食大有盈餘」正好相反；近義成語有「捉襟見肘」「左支右絀」，現代說法是「透支」「當月光族」。
@ana D x
〈良馬對〉原文：「介而馳，初不甚疾，比行百里，始奮迅，自午至酉，猶可二百里。」介，披上鎧甲。意思是披甲奔馳，起初不很快，等跑了百里才開始加速，從{k:午時（約中午）到酉時（約傍晚）}還能再跑二百里——強調的是後勁與耐力。午至酉相隔三個時辰，約六小時；選項誤把「三個時辰」當成「三小時」，又把「還能再跑」誤解為「只需」。

@ana A x
古文運動由韓愈、柳宗元倡導，主張恢復先秦兩漢質樸的散文，反對六朝以來內容空洞、形式華美的{k:駢文}，並非針對「韻文」。「文起八代之衰，而道濟天下之溺」出自蘇軾〈潮州韓文公廟碑〉，是蘇軾對韓愈的評價；「八代」指東漢、魏、晉、宋、齊、梁、陳、隋。應將「韻文」改為「駢文」。
@ana B o
詞原是配合音樂歌唱的歌詞，每一個詞牌（如〈水調歌頭〉〈念奴嬌〉）代表一種曲調，規定了句數、字數、平仄與押韻；曲牌（如〈天淨沙〉〈山坡羊〉）亦然。作者依調「填」詞，詞牌、曲牌與內容不一定相關，所以常在其下另加題目或小序。唐詩的詩題（如〈送友人〉〈春望〉）則直接說明內容。敘述正確。
@ana C x
《水滸傳》（施耐庵）、《紅樓夢》（曹雪芹）、《老殘遊記》（劉鶚）都是白話章回小說；{k:《聊齋志異》}是清代蒲松齡所作的{k:文言短篇小說集}，多寫狐鬼花妖，並非章回體。
@ana D x
盛唐邊塞詩派的代表是高適、岑參（並稱「高岑」）、王昌齡、王之渙等。{k:杜甫}雖然也寫戰爭（如〈兵車行〉、「三吏」「三別」），但重點在反映民生疾苦，屬{k:社會寫實詩人}，人稱「詩聖」，其詩號為「詩史」，不列入邊塞詩派。

=== Q 9
@type 使動用法與意動用法
@cat 語文應用
@tags 文法, 詞類活用, 使動, 意動
@diff 4
@answer D
@stem
在文句之中，如果動詞與賓語（受詞）的關係含有「{b:使賓語如何如何}」即是「使…… 怎麼樣」的意思，就稱為「使動用法」，其動詞則稱之為「致使動詞」。例如王安石〈泊船瓜洲〉「春風又綠江南岸」之「綠」解為「使……變綠」，下列動詞何者{y:__**並非致使動詞**__|找「認為」型}：
@note red
先用題幹的定義：
{c:使＋賓語＋怎樣}
@note blue
檢驗：賓語{u:真的變了}嗎？
真的變＝使動
只是覺得＝意動
@opt A
大孝「尊」{nb:使…受尊敬}親，其次不辱，其下能養
@opt B
心猶未死杯中物，春不能「朱」{nb:使…變紅}鏡裡顏
@note blue
朱：紅色 → 使紅潤
@opt C
日思「高」{nb:使…升高}其位，「大」{nb:使…增多}其祿，而貪取滋甚
@note blue
想讓官位更高、俸祿更多
@opt D
孔子登東山而「小」{n:認為…小}魯，登泰山而「小」{n:認為…小}天下。
@note red
魯國沒有真的變小
→ {y:意動}，不是使動 ✓
@cols 1
@key
「小魯」「小天下」是登高後「覺得」魯國、天下變小，屬意動用法（以……為小）；尊親、朱顏、高其位、大其祿都是「使……怎樣」的使動用法。
@logic
1. 【讀懂定義】使動用法＝主語{k:使}賓語產生某種變化或狀態，可還原為「使＋賓語＋動詞／形容詞」。
2. 【逐項還原】(A) 尊親＝使雙親受尊敬；(B) 朱顏＝使容顏紅潤；(C) 高其位、大其祿＝使官位升高、使俸祿增多。三者的賓語都（被期待）發生實際變化。
3. 【找出例外】(D)「小魯」若還原成「使魯國變小」顯然不通——孔子登山不可能讓魯國縮小；合理的理解是「{k:認為}魯國小」，這是{k:意動用法}。
4. 【結論】並非致使動詞的是 (D)。
@ana A x
語本《禮記‧祭義》曾子語：「孝有三：大孝尊親，其次弗辱，其下能養。」尊親，{k:使雙親受到尊敬}（因子女的德行成就而尊榮）；其次是不使父母蒙羞；最下一等只是能奉養。「尊」為使動用法，是致使動詞。
@ana B x
語出黃庭堅〈次韻柳通叟寄王文通〉。朱，紅色，本為形容詞（名詞），此處帶賓語「鏡裡顏」，意為{k:使鏡中的容顏紅潤}。全句說：心還沒有對杯中酒死心，春天卻已無法讓鏡中衰老的容顏恢復紅潤。「朱」為使動用法，與「春風又綠江南岸」的「綠」結構相同。
@ana C x
語出柳宗元〈蝜蝂傳〉，諷刺貪得無厭的人「日思高其位，大其祿，而貪取滋甚，以近於危墜」。高其位，{k:使自己的官位升高}；大其祿，{k:使自己的俸祿增多}。「高」「大」皆形容詞作使動用法。
@ana D o
語出《孟子‧盡心上》。小魯、小天下：{k:認為魯國小、認為天下小}（以魯為小、以天下為小）。孔子登上東山、泰山，眼界開闊，主觀上覺得魯國、天下變小了，客觀上魯國、天下並沒有改變。這是{k:意動用法}，「小」是意謂動詞而非致使動詞，為本題答案。
@translation
- (A) 最大的孝是使父母受人尊敬，其次是不讓父母蒙受羞辱，最下等的只是能夠奉養父母。
- (B) 我的心對杯中酒仍未死心，但春天已不能讓鏡中的容顏再紅潤起來。
- (C) 每天想著提高自己的官位，增加自己的俸祿，貪求索取越來越厲害。
- (D) 孔子登上東山就覺得魯國小了，登上泰山就覺得天下小了。
@trap
使動與意動的外形完全相同（形容詞＋賓語），差別只在{k:客觀改變}或{k:主觀認定}。口訣：「使動真的變，意動心裡想。」把句子改寫成「使＿＿＿」與「認為＿＿＿」各念一遍，哪個合理就是哪一種。

| 例三 | {k:舞}幽壑之潛蛟，{k:泣}孤舟之嫠婦（〈赤壁賦〉）：使蛟龍起舞、使寡婦哭泣 | {k:侶}魚蝦而{k:友}麋鹿（〈赤壁賦〉）：把魚蝦當伴侶、把麋鹿當朋友 |

@know 「春風又綠江南岸」的鍊字故事
- 南宋洪邁《容齋續筆》記載，王安石這句詩的草稿最初作「又{k:到}江南岸」，圈去改為「過」，再改「入」、改「滿」，前後換了十來個字，最後才定為「{k:綠}」。
- 「到、過、入、滿」只寫出春風的動作；「綠」字由形容詞轉為使動，既有顏色，又寫出春風吹過、草木轉青的{k:動態變化}，一字兼有視覺與時間感。
- 這種改變詞性以增加表現力的手法，修辭學稱為{k:轉品}（轉類）。

下列關於「」內詞語用法的說明，正確的選項是：
- (A) 先破秦入咸陽者「王」之：名詞作使動用法，使他稱王
- (B) 范增數「目」項王：意動用法，把項王當作眼睛
- (C) 孟嘗君「客」我：使動用法，使我成為他的客人
- (D) 沛公旦日「從」百餘騎來見項王：一般動詞，跟隨在百餘名騎兵之後

- (A) 語出〈鴻門宴〉。王，名詞活用為動詞，且為使動：{k:使}之為王，正確。
- (B) 目，名詞活用為{k:一般動詞}，用眼神示意，不是意動。

=== Q 10
@type 「相」字的單向與雙向
@cat 語文應用
@tags 文法, 相, 偏指副詞, 唐詩宋詞
@diff 3
@answer D
@stem
動詞前加「相」字，有表示其動作、事況、情態是{b:雙向}的，如「相見{u:實}難別亦難」﹔也有表示{b:單向}的，如「山中相送罷，日暮掩柴扉」。下列文句「」內的「相」字，{y:__**表示「雙向」**__|問：誰對誰？}的是：
@note purple
原卷作「相見實難」
李商隱〈無題〉通行本作
「相見{y:時}難別亦難」
@note red
判斷法：畫箭頭
甲→乙 且 乙→甲＝雙向
只有甲→乙＝單向
@opt A
深林人不知，明月來「相」{nb:月→我}照
@note blue
月照我，我不照月
@opt B
洛陽親友如「相」{nb:親友→我}問，一片冰心在玉壺
@note blue
親友問起我
@opt C
煮豆燃豆萁，豆在釜中泣，本是同根生，「相」{nb:萁→豆}煎何太急
@note blue
豆萁煎豆（兄逼弟）
@opt D
都門帳飲無緒，留戀處，蘭舟催發。{g:執手}「相」{n:你⇄我}看淚眼，竟無語凝噎。
@note red
兩人牽手互看 ✓
@cols 1
@key
「執手相看淚眼」是離別的兩人牽著手、互相凝望對方的淚眼，動作是雙向的；明月照我、親友問我、豆萁煎豆都只是一方對另一方。
@logic
1. 【讀懂定義】雙向＝「互相」，甲對乙、乙也對甲；單向＝偏指一方，「相」字相當於代詞「我、你、他」。例句「山中相送罷」是我送朋友，朋友並沒有送我。
2. 【畫箭頭】每一句都問「誰對誰做這個動作」：(A) 明月→我；(B) 親友→我；(C) 豆萁→豆；(D) 你⇄我。
3. 【代換檢驗】把「相」換成「互相」：明月和我互相照？親友和我互相問？都不通。只有「互相看著淚眼」通順。
4. 【結論】選 (D)。
@ana A x
語出王維〈竹里館〉。幽深的竹林裡無人知曉，只有明月前來照著我。動作由明月發出、指向詩人，「相」偏指「我」，是{k:單向}。
@ana B x
語出王昌齡〈芙蓉樓送辛漸〉。洛陽的親友如果問起我，「相問」即「問我」，「相」偏指說話者自己，是{k:單向}。
@ana C x
相傳為曹植〈七步詩〉。豆萁在鍋下燃燒，煎熬鍋中的豆子——是豆萁（比喻兄長曹丕）煎豆（比喻曹植），「相煎」即「煎我」，是{k:單向}。若解為互相煎熬，則與「豆在釜中泣」的受害者口吻不合。
@ana D o
語出柳永〈雨霖鈴〉。在京城門外設帳餞別，正依依不捨時，船家已催促出發；兩人緊握著手、{k:彼此}望著對方含淚的雙眼，哽咽得說不出話。「執手」已點明是兩人共同的動作，「相看」是互相看，為{k:雙向}，正解。
@translation
- (A) 幽深的竹林中沒有人知道我在這裡，只有明月來照著我。
- (B) 洛陽的親友如果問起我的近況，（請告訴他們）我的心像玉壺裡的冰一樣純潔。
- (C) 煮豆子時燒的是豆萁，豆子在鍋裡哭泣：我們本是同一條根上長出來的，你為何煎熬我這樣急迫？
- (D) 在京城門外設帳飲酒餞別，卻毫無心緒；正在依依不捨的時候，船家已催著出發。握著手互相望著淚眼，竟哽咽得一句話也說不出來。
@trap
(C)「相煎」因為後世常說「兄弟相煎」「同室操戈」，容易誤以為是互相傷害。回到原詩：加害者是「萁」，受害者是「豆」，是{k:單方面}的迫害。判斷時要以{k:原文語境}為準，不要用後起的成語意義回推。
@know 副詞「相」的兩種用法
| 用法 | 意義 | 例句 | 「相」的指涉 |
| 互指（雙向） | 互相、彼此 | 相看兩不厭，只有敬亭山（李白） | 我與山互看 |

@key
「除了……（吵醒你的）應該是……」鎖定甲→丁；末句「不過是……沉澱吧」需要主語，只有（乙）「童年、少年」能接；中間「然後在桌上→面對雛菊」為戊→丙。
@logic
1. 【找關聯詞】（甲）「除了鳥叫與太陽，」語意未完，必須接「還有什麼」；（丁）「吵醒你的應該是……黑咖啡」正好補足——清晨把人喚醒的，除了鳥叫與陽光，還有咖啡香。甲丁相連，且「露重的清晨，」後面接「醒來」最自然 → 甲丁在最前。
2. 【接末句】末句「不過是把臂之間／杯底咖啡的沉澱吧」是「A 不過是 B」的後半，前面要有名詞性的主語。（乙）「愚騃的童年，動盪的少年，」正是主語 → 乙在最後。此時只剩 (A)(D)。
3. 【排中段】（戊）以「然後」開頭，承接「被咖啡喚醒」之後；「在圓形的玻璃桌上」是地點，後接（丙）「面對……雛菊」的動作 → 戊丙。

@ana A o
全段為：「露重的清晨，／除了鳥叫與太陽，／吵醒你的應該是一壺香濃的黑咖啡，／然後在圓形的玻璃桌上，／面對一叢窗外淡紫而柔怯的雛菊，／愚騃的童年，動盪的少年，／不過是把臂之間／杯底咖啡的沉澱吧。」脈絡是{k:清晨醒來 → 桌前坐定 → 望見雛菊 → 回想往事}，由外在景物轉入內心感懷，順序最自然。
@ana B x
以（乙）開頭，「露重的清晨，愚騃的童年……」時間詞與回憶直接相撞；又以（戊）「然後在圓形的玻璃桌上，」接末句「不過是……沉澱吧」，「不過是」前面是地點而非主語，語意不通。
@ana C x
以（丁）收尾，變成「吵醒你的應該是一壺香濃的黑咖啡，不過是……杯底咖啡的沉澱吧」，前句才說「應該是」，後句又說「不過是」，自相矛盾；且（甲）「除了」前面隔著（戊），句意被拆散。
@ana D x
頭尾（丁開頭、乙收尾）看似合理，但中段「（丙）面對……雛菊，（甲）除了鳥叫與太陽，（戊）然後在……玻璃桌上」把「除了……應該是……」的固定搭配拆開，「除了」懸空、「然後」之前也沒有可承接的動作。
@trap
(D) 是最強的誘答，因為它和正解一樣以（乙）收尾。兩者的差別在於「除了」的位置：「除了 A，（還有／應該是）B」中，A 必須在 B 的{k:前面}。先鎖定「甲丁」再看選項，就不會被 (D) 迷惑。

@know 詩句賞析：咖啡的沉澱

## 自編小題
下列是一段古文，請依文意選出排列順序最恰當的選項：
> 「吾嘗終日而思矣，不如須臾之所學也；
> （甲）而見者遠
> （乙）登高而招
> （丙）吾嘗跂而望矣
> （丁）臂非加長也
> （戊）不如登高之博見也
> 順風而呼，聲非加疾也，而聞者彰。」（《荀子‧勸學》）
- (A) 丙戊乙丁甲　(B) 乙丁甲丙戊　(C) 丙戊丁乙甲　(D) 乙甲丁丙戊
{k:答案：(A)}
- 首句「吾嘗……矣，不如……也」是固定句式，緊接其後的應是同構的（丙）（戊）：「吾嘗跂而望矣，不如登高之博見也」。
- 末句「順風而呼，聲非加疾也，而聞者彰」為「動作—非……也—而……」的結構，其前應是同構的（乙）（丁）（甲）：「登高而招，臂非加長也，而見者遠」。
- 語譯：我曾經整天苦思，卻不如片刻的學習；我曾經踮起腳遠望，卻不如登上高處看得廣。登高招手，手臂並沒有加長，遠處的人卻看得見；順風呼喊，聲音並沒有加大，聽的人卻聽得清楚。

@type 現代詩鍊字與用典

@stem
下引現代詩，請依詩意仔細推敲，選出{y:__**最適合填入□的選項**__|看句式＋搭配}：
@note red
每格都找「搭配對象」：
□我以…／細雨□□／□□落木
@box poem
「於是夜來了／敲打著我十一月的窗／從南國的馨香中醒來／從回家的夢裏醒來／布魯塞爾的燈火輝煌

@note red
上句「投身」→ 下句「投我以」
（《詩經》投我以木瓜）
@note blue
細雨 → 霏霏（雨雪霏霏）
落木 → 蕭蕭（杜甫〈登高〉）
@note purple
十一月、落木＝深秋
南國的夢 vs 異域的夜
@opt A
待／{x:霪霪}／飄飄
@opt B
{g:投}／{g:霏霏}／{g:蕭蕭}
@opt C
{x:視}／滴滴／漠漠
@opt D
{x:離}／紛紛／{x:靡靡}。
@note blue
霪＝久雨，與「細雨」不合
靡靡＝頹廢、遲緩
@cols 2
@key
「我投身人群，人群投我以孤獨」上下句以「投」字呼應，並化用《詩經》「投我以木瓜」；細雨配「霏霏」、落木配「蕭蕭」都是古典詩的固定搭配。
@logic
1. 【第一格看句式】「□我以孤獨」是「動詞＋我＋以＋名詞」，即「把孤獨□給我」。上一句是「我孤獨地{k:投}身在人群中」，下一句用同一個動詞回應最有張力：我把自己投給人群，人群卻只回報我孤獨。「視我以」「離我以」不合語法 → 刪 (C)(D)。
2. 【第二格看主語】主語是「細雨」。「霏霏」形容雨雪細密紛飛；「霪」是久下不停的大雨，與「細」矛盾，且一般只說「霪雨」不說「霪霪」→ 刪 (A)。
3. 【第三格驗證】「□□落木」令人想到杜甫〈登高〉「無邊落木蕭蕭下」；「蕭蕭」是風吹葉落的聲音，也帶出深秋的蕭瑟。
4. 【結論】投／霏霏／蕭蕭，選 (B)。
@ana A x
- 待：「待我以孤獨」（用孤獨對待我）語法可通，但少了與上句「投身」的呼應。
- 霪霪：霪，下了很久的雨（霪雨）。與「細雨」的輕細不合，也不是常見的疊字詞。
- 飄飄：形容輕盈飛揚，可寫落葉，但沒有聲音與蕭瑟感，不如「蕭蕭」。
@ana B o
- {k:投}：給予、投贈。上句「投身」、下句「投我以孤獨」，同字回環，寫出「熱切投入卻換來冷落」的落差；句式出自《詩經‧衛風‧木瓜》「投我以木瓜，報之以瓊琚」。
- {k:霏霏}：雨雪細密的樣子，《詩經‧小雅‧采薇》「今我來思，雨雪霏霏」正是寫遊子的心情。
- {k:蕭蕭}：風聲、落葉聲。杜甫〈登高〉：「無邊落木蕭蕭下，不盡長江滾滾來。」
- 三格皆合詩意，並使現代詩帶有古典的韻味，為正解。
@ana C x
- 視：「視我以孤獨」不成句（「視」不能帶「以」字補語來表示給予）。
- 滴滴：可形容雨聲，但「細雨滴滴」偏重聲響，與「不是我的淚」的迷濛畫面不合。
- 漠漠：密布或寂靜的樣子，如「漠漠水田飛白鷺」（王維），多形容煙、雲、水田，不用來形容落葉。
@ana D x

@translation
君子可以把心意寄託在外物上，卻不可以把心思留滯在外物上。把心意寄託在外物上，即使是微小的東西也足以帶來快樂，即使是珍奇的東西也不足以成為禍害；把心思留滯在外物上，即使是微小的東西也足以成為禍害，即使是珍奇的東西也不足以帶來快樂。老子說：「繽紛的色彩使人眼花，紛雜的音樂使人耳聾，豐美的滋味使人味覺敗壞，縱馬打獵使人心神狂蕩。」然而聖人並沒有廢棄這四樣東西，也只是姑且藉它們寄託心意罷了。劉備有雄才大略，卻喜歡編織毛物；嵇康曠達，卻喜歡打鐵；阮孚放達，卻喜歡給木屐上蠟。這些事難道有什麼聲色滋味嗎？他們卻樂在其中，終身不厭倦。
大凡可喜的事物，足以使人愉悅卻不足以改變人心志的，沒有比得上書法和繪畫的了。然而到了沉迷其中而放不下的地步，那禍害就說也說不完了。鍾繇甚至為此吐血、挖人墳墓；宋孝武帝和王僧虔甚至為此互相猜忌……，都是因為兒戲般的事情危害了國家、禍及自身。這就是「留意」的禍害。
當初我年輕的時候，曾經喜好這兩樣東西，家裡有的，唯恐失去；別人有的，唯恐人家不給我。後來自己笑自己說：我看輕富貴卻看重書法，輕視生死卻看重繪畫，豈不是顛倒錯亂、喪失本心了嗎？從此不再沉迷。看到喜歡的雖然有時也還收藏，但被人拿走了，也不再覺得可惜。就好比煙雲從眼前飄過、百鳥的鳴聲傳入耳中，怎會不欣然接受呢？然而它們離去了，也就不再掛念。於是書和畫這兩樣東西，常常成為我的快樂，卻不能成為我的禍患。

下文「寓意於物……為樂」「留意於物……為病」決定前兩格為「寓意／留意」；「薄富貴而□於書，輕死生而重於畫」以「薄↔厚、輕↔重」成對，末格為「厚」。
@logic
1. 【前兩格：看緊接的解釋】首句說「可以□□」「不可以□□」，下文立刻解釋：「寓意於物」→ 足以為樂、不足以為病（好）；「留意於物」→ 足以為病（壞）。好的配「可以」，壞的配「不可以」→ 寓意／留意。刪 (A)(C)。
2. 【第四格：看對偶】「吾薄富貴而□於書，輕死生而重於畫」兩句結構相同：輕↔重是反義，所以「薄」也要配反義詞 →「厚」。(D) 的「賤」與「薄」同為輕視之意，無法構成「顛倒錯繆」的對比。刪 (D)。
3. 【第三格：驗證】「家之所有，惟恐其失之；□之所有，惟恐其不吾予也」——「家」指自己家，相對的是別{k:人}；「不吾予」是「不給我」，東西在別人手上才說得通。
4. 【結論】寓意／留意／人／厚，選 (B)。
@ana A x

@ana B o
- 寓意／留意：與下文兩組對比句及第二段「留意之禍」一致。

- 厚：「薄富貴而厚於書」與「輕死生而重於畫」對偶，意為看輕富貴卻看重書法。

前三格大致可通（「世之所有」雖不如「人」與「家」對得工整），但第四格「賤於書」是「輕視書法」，與「薄富貴」同方向，句子變成「看輕富貴也看輕書法」，就談不上「顛倒錯繆失其本心」了。
@trap

@know 文言常見的反義對舉

- 輕／重：輕重緩急、避重就輕、舉足輕重。

@key
「然去而不復念也」的「去」是離去、消逝——煙雲飄過、鳥聲遠去，並不是「回去」；病（禍害）、移（改變）、勝（盡）三項解釋皆正確。
@logic
1. 【審題】選「解釋錯誤」者。把每個解釋代回原句，看通不通。
2. 【A】「雖尤物不足以為病」與上句「足以為樂」相對，樂的反面是禍患 →「禍害」可通。
3. 【B、C】「足以悅人而不足以移人」：能讓人喜悅卻不至於改變人的心志 →「改變」可通；「其禍有不可勝言者」＝禍害多到說不盡 →「盡」可通。
4. 【D】主語是「煙雲」「百鳥（之聲）」，它們經過眼前耳畔之後是「離開、消失」，無所謂「歸去」。文言的「去」本義就是{k:離開}，選項解為「歸去」是添字誤釋。
@ana A o
病：禍害、憂患。此句與「雖微物足以為樂」相對——樂是好處，病是壞處。文末「常為吾樂而不能為吾病」同義。解釋正確。
@ana B o
移：改變、動搖（人的心志）。如《孟子‧滕文公下》「貧賤不能移」。蘇軾此句化用《左傳》「夫有尤物，足以移人」，意思是書畫能使人愉悅，卻不像聲色之類足以改變人的性情。解釋正確。
@ana C o
勝：音ㄕㄥ，盡、完全。「不可勝言」即說不完，同「不可勝數」「不勝枚舉」。解釋正確。
@ana D x
去：{k:離去、消逝}。原句說煙雲從眼前飄過、鳥鳴傳入耳中，當下欣然接受；等它們離開了，也就不再掛念。「去」是「離開此處」，沒有「回到原處」的意思，解為「歸去」不當，為本題答案。
@trap

| 發言 | 內容 | 言外之意 |

@logic
1. 【回到語境】題幹強調「按照上下文意」。上文太宗問「朕有不善，卿必記之耶」，暗示希望不被記；遂良答「君舉必記」。所以劉洎口中「遂良不記」的情況，只可能來自{k:君主的要求}，不會是遂良自己不想記。
2. 【拆解字詞】設令：假使（讓）；不記：不記錄（君之不善）；之：指君主的不善之事。
3. 【刪去】(A)「不想記」把原因歸給遂良，與「臣職當載筆」矛盾；(B)「不聽令而記下」把「不記」變成「記」，意思相反。
4. 【比較 C、D】(C)「不需再去記載」像是免去遂良的記錄工作，而且後半「記載它」的「它」沒有著落；(D)「（被）強迫不去記載的事」說明了外力來源，也交代了被記的對象。依語境選 (D)。
@ana A x
「不想記」是遂良主觀意願。但遂良剛說「臣職當載筆，君舉必記」，立場是一定要記；劉洎設想的是「如果他被要求不記」，並非他不想。錯在主觀意願的歸屬。
@ana B x
原句是「遂良{k:不記}」，此項卻說成「不聽令而{k:記下}」，把否定變成肯定；而且若遂良已經記下，後句「天下之人皆記之」就失去「即使……也……」的讓步意味。
@ana C x

@ana D o
此項把語境補足：有人（君主）施加壓力，使褚遂良不去記載某些事（君主的不善），但那些事天下人都會記住。雖然「強迫」比原文的「令」語氣重，也未譯出「設」的假設語氣，但在四個選項中，它最能呼應上文太宗的提問與劉洎進言的用意，為官方答案。
@trap
- 本題有討論空間。「設令」在文言中通常是同義複詞，作假設連詞「假使、假如」解，(C) 的「假設讓」其實比 (D) 的「強迫」更貼近字面；若只看單句翻譯，不少人會選 (C)。
- 官方參考答案為 (D)。可以這樣理解命題者的取捨：題幹要求「按照上下文意」，(C)「不需再去記載」偏離了「君主不願過失被記」的語境，(D) 則保留了「上位者使之不記」與「所記之事」兩個要素。

@logic
1. 【審題】題目說三則出自同一類篇目，要找的是三則的{k:交集}。
2. 【歸納】甲：九歲孩童以瞳子為喻答月亮之問；乙：兩少年對皇帝問汗；丙：成年的鄧艾回應上司戲弄。共同點＝{k:對答巧妙}。

@ana A x
夙慧：夙，早；指{k:幼年即聰明過人}（《世說新語》原篇名作「夙惠」）。甲則徐孺子九歲、乙則鍾氏兄弟十三歲，確有早慧色彩；但丙則鄧艾已是成年武將，故三則無法同歸此篇。
@ana B x

@ana C o

@ana D x

@trap

@cols 1
@key
鄧艾被取笑口吃，引《論語》「鳳兮鳳兮」說明連呼兩聲仍是一鳳，既解圍又自比為鳳；(A) 誤把比喻當實事，(B)(C) 弄錯出汗與否的原因。
@logic
1. 【A：分清本體與喻體】徐孺子說「譬如人眼中有瞳子」，「譬如」表示這是比喻：月中有物就像眼中有瞳孔。他談的是月亮為何明亮，不是用瞳孔看月亮。
2. 【B：找原因】鍾毓自己說明出汗的原因是「戰戰惶惶」（恐懼不安），文中沒有「急促匆忙」。
3. 【C：看本人說法】鍾會說「戰戰慄慄，汗不得出」，表示自己同樣戰慄，甚至緊張到汗都出不來，並非不戒慎。
4. 【D：確認】晉文王戲問「定是幾艾」，鄧艾以《論語》典故回應，化解被嘲弄的尷尬，敘述正確。
@ana A x
原文是有人問「月中若無物，是否更明亮」，徐孺子反駁「不然」，並以「眼中有瞳子，無此必不明」作{k:類比}：瞳孔之於眼睛，如同月中之物之於月亮，有了它才明亮。選項把喻體（瞳子）誤解成觀月的工具，並曲解成「體察月光」。
@ana B x
「戰戰惶惶，汗出如漿」：因為面見皇帝而恐懼惶恐，所以汗流如漿。出汗的原因是{k:敬畏緊張}，不是趕路匆忙。
@ana C x
鍾會的回答「戰戰慄慄」與兄長的「戰戰惶惶」同義，都是恐懼戒慎；他把「不出汗」解釋為緊張到汗都不敢（不得）冒出來。所以不能由無汗推論他不戒慎——這正是他回答的巧妙之處。
@ana D o
「鳳兮鳳兮」出自《論語‧微子》楚狂接輿之歌。歌中連呼兩次「鳳兮」，指的只是一隻鳳（比喻孔子）；鄧艾藉此說明自己說「艾艾」也只是一個艾。{k:引用經典}顯示學識，{k:即時回應戲弄}顯示機敏，還巧妙地以鳳自比，正確。
@trap
(C) 的陷阱是用「常理」取代「文本」：一般人不流汗代表不緊張，但鍾會偏偏說「因為太緊張所以不流汗」。閱讀題要以{k:文中人物自己的說法}為依據，不可用生活經驗推翻原文。
@know 「鳳兮鳳兮」的出處
> 楚狂接輿歌而過孔子曰：「鳳兮！鳳兮！何德之衰？往者不可諫，來者猶可追。已而！已而！今之從政者殆而！」（《論語‧微子》）
- 楚國的隱士接輿以「鳳」比喻孔子，感嘆世道衰微，勸孔子不要再奔走從政。
- 成語「{k:來者可追}」即出於此；陶淵明〈歸去來辭〉「悟已往之不諫，知來者之可追」也化用這兩句。
@know 類比論證：徐孺子怎麼反駁？
| 項目 | 本體 | 喻體 |
| 整體 | 月亮 | 眼睛 |
| 其中之物 | 月中之物（傳說中的桂樹、玉兔等陰影） | 瞳子（瞳孔） |
| 結論 | 有物才明 | 無瞳子必不明 |
- 對方的假設是「東西少一點比較亮」；徐孺子找出一個{k:結構相同、結論相反}的例子，一句話就駁倒對方。這種以相似事物說理的方法稱為{k:類比}，在《孟子》《莊子》中極為常見。
@know 「戰戰」相關詞語
- {k:戰戰兢兢}：恐懼謹慎的樣子，語出《詩經‧小雅‧小旻》「戰戰兢兢，如臨深淵，如履薄冰」。

- {k:惶惶}：恐懼不安，如「人心惶惶」「惶惶不可終日」。
- 乙則兩人的回答各自押韻（惶、漿；慄、出），可見是脫口而出的{k:韻語}，更顯才思敏捷。

@ana A x

@ana C x

@know 拉瓦謝是誰？
- 拉瓦謝（Antoine Lavoisier，1743–1794），法國化學家，被稱為「近代化學之父」。
- 主要貢獻：以精確的定量實驗提出{k:氧化學說}，推翻當時流行的「燃素說」；確立{k:質量守恆定律}；為氧、氫等元素命名並建立化學命名系統。
- 他同時擔任徵稅機構的包稅人，法國大革命期間因此被捕，1794 年被送上斷頭臺。相傳數學家拉格朗日感嘆：砍下這顆頭只要一瞬間，但再長出一顆這樣的頭，也許一百年都不夠。
- 補充：文中說他「以硃砂做實驗」。科學史上一般的記載是加熱汞的紅色氧化物（氧化汞）而得到氧氣；「硃砂」在礦物學上則指硫化汞。閱讀測驗仍以文本敘述為準。
