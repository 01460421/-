- **基礎題「一題一考點」，涵蓋面廣**：十題就考了十種題型，沒有重複。其中第 4 題對聯填字、第 7 題以「劉備寫信」包裝的應用文、第 10 題轉品，都是把課本知識放進新情境，死背規則不夠，要會判斷。
- **疫情入題，緊扣時事**：109 學年度甄選正值新冠肺炎爆發，第 15 題選陳克華的疫情詩，第 16–17 題選 1793 年費城黃熱病的醫學史散文，考「文學如何回應時代」與「人能否戰勝疾病」的反思。
- **科普、數理文本占題組四成**：乳酪凝結的生物化學（22–23）、烤吐司的比值公式（24–25）都要求讀懂「機制」與「變因」，第 24 題甚至直接考分子、分母的增減，是科學班國文卷的招牌題型。
- **文言取材經典而重對讀**：《莊子》寓言、蘇軾筆記、儒法道三家語錄辨派、鍾嗣成散曲各一題；《世說新語》則以三則故事並讀同一人物（王藍田），考「綜合評價」而非單句翻譯。
- **重視「評價與立場」**：第 16、17、20、25 題的題幹都是「最適切客觀」「作者的理念」，選項多半「部分正確」，要選的是最周全、最貼近全文立場的一個。
@tips
- 每題 4 分，基礎題不容失手：前 10 題用 8–10 分鐘穩穩拿下，字音、錯別字、書信用語靠平日整理成表，考前反覆看。
- 題組一律「先看題目、再讀文章」：帶著「（甲）（乙）要填什麼」「條件是指什麼」去找答案，科普文邊讀邊畫因果箭頭（原因 → 機制 → 結果）。
- 遇到「最客觀」「作者理念」的題目，先刪去只講一半的選項（只褒或只貶、只根據其中一段），再比剩下的哪一個能涵蓋全文。

@opt A

@opt C

@note blue

@opt D

@key

@logic
1. 【審題】題目比的是「字音」。四組都是{k:聲符相同的形聲字}（莫、平、辱、此），命題者要考的正是「有邊讀邊」會出錯的地方。
2. 【逐字標音】利用熟悉的詞語幫忙：驀然回首（ㄇㄛˋ）、民瘼（ㄇㄛˋ）；怦然（ㄆㄥ）、浮萍（ㄆㄧㄥˊ）；繁縟（ㄖㄨˋ）、耨（ㄋㄡˋ）；齜牙（ㄗ）、瑕疵（ㄘ）。
3. 【比對】(B) 韻母不同（ㄥ／ㄧㄥ）、聲調不同；(C) 聲母、韻母全不同；(D) 只差在聲母ㄗ／ㄘ，最容易混淆。
4. 【結論】只有 (A) 完全同音。
@ana A o
「驀」然回首：驀，ㄇㄛˋ，忽然、突然。語出辛棄疾〈青玉案‧元夕〉：「眾裡尋他千百度，驀然回首，那人卻在燈火闌珊處。」
關心民「瘼」：瘼，ㄇㄛˋ，病痛、疾苦，所以是「疒」部。「民瘼」即人民的疾苦。
→ 兩字同讀ㄇㄛˋ，為正解。
@ana B x
「怦」然心動：怦，ㄆㄥ，心跳動的樣子。「怦然心動」指對某事物產生了興趣或心動。
「萍」水相逢：萍，ㄆㄧㄥˊ，浮萍。浮萍隨水漂流、聚散不定，比喻素不相識的人偶然相遇，語出王勃〈滕王閣序〉：「萍水相逢，盡是他鄉之客。」
→ ㄆㄥ ≠ ㄆㄧㄥˊ。
@ana C x
繁文「縟」節：縟，ㄖㄨˋ，繁多、繁瑣。指繁瑣的儀式與禮節。
深耕易「耨」：耨，ㄋㄡˋ，除草（也指除草的農具）。語出《孟子‧梁惠王上》，指深耕土地、勤除雜草，盡力耕作。
→ ㄖㄨˋ ≠ ㄋㄡˋ。「耨」最常被誤讀成ㄖㄨˋ。
@ana D x
「齜」牙咧嘴：齜，ㄗ，張嘴露出牙齒。形容凶狠，或因疼痛、驚恐而面部扭曲的樣子。
吹毛求「疵」：疵，ㄘ，毛病、缺點。吹開皮上的毛去找小毛病，比喻刻意挑剔，語本《韓非子‧大體》：「不吹毛而求小疵。」
→ ㄗ ≠ ㄘ。
@trap
(D) 是最大的陷阱：「齜」「疵」都以「此」為聲符，聲調也同為一聲，只差在聲母ㄗ（不送氣）與ㄘ（送氣）。平時把「齜牙咧嘴」唸成「ㄘ牙咧嘴」的人，就會誤選 (D)。

@cat 形音義

@note red
先圈{c:成語}，再查一般詞語
同音字最容易藏錯
@opt A
人非聖賢，孰能無過？只要坦{x:誠}{n:承}錯誤，改過自新，終{x:就}{n:究}會得到他人的原諒
@note blue
坦承（動詞）＋錯誤
坦誠（形容詞）不接賓語
@opt B
看著劇中壞蛋趨炎{x:赴}{n:附}勢，橫刀奪愛，即便{x:腦}{n:惱}恨編劇虐心，卻還是天天追劇
@note blue
附＝依附；惱＝生氣
@opt C
王老闆年輕時就離鄉背{x:景}{n:井}到台北奮鬥，經過無數挫折艱難，終於鴻圖大展
@note blue
井＝鄉里、家鄉
@opt D
選舉時，各候選人皆使出{g:渾身解數}攻擊異己，可真是{g:爾虞我詐}，{g:針鋒相對}
@note red
三個成語都沒錯 ✓
@key
(A) 坦「承」、終「究」；(B) 趨炎「附」勢、「惱」恨；(C) 離鄉背「井」；只有 (D) 的渾身解數、爾虞我詐、針鋒相對全部正確。
@logic
1. 【先抓成語】把四句的四字格圈出來：人非聖賢、改過自新／趨炎赴勢、橫刀奪愛／離鄉背景、鴻圖大展／渾身解數、爾虞我詐、針鋒相對。
2. 【以義辨形】趨炎「附」勢是「依附」權勢，不是「奔赴」；離鄉背「井」的「井」指家鄉，與「背景」無關 → (B)(C) 出局。
3. 【再查一般詞語】(A) 沒有成語錯字，錯在{k:同音詞}：「坦誠」是形容詞（態度坦誠），後面不能接賓語；「坦白承認錯誤」要用動詞「坦承」。「終就」應為「終究」。
4. 【確認正解】(D) 三個成語逐字檢查皆無誤。
@ana A x
錯兩處：
坦「誠」錯誤 → 坦「{k:承}」錯誤。坦承：坦白承認（動詞）；坦誠：坦白真誠（形容詞，如「坦誠相待」）。
終「就」→ 終「{k:究}」。終究：到底、畢竟；究，窮盡、到底。
@ana B x
錯兩處：
趨炎「赴」勢 → 趨炎「{k:附}」勢。炎，比喻有權勢的人；附，依附。指奉承、依附權貴。
「腦」恨 → 「{k:惱}」恨。惱恨：惱怒怨恨，與心情有關，故為「心」部；「腦」是器官。
「虐心」是網路流行語（指劇情令人揪心），不算錯別字。
@ana C x
離鄉背「景」→ 離鄉背「{k:井}」。背，離開；井，指鄉里（古代聚井而居，如「市井」）。離鄉背井指離開故鄉到外地生活，也作「背井離鄉」。
「鴻圖大展」用字正確（鴻圖：遠大的志向或計畫）。
@ana D o
全句無錯別字。
渾身解數：解數本指武術的招式，「渾身解數」指使出全身所有的本領。不可寫作「混身」「解術」。
爾虞我詐：虞，欺騙。彼此互相欺騙、鉤心鬥角，語本《左傳‧宣公十五年》「我無爾詐，爾無我虞」。不可寫作「爾愚我詐」。
針鋒相對：針尖對著針尖，比喻雙方言論或行動尖銳對立。
@trap

=== Q 3
@type 文言字詞義辨析
@cat 形音義
@tags 字義, 虛詞, 詩文名句
@diff 3
@answer B
@stem
下列各組文句「 」內的詞義，{y:前後相同|用「代換法」}的是：
@note red
找一個解釋同時{c:代入}
前後句，都通才相同
@opt A
王師北定中原日，家祭無忘告「乃」{nb:你的}翁／人之巧「乃」{nb:竟然}可與造化者同功乎
@note blue
乃翁＝你的父親
後句是驚嘆語氣 → 竟
@opt B
故人「具」{n:準備}雞黍，邀我至田家／特「具」{n:準備}小酌，敬邀兄長到寒舍共賞明月
@note red
都是「準備、備辦」✓
@opt C
一室「之」{nb:助詞，無義}不治，何以天下國家為／醉翁「之」{nb:的}意不在酒，在乎山水之間也
@note blue
主語＋之＋謂語
→ 之不翻譯
@note purple
〈習慣說〉原文作「天下家國」
@opt D
明月照積雪，北風勁「且」{nb:又}哀／持杯復更勸花枝，「且」{nb:姑且}願花枝常在莫披離
@note blue
A 且 B（形容詞並列）
@note purple
謝靈運原詩作「朔風」
@cols 1
@key
兩個「具」都是「準備、備辦」；「乃」是你的／竟然，「之」是無義助詞／的，「且」是而且／姑且，意義都不同。
@logic
1. 【代換法】字義題的標準作法：先解出前一句的意思，再把同一個解釋代入後一句，讀得通才算相同。
2. 【A】「乃翁」是「你的父親」（代詞）；代入後句「人之巧『你的』可與…」不通，後句是「竟然」（副詞）。
3. 【B】「具雞黍」是「準備雞和黍飯」；代入後句「特地『準備』小酌」完全通順 → 相同。
4. 【C、D 看詞性】(C) 前句「之」夾在主語「一室」與謂語「不治」之間，無實義；後句「醉翁之意」是「的」。(D) 前句「勁且哀」連接兩個形容詞，是「又、而且」；後句「且願」在動詞前，是副詞「姑且」。
@ana A x
家祭無忘告「乃」翁：乃，{k:你的}（第二人稱代詞）。出自陸游〈示兒〉，叮囑兒子在朝廷軍隊收復中原那天，祭祀時別忘了告訴父親。
人之巧「乃」可與造化者同功乎：乃，{k:竟然}（副詞）。出自《列子‧湯問》，周穆王見到工匠偃師所造、能歌善舞的木偶後驚嘆：人的技巧竟然可以和造物主有同樣的功效啊！
→ 你的 ≠ 竟然。
@ana B o
故人「具」雞黍：具，{k:準備、備辦}。出自孟浩然〈過故人莊〉，老朋友準備了豐盛的飯菜，邀請我到他的田家作客。
特「具」小酌：具，{k:準備}。現代請柬、邀約便條的常用語，「具」即備辦（酒菜）。
→ 意義相同，為正解。
@ana C x
一室「之」不治：之，{k:結構助詞}，放在主語和謂語之間，使「一室不治」變成不獨立的分句，無實義，不必翻譯。出自清代劉蓉〈習慣說〉：一間屋子都整理不好，還談什麼治理天下國家呢？（「何以…為」是表反問的固定句式。）

→ 無義 ≠ 的。
@ana D x
北風勁「且」哀：且，{k:又、而且}（連詞，連接「勁」與「哀」兩個形容詞）。出自南朝宋謝靈運〈歲暮〉，原句作「朔風勁且哀」：北風又強勁又淒厲。

@translation
(A) 朝廷軍隊向北收復中原的那一天，家祭時不要忘記告訴你們的父親。／人的技巧竟然可以和造物者有同樣的功效啊！
(B) 老朋友準備了雞和黃米飯，邀請我到他鄉下的家。／特地備辦薄酒，敬邀兄長到寒舍一同賞月。
(C) 一間屋子都不能整治，還憑什麼治理天下國家呢？／醉翁的心意不在酒，而在山水之間。
(D) 明月照著積雪，北風又強勁又淒厲。／舉起酒杯再勸花枝，但願花兒長久開放，不要凋落離散。
@trap
(D) 兩句的「且」都可以用白話的「且」含混帶過，容易誤以為相同。訣竅是看它{k:連接什麼}：夾在兩個形容詞之間（勁、哀）是並列連詞；放在動詞（願）之前則是副詞。

同位置、{c:同詞性}

@opt B

@key
對聯上下聯同位置的字詞性要相同：「皆」對「總」、「才」對「半」、「反」對「真」，且「才入戶→半垂堤」「不報→反成仇」文意最順。
@logic
1. 【對仗定位】對聯的上、下聯字數相等，相同位置的字詞性相同。三個空格都在第五字，對應的另一聯第五字分別是：甲「總」、乙「半」、丙「真」。
2. 【甲】下聯「桃李盈門{k:總}是春」，「總」是範圍副詞（全、都），上聯應填同義的「皆」：芝蘭滿徑「皆」成趣。若填「反」，「反成趣」語意不通 → 刪 (C)(D)。
3. 【乙】只剩「才」或「反」。昨夜春風「才」入戶，今朝楊柳已「半」垂堤——「才…（就）…」寫春天來得快，文意通順；「春風反入戶」不知所云 → 刪 (B)。
4. 【丙驗證】「洪恩不報{k:反}成仇」：受人大恩不但不回報，反而成了仇人，「反」表轉折，並與上聯副詞「真」相對。答案 (A)。
@ana A o
皆／才／反：
甲「皆成趣」對「總是春」，副詞對副詞。
乙「才入戶」對「半垂堤」，以「才」寫時間之短，襯出「半垂堤」春意之盛。
丙「真可法」對「反成仇」，「反」字點出忘恩負義的轉折。
三處皆合。
@ana B x
甲填「皆」正確，但乙、丙對調：「昨夜春風{k:反}入戶」沒有可以「反」的前提，語意不通；「洪恩不報{k:才}成仇」變成「因為不報恩才結仇」，失去原聯「恩將仇報」的諷刺力道。
@ana C x
甲填「反」：「芝蘭滿徑反成趣」暗示芝蘭滿徑本來不該有趣，與吉祥聯語的語氣不合，也無法和「總」相對。丙填「皆」：「洪恩不報皆成仇」語意牽強。
@ana D x
甲填「反」已誤（理由同 C）；乙填「皆」：「昨夜春風皆入戶」不合情理，也與「半」的程度義不相對。
@translation
甲：芝草蘭花長滿小徑，處處都有意趣；桃樹李樹（比喻學生、後進）站滿門庭，時時都是春天。
乙：昨夜春風才剛吹進門戶，今天早晨堤上的楊柳就已經垂下了一半的枝條。
丙：歷史的借鑑流傳下來，真值得效法；浩大的恩德不知回報，反而結成了仇。

@know 「芝蘭」與「桃李」的文化意涵
- {k:芝蘭}：香草，比喻德行高潔或優秀的子弟。成語「芝蘭玉樹」出自《世說新語‧言語》，謝玄說希望好子弟像芝蘭玉樹一樣生長在自家庭階前。
- {k:桃李}：比喻所教的學生，如「桃李滿天下」；「桃李不言，下自成蹊」（《史記‧李將軍列傳》）則比喻為人真誠，自然受人敬仰。
- 因此甲聯以「芝蘭」「桃李」並舉，適合用來祝賀教師或書香門第。

@note blue

→ 刪 (D)
@note green

@opt A

@opt B

@opt C

@key

@logic
1. 【定結尾】題幹末句以「並」開頭，表示承接上一句的動作；「一段或一頁」指寫下的文字，所以前一句一定是（戊）「…化為文字」。四個選項的結尾分別是甲、戊、丁、甲 → 只有 (B) 以戊收尾。
2. 【驗開頭】首句「依舊茫然，」之後，（丁）「{k:如}那時我站在孟加拉灣面對陌生的大海」用比喻說明茫然的感覺，（乙）「不知道下一步該何去何從」再把「茫然」說破 → 丁乙相連。
3. 【驗中段】（丙）「{k:然後}，我…沿著恆河走」表示行動開始；（甲）「走到哪，就算到哪」承「走」字而來 → 丙甲相連。

@ana A x
「丁戊丙乙甲」：以丁開頭正確，但（戊）「每天想起甚麼，便…化為文字」緊接在「面對陌生的大海」之後，還沒出發就先寫作，順序顛倒；結尾（甲）「走到哪，就算到哪」也接不上「並鮮少再回頭檢視…一段或一頁」。
@ana B o

@ana C x

@ana D x

@know 排序題的解題步驟
| 步驟 | 做法 | 本題應用 |
| ① 看題幹頭尾 | 首句、末句是免費的線索 | 末句「並…一段或一頁」→ 戊在最後 |
| ② 找連接詞 | 然後、於是、但是、並、而 等不能當開頭 | 丙「然後」不在句首 |
| ③ 找比喻、指代 | 「如…」「這…」「那…」要有說明或指涉的對象 | 丁「如那時…」說明「茫然」 |
| ④ 找詞語接力 | 上句的詞在下句再出現（頂真式銜接） | 丙「沿著恆河走」→ 甲「走到哪」 |
| ⑤ 用選項刪去 | 不必自己排，檢查選項即可 | 定了尾巴就只剩 (B) |

=== Q 10
@type 轉品修辭與詞類活用
@cat 語文應用
@tags 轉品, 詞類活用, 名詞作動詞
@diff 3
@answer C
@stem
行文時，把一個詞彙原來的詞性轉變為其他詞性，稱之為轉品修辭。例如〈馮諼客孟嘗君〉：「孟嘗君客我」，「客」本意是客人，此處名詞當動詞使用，解釋為「以……為客」。下列「 」內的字詞，屬於{y:名詞當動詞|兩個條件}使用的是：
@note red
①原本是{c:名詞}
②句中當{c:動詞}（謂語）
@opt A
庭有枇杷樹，吾妻死之年所「手」{nb:親手}{u:植}也，今已亭亭如蓋矣
@note blue
手＋植（動）
→ 名詞當副詞
@opt B
有「席」{nb:像捲蓆子般}{u:捲}天下，包舉宇內，囊括四海之意，併吞八荒之心
@note blue
席＋捲（動）
→ 名詞當副詞
@opt C
巫、醫、樂師、百工之人，君子{c:不}「齒」{n:並列、同列}，今其智乃反不能及
@note red
副詞「不」＋齒
→ 齒是動詞 ✓
@opt D
三十功名塵與土，八千里路雲和月。莫等閒，「白」{nb:變白}了少年頭
@note blue
白原是{u:形容詞}
→ 形容詞當動詞
@key
「不齒」的「齒」本是名詞（牙齒），前有副詞「不」修飾，活用為動詞「並列」；「手」「席」是名詞當副詞，「白」是形容詞當動詞。
@logic
1. 【審題】題幹要求兩個條件同時成立：原本是{k:名詞}，在句中當{k:動詞}。所以每個選項都要問兩件事：它本來是什麼詞？它在句中做什麼用？
2. 【看後面接什麼】(A)「手」後面接動詞「植」、(B)「席」後面接動詞「捲」——名詞放在動詞前面修飾動詞，是當{k:副詞}（狀語）用，表示「用什麼方式」。
3. 【看前面有什麼】(C)「齒」前面有否定副詞「不」。副詞只能修飾動詞或形容詞，所以「齒」在這裡是動詞。
4. 【查本來詞性】(D)「白」的確當動詞用（使…變白），但它本來是形容詞，不合條件①。
5. 【結論】只有 (C) 是名詞 → 動詞。
@ana A x
出自歸有光〈項脊軒志〉。「手」本是名詞，此處放在動詞「植」之前，表示「親手」種植，是{k:名詞當副詞}（文言語法稱「名詞作狀語」）。
語譯：庭院中有一棵枇杷樹，是我妻子去世那年親手種的，如今已經高高挺立、枝葉茂盛得像傘蓋一樣了。
@ana B x
出自賈誼〈過秦論〉。「席」本是名詞（草蓆），此處修飾動詞「捲」，表示「像捲蓆子一樣」地捲取，是{k:名詞當副詞}。同句的「囊括」的「囊」（像用口袋裝）也是相同用法。
語譯：（秦孝公）有席捲天下、統括宇內、囊括四海的意圖，併吞八方的野心。
@ana C o
出自韓愈〈師說〉。「齒」本是名詞（牙齒）；牙齒並排而生，引申為「並列、同列」。「不齒」即{k:不屑與之同列}，表示鄙視。此處「齒」作謂語，前有副詞「不」，是{k:名詞當動詞}，為正解。
語譯：巫師、醫生、樂師和各種工匠，是士大夫所不屑與之並列的，如今士大夫的見識竟然反而比不上他們。
@ana D x
出自岳飛〈滿江紅〉。「白」本是形容詞，此處後接「了」和賓語「少年頭」，意為「使…變白」，是{k:形容詞當動詞}，不合「名詞」的條件。
語譯：三十年來的功名如同塵土，八千里路的征戰伴著雲和月。不要隨便虛度光陰，等到少年的頭髮白了（才空自悲傷）。
@trap
「名詞當動詞」與「名詞當副詞」最容易混淆。口訣：{k:名詞後面緊跟著動詞 → 它是副詞}（手植、席捲、蠶食、鯨吞、瓦解、雲集、蜂擁）；{k:名詞前面有副詞或後面帶賓語 → 它是動詞}（不齒、客我、衣錦還鄉的「衣」）。
@know 文言常見的詞類活用（轉品）
| 類型 | 判斷特徵 | 例句 |
| 名詞 → 動詞 | 前有副詞／能願動詞，或後帶賓語 | 君子不「齒」（〈師說〉）；孟嘗君「客」我；「衣」錦還鄉；假舟楫者，非能「水」也（《荀子‧勸學》） |
| 名詞 → 副詞 | 名詞在動詞之前，表方式、狀態 | 「手」植；「席」捲；「蠶」食「鯨」吞；其一「犬」坐於前（蒲松齡〈狼〉） |
| 形容詞 → 動詞 | 形容詞後帶賓語 | 「白」了少年頭；春風又「綠」江南岸（王安石〈泊船瓜洲〉）；親「賢」臣，「遠」小人（〈出師表〉） |
| 形容詞 → 名詞 | 形容詞作主語或賓語 | 披「堅」執「銳」；乘「堅」策「肥」 |
| 動詞 → 名詞 | 動詞作主語或賓語 | 殫其地之「出」，竭其廬之「入」（柳宗元〈捕蛇者說〉） |
@know 使動用法與意動用法
| 用法 | 意義 | 例句 | 語譯 |
| 使動 | 主語「使」賓語怎麼樣 | 春風又「綠」江南岸 | 春風又使江南岸變綠 |
| 使動 | 同上 | 「生」死人，「肉」白骨 | 使死人復生，使白骨長肉 |
| 意動 | 主語「認為／把」賓語當作什麼 | 孟嘗君「客」我 | 孟嘗君把我當作門客 |
| 意動 | 同上 | 不獨「親」其親，不獨「子」其子（《禮記‧禮運》） | 不只把自己的父母當父母、把自己的子女當子女 |
- 題幹的「孟嘗君客我」解釋為「以……為客」，就是{k:意動用法}。
@know 「齒」的引申義
- 本義：牙齒。→ 因馬、牛的牙齒隨年齡增長，引申為{k:年齡}：「齒德俱尊」「馬齒徒長」。
- 牙齒整齊排列 → 引申為{k:並列、同列}：「不齒」「齒列」。
- 說話要用到齒 → 引申為{k:談到、提及}：「何足掛齒」「難以啟齒」。

1. 【找招牌詞】各家都有「一看就知道」的關鍵詞：甲「{k:性惡}」「禮義」；乙「明主」「{k:刑、德}（賞罰）」「人主」「群臣」；丙「{k:柔弱勝剛強}」。
2. 【甲】主張性惡的是荀子。荀子雖然講性惡，但解決方法是「師法之化、禮義之道」，重視教育與禮，仍是{k:儒家}。→ 刪 (B)(D)。
3. 【乙】全段站在「君主如何控制臣下」的角度，手段是賞與罰，這是{k:法家}的統治術。→ 選 (C)。
4. 【丙驗證】「將欲…必固…」是「物極必反」的辯證思維，「柔弱勝剛強」是老子名言，為{k:道家}。
@ana A x
甲為儒家正確，但乙、丙對調。乙講賞罰二柄，是法家而非道家；丙講柔弱勝剛強，是道家而非法家。
@ana B x
甲並非法家。雖然文中出現「法度」「性惡」，但荀子強調以{k:禮義、師法}教化人性，屬於儒家；乙講刑賞，也不是儒家——儒家主張「道之以德，齊之以禮」（《論語‧為政》），反對只靠刑罰治民。
@ana C o
甲：《荀子‧性惡》——儒家。
乙：《韓非子‧二柄》——法家。
丙：《老子》第三十六章——道家。
三者皆正確，為正解。
@ana D x
三者全部錯位。尤其丙絕非儒家：儒家講剛健有為、「知其不可而為之」，不會主張「柔弱勝剛強」。
@trap

@ana B x

@ana D o

@ana B x

@trap
(C) 與 (D) 的取捨是本題關鍵。(C) 的敘述用來評論這首詩並沒有錯，但題目問的不是「這首詩寫得如何」，而是「對照時空背景，作者為何而寫」。審題時把「{k:對照寫作的時空背景}」圈起來，就不會被 (C) 吸引。另外，詩中也寫到「遠方的每一個人」，視野其實不限於本土；(D) 的重心應放在後半句「歌唱自己生存的時代」來理解。
@know 詩裡的科學：閃電與雷聲的「時間差」
- 閃電和雷聲同時產生，但{k:光速}（約每秒 30 萬公里）遠大於{k:聲速}（空氣中約每秒 340 公尺），所以我們總是先看到閃電、後聽到雷聲。
- 估算法：看到閃電後開始讀秒，秒數 × 340 公尺 ≈ 雷擊的距離。時間差越短，雷離我們越近。
- 詩人借用這個現象：疫情的消息（閃電）先到，真正的衝擊（雷聲）隨後才來——「那時間差令人起疑：究竟／病毒還距離我們多遠？」把物理知識轉化成{k:譬喻}，是知性入詩的好例子。

@know 《紅樓夢》首尾兩首詩

## 把機制畫成流程
- 牛奶（pH 6.5）：微膠粒的多毛層帶負電 → 互相排斥 → 均勻散布（液態）
- 條件①{k:加酸}：pH 降到 5.5，負電荷被中和 → 降到約 4.7，負電荷消失 → 微膠粒互相結合 → 凝固
- 條件②{k:凝乳酶}：剪掉多毛層 → 微膠粒互相結合 → 凝固（不改變味道）
- 凝固之後：{k:不熟成} → 新鮮軟質乳酪（奶油乳酪）；{k:加微生物熟成} → 風味複雜、氣味強烈的乳酪
## 兩種凝乳方法比較
| 項目 | 加酸（酸凝乳） | 凝乳酶 |
| 來源 | 讓牛奶變酸即可 | 牛羊的胃，超市不易取得 |
| 作用 | 中和並去除酪蛋白的負電荷 | 剪掉 k-酪蛋白的多毛層 |
| 對味道的影響 | 帶酸味 | 不改變牛奶的味道 |
| 共同結果 | 微膠粒不再互斥 → 互相結合 → 牛乳凝固 | 同左 |

| 發酵 | 微生物分解有機物的過程 | 優格、麵包、釀酒 |
