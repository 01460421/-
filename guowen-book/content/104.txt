4. 【結論】只有 (B) 三音完全相異。

@ana D x

@cat 形音義

@answer D
@stem
以下各段文句中何者出現的錯別字{y:最少|要「數」每句幾個}？
@note red
原卷「最少」加框
不是找「沒有錯字」
而是{c:比個數}
@opt A
別看他平日對人疾{x:顏}{n:言}厲色，殊不知他為人古道熱腸，急{x:功}{n:公}好義。
@note blue
2 個：言、公
@opt B
航行遠洋的大船，{x:既}{n:即}使在狂風{x:劇}{n:巨}浪中顛{x:跛}{n:簸}，船頭的羅盤針卻永遠指著不變的方向。
@note blue
3 個：即、巨、簸
@opt C
感謝你{ub:專誠|辭典有收}搭機來臺，為我的新畫廊剪{x:彩}{n:綵}，我備感榮幸。
@note blue
至少 1 個：綵
@opt D
他{g:寧死不屈}，就算{g:株連}親族也不肯{g:委屈}認罪。
@note red
0 個 ✓ 最少
@key
逐句清點：(A) 疾言厲色、急公好義，2 個；(B) 即使、巨浪、顛簸，3 個；(C) 剪綵，至少 1 個；(D) 全句無誤，0 個，錯別字最少。
@logic
1. 【審題】題目不是問「哪一句沒有錯字」，而是「哪一句錯字最少」，所以四句都要{k:數出個數}再比較，不能抓到一個錯字就跳下一句。
2. 【鎖定詞語】錯字多藏在成語與常用複詞：疾顏厲色、急功好義、既使、劇浪、顛跛、專誠、剪彩、備感、寧死不屈、株連、委屈。
3. 【以義辨形】「疾言」是說話急迫（言語）；「急公」是熱心公眾之事（公益）；「即使」是假設連詞；「巨浪」是大浪；「顛簸」是上下搖動（竹部的簸）；「剪綵」剪的是綵帶（糸部）。
4. 【比較】A＝2、B＝3、C≧1、D＝0，選 (D)。
@ana A x
疾「顏」厲色 → 疾「{k:言}」厲色：言語急迫、神色嚴厲，形容發怒的樣子。「疾言」對「厲色」，一指說話、一指臉色。
急「功」好義 → 急「{k:公}」好義：熱心公益、樂於助人。「急公」是以公眾的事為急；「急功」則見於「急功近利」（急於求成、貪圖眼前利益）。
共 2 個錯字。
@ana B x
「既」使 → 「{k:即}」使：表示假設讓步的連詞（即使…也…）。「既」表示已經（既然）。
狂風「劇」浪 → 狂風「{k:巨}」浪：巨，大。「劇」是猛烈（劇烈、劇痛），不與「浪」搭配。
顛「跛」 → 顛「{k:簸}」：簸，ㄅㄛˇ，上下搖動。「跛」是腳有殘疾。
共 3 個錯字，為四句中最多。
@ana C x
剪「彩」 → 剪「{k:綵}」：綵是彩色的絲織品，剪綵即剪斷綵帶，教育部辭典作「剪綵」「張燈結綵」。
「專誠」：辭典收有此詞，意為「特地；專心誠意」，與「專程」相通，不算錯字。
「備感」：備，盡、完全；坊間亦見寫作「倍感」（加倍感到），兩種寫法各有支持者。
無論「備感」算不算錯，本句至少有 1 個錯字，仍比 (D) 多。
@ana D o
寧死不屈、株連（一人犯罪而牽連他人）、委屈（受到冤枉、使自己受屈）皆書寫正確，全句沒有錯別字，個數為 0，是四句中最少的，為正解。
@trap
計數型的錯別字題最怕「數到一半就選」。(C) 的「專誠」看起來像「專程」的錯字，其實辭典兩詞並收；「備感／倍感」也有爭議。遇到這種{k:不確定算不算錯}的字，先放著，改比「確定的錯字數」：A 確定 2、B 確定 3、C 確定 1、D 確定 0，答案並不受爭議字影響。
@know 本題五組同音字辨析

| 言 | 說話 | 疾言厲色、正言若反 | 顏：和顏悅色、厚顏 |
| 公 | 公眾 | 急公好義、克己奉公 | 功：急功近利、好大喜功 |
| 即 | 就算、立刻 | 即使、即便、稍縱即逝 | 既：既然、既往不咎、一如既往 |

@know 「綵／彩／采」怎麼分？
| 字 | 本義 | 常用詞語 |
| 綵 | 彩色的絲織品 | 剪綵、張燈結綵、綵帶、綵球 |
| 彩 | 顏色；光榮；負傷 | 彩色、彩排、彩券、掛彩 |
| 采 | 神色、風度；讚美聲 | 風采、神采奕奕、興高采烈、無精打采、喝采、文采 |
- 「精采／精彩」「多采多姿／多彩多姿」辭典皆收，兩寫均可；但「興高采烈」「無精打采」「神采」習慣用「采」。
- 記憶法：有{k:絲帶、布料}可以摸得到的用「綵」；{k:看得到的顏色}用「彩」；{k:人的精神面貌}用「采」。
@know 「委屈」與「委曲」
- {k:委屈}：受到不應有的指責或待遇，心裡難過——受委屈、委屈你了。
- {k:委曲}：①彎曲、曲折——委曲的山路；②事情的底細原委——告知委曲；③勉強遷就——委曲求全。
- 本題「不肯委屈認罪」指不肯讓自己受冤屈而認罪，用「委屈」正確；成語「委曲求全」則固定用「曲」。

- 郁永河，字滄浪，浙江仁和（今杭州）人。清康熙三十六年（1697），因福州火藥庫失火、硝磺焚毀，自願來臺採辦硫磺。
- 他由臺南府城出發，乘牛車沿西部平原北上，抵達北投一帶採硫煉硫，將沿途見聞寫成《裨海紀遊》，又名《採硫日記》，是認識清初臺灣西部地理、原住民生活的重要文獻。
- 「裨海」意為小海，語出《史記‧孟子荀卿列傳》記鄒衍「大九州」之說，此處指臺灣海峽。
- 本題四句出自書中描寫北投硫穴（今北投、陽明山硫氣孔地帶）的段落，以「沸鑊」「怒雷」「驚濤」等比喻寫火山地熱，是臺灣古典散文的寫景名段。

@know 複詞構詞法總表
| 類型 | 兩語素的關係 | 例詞 |
| 並列式 | 地位平等（同義、反義、相關） | 語言、朋友、動靜、是非、俎豆、干戈 |
| 主從式（偏正式） | 前修飾後，重心在後 | 老人、青菜、狂熱、飛快、雪白、輕視 |
| 動賓式（述賓式） | 前為動作，後為對象 | 握手、負責、司機、知音、傷心 |
| 述補式 | 後補充說明前者的結果或趨向 | 說明、打倒、推翻、提高、搖動 |
| 主謂式 | 前為主語，後為陳述 | 地震、年輕、心疼、日蝕、眼花 |
| 附加式 | 詞根加上詞頭或詞尾 | 老虎、阿姨、桌子、石頭、忽然 |
- 以上各類的語素都有意義，合稱{k:合義複詞}；題幹未列的「主謂式」「附加式」也常考，一併記住。
@know 聯綿詞與音譯詞——不能拆開的詞
| 類別 | 特徵 | 例詞 |
| 雙聲聯綿詞 | 兩字聲母相同 | 鞦韆、璀璨、惆悵、參差、彷彿、躊躇、崎嶇 |
| 疊韻聯綿詞 | 兩字韻母相同 | 徘徊、逍遙、窈窕、蹉跎、燦爛、荒唐 |
| 非雙聲疊韻 | 聲韻皆無關 | 蝴蝶、芙蓉、鸚鵡、珊瑚、蜈蚣 |
| 音譯外來詞 | 借音不借義 | 菩薩、剎那、葡萄、邏輯、幽默、沙發 |
- 聯綿詞靠{k:聲音}構成，單字沒有獨立意義，所以常有不同寫法（彷彿／仿佛、徘徊／俳佪）。課本稱這類詞為「衍聲複詞」。
- 本卷第 1 題的「躊躇」就是雙聲聯綿詞。
@know 並列式的三種小類
- {k:同義並列}：兩字意思相同或相近——語言、朋友、道路、奇怪。
- {k:反義並列}：兩字意思相反——動靜、是非、得失、存亡。
- {k:偏義複詞}：形式上是反義並列，實際只取其中一字的意思——「晝夜勤作息」（只取「作」）、「緩急，人之所時有也」（只取「急」）、「國家」（只取「國」）、「窗戶」（只取「窗」）。偏義複詞是文言閱讀的常考點。

(A)《荀子‧修身》：半步半步地走個不停，跛腳的鱉也能走到千里之外；一筐一筐地堆土不停止，高山終究可以堆成。

@logic
1. 【讀懂題幹】孔子說了兩個相反的情境：快完成卻停手（止）→ 失敗；剛開始但持續（進）→ 有望。共同結論是{k:成敗在於是否堅持，而且決定權在自己}（吾止、吾往）。
2. 【轉成關鍵詞】堅持不懈、不可功虧一簣、操之在己。
3. 【逐項歸類】(A) 不休、不輟 → 堅持；(B) 放棄時離成功很近 → 別放棄；(C) 掘井不及泉 → 半途而廢等於白做。三者同屬「恆心」主題。
4. 【找出異類】(D) 兩句都是「非一……之……」：大事物不是單一來源能成就的，講的是{k:集合眾人之力}，與個人恆心無關。題目問「最不相近」，選 (D)。
@ana A o

@ana B o

望帝啼血 → 杜鵑花
@key
「遍植□□…少了一人」化用王維「遍插茱萸少一人」，空格為茱萸；(B)「插鬢」「陶潛籬下醉」寫重陽節佩茱萸、飲菊酒，所缺正是茱萸。
@translation
(A) 張旭〈桃花溪〉：遠處高高的橋隱隱約約隔著山野的煙靄，我在溪邊石磯的西側向漁船打聽：桃花整天隨著溪水漂流，那桃源洞口究竟在清溪的哪一邊呢？
(B) 王昌齡〈九日登高〉後四句：把茱萸插在鬢邊，這花正適合祝人長壽；佳人頭戴翡翠橫釵起舞，舞姿卻勾起愁緒。別再說陶淵明在東籬下醉酒賞菊了，他哪裡見過今日這般的風流盛況？
(D) 吳融〈送杜鵑花〉：春天的紅花才剛凋謝，秋天又紅了一回，就像息國滅亡後被帶進楚宮的息夫人。想必是蜀帝的冤魂怎麼啼也啼不盡，還要藉著這鮮紅的顏色向秋風傾訴。
@logic
1. 【解題幹】「在各自的異地」「少了一人」是線索。王維〈九月九日憶山東兄弟〉：「遙知兄弟登高處，{k:遍插茱萸少一人}。」現代詩把「遍插」改成「遍植」，空格是「茱萸」。
2. 【把選項當謎語】每個選項都是詠物詩，要從詩中的線索猜植物：找季節、節日、典故、花色等關鍵詞。
3. 【逐項解謎】(A) 隨流水＋洞＋問漁船 → 桃花源 → 桃花；(B) 插鬢＋宜壽＋陶潛籬下 → 重陽 → 茱萸；(C) 夏天＋君子＋幽香 → 荷（蓮）；(D) 蜀冤啼 → 杜宇化鵑 → 杜鵑花。
4. 【結論】只有 (B) 與題幹同為茱萸。
@ana A x
唐代張旭〈桃花溪〉，全詩暗用陶淵明〈桃花源記〉：漁人「緣溪行」「忽逢桃花林」「山有小口」。空格為「{k:桃花}」。原詩作「桃花盡日隨流水」，原卷作「竟日」，意思相同（整天）。
@ana B o
唐代王昌齡〈九日登高〉的後半。九日即農曆九月九日重陽節，習俗是登高、佩插茱萸以避邪、飲菊花酒以延壽，所以說「插鬢花宜壽」；後兩句再以陶淵明「采菊東籬下」的重陽飲酒典故作陪襯。空格為「{k:茱萸}」，與題幹相同，為正解。
@ana C x
這是一段現代詩文。「漫長的夏天」點出花期，「君子般的幽香」用周敦頤〈愛蓮說〉「蓮，花之君子者也」「香遠益清」的典故，所詠為「{k:荷花（蓮）}」。
@ana D x
唐代吳融〈送杜鵑花〉。「蜀冤」指古蜀國君主望帝杜宇，傳說他死後魂魄化為杜鵑鳥，日夜悲啼至口中流血，染紅了花，故名杜鵑花。「息國亡來入楚宮」則借息夫人亡國後入楚、終日不語的哀怨，比喻花的含悲帶恨。本詩沒有空格，直接歌詠「{k:杜鵑花}」。
@trap
(D)「息國亡來入楚宮」的主角息夫人，後世稱為「桃花夫人」，有背過這個典故的同學反而可能誤判成桃花。判斷詠物詩要抓{k:最具指標性}的線索：「蜀冤啼不盡」只能指杜鵑。另外，(B) 出現「陶潛籬下」，也有人直覺填「菊花」——但菊花是用來「飲」（菊花酒）和「采」的，會「插鬢」的是茱萸；而且後兩句說「漫說陶潛…」，是把菊花當作對照，不是本詩所詠。
@know 重陽節的習俗與詩文

- 現代詩人常把古典名句拆解、改寫後放進新的情境，稱為{k:化用}。本題洛夫把「遍插茱萸少一人」改成「遍植茱萸發現少了一人」，寫的是分隔兩地的親友靠書信確認彼此平安的心情——古典的「重陽思親」，被轉化成現代的離散之痛。

=== Q 9
@type 移覺（通感）修辭判斷
@cat 語文應用
@tags 修辭, 移覺, 轉化, 現代文學
@diff 3
@answer C
@stem
作家在描摹景物時，常運用「{y:移覺}」技巧將{c:各種感官}的感受相互溝通，以產生更大的感染效果。如：「我將如何進入秋天，在這個城市的盡頭，我{g:聽到}南方的雨水，一次比一次更{g:寒涼}。」雨水的寒涼屬於觸覺所感，而作者說是「聽到」，顯然是借用這個動詞，讓聽覺與觸覺間產生了移借的現象。以下各選項中何者亦屬於「移覺」效果的運用？
@note red
移覺＝{y:甲感官}的感受
用{y:乙感官}的詞來寫
@note blue
例句：聽（聽覺）→ 寒涼（觸覺）
@opt A
我也曾竚立水榭，遙望一葉輕舟，浮漾於廣遼無際的水面，輕舟上彷彿{ub:載滿了詩和夢想|抽象→具體}。
@note blue
A：全是視覺＋想像
是「形象化」
@opt B
萬里長城遠遠的{ub:橫飛而來|擬物}，要壓到我的頭上，我從此入關去了。回望著西北的浮雲，呵，別了，女英雄，青山不老，綠水長存，得機緣我總要見你一面，——誰知道我能否見你一面？今日域中，如此關山！
@note blue
B：轉化＋誇飾＋呼告
@opt C
那天我看見一個少婦／雕像般站在十字路口／她把{g:笑聲}{y:斜插在髮間|聽覺→視覺}。
@note red
笑聲本來「看不見」
卻能像髮簪「插」著 ✓
@opt D
啊！我不遠千里而去，希望結束生命的總合命題之枯思，開始嘗試新的呼吸！…啊！我不拒絕袖子捲至肩頭，讓陽光{ub:吮黑|擬人}手臂！也不拒絕風的{ub:搜身|擬人}！
@note blue
D：擬人；觸覺還是觸覺
@key
移覺必須「跨感官」：(C) 把只能聽見的「笑聲」寫成可以看見、可以拿來「斜插在髮間」的飾物，聽覺轉為視覺；其餘三項是轉化或誇飾，沒有感官的互換。
@logic
1. 【讀懂定義】題幹說得很清楚：移覺是{k:感官之間}的移借——本來屬於 A 感官的對象，用 B 感官的動詞或形容詞去寫。例句是「聽到…寒涼」（聽覺↔觸覺）。
2. 【設定檢查法】每個選項問兩個問題：①描寫的對象原本屬於哪一種感官？②作者用了哪一種感官的字眼？兩者{k:不同}才是移覺。
3. 【逐項檢查】(A) 輕舟（視覺）—遙望（視覺），「載滿詩和夢想」是把抽象事物具體化；(B) 長城（視覺）—橫飛、壓（動態想像）；(D) 陽光、風（觸覺）—吮、搜身（仍是皮膚的感受，只是擬人）。
4. 【確認正解】(C) 笑聲（聽覺）—斜插在髮間（視覺可見的飾物、手可觸的動作），發生了跨感官的轉移。
@ana A x
「遙望一葉輕舟」是視覺摹寫；「輕舟上彷彿載滿了詩和夢想」把抽象的「詩」「夢想」當成可以裝載的貨物，是{k:轉化中的形象化}（化抽象為具體）。「詩和夢想」不是任何一種感官的感受，所以談不上移覺。
@ana B x
「萬里長城遠遠的橫飛而來，要壓到我的頭上」把靜止的長城寫成會飛、會壓人，是{k:轉化}（化靜為動）兼{k:誇飾}；「別了，女英雄」是對不在眼前的對象說話，屬{k:呼告}。全段都在視覺與想像之內，沒有感官互換。
@ana C o
「笑聲」訴諸聽覺，本來無形；詩人卻讓少婦把它「斜插在髮間」，彷彿笑聲是一支看得見的髮簪或一朵花。{k:聽覺的對象被寫成視覺的形象}，兩種感官互相溝通，正是移覺，為正解。
@ana D x
「讓陽光吮黑手臂」「不拒絕風的搜身」把陽光、風當作人，會吸吮、會搜身，是{k:擬人}（轉化）。陽光曬在手臂、風吹過身體原本就是觸覺，寫出來還是觸覺，感官沒有轉移。
@trap
移覺最容易和「轉化」混淆，因為兩者都讓句子「不合常理」。分辨的關鍵是{k:有沒有換感官}：轉化是換「身分」（物變人、人變物、抽象變具體）；移覺是換「感官」（聲音有了顏色、氣味有了聲音）。(D)「陽光吮黑手臂」很生動，但太陽曬人本來就是皮膚的感覺，只是多了擬人，不能算移覺。
@know 移覺（通感）名句整理
| 例句 | 出處 | 感官的轉移 |
| 紅杏枝頭春意鬧 | 宋祁〈玉樓春〉 | 視覺（花開繁盛）→ 聽覺（喧鬧） |
| 晨鐘雲外濕 | 杜甫〈船下夔州郭宿雨濕不得上岸別王十二判官〉 | 聽覺（鐘聲）→ 觸覺（潮濕） |
| 微風過處，送來縷縷清香，彷彿遠處高樓上渺茫的歌聲似的 | 朱自清〈荷塘月色〉 | 嗅覺（荷香）→ 聽覺（歌聲） |
| 光與影有著和諧的旋律，如梵婀玲上奏著的名曲 | 朱自清〈荷塘月色〉 | 視覺（光影）→ 聽覺（樂曲） |
| 我聽到南方的雨水，一次比一次更寒涼 | 本題題幹 | 聽覺 ↔ 觸覺 |
- 「移覺」又稱「通感」，日常語言裡也有：{k:甜美}的歌聲（味覺→聽覺）、{k:冷}色調（觸覺→視覺）、{k:尖銳}的叫聲（觸覺→聽覺）。
@know 移覺、轉化、摹寫的比較
| 修辭 | 定義 | 判斷重點 | 例句 |
| 摹寫 | 把感官的感受如實描寫出來 | 感官與對象一致 | 溪水潺潺（聽覺寫聲音） |
| 移覺 | 用另一種感官來寫某一感官的感受 | 感官與對象錯位 | 她把笑聲斜插在髮間 |
| 轉化 | 改變描寫對象的性質 | 物↔人、抽象→具體 | 讓陽光吮黑手臂 |
| 誇飾 | 故意誇大或縮小 | 超過客觀事實 | 長城要壓到我的頭上 |
@know 轉化的三種類型
- {k:擬人}（以人比物）：把物當作人來寫——「不拒絕風的搜身」。
- {k:擬物}（以物比人）：把人當作物來寫——「他夾著尾巴逃走了」。
- {k:形象化}（以具體寫抽象）：把抽象概念寫成有形的東西——「輕舟上載滿了詩和夢想」；李清照「只恐雙溪舴艋舟，載不動、許多愁」。
- 本題 (A) 與李清照的名句手法相同：小船載的不是貨物，而是抽象的情思。

=== Q 10
@type 複句關係判斷
@cat 語文應用
@tags 複句, 關聯詞, 文法
@diff 4
@answer A
@stem
古人為文，文句常存在著{c:因果、假設、比較、遞進、條件}等關係。下列各選項中的文句，前後皆使用{y:相同|兩句同一種關係}複句關係的是：
@note red
原卷「相同」加框
方法：圈出{c:關聯詞}
@note purple
破折號後的關係名稱
是命題者給的「標籤」
要檢查兩句是否都符合
@opt A
{y:與其}食人之祿，俯首而包羞；{y:孰若}無愧於心，放身而自得？／父母{y:寧可}自己多吃苦受累，{y:也不肯}讓兒女受委屈。──比較關係
@note red
與其A孰若B／寧可A也不B
都是「比較後取捨」✓
@opt B
欲速，{g:則}不達；見小利，{g:則}大事不成。／螽斯，俗稱「紡織娘」，能高聲鳴唱，{x:而且}繁殖力強，用來祝福新娘多子多孫。──條件關係
@note blue
前：條件 ✓
後：而且＝遞進 ✗
@opt C
吾馬賴柔和，{g:令}他馬，固不敗傷我乎？／他們{x:為了}不輸給蔓延下去的雜草，每天工作到看不見臉的黃昏。──假設關係
@note blue
前：令＝假使 ✓
後：為了＝目的 ✗
@opt D
不識廬山真面目，{x:只緣}身在此山中。／服五石散，{g:非唯}治病，{g:亦}覺神明清朗。──遞進關係
@note blue
前：只緣＝因果 ✗
後：非唯…亦…＝遞進 ✓
@key
(A)「與其…孰若…」「寧可…也不…」都是比較兩件事之後有所取捨；(B) 後句是遞進、(C) 後句是目的、(D) 前句是因果，皆前後不一。
@translation
(A) 前句：與其領別人的俸祿、低著頭忍受羞辱，哪裡比得上問心無愧、自由自在而怡然自得呢？
(B) 前句（《論語‧子路》）：想求快，反而達不到目的；貪圖小利，就辦不成大事。
(C) 前句（《史記‧張釋之馮唐列傳》）：幸虧我的馬性情溫馴，假使換了別的馬，豈不是要摔傷我了嗎？
(D) 前句（蘇軾〈題西林壁〉）：看不清廬山的真實面貌，只因為自己身在這座山中。後句（《世說新語‧言語》）：服用五石散，不只能治病，還覺得精神清爽開朗。
@logic
1. 【審題】每個選項有「前句／後句──關係名稱」三個部分。要選的是前後兩句{k:都}屬於破折號後所標的那種關係。
2. 【圈關聯詞】複句關係幾乎都由關聯詞決定：與其…孰若、寧可…也不、則、而且、令、為了、只緣、非唯…亦。
3. 【逐項配對】(B) 則（條件）／而且（遞進）；(C) 令（假設）／為了（目的）；(D) 只緣（因果）／非唯…亦（遞進）。三項都是「一對一錯」。
4. 【確認 A】「與其 A，孰若 B」＝比較 A、B 後取 B；「寧可 A，也不 B」＝比較 A、B 後取 A。兩句都是比較之後的選擇，符合「比較關係」。
@ana A o
前句以「與其…孰若…」比較「食祿包羞」與「無愧自得」，認為後者較好；後句以「寧可…也不…」比較「自己吃苦」與「兒女受委屈」，選擇前者。兩句都是{k:權衡兩件事後決定取捨}，即題幹所稱的「比較關係」（語法書多稱為「選擇複句」中的取捨句），前後相同，為正解。
@ana B x
前句「欲速，則不達」：如果（只要）求快，就達不到——前一分句是條件，後一分句是結果，屬條件（假設）關係，符合標籤。
後句「能高聲鳴唱，{k:而且}繁殖力強」：後一分句比前一分句更進一層，是{k:遞進關係}，不是條件關係。
@ana C x
前句「令他馬，固不敗傷我乎」：令，假使。這是漢文帝的座車馬匹受驚後所說的話——假如是別的馬，早就讓我受傷了。屬假設關係，符合標籤。
後句「{k:為了}不輸給…雜草，每天工作到…黃昏」：前一分句說明目的，後一分句說明行動，是{k:目的關係}。
@ana D x
前句「不識廬山真面目，只{k:緣}身在此山中」：緣，因為。先說結果、後說原因，是{k:因果關係}。
後句「非唯治病，亦覺神明清朗」：非唯…亦…＝不但…而且…，是遞進關係，符合標籤。（《世說新語》原文作「神明開朗」。）
@trap
這題的陷阱是「每個選項都有一句是對的」：(B)(C) 對在前句，(D) 對在後句。只看前句就作答的人，很容易選 (B) 或 (C)。另外，「比較關係」並非一般國中課本的標準分類名稱，不必被名稱困住——只要確認兩句都是{k:兩事相較、取一捨一}的句式即可。
@know 常見複句關係與關聯詞
| 關係 | 意義 | 白話關聯詞 | 文言關聯詞與例句 |
| 並列 | 幾件事平列 | 既…又…、一邊…一邊… | 「學而不思則罔，思而不學則殆」 |
| 承接 | 依先後順序敘述 | 於是、然後、接著 | 「乃」「遂」「既而」 |
| 遞進 | 後句比前句更進一層 | 不但…而且…、甚至 | 「非唯…亦…」「非徒…又…」 |
| 選擇（取捨） | 幾者之中選一 | 與其…不如…、寧可…也不… | 「與其…孰若…」「寧…無…」 |
| 轉折 | 後句與前句相反 | 雖然…但是…、卻 | 「雖…然…」「而」「顧」 |
| 因果 | 原因與結果 | 因為…所以…、由於 | 「以」「緣」「故」「是以」 |
| 假設 | 假定某情況 | 如果…就…、要是 | 「苟」「若」「使」「令」「向使」 |
| 條件 | 具備條件才有結果 | 只要…就…、除非…才… | 「…則…」「必…然後…」 |
| 目的 | 行動與目的 | 為了…、以便… | 「以」「俾」 |
@know 文言的「取捨句」句式
| 句式 | 取哪一邊 | 例句 |
| 與其 A，孰若 B | 取 B | 與其有譽於前，孰若無毀於其後。（韓愈〈送李愿歸盤谷序〉） |
| 與其 A，寧 B | 取 B | 禮，與其奢也，寧儉。（《論語‧八佾》） |
| 寧 A，無（毋）B | 取 A | 寧為雞口，無為牛後。（《戰國策‧韓策》） |
| A 孰與 B | 詢問比較 | 我孰與城北徐公美？（《戰國策‧齊策》） |
@know 表示「假設」的文言虛詞
- {k:苟}：「苟富貴，無相忘。」（《史記‧陳涉世家》）
- {k:若}：「若入前為壽，壽畢，請以劍舞。」（《史記‧項羽本紀》）
- {k:使／向使}：「使六國各愛其人，則足以拒秦。」（杜牧〈阿房宮賦〉）
- {k:令}：「令他馬，固不敗傷我乎？」（本題）
- {k:微}（如果沒有）：「微斯人，吾誰與歸？」（范仲淹〈岳陽樓記〉）
