@logic
1. 【審題】題目問「字形」是否相同（字音本來就一樣），所以四個選項、八個詞都要寫出國字。
2. 【以義定形】用詞義推回國字：「刮目」是擦亮眼睛 → 刮（刀部）；「強聒」是硬在人耳邊嘮叨 → 聒（耳部）；「驚鴻」是受驚飛起的鴻雁 → 鴻；「洪鐘」是大鐘 → 洪；「繼踵」是腳跟接著腳跟 → 踵（足部）；「臉腫」是皮肉浮脹 → 腫（肉部）。
3. 【鎖定】「欲深谿壑」形容貪欲比山谷還深；「以鄰為壑」是把鄰國當成排洪的大水溝。兩個「ㄏㄨㄛˋ」都是「深谷、深溝」的{k:壑}。
4. 【結論】(A)(C)(D) 皆同音異字，選 (B)。
@ana A x
「{k:刮}」目相待：刮，擦拭。擦亮眼睛重新看待，指用新的眼光看人。語本《三國志‧吳書‧呂蒙傳》裴松之注引《江表傳》：「士別三日，即更刮目相待。」
強「{k:聒}」不舍：聒，音ㄍㄨㄚ，喧譁吵耳。指嘮嘮叨叨說個不停，語出《莊子‧天下》「強聒而不舍」。此處「強」音ㄑㄧㄤˇ，「舍」同「捨」。
→ 刮 ≠ 聒。
@ana B o
欲深谿「{k:壑}」：谿壑，山谷中水流匯聚的深溝，比喻人的貪欲像溪谷一樣難以填滿，義同「欲壑難填」。
以鄰為「{k:壑}」：把鄰國當作排洩洪水的大溝，比喻損人利己。典出《孟子‧告子下》，孟子批評白圭治水「以鄰國為壑」。
→ 前後皆為「壑」，字形相同，為正解。
@ana C x
驚「{k:鴻}」一瞥：驚鴻，受驚而輕捷飛起的鴻雁，曹植〈洛神賦〉用「翩若驚鴻」形容洛神體態輕盈，後借指美女。全詞比喻美人或美好事物短暫出現。
聲如「{k:洪}」鐘：洪，大。形容聲音像大鐘一樣響亮（「洪鐘」也作「洪鍾」）。
→ 鴻 ≠ 洪。
@ana D x
比肩繼「{k:踵}」：踵，腳後跟。肩並著肩、腳跟接著腳跟，形容人多擁擠。語出《晏子春秋‧內篇‧雜下》：「張袂成陰，揮汗成雨，比肩繼踵而在。」
鼻青臉「{k:腫}」：腫，皮肉浮脹。形容臉部傷勢嚴重。
→ 踵 ≠ 腫。
@trap
「驚鴻」「洪鐘」最容易寫反。記法：{k:鴻是鳥}（江＋鳥，鴻雁、鴻毛），用在「驚鴻一瞥」「輕於鴻毛」「雪泥鴻爪」；{k:洪是水}，引申為「大」，用在「洪水」「洪亮」「聲如洪鐘」。另外「鴻圖／宏圖」「鴻福／洪福」為辭典認可的兩寫，考試通常不會拿來考字形。

@type 文言一字多義辨析
@cat 形音義
@tags 字義, 通同字, 古詩文名句
@diff 3
@answer C
@stem
下列各組「」內的詞，{y:意義前後相同|字義比較}的是：
@note red
方法：{c:代換法}——同一個解釋代入兩句都通才算相同
@opt A
寡取「易」盈{nb:容易}／深耕「易」耨{nb:整治}
@note blue
易耨＝治田除草（朱熹：易，治也）
@opt B
尸位「素」餐{nb:空、白白地}／只因「素」稔讀書趣{nb:向來}
@note blue
素稔＝一向熟悉
@opt C
不得志，修身「見」於世{n:顯現}／何時眼前突兀「見」此屋{n:出現}
@note red
兩個都同「現」ㄒㄧㄢˋ ✓
@opt D
初「聞」涕淚滿衣裳{nb:聽到}／入芝蘭之室，久而不「聞」其香{nb:嗅到}
@note blue
耳聞 ≠ 鼻聞
@cols 1
@key
兩個「見」都同「現」（ㄒㄧㄢˋ），作「顯現、出現」解；其餘為容易／整治、空／向來、聽到／嗅到。
@logic
1. 【審題】比較字義，用{k:代換法}：找一個解釋同時代入前後兩句，都通順才算相同。
2. 【抓通同字】文言的「見」常同「現」。「修身見於世」是修養品德而{k:顯現}於世；「突兀見此屋」是高聳的房屋{k:出現}在眼前，兩句都不能解作「看見」，都讀ㄒㄧㄢˋ。
3. 【刪去】(A)「易盈」是容易滿足，「易耨」是整治田地、除草；(B)「素餐」是白吃飯，「素稔」是一向熟悉；(D) 一用耳朵聽、一用鼻子嗅。
4. 【結論】只有 (C) 前後同義，選 (C)。
@ana A x
寡取「易」盈：易，{k:容易}。岳飛〈良馬對〉形容劣馬「寡取易盈，好逞易窮」——吃得少而容易滿足，愛逞強而容易力竭。
深耕「易」耨：易，{k:整治}；耨（ㄋㄡˋ），除草。《孟子‧梁惠王上》：「省刑罰，薄稅斂，深耕易耨。」朱熹注：「易，治也。」指深耕土地、勤除雜草。
→ 容易 ≠ 整治。
@ana B x
尸位「素」餐：素，{k:空、白白地}。占著職位、白領俸祿而不做事，語出《漢書‧朱雲傳》。
只因「素」稔讀書趣：素，{k:平素、向來}；稔（ㄖㄣˇ），熟悉。出自宋末元初翁森〈四時讀書樂〉（夏）：「北窗高臥羲皇侶，只因素稔讀書趣。」
→ 白白地 ≠ 向來。
@ana C o
不得志，修身「見」於世：見，同「現」，{k:顯現}。《孟子‧盡心上》：「古之人，得志，澤加於民；不得志，修身見於世。」意指不得志時就修養自身，以品德顯現於世。
何時眼前突兀「見」此屋：見，同「現」，{k:出現}。杜甫〈茅屋為秋風所破歌〉：「嗚呼！何時眼前突兀見此屋，吾廬獨破受凍死亦足！」
→ 皆為「顯現、出現」，為正解。
@ana D x
初「聞」涕淚滿衣裳：聞，{k:聽到}。杜甫〈聞官軍收河南河北〉：「劍外忽傳收薊北，初聞涕淚滿衣裳。」
久而不「聞」其香：聞，{k:嗅到}。《孔子家語‧六本》：「與善人居，如入芝蘭之室，久而不聞其香，即與之化矣。」
→ 聽 ≠ 嗅。
@trap
(A)「深耕易耨」最容易望文生義，以為是「容易除草」。記住它與「省刑罰、薄稅斂」並列，「深耕」「易耨」都是「動詞＋賓語」的農事。另外 (C) 的兩個「見」，一個偏「顯露德行」、一個偏「出現眼前」，但同屬「現」的義項；字義題比的是{k:義項}，不是翻譯字眼要一模一樣。
@know 「見」的文言用法整理

=== Q 3
@type 詞語填空與語境判斷
@cat 詞語成語
@tags 詞語運用, 關聯詞, 擬人
@diff 2
@answer C
@stem
閱讀下文，□□內最適合填入的詞語{y:依序|一格一格判斷}是：
@stem
甲、山路{c:不像}{g:坦途}那樣，{n:匍匐}在人們足下。
乙、{c:只要}能收穫甜蜜，{n:荊棘}叢中{c:也}會有蜜蜂忙碌的身影。
@note red
甲：空格形容的是{y:坦途}，不是山路！
@note blue
乙：「只要……也」＝讓步
→ 填{y:不利的環境}
@opt A
起伏／荊棘
@opt B
起伏／百花
@opt C
匍匐／荊棘
@opt D
匍匐／百花
@note green
坦途「趴」在腳下任人走 → 匍匐
@key
甲句空格形容的是「坦途」平伏在腳下 → 匍匐；乙句「只要……也」是讓步語氣，要填逆境 → 荊棘。
@logic
1. 【甲句：找出被形容的對象】句型是「山路不像坦途那樣，□□在人們足下」，「□□在人們足下」說的是{k:坦途}的樣子。平坦的大路不會「起伏」，而是乖順地「趴伏」在腳下任人行走 → 匍匐（擬人）。
2. 【乙句：看關聯詞】「只要……，……也會……」表示「即使條件不好，結果依然成立」。蜜蜂在「百花叢」中忙碌是理所當然，用不著「也」；在「荊棘叢」中仍然忙碌，才顯出「為了甜蜜不畏艱難」。
3. 【合併】匍匐／荊棘，選 (C)。
4. 【檢核】兩句主旨一致：山路雖不平順、荊棘雖多刺，但值得追求的事物往往就在艱難之處。
@ana A x
「起伏」形容高低不平，正好是「山路」的特徵；但句子說山路「不像」坦途那樣□□，空格是坦途的特徵，填「起伏」語意矛盾。第二格「荊棘」正確。
@ana B x
兩格皆不妥。「起伏」不合甲句（理由同 A）；「百花叢中有蜜蜂」是常態，與「只要……也」的讓步語氣不合。
@ana C o
「匍匐」（ㄆㄨˊ ㄈㄨˊ）本指手足伏地爬行，此處用{k:擬人}手法，寫坦途平順地伏在人的腳下；山路則須費力攀登，不會如此「順從」。「荊棘」是多刺的灌木，比喻困難的環境，與「只要……也」的語氣相合。兩格皆恰當。
@ana D x
第一格「匍匐」正確，但第二格「百花」使「只要能收穫甜蜜」的條件變得多餘——百花叢中本來就有蜜，不需要強調「只要」。
@trap
甲句最常見的錯誤是「看到山路就填起伏」。這類填空題要先畫出句子骨架：{k:「A 不像 B 那樣，□□」}——□□ 永遠是 B 的特徵、A 所沒有的特徵。
@know 讓步關聯詞一覽
| 關聯詞 | 語意 | 例句 |
| 只要……也／就…… | 充分條件：有此條件，結果就成立 | 只要肯努力，再難的題目也解得開 |
| 即使／縱使……也…… | 假設讓步 | 即使下雨，比賽也照常舉行 |
| 儘管／雖然……卻／仍…… | 事實讓步 | 儘管路途遙遠，他仍準時抵達 |
| 無論／不管……都…… | 無條件 | 無論晴雨，他都去晨跑 |
- 看到「也、仍、都」等副詞，前面的分句通常放{k:不利的條件}，這是填空題的重要線索。
@know 「匍匐」與「荊棘」的延伸用法
- 匍匐：①伏地爬行（匍匐前進）；②盡力（《詩經‧邶風‧谷風》「凡民有喪，匍匐救之」）。《莊子‧秋水》邯鄲學步的壽陵餘子，最後也是「匍匐而歸」。
- 荊棘：比喻困難、障礙。相關成語有{k:披荊斬棘}（克服種種困難）、{k:荊天棘地}（障礙重重）。
@know 修辭小教室：把「路」寫活
- 「坦途匍匐在人們足下」把道路當成伏地的生物，是{k:轉化}中的擬人（擬物為人或動物）。
- 類似寫法：鄭愁予〈錯誤〉「我達達的馬蹄是美麗的錯誤」是譬喻；而「山路迎面撲來」「小路鑽進樹林」則是擬人。判斷關鍵：是否把{k:人或動物才有的動作}加在無生命的事物上。

4. 【因果】先聞到「沖鼻的氣味」（丁），才會「胃裡翻起一陣噁心」（丙）→ {k:丁丙}相連。

@ana A x

@ana B x

@ana C x

@ana D o

@translation

@trap
題幹寫「下列是一段散文」，但文末標明出自白先勇〈芝加哥之死〉——這其實是{k:短篇小說}。此處的「散文」是相對於韻文的廣義用法（散體文字），不影響作答，但文體常識要分清楚。
@know 排序題的四個線索
| 線索 | 作法 | 本題例證 |
| 首句與末句 | 看首句的標點與句式，找「接得上」的一句 | 「把……」接「將……」 |
| 殘句 | 只有主語或只有述語的句子，要和另一句拼合 | 戊（主語）＋甲（述語） |
| 指示詞、代詞 | 「這、那、其、此」一定回指前文 | 丁「這些腐屍」← 甲 |

@know 白先勇與〈芝加哥之死〉
- 白先勇，臺大外文系畢業，與王文興、歐陽子、陳若曦等人創辦《現代文學》雜誌；代表作有短篇小說集《臺北人》、《寂寞的十七歲》、《紐約客》與長篇小說《孽子》。
- 〈芝加哥之死〉是他赴美後所寫的留學生題材小說：主角吳漢魂在芝加哥苦讀六年取得博士學位，畢業之際卻驚覺自己與世隔絕、精神無所依歸。本段正是他「驚覺」的一刻——書本變成腐屍，象徵他賴以為生的學問忽然失去了生命。
@know 本段的摹寫與譬喻
- 視覺：「密密麻麻的書本」「花花綠綠的腐屍」
- 嗅覺：「沖鼻的氣味」「嗅中了解剖房中的福馬林」
- 譬喻：書本「好像」腐屍、噁心「如同」嗅到福馬林（皆為明喻）；「學問的深淵」則是把抽象的學問比作深淵（略喻）。
- 作者以{k:令人不適的感官描寫}表現人物的心理崩潰，這是現代主義小說常見的手法。

=== Q 5
@type 現代散文文意理解
@cat 白話閱讀
@tags 張愛玲, 文意推論, 因果脈絡
@diff 4
@answer D
@stem
依據下文，最符合「{y:證實自己的存在|找這句的前因後果}」的敘述是：
@box
這時代，舊的東西在崩壞，新的在滋長中，但在時代的高潮來到之前，{ub:斬釘截鐵的事物不過是例外|→(A)}。人們只是感覺到日常的一切都有點兒不對，不對到恐怖的程度。人是生活在一個時代裡的，可是這時代卻在影子似的沉沒下去，{o:人覺得自己是被拋棄了}。{c:為了要}證實自己的存在，抓住一點真實的，最基本的東西，{y:不能不求助於古老的記憶}，人類在一切時代之中生活過的記憶，這{ub:比瞭望將來要更明晰、親切|不是為了「知來」}。於是他對周圍的現實發生了一種奇異的感覺，疑心這是一個荒唐的，古代的世界，陰暗而明亮的。{g:回憶與現實之間時時發現尷尬的不和諧，因而產生鄭重而輕微的騷動，認真而未有名目的鬥爭。}　（改寫自張愛玲〈自己的文章〉）
@note orange
被拋棄＝「原因」
不是證實的方法
@note red
脈絡：被拋棄 → 求助記憶
→ 與現實不和諧 → 騷動、鬥爭
@note green
末句＝證實存在的「樣貌」→ (D)
@opt A
需透過斬釘{x:解}{n:截}鐵的事物來建構存在的事實
@note purple
原卷誤植：解 → 應為「截」
@opt B
在日常生{x:或}{n:活}中感到恐怖，產生被拋棄之感
@note purple
原卷誤植：或 → 應為「活」
@opt C
求助於古老的記憶，尋求{u:鑑往知來}的基石
@note blue
前對後錯！記憶比「瞭望將來」親切，並非用來知來
@opt D
在回憶與現實的尷尬，對騷動認真地鬥爭
@key
人為了證實自己的存在而求助古老的記憶，結果在「回憶與現實的不和諧」中產生騷動與鬥爭——末句正是這段話的落點。
@logic
1. 【定位】題幹引的是「為了要證實自己的存在」一句。先畫出它的前因與後果：前因是「時代沉沒、人覺得被拋棄」；作法是「求助於古老的記憶」；後果是「回憶與現實不和諧 → 騷動、鬥爭」。
2. 【刪 A】原文說「斬釘截鐵的事物不過是例外」，可見這種事物在此時代難以依靠，與 (A) 相反。
3. 【刪 B】「感到恐怖、被拋棄」是人{k:需要}證實自己存在的原因，還不是「證實」本身。
4. 【辨 C、D】(C) 前半「求助於古老的記憶」與原文相同，但後半「鑑往知來」是指借過去推知未來；原文卻說記憶「比瞭望將來要更明晰、親切」——人抓住記憶是為了得到一點「真實的、最基本的東西」，不是為了預見未來。(D) 對應末句：人帶著記憶回看現實，在兩者的尷尬不和諧中「認真地鬥爭」，這正是人努力證實自己存在的具體樣貌。
5. 【結論】選 (D)。
@ana A x
原文：「在時代的高潮來到之前，斬釘截鐵的事物不過是例外。」既然是「例外」，就不可能成為人們建構存在感的憑藉。選項與原文意思相反。（選項中的「斬釘解鐵」為原卷誤植，應作「斬釘截鐵」。）
@ana B x
「日常的一切都有點兒不對，不對到恐怖的程度」「人覺得自己是被拋棄了」確實是原文內容，但這是{k:處境}，是「為了要證實自己的存在」的前提，並非證實存在的方式或表現。答非所問。（「日常生或」為原卷誤植，應作「日常生活」。）
@ana C x
前半正確，後半錯誤。「鑑往知來」意為觀察過去以推知未來，重點落在「未來」；原文則強調古老的記憶「比瞭望將來要更明晰、親切」，人求助於記憶是為了「抓住一點真實的，最基本的東西」，並沒有藉此預測或規畫未來的意思。
@ana D o
對應末句「回憶與現實之間時時發現尷尬的不和諧，因而產生鄭重而輕微的騷動，認真而未有名目的鬥爭」。人求助於記憶之後，並未就此安頓，而是在回憶與現實的落差之間騷動、掙扎；這種「認真的鬥爭」就是人在沉沒的時代裡證實自己還存在的方式。為四個選項中最貼近原文者。
@trap
(C) 是典型的「{k:前對後錯}」選項：前半句幾乎照抄原文，讓人放下戒心，後半句再偷偷加上原文沒有的「鑑往知來」。作答時務必把選項拆成前後兩截分別檢查。
另須留意：(D) 的措辭「對騷動認真地鬥爭」比原文簡略——原文的「騷動」與「鬥爭」是並列的兩種反應，並不是「對騷動」進行鬥爭。但 (D) 沒有與原文牴觸的關鍵詞，仍是最適當的答案，也是官方公布的答案。
@know 張愛玲與〈自己的文章〉
- 張愛玲（1920–1995），生於上海，1940 年代以小說集《傳奇》、散文集《流言》成名；代表作有〈傾城之戀〉、〈金鎖記〉、〈紅玫瑰與白玫瑰〉、《半生緣》等。
- 〈自己的文章〉收於《流言》，是她回應批評、自述創作觀的重要文章。文中提出兩個著名主張：一是寫人生「{k:安穩}的一面」而非只寫「飛揚的一面」；二是喜歡「{k:參差的對照}」的寫法，追求「蒼涼」而非「壯烈」的美感。
- 本題節錄的段落，說明她筆下人物為何總在新舊交替的時代裡不徹底、不痛快——因為時代本身就「在影子似的沉沒下去」。
@know 閱讀技巧：把長段落畫成「因果鏈」
| 階段 | 原文關鍵句 | 對應選項 |
| 背景 | 舊的崩壞、新的滋長；斬釘截鐵的事物是例外 | (A) 說反了 |
| 處境 | 日常不對到恐怖；人覺得被拋棄 | (B) 只是原因 |
| 作法 | 求助於古老的記憶（比瞭望將來親切） | (C) 多加「知來」 |
| 結果 | 回憶與現實不和諧 → 騷動、鬥爭 | (D) 正解 |
- 題幹若引用文中某一句，答案常在該句的{k:後文}（結果、表現），而不在前文（原因）。
@know 張愛玲的「矛盾修飾」
- 本段出現「陰暗而明亮的」「鄭重而輕微的騷動」「認真而未有名目的鬥爭」，都是把{k:相反或不相稱的形容詞}並置，屬於映襯（第 11 題考點）。
- 這種寫法正是她所謂「參差的對照」：不是黑白分明的強烈對比，而是「蔥綠配桃紅」式的、帶著含混與蒼涼的對照。

四川的邊遠地方有兩個和尚，一個貧窮，一個富有。窮和尚對富和尚說：「我想到南海去，你看怎麼樣？」富和尚說：「你憑什麼去呢？」窮和尚說：「我只要一個水瓶、一個飯缽就夠了。」富和尚說：「我好幾年來一直想雇船順江而下，到現在還沒能去成。你憑什麼去呢？」到了第二年，窮和尚從南海回來，把這件事告訴富和尚，富和尚露出了慚愧的神色。
@logic
1. 【找批評對象】故事以{k:對比}寫成：貧者只憑一瓶一缽就出發，隔年從南海歸來；富者有錢雇船，卻「數年來……猶未能也」。結尾「富者有慚色」點明作者批評的是富者。
2. 【歸納富者的毛病】富者不是方法錯誤（雇船南下是可行的），也不是能力不足，而是{k:只有願望、沒有行動}。
3. 【比對成語】(A) 談法網，(B) 談積累，(C) 談方法錯誤，(D)「臨川羨魚」——站在水邊只想得到魚卻不動手——最吻合。
4. 【結論】選 (D)。
@ana A x
網漏吞舟：網，法網；吞舟，能吞下船的大魚，比喻大奸大惡之人。語本《史記‧酷吏列傳‧序》「網漏於吞舟之魚」，指法律過於寬疏，使重大罪犯得以逃脫。與「立志而不行動」無關。
@ana B x
成語通行寫法是「積羽{k:沉}舟」：輕飄飄的羽毛堆積多了，也能把船壓沉，比喻積少成多、力量可觀，語出《戰國策‧魏策》「積羽沉舟，群輕折軸」。若取「積少成多」之意，反而可以形容貧者一步一步走到南海，是正面的形容，不是批評的對象。
@ana C x
緣木求魚：爬到樹上去找魚，比喻{k:方法錯誤}，徒勞無功，語本《孟子‧梁惠王上》。富者想「買舟而下」，方法並沒有錯，錯在遲遲不動身，故不適用。
@ana D o
臨川羨魚：也作「臨淵羨魚」「臨河羨魚」，比喻雖有願望，若無實際行動，也無濟於事。《漢書‧董仲舒傳》：「臨淵羨魚，不如退而結網。」富者年年想去南海卻始終沒有動身，正是「羨魚」而不「結網」。為正解。
@trap
(C)「緣木求魚」是最強的誘答：兩個成語都有「魚」，也都「得不到魚」。差別在{k:原因}——緣木求魚是「做了，但方法不對」；臨川羨魚是「想了，但根本沒做」。本文的富者屬於後者。
另外，(B)「積羽成舟」並非辭典收錄的成語，通行寫法為「積羽沉舟」，本書照原卷著錄。

3. 【分辨先後】「念無與樂者，遂至承天寺尋張懷民」發生在「起行」之後，說明的是「為什麼去承天寺」，不是「為什麼出門」。

@ana A x

@ana B o

@ana C x

@ana D x

@trap

@translation

1. 【抓主線】全文因果：盜多、官不敢捕 → 招撫後另編「盜戶」→ 官府怕其復叛而偏袒 → 訟者爭相冒稱 → 審案只辨真偽、不辨曲直 → 連狐妖都自稱盜戶。
2. 【找關鍵句】「凡值與良民爭，則{k:曲意左袒之}」直接說明盜戶在爭訟中受到偏袒；「訟者輒冒稱盜戶」則從反面證明這個身分有利可圖。
3. 【逐項檢查】(A)「刻意縱容」與「不敢捕」的被動畏懼不符；(C) 真偽可由「稽籍」查明；(D) 把諷刺性的結尾當成實寫，目的也說錯。
4. 【結論】選 (B)。
@ana A x
錯在「緣起」與「刻意縱容」。「盜戶」這個名目是盜賊「受撫」之後，由縣令「別之」（另行編列）而來；官府對盜賊的態度是「不敢捕」「恐其復叛」，出於畏懼，而非有意放縱。可改為「盜戶緣起於官府招撫後的另行編戶」。
@ana B o
「凡值與良民爭，則曲意左袒之」：只要盜戶與良民起爭執，官府就委屈本意去偏袒盜戶。後文「訟者輒冒稱盜戶」更可見這個身分在訴訟中的優勢。敘述正確。
@ana C x
文中說雙方「以盜之真偽反覆相苦，煩有司稽籍焉」——真偽之爭雖然惱人，但官吏查核戶籍冊便能確認，並非「難以辨明」。作者真正要指出的荒謬是：官府只查「是不是盜戶」，卻把案情的「曲直且置不辨」。
@ana D x
狐妖自稱盜戶，是想比照盜戶受到寬縱、免於火燒，重點在{k:求免}；作者更是藉這句話嘲諷「連妖狐都知道當盜戶有好處」。選項說成「乃欲欺瞞官府」，只看到手段、說錯目的，也忽略了這是寓言式的諷刺。
@trap
(C) 很容易誤選，因為文中確實花了不少篇幅寫「真偽」之爭。關鍵在分清{k:「麻煩」與「不能」}：「反覆相苦」「煩有司稽籍」是說查起來很煩，但「稽籍」二字正表示有冊可查。題目問的是對「盜戶」最適當的敘述，應回到全文的核心——偏袒。
@know 《聊齋誌異》文學常識
- 作者蒲松齡，字留仙，別號柳泉居士，清代山東淄川人，世稱「聊齋先生」。一生科場失意，以教書為業。
- 《聊齋誌異》是{k:文言短篇小說集}，多寫狐、鬼、花妖，藉以諷刺科舉弊端、吏治黑暗與世態人情。「聊齋」是書房名，「誌異」即記錄奇聞異事。
- 國中階段常見選文：〈種梨〉、〈勞山道士〉、〈狼〉等。
- 本篇特色：前半近乎史筆，記順治年間的社會亂象；後半忽然接上狐妖，以一句「我盜戶也」的{k:荒誕笑料}收束，使官府「畏惡欺善、是非不分」的可笑暴露無遺。
@know 「左袒」的典故
- 袒，露出手臂。漢初呂后死後，太尉周勃入軍中下令：「為呂氏右袒，為劉氏左袒。」全軍皆露出左臂，表示擁護劉氏（《史記‧呂太后本紀》）。後以「左袒」指{k:偏護某一方}。
- 近義：偏袒、袒護、偏私；反義：不偏不倚、一視同仁、大公無私。

@know 賦、比、興怎麼分
| 手法 | 鍾嶸〈詩品序〉 | 朱熹《詩集傳》 | 《詩經》例句 |
| 賦 | 直書其事，寓言寫物 | 敷陳其事而直言之 | 「七月流火，九月授衣」（〈豳風‧七月〉） |

| 興 | 文已盡而意有餘 | 先言他物以引起所詠之詞 | 「關關雎鳩，在河之洲。窈窕淑女，君子好逑」（〈周南‧關雎〉） |
- 風、雅、頌是《詩經》的{k:體裁}；賦、比、興是{k:作法}，合稱「六義」。
- 鍾嶸把「興」解為「言有盡而意無窮」的餘韻，與朱熹「起興」的說法不同，是他「滋味說」的延伸。
@know 「以味論詩」的傳統
- 鍾嶸「滋味」之後，唐代司空圖提出「{k:味外之旨}」「韻外之致」，認為「辨於味而後可以言詩」；宋代嚴羽《滄浪詩話》主張好詩「{k:言有盡而意無窮}」。
- 今天我們說一首詩「耐人尋味」「餘味無窮」「索然無味」，都是這個傳統留下的說法——用舌頭的感覺來說心靈的感受，在修辭上稱為「移覺」（通感）。

@logic
1. 【讀定義】題幹已給出判斷標準：必須有{k:兩個相反（或不同）的觀念}，而且{k:對列在一起}互相比較。範例中「最沉重」與「最甜蜜」同時形容「負荷」。
2. 【找相反詞】逐一圈出各選項中意義相反的詞：(A) 努力／勇氣——不相反；(B) 沒有；(C) 傷心／幸福、坎／階梯——兩組相反；(D) 直／彎——只在字面上相對。
3. 【驗證 C】「坎」是地面的坑陷，比喻難關；「階梯」是讓人向上的通道。把同一件事（挫折）用兩種相反的觀點來說，寫法與範例「沉重又甜蜜的負荷」一致。

@ana A x
「不是……而是……」是表示{k:取捨}的句型：否定前者、肯定後者。「努力」與「反骨的勇氣」只是兩種不同的特質，意義並不相反，句子的作用是「更正讀者的認知」，不是把兩種相反的觀念並列對照。
@ana B x
「不勉強自己」「把日子過成喜歡的樣子」前後意思一致，是順承關係，全句沒有相反或相對的概念，屬一般直述。
@ana C o
「傷心」與「幸福」是相反的情感；「坎」（坑陷、難關）與「階梯」（向上的途徑）是相反的意象。書名把兩者對列，說每一次傷心其實都通往幸福，使語意在對比中更鮮明；同時「坎」「階梯」也是譬喻。符合映襯。
@ana D x
「理直氣壯」形容走路的{k:態度}，「彎路」是所走的{k:路}，兩者是「修飾語＋被修飾的動作」的關係，並沒有把兩種相反的觀念拿來對列比較。「直」與「彎」在字面上相映成趣，是用字的巧思，但「理直」的「直」指道理正當，與道路的彎曲不在同一層次。
@trap
(D) 有討論空間：「走彎路」通常讓人心虛，卻說得「理直氣壯」，確實帶有反差趣味，寬鬆地看也可視為映襯。但本題要選的是最符合題幹定義者——(C) 的兩組相反概念（傷心／幸福、坎／階梯）分置前後兩句、明顯對列，是最典型的映襯，也是官方答案。遇到修辭題出現「好像都可以」的選項時，回到{k:題幹給的定義與範例}比對，選最像範例的那一個。
@know 映襯的三種類型
| 類型 | 說明 | 例句 |
| 反襯 | 對一種事物，用與它相反的現象來襯托 | 蟬噪林逾靜，鳥鳴山更幽（王籍〈入若耶溪〉） |
| 對襯 | 對兩種不同的人事物，用相反的觀點對照 | 朱門酒肉臭，路有凍死骨（杜甫） |
| 雙襯 | 對同一人事物，用兩種相反的觀點形容 | 最沉重也是最甜蜜的負荷（吳晟〈負荷〉） |
- 本題 (C)「傷心的坎＝幸福的階梯」是對同一件事（挫折）提出兩種相反的看法，與題幹範例同屬{k:雙襯}。
@know 吳晟與〈負荷〉
- 吳晟，本名吳勝雄，彰化溪州人，長年任教於國中並務農，是臺灣鄉土詩的代表詩人，著有詩集《吾鄉印象》、《向孩子說》等。
- 〈負荷〉是「向孩子說」系列的作品，以父親的口吻寫為子女辛勞的心情。「負荷」原是負擔，冠上「甜蜜」，寫出父母{k:甘願承擔}的愛。
- 全詩語言樸素、不用典故，卻以結尾這一句映襯成為名句。
@know 映襯、對偶、排比的分別
| 修辭 | 看什麼 | 判斷關鍵 | 例句 |
| 映襯 | 內容 | 意思相反或相對 | 生也有涯，知也無涯 |
| 對偶 | 形式 | 兩句字數相等、句法相似 | 海內存知己，天涯若比鄰 |
| 排比 | 形式 | 三句以上結構相似 | 苦其心志，勞其筋骨，餓其體膚（《孟子》） |
- 一個句子可以同時兼用：如「朱門酒肉臭，路有凍死骨」內容是映襯，形式上兩句字數相等、兩兩相對。

=== Q 12
@type 量詞的功能分析
@cat 語文應用
@tags 量詞, 語法, 詞語結構
@diff 4
@answer A
@stem
下框中的八組詞語中的第二個字，位置都在「數詞」與「名詞」之間；關於這八個字的{y:用法|逐字代入測試}，敘述最適當的是：
@note red
每個選項都是一種「測試」：
刪掉／換「個」／看形貌／加「的」
@box lines
一{g:__①盞__}寒泉　　一{o:__②把__}眼淚　　一{o:__③副__}對聯　　一{g:__④枝__}煙囪
雙{b:__⑤峰__}駱駝　　四{b:__⑥面__}荷花　　五{b:__⑦日__}京兆　　七{g:__⑧匹__}野狼
@note green
①④⑧＝單純計數的量詞
@note blue
⑤峰＝駝峰（名詞）
⑥四面＝四周（方位）
⑦五日＝五天（時間）
→ 都不是在「數」後面的名詞
@opt A
①④⑧若不出現，不影響語意
@note green
一寒泉、一煙囪、七野狼 → 意思仍明白 ✓
@opt B
③⑦⑧可用「個」替換，亦可清楚表達
@note blue
五「個」京兆 ✗（變成五位京兆尹）
@opt C
②⑤⑥對於後面所接的名詞，能提供形貌的訊息
@note blue
只有⑤峰說出外形
@opt D
除了①④⑦外，其餘與後面的名詞間，均可加「的」
@note blue
一副「的」對聯 ✗　七匹「的」野狼 ✗
@key
盞、枝、匹是單純計數的量詞，拿掉後「一寒泉、一煙囪、七野狼」語意不變；峰、面、日則各有實義，其餘選項都找得到反例。
@logic
1. 【把選項當成測試】四個選項分別是「刪除測試」「換『個』測試」「形貌測試」「加『的』測試」。每個選項提到的字都要代入，只要有一個不成立，該選項就錯。
2. 【先分類】八個字其實不是同一種：①盞、④枝、⑧匹是替後面名詞計數的量詞；②把、③副是表示「一手之量」「成對成組」的量詞；⑤峰、⑥面、⑦日則分別是駝峰、方位、時間，「雙峰」「四面」「五日」是整組修飾後面的名詞。
3. 【測試 A】刪除後成為「一寒泉」「一煙囪」「七野狼」，數詞直接加名詞（文言常見），數量與所指都沒有改變 → 成立。
4. 【找 B、C、D 的反例】(B) 五個京兆 ✗；(C)「一把」是手握的量、「四面」是方位，都不是形貌；(D)「一副的對聯」「七匹的野狼」不合語法。
5. 【結論】選 (A)。
@ana A o
①「盞」是計算燈或飲料的量詞，④「枝」計算細長物，⑧「匹」計算馬、騾等牲畜，此處用於狼。三者的功能都只是幫名詞計數，本身不增加新的訊息。刪去後「一寒泉、一煙囪、七野狼」仍可理解為同樣的數量與事物（文言本就常以數詞直接接名詞，如〈口技〉「一桌、一椅、一扇、一撫尺」）。敘述最為適當。
@ana B x
③「一個對聯」口語勉強可通，但失去「副」所表示的{k:上下聯成對}之意；⑧「七個野狼」不合習慣（動物多用隻、匹、頭）；⑦「五日京兆」的「日」是時間單位，「五日」指任期只剩五天，換成「五個京兆」就變成「五位京兆尹」，意思全非。
@ana C x
⑤「峰」指駝峰，「雙峰」確實說明了駱駝背部的外形。但②「把」是「一手所握的量」，「一把眼淚」形容淚多，並未描述眼淚的形狀；⑥「四面」是方位詞，指四周都是荷花，也不是荷花的形貌。三者中只有一項成立。
@ana D x
依選項，②③⑤⑥⑧都應能加「的」。「雙峰的駱駝」「四面的荷花」可以，因為「雙峰」「四面」本來就是修飾語；但「一副的對聯」「七匹的野狼」不合語法——「數詞＋量詞」與名詞之間，一般不加「的」。「一把的眼淚」也不自然。
@trap
①「盞」有討論空間：嚴格說，「一盞寒泉」是借容器（杯盞）為量，意為「一杯泉水」；刪去後的「一寒泉」可能被理解為「一道泉水」，數量概念略有出入。不過題目問的是「最適當」的敘述，(B)(C)(D) 各有明確而無法補救的反例，(A) 仍是相對最佳的選項，也是官方答案。作答這類語法題，{k:找反例刪去}比逐項求證更可靠。
@know 量詞的種類
| 種類 | 說明 | 例子 |
| 個體量詞 | 計算單一事物，常與名詞固定搭配 | 一匹馬、一枝筆、一盞燈、一張紙 |
| 集合量詞 | 計算成組、成群的事物 | 一副對聯、一雙筷子、一群羊、一套書 |
| 借用量詞 | 借容器、身體部位等名詞或動作為量 | 一碗飯、一杯水、一把米、一身汗 |
| 度量衡量詞 | 表示長度、重量、容量等 | 三尺、五斤、一公升 |
| 時間量詞 | 表示時間長短 | 五日、三年、一會兒 |
| 動量詞 | 計算動作的次數 | 去一趟、看兩遍、打三下 |
- 本題①④⑧屬個體量詞（①也可視為借用量詞），③屬集合量詞，②屬借用量詞，⑦屬時間量詞；⑤「峰」、⑥「面」在此則是名詞與方位詞。
@know 文言與白話的數量表達
| 形式 | 例句 | 說明 |
| 數詞＋名詞 | 一桌、一椅、一扇、一撫尺（〈口技〉） | 文言常省略量詞 |
| 名詞＋數詞＋量詞 | 白璧一雙、玉斗一雙（《史記‧項羽本紀》） | 數量放在名詞之後 |
| 數詞＋量詞＋名詞 | 一張桌子、一把椅子 | 現代白話的標準形式 |
- 翻譯文言時，要替「數詞＋名詞」補上適當的量詞，這是語譯題的基本功。
@know 框中詞語的典故
- {k:一盞寒泉}：蘇軾〈書林逋詩後〉「一盞寒泉薦秋菊」，以清泉、秋菊祭祀隱士林逋。
- {k:四面荷花}：濟南大明湖鐵公祠的對聯「四面荷花三面柳，一城山色半城湖」，見於劉鶚《老殘遊記》第二回（課文〈大明湖〉）。
- {k:五日京兆}：漢代京兆尹張敞因案將被免職，下屬絮舜不肯替他辦事，說：「今五日京兆耳，安能復案事？」（《漢書‧張敞傳》）後比喻任職時間短暫或即將去職。

=== Q 13
@type 四大句型的辨識
@cat 語文應用
@tags 語法, 句型, 倒裝
@diff 4
@answer A
@stem
中國語法有四大句型：敘事句、有無句、表態句、判斷句。下表中的例句與句型，{y:完全正確|兩個例句都要符合}的選項是：
@note red
判斷法：只看{c:謂語}的核心
動詞→敘事　有／無→有無
形容詞→表態　是／為／也→判斷
@table
| 選項 | 例句一 | 例句二 | 句型 |
| (A) | 主義是從 | 天將降大任於是人也 | 敘事句 |
| (B) | 有恆為成功之本 | 此地無銀三百兩 | 有無句 |
| (C) | 但聞黃河流水鳴濺濺 | 靜極了，這朝來水溶溶的大道 | 表態句 |
| (D) | 蓮，花之君子者也 | 君不見黃河之水天上來 | 判斷句 |
@note blue
以下選項即表中各列，手寫字為實際句型
@opt A
主義是{y:從}{n:敘事}／天將{y:降}大任於是人也{n:敘事}　→ 敘事句
@note red
從主義（賓語提前）✓
@opt B
有恆{y:為}成功之本{n:判斷}／此地無銀三百兩{nb:有無}　→ 有無句
@note blue
「為」＝是，不是「有」！
@opt C
但{y:聞}黃河流水鳴濺濺{n:敘事}／靜極了，這朝來水溶溶的大道{nb:表態}　→ 表態句
@opt D
蓮，花之君子者也{nb:判斷}／君不{y:見}黃河之水天上來{n:敘事}　→ 判斷句
@cols 1
@key
「主義是從」是「從主義」的賓語提前，與「天將降大任於是人也」都以動詞為謂語核心，同屬敘事句；其餘三項各有一句不合。
@logic
1. 【記住判準】句型看的是謂語：以{k:動詞}敘述行為 → 敘事句；以{k:有、無}表示存在或領有 → 有無句；以{k:形容詞}描寫性質狀態 → 表態句；以{k:是、為、乃}或「……者，……也」對主語下判斷 → 判斷句。
2. 【還原倒裝】「主義是從」不是判斷句！「是」在這裡是幫助賓語提前的助詞，原句為「從主義」（遵從主義），與「唯利是圖」「馬首是瞻」同一結構。
3. 【別被第一個字騙】「有恆為成功之本」開頭有「有」，但「有恆」是主語，謂語是「為成功之本」→ 判斷句。
4. 【逐項檢查】(B) 例句一是判斷句；(C) 例句一是敘事句（聞）；(D) 例句二是敘事句（見）。只有 (A) 兩句皆為敘事句。
@ana A o
主義是從：出自國歌歌詞「夙夜匪懈，主義是從」。原序為「從主義」，以「是」為標誌把賓語「主義」提到動詞「從」之前，謂語核心是動詞「從」→ 敘事句。
天將降大任於是人也：出自《孟子‧告子下》。主語「天」、述語「降」、賓語「大任」、補語「於是人」→ 敘事句（此句的「是」為指示代詞「這」）。
兩句皆為敘事句，完全正確。
@ana B x
有恆為成功之本：主語「有恆」，繫詞「為」（是），斷語「成功之本」→ {k:判斷句}，不是有無句。
此地無銀三百兩：主語「此地」，述語「無」，賓語「銀三百兩」→ 有無句。
例句一不合。
@ana C x
但聞黃河流水鳴濺濺：出自〈木蘭詩〉。主語（木蘭）省略，述語「聞」，賓語是「黃河流水鳴濺濺」整個子句 → {k:敘事句}。
靜極了，這朝來水溶溶的大道：出自徐志摩〈我所知道的康橋〉。原序為「這朝來水溶溶的大道靜極了」，謂語是形容詞「靜」→ 表態句（主謂倒裝）。
例句一不合。
@ana D x
蓮，花之君子者也：出自周敦頤〈愛蓮說〉。以「……者也」對主語「蓮」下判斷 → 判斷句（文言判斷句常不用繫詞）。
君不見黃河之水天上來：出自李白〈將進酒〉。主語「君」，述語「見」，賓語是「黃河之水天上來」→ {k:敘事句}。
例句二不合。
@trap
本題三大陷阱都在「看到某個字就下判斷」：看到「是」就選判斷句（主義是從）、看到「有」就選有無句（有恆為……）、看到「也」就選判斷句（天將降大任於是人也）。句型要看{k:謂語的核心詞}，不是看句中出現了哪個字。
@know 四大句型一覽
| 句型 | 謂語核心 | 白話例 | 文言例 |
| 敘事句 | 動詞（述語） | 我讀書 | 沛公軍霸上；天將降大任於是人也 |
| 有無句 | 有、無（沒有） | 我有一本書 | 山不在高，有仙則名；此地無銀三百兩 |
| 表態句 | 形容詞（表語） | 花很香 | 天蒼蒼，野茫茫；山高月小 |
| 判斷句 | 繫詞是、為、乃、非（斷語） | 他是學生 | 蓮，花之君子者也；有恆為成功之本 |
- 以「像、如、似、猶」連接主語和斷語的，稱為{k:準判斷句}，如「人生如夢」。
@know 賓語提前的固定格式
| 格式 | 例子 | 還原 |
| 賓語＋是＋動詞 | 主義是從、唯利是圖、馬首是瞻、唯命是從 | 從主義、圖利、瞻馬首、從命 |
| 賓語＋之＋動詞 | 何陋之有、何罪之有 | 有何陋、有何罪 |
| 否定句代詞賓語前置 | 時不我與、莫我知也 | 時不與我、莫知我也 |
- 這裡的「是」「之」沒有實際意義，只是{k:提前賓語的標誌}，翻譯時不必譯出。
@know 例句出處整理
- 主義是從：國歌歌詞（原為孫中山先生對黃埔軍校的訓詞）。
- 天將降大任於是人也：《孟子‧告子下》「生於憂患，死於安樂」章。
- 此地無銀三百兩：民間故事，後接「隔壁張三未曾偷」，比喻想隱瞞反而暴露。
- 但聞黃河流水鳴濺濺：〈木蘭詩〉；「濺濺」是形容流水聲的擬聲詞。
- 靜極了，這朝來水溶溶的大道：徐志摩〈我所知道的康橋〉。
- 蓮，花之君子者也：周敦頤〈愛蓮說〉。
- 君不見黃河之水天上來：李白〈將進酒〉。

=== Q 14
@type 六書造字法的判別
@cat 國學常識
@tags 六書, 象形, 形聲, 會意
@diff 3
@answer A
@stem
下列六書的分類，{y:正確|兩個字都要對}的敘述是：
@note red
每項兩個字，{c:一錯全錯}
先問：能不能拆成兩個字？
@opt A
「泉、貝」屬於{g:象形}字
@opt B
「果、田」屬於{x:指事}{n:象形}字
@opt C
「{u:固}、囚」屬於會意字
@opt D
「吟、{u:琴}」屬於形聲字
@note green
(A) 泉：水從穴中流出；貝：貝殼 ✓
@note blue
(B) 果＝樹上結果；田＝田地阡陌，都畫實物
(C) 固：囗＋古聲 → 形聲
(D) 琴：小篆象琴身之形 → 象形
@key
「泉」象泉水自穴流出、「貝」象貝殼之形，皆為象形；果、田亦象形，固為形聲，琴在《說文》屬象形。
@logic
1. 【先分獨體、合體】象形、指事多為不能再拆的「獨體字」；會意、形聲是由兩個以上部件組成的「合體字」。
2. 【合體字找聲符】拆開後若有一個部件表示讀音，就是形聲；若各部件都表意，就是會意。「固」從囗、{k:古}聲 → 形聲；「囚」是人在囗中 → 會意。(C) 一對一錯。
3. 【獨體字分象形、指事】畫出具體實物的是象形；用抽象符號或在象形字上加記號的是指事。「果」畫的是樹上的果實、「田」畫的是田地與阡陌，都是實物 → 象形，(B) 錯。
4. 【留意古文字】「琴」的楷書看似「上形下聲」，但《說文解字》據小篆列為象形；「吟」從口、今聲是形聲。(D) 一對一錯。故選 (A)。
@ana A o
泉：《說文》「水原也。象水流出成川形」，像泉水從洞穴中流出 → 象形。
貝：《說文》「海介蟲也……象形」，像貝殼的形狀 → 象形。
兩字皆正確。
@ana B x
果：《說文》「木實也。从木，象果形在木之上」，在「木」上畫出果實之形，是依附於「木」的象形字（又稱合體象形）。
田：《說文》「象四囗；十，阡陌之制也」，像一塊塊田地與田間的道路 → 象形。
兩字都是象形，不是指事。指事字如上、下、本、末、刃。
@ana C x

@ana D x

@trap
六書題的歸類一律以{k:《說文解字》的小篆字形}為準，不能只看楷書。「琴」是最典型的陷阱字：楷書看起來上「玨」下「今」，很像形聲，考試時卻要答象形。同類的還有「果」「瓜」「眉」「石」——看似可拆，其實是「合體象形」。
@know 六書定義與例字
| 六書 | 許慎的定義 | 白話說明 | 例字 |
| 象形 | 畫成其物，隨體詰詘 | 照實物的樣子畫出來 | 日、月、山、水、泉、貝、田、果 |
| 指事 | 視而可識，察而見意 | 用抽象符號，或在象形字上加記號 | 上、下、本、末、刃、寸 |
| 會意 | 比類合誼，以見指撝 | 合併兩個以上的字，產生新義 | 武、信、明、休、囚、森 |
| 形聲 | 以事為名，取譬相成 | 一半表意（形符），一半表音（聲符） | 江、河、吟、固 |
| 轉注 | 建類一首，同意相受 | 同部首、意義相通的字互相解釋 | 考、老 |
| 假借 | 本無其字，依聲託事 | 借用同音字來表示新的意思 | 令、長 |
- 前四種是{k:造字}的方法，後兩種是{k:用字}的方法；中文字以形聲字占絕大多數。
@know 判別六書的三步驟
- 第一步：這個字能不能拆成兩個「獨立成字」的部件？不能 → 象形或指事；能 → 會意或形聲。
- 第二步（獨體）：畫的是具體的東西 → 象形；有抽象的點、畫作記號 → 指事（如「本」是在木的根部加一橫、「刃」是在刀口加一點）。
- 第三步（合體）：唸唸看，有沒有部件和整個字的讀音相同或相近？有 → 形聲；沒有 → 會意。
@know 「囗」部字：形聲還是會意？
| 類別 | 例字 | 說明 |
| 形聲 | 固（古聲）、圍（韋聲）、園（袁聲）、圓（員聲）、圃（甫聲） | 裡面的部件表音 |
| 會意 | 囚（人在囗中）、困（木在囗中）、因（从囗、大） | 裡面的部件表意 |
- 口訣：{k:裡面那個字唸得出整個字的音，就是形聲}。

本題的關鍵是「{k:引述 ≠ 認同}」。學術性文章常常先陳述別人的理論再加以批評，誘答選項就從「被批評的理論」裡取材（如 B），或從「被引述者的讓步」裡取材（如 D）。作答時在每個選項旁註明「這是誰說的」，就不會選錯。
@know 分辨「作者觀點」的三個線索
| 線索 | 說明 | 本文例子 |
| 評價詞 | 帶有褒貶色彩的形容 | 偽科學、尖刻諷刺、成見、標籤 |
| 轉折詞之後 | 作者真正要說的話常在「但、不過、然而」後面 | 「不過，在實證主義當令的十九世紀……」 |
| 結尾段 | 全文推論的落點 | 仇恨扭曲了他們的臉 |
@know 「滑坡」式的論述：短短一步而已
- 第三段用「從……到……，短短一步而已。再下一步，就是……」的句式，呈現一個觀念如何一步步滑向極端：{k:學術理論 → 社會成見 → 標籤與歧視 → 種族仇恨}。
- 這提醒讀者：看似中性的「分類」，一旦和「道德評價」綁在一起，就可能成為迫害的藉口。閱讀科普或社會議題文章時，可以多問一句：「這個說法如果被濫用，會發生什麼事？」

## 一、兩則文本的關係
| 比較 | 甲：曹沖稱象 | 乙：〈冰之道〉 |
| 文體 | 文言史傳（《三國志‧魏書》） | 白話科普短文 |
| 主題 | 用船與水痕量出大象的重量 | 水的密度隨溫度變化，冰由水面結起 |
| 用到的科學概念 | 浮力、等重替換 | 密度、熱脹冷縮與「熱縮冷脹」、凝固點 |

## 二、甲文：曹沖的方法為什麼可行
- 步驟：①象上船，刻下水痕 → ②象下船 → ③搬物品上船，直到水面再次到達刻痕 → ④分批秤出物品的重量，加總即為象重。
- 原理：船浮在水上時，{k:浮力＝船與載重的總重＝排開的水重}。同一艘船、在同一片水域沉到同一刻痕，表示排開的水一樣多，所以「象重＝物重」。
- 文中只有「刻其水痕」「稱物以載之」十個字，原理完全省略——這就是第 23 題所說的「預設背景知識」。
## 三、乙文：推理鏈
- 水面降溫（4℃ 以上）→ 冷的水密度大 → 下沉、對流混合。
- 水面降到 4℃ 以下 → 愈冷密度愈小 → 停在水面 → 0℃ 時由水面結冰。
- 結果：冰層在上、接近 4℃ 的水在下，水中生物不致凍死。
- 注意這條推理鏈的{k:適用條件}是「水面溫度低於 4℃」的寒冷水域，第 24 題就考這個條件。
@know 浮力重點整理（國中理化）
| 狀態 | 密度關係 | 浮力與重量 |
| 漂浮（浮體） | 物體密度＜液體密度 | 浮力＝物重＝排開的液體重 |
| 懸浮 | 物體密度＝液體密度 | 浮力＝物重 |
| 沉底（沉體） | 物體密度＞液體密度 | 浮力＜物重 |
- 阿基米德原理：物體在液體中所受的浮力，等於它所排開的液體的重量。
- 完全沒入液體的物體，排開的體積固定，浮力{k:與深度無關}。
- 同一浮體在不同液體中：浮力都等於物重（相同），但液體密度愈大，排開的體積愈小、吃水愈淺。
@know 水的「反常膨脹」
- 一般物質熱脹冷縮，水在 4℃ 以上也是如此；但在 0℃ 到 4℃ 之間，水是「熱縮冷脹」——溫度愈低，體積愈大、密度愈小。所以 4℃ 的水密度最大。
- 水結成冰後體積更大、密度更小，因此冰浮在水面。
- 生活例子：寒帶湖泊冬天只有表面結冰，魚類仍可在冰層下的水中活動；裝滿水的玻璃瓶放進冷凍庫會脹裂。
@know 曹沖與「稱象」故事
- 曹沖，字倉舒，曹操之子，自幼聰慧，十三歲病逝，後追諡為鄧哀王；稱象之事見《三國志‧魏書‧鄧哀王沖傳》。
- 「太祖」是後人對曹操的廟號稱呼（魏武帝）。
- 這個故事所用的「以物代象、化整為零」，在科學方法上稱為{k:等效替代}：把無法直接測量的量，換成可以測量而效果相同的量。
- 學者陳寅恪曾指出，稱象的故事與佛經中的故事相似，可能受到佛教傳說的影響。

@stem
依據甲文，關於太祖所「{y:施行}」的方式，理解最恰當的是：
@note red
施行的就是曹沖的話：
刻水痕 → 稱物以載之
@opt A
巨象乘船{x:不分大小}，都可浮在水面上
@note blue
原文強調「大船」
@opt B
巨象上船後{x:再加上}「物」，讓船得以{x:保持平衡}
@note blue
物是「代替」象，不是同載
@opt C
大船靜止後，{x:不論在河水或海水}，下降的水痕刻度會相同
@note blue
海水密度大 → 吃水較淺
@opt D
大船所載之「物」不論是石塊或鉛塊，藉此推算巨象的重量會相同
@note red
只要沉到同一水痕 → 總重相同 ✓
@key
曹沖的方法是「等重替換」：物品把船壓到同一道水痕時，重量就等於象重，與所載的是石塊或鉛塊無關。
@logic
1. 【還原步驟】「置象大船之上，而刻其水痕所至」→ 象上船、作記號；「稱物以載之」→ 改載可以秤重的物品，使船沉到同一記號；「則校可知」→ 物品總重即象重。
2. 【想原理】船沉到同一刻痕，表示排開的水一樣多、浮力一樣大，所以船上的載重一樣。決定吃水深淺的是{k:重量}，不是物品的材質。
3. 【逐項檢查】(A) 小船載不動巨象；(B) 把「替換」說成「加上」、把目的說成「平衡」；(C) 換了液體密度，吃水深度會變。
4. 【結論】(D) 石塊、鉛塊雖然密度不同，但只要把船壓到同一水痕，總重量相同，推得的象重也相同。
@ana A x
原文明說「置象{k:大船}之上」。船能承載的重量取決於它能排開多少水；船太小，載上巨象就會沉沒。「不分大小都可浮」不合文意，也不合物理。
@ana B x
錯在「再加上」與「保持平衡」。稱象時，物品是在大象{k:下船之後}才搬上船的，用來「代替」大象把船壓到同一水痕；目的是求得與象等重的物品，不是為了讓船平衡。
@ana C x
同一艘船載同樣的重量，在河水或海水中所受的浮力相同（都等於總重）；但海水密度較大，只需排開較少的體積就能產生同樣的浮力，所以船在海水中吃水較淺，水痕位置{k:不同}。這也是稱象必須在同一片水域完成的原因。
@ana D o
無論載的是石塊還是鉛塊，只要船下沉到與載象時相同的水痕，船上物品的總重就等於象重。鉛塊密度大、體積小，石塊密度小、體積大，但影響吃水的是重量而非體積或材質。理解正確。
@trap
(B) 的說法似是而非：很多人記得「船上放石頭」，卻沒注意象與石頭{k:不是同時在船上}。原文「稱物以載之」省略了「牽象下船」的步驟，要靠推理補足——既然要「校」（比較），就必須是「象」與「物」分別造成相同的水痕。
@know 文言的「省略」與補讀
- 甲文僅五十餘字，卻省略了：牽象下船、把物搬上船至水痕、分次秤物、加總等步驟。文言敘事重簡潔，讀者須依{k:事理}補上。
- 補讀方法：遇到「而」「以」「則」等連接詞，問自己「這兩個動作之間，還需要發生什麼事？」
| 原文 | 省略的內容 |
| 刻其水痕所至 | （然後把象牽下船） |
| 稱物以載之 | （裝到水面到達刻痕為止） |
| 則校可知矣 | （把物品的重量加總，就等於象重） |
@know 本文字詞整理
| 字詞 | 意義 | 補充 |
| 致 | 送來、進獻 | 「致贈」的致 |
| 訪 | 詢問、徵求意見 | 不是拜訪 |
| 羣下 | 手下眾人、群臣 | 羣同「群」 |
| 咸 | 全、都 | 「老少咸宜」的咸 |
| 理 | 方法、道理 | 「莫能出其理」＝想不出辦法 |
| 稱 | 測量輕重 | 動詞，音ㄔㄥ；「稱物」即秤量物品的重量 |
| 校 | 比較、核算 | 音ㄐㄧㄠˋ，「校對」的校 |
@know 同類思考：阿基米德與王冠
- 相傳古希臘的阿基米德受命檢驗王冠是否為純金，他在洗澡時想到：把物體浸入水中，溢出的水體積就等於物體的體積，由此可比較王冠與等重純金的體積。
- 曹沖用水量「重量」，阿基米德用水量「體積」，兩者都是{k:把難以直接測量的量，轉換成容易測量的量}。

@note red
作法：每個選項問——
「少了它，甲或乙還讀得懂嗎？」
@opt A
密度小於水的物體，就會浮在水面
@note blue
乙：密度小的水、冰留在水面
@opt B
同一物體漂浮在{g:河水或海水}上，浮力是一樣的
@note red

@opt C

@note blue

@opt D

@logic
1. 【理解題意】「預設為背景知識」＝文章用到了這個知識，卻沒有解釋。題目要找的是兩篇文章都{k:沒有用到}的那一項。四個選項本身都是正確的科學知識，不必判斷對錯。
2. 【檢查甲文】曹沖只說「刻水痕、稱物」，為何可行？因為浮力等於排開的液體重 → 預設了 (C)。
3. 【檢查乙文】「熱縮冷脹的水自然會維持在水面」、冰由水面結起 → 預設密度小者在上，即 (A)；「海水比淡水更難結冰」沒有說明原因 → 預設了 (D)。
4. 【剩下 B】甲文的稱象在同一片水域進行，乙文也沒有比較物體在河、海中的浮力 → (B) 未被預設。
@ana A x
乙文說水面的水降到 4℃ 以下後「熱縮冷脹」「自然會維持在水面」，又說冰從水面結起——為什麼密度變小就留在上面？文章沒有解釋，是預設讀者知道「密度較小者會浮在上方」。甲文的船能浮在水上也與此有關。已被預設。
@ana B o
這項知識要在「同一物體分別放在河水與海水」的情境才用得上。甲文稱象前後都在同一處水面，乙文談的是水溫與結冰，都沒有涉及在不同水域比較浮力。兩文皆未預設，為正解。
@ana C x

@ana D x

@trap
這題有兩個容易出錯的地方。第一，題幹是{k:否定型}（「未被」原卷以粗體加底線標示），不要選成「有被預設」的。第二，(B) 看起來和甲文很有關係——上一題 (C) 才剛討論過河水與海水——但那是{k:選項}帶進來的情境，甲文本身從頭到尾只有一片水域。判斷「文章預設了什麼」，只能看文章，不能看其他題目的選項。
@know 什麼是「預設知識」
- 作者寫作時會設想讀者已經知道某些事，因而省略不說。讀者若缺少這些知識，就會覺得「跳步」或讀不懂。
| 文本 | 文章說了什麼 | 沒說、但必須知道的 |
| 甲 | 刻水痕、稱物以載之 | 浮力＝排開的液體重（C） |
| 乙 | 熱縮冷脹的水留在水面；冰從水面結起 | 密度小的浮在上面（A） |
| 乙 | 海水比淡水更難結冰 | 海水含鹽，凝固點較低（D） |
- 閱讀科普文章的好習慣：每讀到一個「所以」「自然會」，就問一句「為什麼？」——答不出來的地方，往往就是作者預設的知識。
@know 浮體在河水與海水中的比較
| 項目 | 河水（密度較小） | 海水（密度較大） |
| 浮力 | ＝船重 | ＝船重（相同） |
| 排開液體的體積 | 較大 | 較小 |
| 吃水深度 | 較深 | 較淺 |
- 這就是 (B) 的內容，也解釋了上一題 (C) 為什麼錯：浮力相同，但水痕不同。
- 生活實例：船從河港駛入大海，船身會略微上浮。

@know 「正確／錯誤／無法判斷」怎麼分
| 研判 | 條件 | 本題 |
| 正確 | 文本的資訊足以證明它成立 | — |
| 錯誤 | 文本的資訊（或其預設的原理）足以證明它不成立 | ②：違反浮力原理 |

@know 水溫隨深度的兩種分布
| 情況 | 水面溫度 | 水的性質 | 溫度分布 |
| 溫暖季節 | 高於 4℃ | 熱脹冷縮，冷水較重而下沉 | 愈深愈冷 |
| 嚴寒結冰 | 0℃ 至 4℃ | 熱縮冷脹，4℃ 的水最重而在下 | 表層最冷，深處接近 4℃ |
- 所以「沉得愈深水溫愈高」只在第二種情況、而且只到 4℃ 為止才成立。
@know 浮力與深度的關係
- 物體{k:尚未完全沒入}時：沒入愈多，排開的液體愈多，浮力愈大。
- 物體{k:完全沒入}後：排開的體積固定，浮力不再改變。
- 口訣：浮力看「排開多少」，不看「沉得多深」。

## 一、全文在回答一個問題：小說為什麼要「說故事」？
- 第一段提出主張：小說表達意念的方式是「{k:不直說}」，但讀者最後能看出作者本意，所以「不說」等於「已說」。
- 第二段用對照與例證來支持：同樣寫母愛，散文可以明說，小說則用杜子春的故事讓讀者自己領會。
## 二、散文與小說的對照
| 比較 | 散文（文中的例子） | 小說（杜子春的故事） |
| 表達方式 | 明白說出「母親都是強者」 | 說故事，字面上不着痕跡 |
| 主旨位置 | 在文字表面 | 藏在故事背後 |
| 讀者要做的事 | 接受作者的結論 | 自己感動、聯想、歸納 |
| 作者的評價 | 是一篇很好的散文 | 一篇很好的小說「不能這麼做」（不能直說） |
## 三、讀者的閱讀歷程（第二段後半）
- {k:特殊事件}（杜子春為孩子叫出聲）→ 受感動 → {k:聯想}同類事件（天下父母為子女放棄理想）→ {k:歸納}出普遍道理（母愛是不可磨滅的人性）→ 用來{k:解釋、批判人生}。
- 末句是全文的結論：小說先以「具體事件」滿足感性，再引發「抽象思考」的理性活動。
## 四、容易誤讀之處
- 「不說」不是「什麼都不寫」。小說不說的只是{k:主旨}；人物的性格、遭遇都必須透過{k:情節}具體地寫出來——這正是第 25 題甲項的考點。
@know 杜子春的故事來源
- 出自唐人傳奇〈杜子春〉，收於《太平廣記》，一般題為李復言《續玄怪錄》（一說出自牛僧孺《玄怪錄》）。
- 原作情節：杜子春受老人之助，入山為其看守丹爐，老人囑咐「慎勿語」。他歷經猛獸、雷雨、酷刑等幻境皆不出聲，後轉生為女子，見丈夫摔死親生孩子，不覺失聲，丹爐遂毀。老人嘆息說，他喜、怒、哀、懼、惡、慾都已忘卻，「所未臻者，愛而已」。
- 日本作家芥川龍之介曾將它改寫為同名短篇〈杜子春〉。
@know 作者王鼎鈞
- 王鼎鈞，山東臨沂人，當代散文名家，來臺後長期從事寫作與編輯，後旅居美國。
- 「人生三書」：《開放的人生》、《人生試金石》、《我們現代人》。
- 談寫作的系列：《文路》、《講理》、《作文七巧》、《作文十九問》、《文學種籽》——本文即出自《文學種籽》。
- 回憶錄四部曲：《昨天的雲》、《怒目少年》、《關山奪路》、《文學江湖》。
@know 寫作應用：把道理「藏」進故事
- 直說：「母愛很偉大。」——讀者點頭，但未必感動。
- 不說：寫一位母親在颱風夜把唯一的雨衣披在孩子身上——讀者自己得出「母愛偉大」。
- 寫記敘文、抒情文時，試著{k:刪掉結尾的大道理}，改用一個具體的動作或畫面收束，往往更有餘味。這與第 9 題鍾嶸所說「文已盡而意有餘」是同一個道理。

後半「藉由故事具體的事件傳遞抽象的旨意」符合文意，但前半「沒有意象的小說是失敗的小說」於文無據——文中談的是「故事」「事件」，沒有提出「意象」的概念，更沒有下「失敗」的斷語。前錯後對，不能選。
@trap
(D) 的後半句寫得比 (B) 還像標準答案，是本題最大的陷阱。選項只要{k:有一半錯就整個錯}；尤其是「沒有……就是失敗」「凡是……都……」這類絕對化的說法，原文沒有就不能選。
@know 闡釋題的作答步驟
- 「闡述」「詮釋」題，是要找「把原句說得更清楚、而且{k:不增不減}」的選項。
- 步驟一：把原句切成幾個意義單位（本題：表達思想感情／字面上不着痕跡）。
- 步驟二：每個單位都要在選項中找到對應，且選項不能多出原文沒有的主張。
- 步驟三：若有兩個選項都不違背原文，選與{k:全文主旨}最貼近的一個。
@know 具體與抽象
| 概念 | 說明 | 本文例子 |
| 具體 | 可以看見、聽見的人事物 | 猛虎、毒蛇、擲嬰、一聲狂叫 |
| 抽象 | 無法直接感知的觀念、道理 | 母愛、人性、理想 |
| 特殊 | 個別的、只發生一次的 | 杜子春修道失敗 |
| 普遍 | 適用於多數情況的 | 天下父母為子女放棄理想 |
- 文學的常見路徑是「{k:以具體寫抽象、以特殊見普遍}」；論說文則常反過來，先提出抽象論點，再舉具體例子。本文作者為了說明前者，自己用的卻是後者的寫法——先說理、再舉杜子春為例。

## 一、寫作背景
- 李煜是南唐最後一位君主。宋太祖開寶八年（975），宋軍攻破金陵，李煜出降，被押往汴京，過著形同囚徒的生活，數年後去世。

## 三、重點句解讀
- 「夢裡不知身是客」：「客」是含蓄的說法，實指被俘的囚徒。夢中的歡樂愈真，醒來的悲哀愈深。
- 「獨自莫憑欄」：不是不想看，而是不敢看——一望江山，就想到再也回不去。
- 「雕欄玉砌應猶在，只是朱顏改」：宮殿還在，人事全非。「朱顏改」表面說容顏衰老，也暗示江山易主。
- 「一江春水向東流」：把看不見的「愁」化為看得見的江水，寫出愁的{k:多}（一江）、{k:長}（東流不盡）、{k:無法阻擋}。

闌珊，衰落、將盡。「春意闌珊」表面寫暮春景象，實則象徵詞人帝王生活與故國的衰亡；結尾「流水落花春去也」再以流水、落花、春去三個消逝的意象收束。一起一結同寫春殘，使全詞籠罩在「美好不再」的氛圍中。敘述正確。
@ana B x

@trap
(B) 的後半句完全正確，只有「順敘」兩個字錯，是典型的「{k:一詞之差}」選項。詩詞中判斷順敘或倒敘，不是看句子排列的先後，而是看{k:事件實際發生的先後}：夢在前、醒在後，詞卻先寫醒、後寫夢。
@know 詩詞中的倒敘
- 順敘：依事件發生的先後敘述。倒敘：先寫結果或後發生的事，再回頭寫起因或先前的事。
| 作品 | 先寫 | 後寫 |
| 李煜〈浪淘沙〉 | 夢醒：雨聲、五更寒 | 夢中：不知身是客，一晌貪歡 |
| 孟浩然〈春曉〉 | 清晨：處處聞啼鳥 | 昨夜：夜來風雨聲 |
- 倒敘的效果：先讓讀者感受到「現在」的淒涼，再對照「先前」的歡樂，落差更強烈。
@know 「落花」「流水」的象徵
- 落花：美好事物的凋零、青春或繁華的消逝。如「無可奈何花落去」（晏殊〈浣溪沙〉）、「林花謝了春紅，太匆匆」（李煜〈相見歡〉）。
- 流水：時間一去不返。如「逝者如斯夫，不舍晝夜」（《論語‧子罕》）。
- 「流水落花春去也」把三個「一去不返」的意象疊在一句裡，是李煜詞{k:意象密集而語言淺白}的代表。成語「落花流水」原指暮春殘景，後來才用以形容慘敗的樣子。
@know 版本小知識
- 「獨自莫憑欄」的「莫」，有的版本作「暮」。作「莫」是告誡自己不要憑欄，作「暮」則是黃昏時獨自憑欄，兩種讀法都通，情感都是面對江山的不堪。
- 讀古典詩詞遇到「一作某」的異文很常見，考試時依題目所給的文字作答即可。

「形象化」用於乙詞可以成立（以一江春水比喻愁）。但「羈旅之思」指旅人寄居他鄉的漂泊感與鄉愁；李煜是亡國之君、被俘之囚，詞中是「故國不堪回首」「無限江山……見時難」的{k:亡國之痛}，性質與一般遊子的羈旅之愁不同。甲詞的「身是客」只是囚徒身分的委婉說法。

(D) 容易因為甲詞有「身是客」而誤選。判斷詩詞情感要結合{k:作者身世與寫作背景}：同樣是「客」，杜甫「萬里悲秋常作客」是漂泊的旅人，李煜的「客」則是失去國家、失去自由的俘虜。題目用「羈旅」這個有固定含義的術語來測驗你能不能分辨。

| 類型 | 關鍵特徵 | 例句 |
| 羈旅鄉愁 | 遊子漂泊、思念家鄉 | 日暮鄉關何處是？煙波江上使人愁（崔顥〈黃鶴樓〉） |

| 閨怨相思 | 思念遠人、獨守空閨 | 忽見陌頭楊柳色，悔教夫婿覓封侯（王昌齡〈閨怨〉） |
@know 摹寫的五種感官
- 視覺：雕欄玉砌、春花秋月。
- 聽覺：簾外雨潺潺。
- 觸覺：羅衾不耐五更寒。
- 嗅覺：暗香浮動月黃昏（林逋〈山園小梅〉）。
- 味覺：別是一般滋味在心頭（李煜〈相見歡〉，以味覺寫愁）。
- 比較題常問「兩首都用了哪種感官」，作答時在詩句旁直接標上「視、聽、觸」最不會漏看。
