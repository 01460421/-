=== Q 2
@type 同音字形辨識（注音還原）
@cat 形音義
@tags 字形, 成語用字, 同音異字
@diff 4
@answer C
@stem
下列詞語「」內{y:字形|把注音寫成國字}，哪一選項{y:前後完全相同}：
@note red
作法：依{c:詞義}還原國字
再前後比對
@opt A
折衝「ㄗㄨㄣ」{nb:樽}俎／「ㄗㄨㄣ」{nb:遵}時養晦
@note blue
樽俎＝酒器＋禮器
遵＝依循
@opt B
析毫剖「ㄌㄧˊ」{nb:釐}／管窺「ㄌㄧˊ」{nb:蠡}測
@note blue
釐＝極小的單位
蠡＝瓠瓢
@opt C
「ㄑㄧㄢ」{n:搴}旗取將 ／「ㄑㄧㄢ」{n:搴（褰）}裳涉溱
@note red
搴：拔取；撩起
★《詩經》作「褰裳」
見「易錯提醒」
@opt D
奮袂「ㄖㄤˊ」{nb:攘}襟／求福「ㄖㄤˊ」{nb:禳}災
@note blue
攘＝捋起（手部）
禳＝祭祀消災（示部）
@key
(A) 樽／遵、(B) 釐／蠡、(D) 攘／禳 絕不可能同字；(C)「搴」兼有拔取、撩起二義，命題者視「搴旗」「搴裳」同字，以刪去法選 (C)。
@logic
1. 【審題】比的是字形。四組讀音本來就相同，必須依{k:詞義}把注音還原成國字。
2. 【以義定形】(A) 外交宴席上的酒器是「樽」，順應時勢是「遵」；(B) 極細微的單位是「釐」，舀水的瓠瓢是「蠡」；(D) 捋起衣襟的動作是「攘」（手部），祭祀消災是「禳」（示部）。這三組部首、意義都不同，確定不是答案。
3. 【看 C】「搴旗」是拔取敵旗，用「搴」。「ㄑㄧㄢ裳」是撩起衣裳，《詩經》原文作「褰」；但「搴」本身也有「揭、撩」的意思，古書中二字可通。
4. 【結論】其餘三項絕對不同字，只有 (C) 可以成立，選 (C)。
@ana A x
折衝「{k:樽}」俎：折衝，使敵人的戰車折返，指克敵制勝；樽是酒器，俎是盛肉的禮器，「樽俎」借指宴席。全句指在酒宴談判間制敵取勝，即外交手段。語本《晏子春秋‧內篇雜上》，也作「折衝尊俎」。
「{k:遵}」時養晦：遵，依循。指順應時勢、暫時退隱以待時機，語本《詩經‧周頌‧酌》「遵養時晦」。
→ 樽（尊）≠ 遵。
@ana B x
析毫剖「{k:釐}」：毫、釐都是極小的計量單位，形容分析得極為細密透澈。
管窺「{k:蠡}」測：蠡，瓠瓜做的水瓢。用竹管看天、用瓢量海水，比喻見識狹小，語本東方朔〈答客難〉「以筦窺天，以蠡測海」。
→ 釐 ≠ 蠡。
@ana C o
「{k:搴}」旗取將：搴，拔取。拔取敵旗、斬殺敵將，形容驍勇善戰，語出《吳子‧料敵》；也作「斬將搴旗」。
「ㄑㄧㄢ」裳涉溱：撩起下裳、涉過溱水，語出《詩經‧鄭風‧褰裳》「子惠思我，褰裳涉溱」，通行本作「{k:褰}」。教育部《重編國語辭典》「搴」字第三義為「揭、撩」（如陶淵明〈閑情賦〉「搴朱幃而正坐」），與「褰」的「提起、揭起」義相通。
→ 官方答案以二者同作「搴」，為本題正解。
@ana D x
奮袂「{k:攘}」襟：袂，衣袖；攘，捋起。揚起衣袖、撩起衣襟，形容振奮而起的樣子。
求福「{k:禳}」災：禳，祭祀祈求消除災禍，故從「示」部。
→ 攘 ≠ 禳。
@trap
本題官方答案 (C) 有用字上的討論空間：查教育部《重編國語辭典》，成語作「{k:搴}旗取將」，《詩經》篇名與詩句則作「{k:褰}裳」，兩詞條分立、用字不同；若嚴格依通行本，(C) 前後也不同字，全題將無解。命題者應是取「搴」的「揭、撩」義，認定「搴裳」亦可成立。
應考策略：字形題若發現「每一項似乎都不同」，不要慌——回頭比較哪一組{k:意義最接近、古書可以通用}。樽／遵、釐／蠡、攘／禳 的意義毫不相干，唯有搴／褰同音、同有「撩起」義，就是命題者設定的答案。本書依官方公布答案 (C)。

動詞的「意動用法」，指的是動詞對其賓語（受詞），有「{y:認為賓語是…}」、「{y:將賓語當作…}」的關係。如《孟子‧梁惠王上》：「叟！不遠千里而來，亦將有以利吾國乎？」其中的「遠」，意為「認為…遠」。下列文句「」的字{y:屬於「意動用法」|代入「以…為…」}的是：
@note red

＝心裡{c:認為}，非真的改變
@note blue
不遠千里＝不以千里為遠

@note blue

@opt B

@note blue

@opt C

@translation

(B) 不經交戰就使敵人的軍隊屈服，才是高明中最高明的。
(C) 百姓以失去國君為恥辱，又哀悼戰死的親人，不怕徵收賦稅、整修軍備，來擁立太子圉為國君。

@logic
1. 【讀懂定義】題幹給了公式：意動＝「認為賓語是…」。示例「不遠千里」＝「不{k:以}千里{k:為}遠」。解題時就用「以…為…」去代換「」內的字。
2. 【逐項代換】(A)「以財為殉」不通；(B)「以人之兵為屈」不通，應是「{k:使}人之兵屈服」；(C)「以失其君為恥」通順；(D)「以聲色之好為極」不通，應是「窮盡聲色之好」。

4. 【結論】選 (C)。

殉：為了某種目的而犧牲生命。「殉財」＝為財而死、「殉名」＝為名而死，動詞與賓語是「為了…而…」的關係，文法上稱為{k:為動用法}，不是意動。此句語本賈誼〈鵩鳥賦〉「貪夫徇財兮，烈士徇名」，《史記‧伯夷列傳》亦引之，「徇」通「殉」。
@ana B x
屈：屈服，本是不及物動詞；「屈人之兵」＝{k:使}敵人的軍隊屈服，是{k:使動用法}。語出《孫子‧謀攻》：「百戰百勝，非善之善者也；不戰而屈人之兵，善之善者也。」
@ana C o
恥：本為名詞或形容詞（恥辱、可恥），此處帶賓語「失其君」，意為「{k:以}失其君{k:為}恥」，是百姓主觀的感受與認定，屬{k:意動用法}。語出《左傳‧僖公十五年》：晉惠公在韓原之戰被秦國俘虜，晉大夫陰飴甥對秦穆公說明晉國民情。圉，晉惠公的太子。
@ana D x
極：窮盡、享盡，作一般動詞用，與下句「口欲{k:窮}芻豢之味」的「窮」同義互文。芻豢，指牛羊豬狗等牲畜的肉。語出《史記‧貨殖列傳》。句意是「想要享盡聲色之美」，並沒有「認為…是極」的意思。
@trap
- 最常誤選 (B)：使動與意動都是「動詞（或形容詞、名詞）＋賓語」，外形一模一樣，只能靠語意分辨。口訣：{k:使動＝「使…怎樣」，事實改變；意動＝「以…為怎樣」，想法而已}。
- 也有人看到題幹示例是形容詞「遠」，就去找形容詞而選 (D)「極」。意動用法的詞不限形容詞，名詞也可以（如「侶魚蝦而友麋鹿」），判斷標準永遠是能否代換成「以…為…」。

@stem

@note red

@opt A

@opt B

@note blue
你＝對手、我＝說話者
@opt C

@note blue

@opt D

@key
「別無他法」的「他」意為「其他的」，是泛指任何別的辦法，並不指稱特定對象；其餘三項的你、我都找得到明確的指涉。
@logic
1. 【讀懂題幹】代詞原本用來「代替」某個明確的人事物；題目要找的是{k:找不到明確對象}的那一個。
2. 【檢驗法】對每個代詞追問「是誰／是什麼？」：(A) 你＝被責備的聽話者；(B) 你＝眼前的對手，我＝說話者自己；(C) 我＝我方陣營。三者都答得出來。
3. 【看 D】「他法」＝別的辦法、其他辦法。「他」在這裡不是第三人稱「他那個人」，而是「其他」的意思，泛指「現有辦法以外的任何辦法」，沒有特定對象。
4. 【結論】選 (D)。
@ana A x
「沒人當你是啞巴」是對某個多嘴的人說的話，「你」就是{k:眼前的聽話者}，指涉明確。（原卷作「啞吧」，教育部辭典作「啞巴」。）
@ana B x
「今日決一死戰」點明了說話的情境：說話者正面對敵手。「你」指{k:對方}，「我」指{k:說話者一方}，都有明確對象。
@ana C x

@ana D o
「別無他法」＝沒有別的辦法。「他」是{k:旁指}用法，意為「其他的、另外的」，不指任何特定的人或事物，符合題幹「未明確指涉特定對象」。
@trap
(B) 容易讓人猶豫：成語「你死我活」「你爭我奪」「你一言我一語」中的你、我確實是{k:虛指}，泛指雙方或眾人，並非真有一個「你」和「我」。但本題把它拆成「不是你死，就是我活」，又加上「今日決一死戰」的情境，就成了說話者對敵手的宣告，你、我各有所指。判斷代詞一定要{k:回到句子的情境}，不能只憑成語印象。

@know 文言中的「他」多是「其他」
- 古文的「他」（也寫作「它」「佗」）本義是「別的、其他的」，到中古以後才逐漸用作第三人稱代詞。
- 例：{k:他}山之石，可以攻玉（《詩經‧小雅‧鶴鳴》）／王顧左右而言{k:他}（《孟子‧梁惠王下》）／子不我思，豈無{k:他}人（《詩經‧鄭風‧褰裳》，見第 2 題）。
- 文言的第三人稱常用「之、其、彼」；第一人稱用「吾、我、余、予」；第二人稱用「爾、汝（女）、若、乃、而」。
@know 用字提醒：「啞巴」與詞尾「巴」
- 選項 (A) 原卷作「啞吧」。「吧」是語氣助詞（好吧、走吧）；作名詞詞尾時用「巴」：啞{k:巴}、尾{k:巴}、下{k:巴}、嘴{k:巴}、泥{k:巴}、結{k:巴}。
- 相關俗語：啞巴吃黃連——有苦說不出；啞巴虧（吃了虧卻無法聲張）。

- 司馬庫斯位於新竹縣尖石鄉深山，是泰雅族部落。因地處偏遠，遲至民國六十八年才有電力供應、八十四年才有對外道路，曾被稱為「黑色部落」，今日以巨木群與部落共同經營的模式聞名。

## 事件背景
- 佛肸是春秋時晉國中牟的邑宰（地方長官），據中牟反叛，並派人召請孔子。孔子周遊列國多年不得重用，動了前往的念頭，因而引來子路的質疑。依一般說法，孔子最後並未成行。
## 對話結構
| 發言者 | 內容 | 手法 | 立場 |
| 子路 | 引老師從前的話：「親於其身為不善者，君子不入也」，質問「如之何」 | {k:以子之矛攻子之盾} | 君子應遠離不善之人，以免同流合汙 |

## 讀懂兩個比喻
- {k:堅白之喻}回答的是「會不會被帶壞」——不會，因為我夠堅、夠白。
- {k:匏瓜之喻}回答的是「為什麼想去」——因為我渴望被任用、實現理想。「繫而不食」舊有二解：一說匏瓜味苦，只能掛著而不被食用；一說指天上的匏瓜星，徒然高懸而不能吃。兩說都比喻{k:有才而不為世所用}。

| 標誌詞 | 例句 | 真正的意思 |
| 豈…哉／乎 | 吾豈匏瓜也哉 | 我不是匏瓜 |
| 焉、安 | 焉能繫而不食／燕雀安知鴻鵠之志哉 | 不能繫而不食／燕雀不知 |
| 何…之有 | 何陋之有（〈陋室銘〉） | 不簡陋 |
| 不亦…乎 | 不亦說乎（《論語‧學而》） | 很喜悅 |

- 口訣：{k:激問的答案在問題的反面}。肯定形式表否定，否定形式表肯定。
@know 「自許」「自況」「自詡」「自居」辨析
- {k:自許}：自我期許，含自負之意——以天下為己任自許。
- {k:自況}：拿某人某物來比擬自己——陶淵明以五柳先生自況。
- {k:自詡}（ㄒㄩˇ）：自誇——自詡為專家。
- {k:自居}：以某種身分自處——以功臣自居。
- 本題若說「孔子以堅白之物{k:自況}」是正確的；說「以匏瓜自許」就錯了。
@know 名句連結：〈愛蓮說〉
> 予獨愛蓮之出淤泥而不染，濯清漣而不妖。
- 北宋周敦頤以蓮花象徵君子：生於汙泥卻不被沾染。這種「環境不能改變本質」的信念，源頭正是《論語》的「磨而不磷，涅而不緇」。
- 相反的觀點是「近朱者赤，近墨者黑」（晉‧傅玄〈太子少傅箴〉），強調環境的影響力——也就是下一題子路所站的立場。

@logic
1. 【圈絕對詞】(A) 任何…必須、(B) 沒有、(C) 皆——這類{k:全稱}說法只要找到一個反例就錯；(D) 用的是{k:部分}說法「多」。
2. 【找反例】(A) 老花、散光並未說要手術；(B) 迷思①醫師說拿近拿遠「可以短暫舒緩疲勞的眼睛」；(C) 白內障成因是「水晶體老化、紫外線傷害」，散光「大部分是天生」。
3. 【統整 D】把九則迷思的「目的」排開：恢復老花、恢復近視、矯正散光、消除白內障青光眼、預防視網膜剝離……全是不靠醫療的自救法，而醫師三度提到手術（②手術不會失明、⑥建議手術、⑦只能手術或雷射）。可推知這些網路說法多半迎合「不想動手術」的心理。
4. 【結論】刪去 (A)(B)(C)，選 (D)。
@ana A x

@ana B x

@ana C x

@ana D o

@know 選項中的「全稱詞」與「限定詞」
| 類型 | 常見用語 | 判斷要領 |

| 限定（部分） | 多、多半、大多、往往、通常、常、部分、有些、可能、或許、相對 | 文中有相當數量的例子即可成立 |
| 比較級 | 更、較、最、尤其 | 文中須有比較的對象與依據 |

| 借喻 vs 借代 | 借喻：只出現喻依，本體與喻依是「{k:相似}」關係，如以「豺狼」喻惡人 | 借代：以相關事物代替，是「{k:相關}」關係，如以「布衣」代平民、「干戈」代戰爭 | 能補成「像…一樣」的是借喻 |

- 題目：關於〈化石吟〉的寫作手法，下列敘述{k:錯誤}的選項是：(A) 第二節與末節句式相近，由疑問改為肯定，形成首尾呼應　(B) 全詩偶數行押韻，如「牙、花、話、畫、答、下、碼」，一韻到底　(C) 詩中以第二人稱「你」稱呼化石，兼用呼告與擬人　(D)「海枯，石爛，日轉，星移」用來歌頌化石堅貞不變的品格

@translation
大凡治理國家的方法，一定要先使人民富裕。人民富裕就容易治理，人民貧窮就難以治理。憑什麼知道是這樣呢？人民富裕就會安於鄉里、看重家園；安於鄉里、看重家園，就會尊敬君上、畏懼犯罪；尊敬君上、畏懼犯罪，就容易治理了。人民貧窮就會不安於鄉里、輕視家園；不安於鄉里、輕視家園，就敢於冒犯君上、觸犯禁令；冒犯君上、觸犯禁令，就難以治理了。所以安定的國家往往富裕，混亂的國家往往貧窮。因此善於治國的人，一定先使人民富裕，然後再治理他們。
從前七十九代的君主，法度制度不一樣，號令也不相同，然而都能稱王天下，是什麼緣故呢？一定是國家富裕而糧食充足。國家富裕、糧食充足，來自於農業，所以先代的君王重視農業。凡是治國的急務，一定要先禁止工商末業和華麗奇巧的工藝；這些被禁止了，人民就沒有辦法不耕作而得食；人民無法不耕而食，就一定從事農業。人民從事農業，田地就得到開墾；田地開墾了，糧食就多；糧食多了，國家就富裕。國家富裕則軍隊強大，軍隊強大則戰爭獲勝，戰爭獲勝則土地廣闊。因此先王懂得：要使人口眾多、軍隊強大、土地廣闊、國家富裕，都必定來自糧食，所以禁止工商末業，杜絕奇巧之物，而使農事得利。
如今從事工商末業、製作奇巧物品的人，做一天工可以吃五天；農夫終年勞作，卻不夠養活自己。這樣一來，人民就會捨棄農業這個根本而去從事末業；捨棄根本而從事末業，就會田地荒蕪而國家貧窮了。

- {k:為什麼要富民}：富 → 安 → 敬畏 → 易治（目的在「治」）。
- {k:怎樣才能富}：禁末 → 務農 → 粟多 → 國富 → 兵強（手段是「重農抑末」）。
- 文章用大量「A 則 B，B 則 C」的句式，上句的結尾就是下句的開頭，修辭上稱為{k:頂真}，內容上則是環環相扣的{k:層遞}。讀這種文章，最好在空白處畫出箭頭圖。
## 讀出作者的立場
- 「一日作而五日食」表面像在說末作的好處，其實是在說明「為什麼人民會棄農」——因為利潤懸殊。作者的結論是「田荒而國貧」，所以主張{k:禁末}而非發展末作。
@know 管仲與《管子》
- {k:管仲}：名夷吾，字仲，春秋時齊國人。早年與鮑叔牙交好（「管鮑之交」），經鮑叔牙推薦為齊桓公之相，輔佐桓公「九合諸侯，一匡天下」，成為春秋五霸之首。孔子評價他：「微管仲，吾其被髮左衽矣！」（《論語‧憲問》）——如果沒有管仲，我們恐怕都要披頭散髮、衣襟左開（淪為夷狄）了。
- {k:《管子》}：託名管仲，實非一人一時之作，一般認為是戰國至漢代學者（多與齊國稷下學宮有關）陸續編成，內容兼含法、道、儒、陰陽、兵、農各家思想。《漢書‧藝文志》列入道家，《隋書‧經籍志》以後改列法家。
- 名句：「倉廩實則知禮節，衣食足則知榮辱」（〈牧民〉）；「禮義廉恥，國之四維；四維不張，國乃滅亡」（〈牧民〉，顧炎武〈廉恥〉即由此發端）；「一年之計，莫如樹穀；十年之計，莫如樹木；終身之計，莫如樹人」（〈權修〉）。

@know 論說文常用的論證方法
| 方法 | 說明 | 本文或課文例子 |
| 正反對比 | 正面、反面並列，凸顯是非 | 民富則易治／民貧則難治（本文） |
| 連鎖推論 | 由 A 推 B、由 B 推 C，層層相扣 | 田墾則粟多，粟多則國富（本文） |
| 舉例論證（例證） | 舉史實或事例為證 | 昔者七十九代之君…俱王天下（本文） |
| 譬喻論證（喻證） | 用比喻說明道理 | 不曰堅乎，磨而不磷（本卷第 11 題）；青，取之於藍，而青於藍（〈勸學〉） |

| 類比論證 | 以性質相似的事物推論 | 以治病比治國、以用兵比用人 |

- 判斷時問自己：這一句是{k:論點}（主張）、{k:論據}（理由、例子）還是{k:論證}（把兩者連起來的過程）？
@know 進階辨析：頂真、層遞與連鎖推論
- {k:頂真}是形式：上句末尾的詞語＝下句開頭的詞語（「…則田墾；田墾，則粟多；粟多，則國富」）。
- {k:層遞}是內容：事物依大小、輕重、先後、因果逐層推進（田墾 → 粟多 → 國富 → 兵彊 → 戰勝 → 地廣，範圍越來越大）。
- 本文兩者兼具，所以讀起來氣勢連貫、不容置疑。同類名句：
- 「古之欲明明德於天下者，先治其國；欲治其國者，先齊其家；欲齊其家者，先修其身……」（《禮記‧大學》）
- 「名不正，則言不順；言不順，則事不成；事不成，則禮樂不興……」（《論語‧子路》）
- 但要留意：連鎖推論只要其中一環不成立，結論就站不住——例如「民富」是否必然「敬上畏罪」？閱讀時能提出這種質疑，就是學測所說的「{k:省思評鑑}」。

- 題目：若要{k:反駁}《管子‧治國》「禁末作文巧則國富」的主張，下列哪一項論據最有力？(A) 農業生產需要大量勞動力　(B) 歷代君主的法制、號令各不相同　(C) 工商業能流通貨物、增加財富，同樣可以使國家富裕　(D) 人民貧窮時容易輕視家園、觸犯禁令

@translation
郭曖曾經和昇平公主夫妻吵架，郭曖罵公主說：「妳是仗著妳父親是天子嗎？我父親是嫌棄天子的位子，不屑去做罷了！」公主氣得哭了，立刻乘車趕回宮中向皇帝稟告。皇上（唐代宗）說：「妳有所不知，他父親確實是嫌棄天子之位而不做。假使他不嫌棄，這天下哪裡還會是妳家的呢？」說著流下淚來，只是叫公主回去。尚父（郭子儀）把郭曖拘禁起來，親自到朝廷等候治罪。皇上召見並安慰他說：「俗話說：『不裝傻、不裝聾，就當不了公公婆婆。』小倆口在閨房裡說的話，您身為大臣何必去聽呢？」賞賜了財物後讓他回去。尚父回家後，只是把郭曖打了幾十杖而已。

## 故事脈絡
| 階段 | 人物 | 言行 | 心理／性格 |
| 起 | 郭曖、昇平公主 | 夫妻口角，郭曖口出狂言「我父嫌天子不作」 | 年輕氣盛，口不擇言 |
| 承 | 公主 | 恚啼，奔車入宮告狀 | 委屈憤怒，仗恃父親 |
| 轉 | 唐代宗 | 「他父實嫌天子不作」，泣下，命公主回去 | 明理、念舊、不袒護女兒 |
| 合 | 郭子儀 | 拘曖、自詣朝待罪；事後杖曖數十 | 恭謹自持，不恃功而驕 |
| 結 | 唐代宗 | 引諺語寬慰，賞賜遣歸 | 把「大逆之言」化為「閨幃之言」，君臣相安 |
## 這則故事好看在哪裡
- 郭曖那句話若照字面追究，是可以滅族的大不敬之罪；公主入宮告狀，等於把{k:家事變成國事}。
- 代宗的處理是把它{k:從國事拉回家事}：先對女兒承認郭家的功勞，再對郭子儀引用民間諺語，以「親家翁」而不是「皇帝」的身分說話。
- 郭子儀的反應則是{k:把家事當國事辦}：綁了兒子親自請罪，絲毫不敢怠慢。一個寬厚、一個恭謹，君臣各退一步，才有「錫賚以遣之」的圓滿收場。
- 這個故事後來演變為著名的戲曲《打金枝》（金枝，指公主）。
@know 歷史背景：郭子儀與安史之亂
- {k:安史之亂}：唐玄宗天寶十四載（755），安祿山、史思明起兵叛亂，歷玄宗、肅宗、代宗三朝，前後約八年才平定，是唐朝由盛轉衰的關鍵。
- {k:郭子儀}：平定安史之亂的主要將領，與李光弼齊名，收復長安、洛陽兩京，封汾陽王。唐德宗即位後尊為「尚父」。《舊唐書》本傳稱他「權傾天下而朝不忌，功蓋一代而主不疑」——權勢極大而朝廷不猜忌，功勞蓋世而君主不懷疑。本則故事正可說明他如何做到。
- 文中稱郭子儀為「尚父」，是作者用後來的尊號{k:追述}（事件發生在代宗時）。「尚父」原是周武王對姜太公（呂尚）的尊稱，意為可尊尚的父輩。
- 連結詩史：杜甫的「三吏」「三別」、〈春望〉（「國破山河在」）、〈聞官軍收河南河北〉，白居易〈長恨歌〉都以安史之亂為背景。

@type 諺語的語意詮釋

@diff 3
@answer B
@stem
關於「不癡不聾，不作阿家阿翁」一句，詮釋{y:最正確|先弄清「阿家阿翁」是誰}的選項是：
@note red
①阿家阿翁＝{c:公婆}
②誰裝聾？長輩
③對誰的事？兒媳
@opt A
{x:岳父岳母}一旦介入女兒的婚事，往往會引發家庭革命
@note blue
阿家阿翁是夫家長輩
句意也不是「引發革命」
@opt B
遇到兒子媳婦吵架，當{g:公婆}的最好{g:當作沒聽到、沒看到}
@note red
身分對、對象對、態度對 ✓
@opt C
{x:夫妻}免不了會吵架，彼此若能裝聾作啞，才能和好如初
@note blue
裝聾的是長輩，不是夫妻
@opt D
清官難斷家務事，{x:外人}如果橫加干涉，反而引起雙方的不滿
@note blue
公婆不是「外人」
@cols 1
@key
阿家（ㄍㄨ）是婆婆、阿翁是公公；全句意為「不裝傻裝聾，就當不好公婆」，即長輩對小倆口的爭吵要睜一隻眼、閉一隻眼。
@logic
1. 【解字】阿家：婦人稱丈夫的母親，「家」音ㄍㄨ，通「姑」；阿翁：婦人稱丈夫的父親。合稱即公婆 → (A) 岳父岳母身分不符。
2. 【解句】「不 A 不 B，不作 C」是雙重否定：{k:若不癡、不聾，就當不成（好）公婆} → 要當公婆，就得裝傻、裝聾。裝聾作啞的主語是公婆 → (C) 主語錯。
3. 【看情境】代宗對郭子儀（公主的公公）說這句話，接著說「小兒女子閨幃之言，大臣安用聽」——勸他別把小倆口吵架的話當真。公婆是家人而非外人 → (D) 不合。
4. 【結論】選 (B)。
@ana A x
「阿家阿翁」是媳婦對{k:丈夫的父母}的稱呼，即公婆，不是岳父岳母。在本文中，被勸的郭子儀正是昇平公主的公公。此外，諺語說的是長輩應有的態度（裝聾作啞），並沒有「介入就會引發家庭革命」的意思。
@ana B o
癡，傻；聾，聽不見。當公婆的若事事聽得清楚、樣樣計較，家庭必生紛爭；所以對兒子、媳婦之間的口角，最好{k:裝作不知道}。這與下文「小兒女子閨幃之言，大臣安用聽」完全呼應。身分（公婆）、對象（兒媳吵架）、態度（當作沒聽到沒看到）三者皆正確。
@ana C x
諺語中「癡、聾」的是「阿家阿翁」，不是夫妻本人。選項把{k:主語}換成吵架的夫妻雙方，成了夫妻相處之道，與原句不合。
@ana D x
「清官難斷家務事」指家庭糾紛複雜，外人難以判定是非，立意與本句有相通處；但選項強調「{k:外人}橫加干涉」「引起雙方不滿」。公婆是家庭成員而非外人，原句也沒有談干涉的後果，詮釋失焦。
@trap
- 最大的障礙是「阿家」二字：現代人看到「家」會讀成ㄐㄧㄚ而不知所云。這裡的「家」音ㄍㄨ，通「姑」（婆婆）；東漢才女班昭嫁曹世叔，被尊稱為「曹大家」，也讀ㄍㄨ。
- 有人因為「說話的唐代宗是岳父」而選 (A)。要分清楚：代宗是{k:引用}諺語來勸{k:郭子儀}，諺語本身的主角是公婆。當然，代宗自己把女兒勸回去、不予追究，也實踐了同樣的精神。

@adv 進階演練（本書自編）
- 題目：唐代宗引「不癡不聾，不作阿家阿翁」的用意，與下列哪一句話的精神最接近？(A) 水至清則無魚，人至察則無徒　(B) 養不教，父之過；教不嚴，師之惰　(C) 千里之堤，潰於蟻穴　(D) 當局者迷，旁觀者清
- 答案：(A)
- 解析：(A) 語出《大戴禮記》（東方朔〈答客難〉亦引），意為水太清就養不了魚，人太明察苛求就沒有夥伴，主張{k:處世要寬容、不必事事計較}，與「裝聾作啞才能當好長輩」相通。(B) 強調嚴加管教，方向相反。(C) 強調小問題會釀成大禍，主張防微杜漸，也相反。(D) 談的是觀察角度，與寬容無關。

=== Q 22

@cat 文言閱讀
@tags 因話錄, 人物形象, 推論判斷
@diff 3
@answer D
@stem
關於文中人物的表現，{y:推論最為合理|每個推論都要有行為依據}的選項是：
@note red
人物題：{c:誰}做了{c:什麼}
→ 才能推性格
@opt A
{x:郭曖}對唐王朝有中興之功，因而{x:完全不把唐代宗放在眼裡}
@note blue
有功的是父親郭子儀

@opt B
昇平公主倚仗父親為天子，而{x:瞧不起郭曖}，所以{x:借題發揮}

@opt C
唐代宗因為{x:怕郭子儀造反}，所以不敢替昇平公主討回公道
@note blue

@opt D

「拘曖，自詣朝待罪」✓
@cols 1
@key
郭子儀功蓋當世，兒子失言後仍立刻「拘曖，自詣朝待罪」，可見他不恃功驕矜、對王室恭謹忠誠。
@logic
1. 【人物題的原則】推論必須建立在{k:該人物自己的言行}上，不能把甲的功勞算給乙，也不能把別人的指控當成事實。
2. 【A：張冠李戴】平亂中興的是郭子儀；郭曖只是在夫妻吵架時說了氣話，事後被父親拘禁、杖責，談不上「完全不把代宗放在眼裡」。
3. 【B、C：缺乏依據】公主是否「瞧不起」丈夫、「借題發揮」，文中沒有任何描寫；代宗的反應是「泣下」「召而慰之」「錫賚以遣之」，是感念與寬慰，不是懼怕。
4. 【D：有行為為證】「尚父拘曖，自詣朝待罪」「杖曖數十」——主動請罪、懲戒兒子，正是功高而不自矜的表現。選 (D)。
@ana A x
「對唐王朝有中興之功」的是{k:郭子儀}，不是郭曖；代宗說「他父實嫌天子不作」，講的也是郭子儀。郭曖的話是口角時的狂言，且他後來被父親拘禁、杖打，並未真的藐視皇帝。選項把父親的功績與兒子的失言混為一談。
@ana B x
「倚乃父為天子耶」是郭曖罵人時的{k:質問}，屬於他單方面的說法；文中關於公主的描寫只有「恚啼，奔車奏之」（氣哭了，趕去告訴父親）。「瞧不起郭曖」「借題發揮」都是添加的情節，沒有文本依據。
@ana C x
代宗對公主說的是「使不嫌，社稷豈汝家有也」，承認郭子儀再造唐室的功勞，並為之「泣下」；對郭子儀則「召而慰之」，還加以賞賜。這是{k:感恩、體諒與政治智慧}的表現。文中沒有任何郭子儀可能造反的跡象——他反而是主動請罪的一方。「怕」「不敢」不合文意。
@ana D o
以郭子儀的功勞與地位，連皇帝都說天下是靠他才保住的；但他得知兒子失言，立刻把兒子拘禁起來，親自到朝廷「待罪」，被寬恕後仍「杖曖數十」。他把一句夫妻間的氣話當成嚴重的失禮來處理，可見其{k:謙恭謹慎、謹守臣節}。推論合理。
@trap
- (C) 有一定的迷惑性：從權力現實看，皇帝對功臣確實有所顧忌。但本題問的是「依文中人物的表現」推論。代宗的言行（泣下、慰之、賞賜）指向的是感念而非恐懼；選項用「怕」「不敢」是{k:誅心之論}，文本無法支持。
- 「最為合理」的推論，標準是{k:找得到對應的動作或話語}。(D) 的每個判斷詞都能對回原文：不自矜 ↔ 拘曖；敬慎 ↔ 自詣朝待罪。

@adv 進階辨析：文言的省略與稱代（以本文為例）
- {k:省略主語}：「（公主）奔車奏之」「（上）因泣下，但命公主還」「（上）錫賚以遣之」——文言常承前省略主語，讀時要自己補上「誰」。
- {k:省略賓語}：「上召（之）而慰之」——召的對象是郭子儀。
- {k:代詞的指涉}：「奏之」的「之」指郭曖的話；「慰之」「遣之」的「之」指郭子儀；「他父」的「他」是第三人稱（指郭曖），與第 5 題「他法」的旁指用法不同——唐代口語中「他」已可作第三人稱。
- {k:稱謂的轉換}：同一個人，敘述者稱「尚父」，皇帝當面稱「大臣」，郭曖稱「我父」，代宗對公主說話時稱「他父」。稱謂隨{k:說話者與聽話者的關係}而變，是閱讀史傳、小說時釐清人物的鑰匙。
- 學測文言閱讀最基本的要求就是「補出省略成分、確認代詞所指」；本卷第 13 題（誰驚、誰使、誰許）、第 14 題（誰問、誰答）也都靠這項功夫。
