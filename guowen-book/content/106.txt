@key

@logic
1. 【審題】「完全相異」是指同一組的{k:三個字都不相同}才算一組；只要有兩個字相同，就不能計入。這是計數題，一組判斷錯誤整題就錯，務必把國字直接寫在注音旁。
2. 【以義定形】利用詞義把注音還原：訪談是「探問」→ 訪；東船西舫是「船」→ 舫；模仿是「效法」→ 仿。同理寫出龜／均／鈞、惱／腦／瑙、里／李／裡、咄／墮／舵。
3. 【抓出例外】（丁）「白沙在涅」與「涅而不緇」的「涅」都指黑色染料（染黑），是同一個字；「孤臣孽子」的「孽」才是另一個字。三字並非完全相異，剔除。
4. 【計數】六組扣掉（丁），共 {k:五組}，選 (B)。
@ana A x
若答六組，表示把（丁）也算了進去。問題出在「白沙在{k:涅}」與「{k:涅}而不緇」：兩句都與「染黑」有關，寫的是同一個「涅」字。
- 白沙在涅：《荀子‧勸學》「白沙在涅，與之俱黑」，白沙混在黑色染料裡，也跟著變黑，比喻環境對人的影響。
- 涅而不緇：《論語‧陽貨》「不曰白乎，涅而不緇」，用黑色染料也染不黑，比喻本質好，不受壞環境影響。
- 孤臣孽子：孽，庶子（非正室所生之子）。
→ 涅、涅、孽，有兩字相同，不能算「完全相異」。

@know 詩中的科學：「太陽又回到這一站」
- 詩人把一年想像成一條有{k:三百六十五站}的環狀路線，每一天是一站；生日就是「太陽又回到這一站」。
- 從天文學看，這是地球繞太陽公轉一周（約 365.24 日）後，太陽在天球上回到相同位置。以「站」寫時間，是把抽象的時間{k:具體化、空間化}的譬喻手法。
- 新詩常用分行與斜線（／）製造停頓：「三百六十五站／只有今天」的停頓，突顯「今天」的獨一無二。
@know 作家檔案：余光中
- 余光中（1928–2017），生於南京，祖籍福建永春，1950 年來臺，曾任教於臺灣師範大學、政治大學、香港中文大學、中山大學。
- 創作橫跨{k:詩、散文、評論、翻譯}，自稱這是他寫作的「四度空間」；梁實秋稱他「右手寫詩，左手寫文，成就之高，一時無兩」。
- 代表作：詩〈鄉愁〉、〈等你，在雨中〉、〈白玉苦瓜〉、〈車過枋寮〉；散文〈聽聽那冷雨〉、〈我的四個假想敵〉。

=== Q 10
@type 六書造字法的判別
@cat 國學常識
@tags 六書, 象形, 指事, 會意, 形聲
@diff 4
@answer D
@stem
下列有關六書的敘述，何者{y:完全正確|字例一個都不能錯}？
@note red
每個選項找「混進去的那個字」
@opt A
對聯「日新月異金雞唱，鳥語花香大地春」的「日、月、{x:金}、鳥、大」五個字，都是象形字
@note blue
金：从土，今聲 → 形聲
@opt B
「見錢眼開，品格低賤」的「錢、眼、格、賤」，是形聲字；「見、開、品、{x:低}」，是會意字
@note blue
低：从人，氐聲 → 形聲
@opt C
「刃、本、末、凶、甘、天、旦」等以符號標示出觀念的特定部位，故屬{x:轉注}{n:指事}
@note blue
定義說對了，名稱卻錯
@opt D
「一、二、三、小、上、下、寸」等字，以{g:符號}標示{g:抽象的觀念}，為{g:指事字}。
@note red
指事：視而可識，察而見意 ✓
@key
(A)「金」是形聲字；(B)「低」是形聲字；(C) 所述是指事的特徵，卻誤稱「轉注」；(D)「一二三上下」等以符號表示抽象觀念，正是指事。
@logic
1. 【審題】「完全正確」表示選項中列舉的字{k:每一個}都要符合所說的造字法，命題者通常只混入一個例外。
2. 【檢查定義】(C)「以符號標示出特定部位」正是指事（在象形字上加指示符號）的說明，結論卻寫「轉注」，名實不符，先刪。
3. 【檢查字例】(A) 日、月、鳥、大都是描摹實物的象形字，但「金」有聲符「今」；(B)「低」有聲符「氐」。兩項各混入一個形聲字。
4. 【確認正解】(D) 一、二、三是積畫記數，上、下以短畫標示位置，都是用抽象符號表意的指事字，敘述與結論一致。選 (D)。
@ana A x
- 日、月、鳥：描畫太陽、月亮、鳥的外形，象形。
- 大：像人正面站立、張開手腳的樣子，象形（借人形表示「大」的概念）。
- {k:金}：《說文解字》「从土，左右注，象金在土中形；今聲」，有聲符「今」，屬{k:形聲}。
→ 五字並非都是象形，錯誤。應刪去「金」。
@ana B x
- 錢（金＋戔聲）、眼（目＋艮聲）、格（木＋各聲）、賤（貝＋戔聲）：形聲，正確。
- 見（目在人上，表示看見）、開（《說文》「从門从幵」，雙手拉開門閂）、品（三口，表示眾多）：會意，正確。
- {k:低}：从人，氐聲（氐兼表「低下」之意），屬{k:形聲}。
→ 「低」不是會意字，錯誤。
@ana C x
刃（在「刀」的鋒口加一點）、本（在「木」下加一橫標示樹根）、末（在「木」上加一橫標示樹梢）、甘（口中含一物）、旦（日出地平線上）等字，都是在既有的象形字上{k:加抽象符號指明部位或事態}，教科書歸為{k:指事}。選項前半的說明是對的，但結論「屬轉注」錯誤，應改為「故屬指事」。轉注是指「建類一首，同意相受」，即意義相同、可以互相解釋的一組字，如「考」「老」。
@ana D o
- 一、二、三：以橫畫的數目表示抽象的數量。
- 上、下：以一長畫為基準，上方或下方加一短畫，標示相對位置。
- 小：古文字作三（或四）個小點，以細碎的符號表示「微小」。
- 寸：从又（手）从一，「一」標示手腕下一寸的寸口處。
這些字都不是描畫具體實物，而是{k:以符號表示抽象的觀念或位置}，為指事字。敘述正確，為正解。
@trap
指事字其實有兩類：一類是{k:純符號}（一、二、三、上、下），另一類是{k:象形字加指示符號}（本、末、刃、寸）。(C) 與 (D) 的字例分屬這兩類，但「都是指事」。本題 (C) 錯在把名稱寫成「轉注」，而不是字例有誤；看到定義與名稱兜不起來，就可以直接刪去。另外，「天」「旦」「凶」等字，學者或歸指事、或歸會意，說法不一，考試時以{k:是否有聲符}（形聲）與{k:是否畫出實物}（象形）作為最穩當的判斷起點。
@know 六書總表（定義出自許慎《說文解字‧敘》）
| 六書 | 《說文》定義 | 白話說明 | 字例 |
| 象形 | 畫成其物，隨體詰詘 | 照實物的形狀畫出來 | 日、月、山、水、鳥、馬 |
| 指事 | 視而可識，察而見意 | 用抽象符號表示觀念或部位 | 一、上、下、本、末、刃 |
| 會意 | 比類合誼，以見指撝 | 合併兩個以上的字，產生新義 | 武、信、休、明、林、森 |
| 形聲 | 以事為名，取譬相成 | 形符表類別＋聲符表讀音 | 江、河、錢、眼、格 |
| 轉注 | 建類一首，同意相受 | 意義相同的字互相解釋 | 考、老 |
| 假借 | 本無其字，依聲託事 | 借同音字表示沒有字的詞 | 令、長；「來」本義為麥 |
- 前四種是{k:造字法}，後兩種是{k:用字法}（「四體二用」說）。
- 象形、指事是不可分割的「獨體文」；會意、形聲是由兩個以上部件組成的「合體字」。漢字中形聲字最多，約占八成以上。
@know 判斷六書的三步驟
- 第一步：{k:找聲符}。有一部分表示讀音 → 形聲（如：金＝土＋今聲；低＝人＋氐聲）。
- 第二步：{k:能否拆成兩個有意義的字}。能，且沒有聲符 → 會意（如：見＝目＋人；品＝三口）。
- 第三步：不能拆 → 看是{k:畫實物}（象形）還是{k:用符號}（指事）。
- 口訣：「有聲是形聲，無聲可拆是會意；不可拆者，實物象形、符號指事。」
@know 容易誤判的常見字
| 字 | 常被誤認為 | 其實是 | 說明 |
| 金 | 象形 | 形聲 | 从土，今聲 |
| 低 | 會意 | 形聲 | 从人，氐聲 |
| 刃 | 象形 | 指事 | 刀上加一點指出刀鋒 |
| 亦 | 會意 | 指事 | 人形兩腋下各加一點，是「腋」的本字 |
| 鳴 | 形聲 | 會意 | 从鳥从口，鳥張口而鳴 |
| 問 | 會意 | 形聲 | 从口，門聲 |
