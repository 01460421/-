@key
把注音逐一還原成國字：訪舫仿、龜均鈞、惱腦瑙、里李裡、咄墮舵，五組三字皆異；只有（丁）涅、涅、孽有兩字相同，故答「五組」。
@logic
1. 【審題】「完全相異」是指同一組的{k:三個字都不相同}才算一組；只要有兩個字相同，就不能計入。這是計數題，一組判斷錯誤整題就錯，務必把國字直接寫在注音旁。
2. 【以義定形】利用詞義把注音還原：訪談是「探問」→ 訪；東船西舫是「船」→ 舫；模仿是「效法」→ 仿。同理寫出龜／均／鈞、惱／腦／瑙、里／李／裡、咄／墮／舵。
3. 【抓出例外】（丁）「白沙在涅」與「涅而不緇」的「涅」都指黑色染料（染黑），是同一個字；「孤臣孽子」的「孽」才是另一個字。三字並非完全相異，剔除。
4. 【計數】六組扣掉（丁），共 {k:五組}，選 (B)。
@ana A x
若答六組，表示把（丁）也算了進去。問題出在「白沙在{k:涅}」與「{k:涅}而不緇」：兩句都與「染黑」有關，寫的是同一個「涅」字。
- 白沙在涅：《荀子‧勸學》「白沙在涅，與之俱黑」，白沙混在黑色染料裡，也跟著變黑，比喻環境對人的影響。
- 涅而不緇：《論語‧陽貨》「不曰白乎，涅而不緇」，用黑色染料也染不黑，比喻本質好，不受壞環境影響。
- 孤臣孽子：孽，庶子（非正室所生之子）。
→ 涅、涅、孽，有兩字相同，不能算「完全相異」。
@ana B o
五組三字皆異，整理如下：

@ana D x

@adv 進階辨析：為什麼不能「有邊讀邊」？——古今音變

@key
(A) 駢文不要求押韻，「平仄通押」是曲的特色；(B) 近體詩格律比古詩嚴格；(C)「詩句字數整齊」忽略了雜言古詩；(D) 關於《詩經》的四個敘述全部正確。
@logic
1. 【審題】「完全正確」題要把長選項切成數個短句，一句一句打勾；只要有一句錯，整個選項就刪。
2. 【找硬傷】(B)「近體詩的格律比古詩自由」與事實完全相反——近體詩又稱「格律詩」，句數、字數、平仄、對仗、押韻都有嚴格規定，可直接刪去。
3. 【辨細節】(A) 前三句是駢文特色，但末句「押韻自由，平仄通押」不對：駢文講究的是對偶與平仄相對，並不要求押韻；平、上、去三聲通押是元曲的押韻特色。
4. 【比較 C、D】(C) 是常見的概括說法，但「詩句字數整齊」只適用於齊言詩，古體詩、樂府有長短參差的雜言體；(D) 四個短句都是課本定論，毫無瑕疵。兩相比較，選 (D)。
@ana A x
駢文盛行於六朝，四大特色是：{k:對偶工整}（多用四字、六字句，故又稱「四六文」）、{k:詞藻華麗}、{k:聲律和諧}（講究平仄相對）、{k:多用典故}。選項前半正確，卻漏了最重要的「對偶」，並加上錯誤的「押韻自由，平仄通押」：駢文屬於「文」，一般不要求押韻；「平仄通押」說的是元曲。應改為「講究對偶工整、詞藻華麗、聲律和諧，多用典故，不要求押韻」。
@ana B x
錯在「比古詩自由」，應改為「比古詩嚴格」。近體詩（絕句、律詩）成熟於唐代：每句五言或七言；絕句四句（二聯），律詩八句（四聯：首聯、頷聯、頸聯、尾聯）；須依平仄譜，律詩中間兩聯必須對仗，一韻到底且多押平聲韻。古體詩則句數、字數不拘，可換韻，不講平仄對仗，反而自由。選項後三句的敘述是正確的。
@ana C x
本項是「大致不錯、但不夠精確」的概括：
- 「詩句字數整齊」：近體詩與多數古詩是齊言，但古體詩、樂府詩有{k:雜言體}，如李白〈將進酒〉、〈蜀道難〉，句子長短不一。
- 「詞委婉浪漫」：只說了婉約一派；詞另有蘇軾、辛棄疾的{k:豪放}詞風。
- 「曲淺白通俗，可加襯字」「詞、曲長短不一」則正確。
既然題目要求「完全正確」，本項不如 (D) 嚴謹，故不選。
@ana D o
- 《詩經》收錄西周初年至春秋中葉的詩歌三百零五篇，是中國{k:最早的詩歌總集}。
- 產生地域以黃河流域為主，是{k:北方文學}的代表（南方文學的代表是《楚辭》）。
- 六義中，「風、雅、頌」是依{k:內容性質}分類（各國民歌／朝廷樂歌／宗廟祭祀樂歌）；「賦、比、興」是{k:寫作手法}（直陳其事／以彼物比此物／先言他物以引起所詠之詞）。
四句皆正確，為正解。
@trap

@cols 1
@key
(A) 的三個「書」依序是書信（名詞）、書寫（動詞）、書信（名詞），恰好「兩同一異」；其餘三組的三個字義各不相同。
@logic
1. 【審題】「有同有異」表示三個字中，要有兩個意思相同、一個不同。三個全同或三個全異都不符合。
2. 【代換法】替每個字找一個白話同義詞寫在旁邊，再比較。(A) 尺素書＝信；亂書＝寫；家書＝信 → 信、寫、信。
3. 【注意詞性】字義比較時，詞性是最快的判斷工具：(A) 的第二個「書」前面有副詞「亂」修飾，是動詞；第一、三個是名詞。
4. 【驗證其餘】(B) 尚且／一邊…一邊／姑且；(C) 生命／運用、選用／命運；(D) 懷胎／胸前／心意——都是三者皆異。選 (A)。
@ana A o
- 中有尺素「書」：書信。語出漢樂府〈飲馬長城窟行〉「呼兒烹鯉魚，中有尺素書」；尺素是一尺長的白絹，古人用來寫信。
- 信手把筆，隨意亂「書」：書寫（動詞）。語出白居易〈與元微之書〉。
- 家「書」抵萬金：書信。語出杜甫〈春望〉「烽火連三月，家書抵萬金」。
→ 信、寫、信，兩同一異，符合「有同有異」，為正解。
@ana B x
- 形骸「且」健，方寸甚安：尚且、還。白居易〈與元微之書〉自述身體還算健康、內心相當安適。
- 「且」戰且走：一邊……一邊……，表示兩個動作同時進行。
- 得過「且」過：姑且、暫且。
→ 三者皆異。
@ana C x
- 「命」在旦夕：生命、性命（名詞）。
- 「命」辭遣意：運用、選用（動詞）；「命辭遣意」指寫作時選用詞語、表達文意，與「遣詞用字」意近。
- 「命」薄緣慳：命運（名詞）；慳音ㄑㄧㄢ，欠缺。指命運不好、緣分淺薄。
→ 三者皆異。第一、三個雖然都是名詞，但「性命」與「命運」是不同義項。
@ana D x
- 「懷」孕在身：腹中有胎兒（動詞）。
- 坐「懷」不亂：胸前、懷抱（名詞）。相傳春秋時魯國柳下惠夜宿城門，遇一受凍女子，讓她坐在自己懷裡、以衣裹之，整夜沒有非禮的行為；後用來形容男子品行端正。
- 正中下「懷」：心意（名詞）。下懷是謙稱自己的心意。
→ 三者皆異。
@trap
(C) 的「命在旦夕」與「命薄緣慳」容易被看成同義。判斷方法是代換：「性命在旦夕」通順、「性命薄」不通；「命運薄」通順、「命運在旦夕」不通——無法用同一個詞代換，就是不同義項。

@key
首句「紅燭是你的光輝最亮」與（丙）「蛋糕是你的滋味最甜」句式相同，丙居首；（乙）問「為什麼」、（丁）答「因為」；（丁）「這一站」帶出（戊）「三百六十五站」，「只有今天」再接（甲）「是……起點」。
@logic
1. 【定首句】已知第一句是「紅燭是你的光輝最亮」，結構為「□□是你的□□最□」。五個選項中只有（丙）「蛋糕是你的滋味最甜」句式完全相同，兩句構成排比，所以{k:丙緊接首句}。只有 (C) 以丙開頭，其實已可作答。
2. 【找問答】（乙）「為什麼我們如此高興」是設問，（丁）「因為太陽又回到這一站」是回答，{k:乙→丁}相連。
3. 【找重複字詞】（丁）末尾「這一站」與（戊）開頭「三百六十五站」以「站」字銜接，{k:丁→戊}。
4. 【看句子完整】（戊）「只有今天」語意未完，要接（甲）「是你生命珍貴的起點」；（甲）之後再接已知的末句「和我們從此結緣」，主語都是「今天」。
5. 【結論】丙→乙→丁→戊→甲，選 (C)。
@ana A x
甲丙乙丁戊：把（甲）「是你生命珍貴的起點」放在首句之後，變成「紅燭是你的光輝最亮／是你生命珍貴的起點」，主語成了紅燭，語意不通；且（戊）「只有今天」之後直接接末句「和我們從此結緣」，少了謂語「是……起點」。
@ana B x
乙丁戊甲丙：乙丁戊甲的內部順序是對的，但（丙）「蛋糕是你的滋味最甜」被放到最後，與首句「紅燭……」的排比被拆散；而且（丙）之後接末句「和我們從此結緣」，變成蛋糕和我們結緣，不合理。
@ana C o

> 紅燭是你的光輝最亮／蛋糕是你的滋味最甜
> 為什麼我們如此高興／因為太陽又回到這一站
> 三百六十五站／只有今天／是你生命珍貴的起點／和我們從此結緣
前兩行寫生日的景物（紅燭、蛋糕），中兩行一問一答點出「生日」，末段說明今天之所以珍貴。結構完整，為正解。
@ana D x
丁甲乙丙戊：一開頭就說「因為太陽又回到這一站」，但前面沒有提問，「因為」無所承接；（乙）的問句後面接（丙）蛋糕，答非所問；（戊）「只有今天」直接接末句也不成句。
@know 文句排序題的四把鑰匙
| 鑰匙 | 作法 | 本題應用 |
| 首尾定位 | 利用題目給的首句、末句，找能銜接的句子 | 首句 → 丙；甲 → 末句 |
| 相同句式 | 排比、對偶的句子必相鄰 | 紅燭是你的…／蛋糕是你的… |
| 關聯詞 | 因為…所以、雖然…但是、為什麼…因為 | 乙（問）→ 丁（答） |
| 重複字詞 | 頂真、指示代詞（這、此、其）承接上句 | 這一站 → 三百六十五站 |
- 考場技巧：不必五句全排完，先確定「哪兩句一定相連」，再用選項刪去。
@know 詩中的科學：「太陽又回到這一站」
- 詩人把一年想像成一條有{k:三百六十五站}的環狀路線，每一天是一站；生日就是「太陽又回到這一站」。
- 從天文學看，這是地球繞太陽公轉一周（約 365.24 日）後，太陽在天球上回到相同位置。以「站」寫時間，是把抽象的時間{k:具體化、空間化}的譬喻手法。
- 新詩常用分行與斜線（／）製造停頓：「三百六十五站／只有今天」的停頓，突顯「今天」的獨一無二。
@know 作家檔案：余光中
- 余光中（1928–2017），生於南京，祖籍福建永春，1950 年來臺，曾任教於臺灣師範大學、政治大學、香港中文大學、中山大學。
- 創作橫跨{k:詩、散文、評論、翻譯}，自稱這是他寫作的「四度空間」；梁實秋稱他「右手寫詩，左手寫文，成就之高，一時無兩」。
- 代表作：詩〈鄉愁〉、〈等你，在雨中〉、〈白玉苦瓜〉、〈車過枋寮〉；散文〈聽聽那冷雨〉、〈我的四個假想敵〉。

| 類型 | 說明 | 例句 |

@ana C x

@ana D x

@logic
1. 【確認題型】這是「刪除冗句」題：四句畫線句中，有一句是從別處移來的，放在這裡會讓文意中斷。作法是替每一句標出{k:描寫對象}與{k:描寫角度}。
2. 【標對象】開頭：登上玉山主峰之巔 →（Ａ）主峰孤絕，睥睨群峰（主峰的氣勢）→（Ｂ）視線轉到眼前的東峰：深淵、斷崖、不見草木（東峰外觀）→（Ｃ）清明、晦暗中的瑰麗與神奇（天候光影下的抽象讚嘆）→（Ｄ）肌理嶙峋、猙獰嚇人，不敢攀登（東峰岩壁與作者感受）。
3. 【看標點】（Ｂ）結尾「看不見任何草木，」是{k:逗號}，表示對東峰岩壁的描寫尚未結束；最能承接的是同樣描寫岩石質地的「肌理嶙峋」。
4. 【看情感色彩】（Ｃ）用「瑰麗」「神奇」，是欣賞、讚嘆；（Ｂ）（Ｄ）用「斷崖」「猙獰」「嚇人」，是驚懼。（Ｃ）夾在中間，語氣也不協調。
5. 【結論】刪去（Ｃ）後，（Ｂ）（Ｄ）一氣呵成，選 (C)。

=== Q 10
@type 六書造字法的判別
@cat 國學常識
@tags 六書, 象形, 指事, 會意, 形聲
@diff 4
@answer D
@stem
下列有關六書的敘述，何者{y:完全正確|字例一個都不能錯}？
@note red
每個選項找「混進去的那個字」
@opt A
對聯「日新月異金雞唱，鳥語花香大地春」的「日、月、{x:金}、鳥、大」五個字，都是象形字
@note blue
金：从土，今聲 → 形聲
@opt B
「見錢眼開，品格低賤」的「錢、眼、格、賤」，是形聲字；「見、開、品、{x:低}」，是會意字
@note blue
低：从人，氐聲 → 形聲
@opt C
「刃、本、末、凶、甘、天、旦」等以符號標示出觀念的特定部位，故屬{x:轉注}{n:指事}
@note blue
定義說對了，名稱卻錯
@opt D
「一、二、三、小、上、下、寸」等字，以{g:符號}標示{g:抽象的觀念}，為{g:指事字}。
@note red
指事：視而可識，察而見意 ✓
@key
(A)「金」是形聲字；(B)「低」是形聲字；(C) 所述是指事的特徵，卻誤稱「轉注」；(D)「一二三上下」等以符號表示抽象觀念，正是指事。
@logic
1. 【審題】「完全正確」表示選項中列舉的字{k:每一個}都要符合所說的造字法，命題者通常只混入一個例外。
2. 【檢查定義】(C)「以符號標示出特定部位」正是指事（在象形字上加指示符號）的說明，結論卻寫「轉注」，名實不符，先刪。
3. 【檢查字例】(A) 日、月、鳥、大都是描摹實物的象形字，但「金」有聲符「今」；(B)「低」有聲符「氐」。兩項各混入一個形聲字。
4. 【確認正解】(D) 一、二、三是積畫記數，上、下以短畫標示位置，都是用抽象符號表意的指事字，敘述與結論一致。選 (D)。
@ana A x
- 日、月、鳥：描畫太陽、月亮、鳥的外形，象形。
- 大：像人正面站立、張開手腳的樣子，象形（借人形表示「大」的概念）。
- {k:金}：《說文解字》「从土，左右注，象金在土中形；今聲」，有聲符「今」，屬{k:形聲}。
→ 五字並非都是象形，錯誤。應刪去「金」。
@ana B x
- 錢（金＋戔聲）、眼（目＋艮聲）、格（木＋各聲）、賤（貝＋戔聲）：形聲，正確。
- 見（目在人上，表示看見）、開（《說文》「从門从幵」，雙手拉開門閂）、品（三口，表示眾多）：會意，正確。
- {k:低}：从人，氐聲（氐兼表「低下」之意），屬{k:形聲}。
→ 「低」不是會意字，錯誤。
@ana C x
刃（在「刀」的鋒口加一點）、本（在「木」下加一橫標示樹根）、末（在「木」上加一橫標示樹梢）、甘（口中含一物）、旦（日出地平線上）等字，都是在既有的象形字上{k:加抽象符號指明部位或事態}，教科書歸為{k:指事}。選項前半的說明是對的，但結論「屬轉注」錯誤，應改為「故屬指事」。轉注是指「建類一首，同意相受」，即意義相同、可以互相解釋的一組字，如「考」「老」。
@ana D o
- 一、二、三：以橫畫的數目表示抽象的數量。
- 上、下：以一長畫為基準，上方或下方加一短畫，標示相對位置。
- 小：古文字作三（或四）個小點，以細碎的符號表示「微小」。
- 寸：从又（手）从一，「一」標示手腕下一寸的寸口處。
這些字都不是描畫具體實物，而是{k:以符號表示抽象的觀念或位置}，為指事字。敘述正確，為正解。
@trap
指事字其實有兩類：一類是{k:純符號}（一、二、三、上、下），另一類是{k:象形字加指示符號}（本、末、刃、寸）。(C) 與 (D) 的字例分屬這兩類，但「都是指事」。本題 (C) 錯在把名稱寫成「轉注」，而不是字例有誤；看到定義與名稱兜不起來，就可以直接刪去。另外，「天」「旦」「凶」等字，學者或歸指事、或歸會意，說法不一，考試時以{k:是否有聲符}（形聲）與{k:是否畫出實物}（象形）作為最穩當的判斷起點。
@know 六書總表（定義出自許慎《說文解字‧敘》）
| 六書 | 《說文》定義 | 白話說明 | 字例 |
| 象形 | 畫成其物，隨體詰詘 | 照實物的形狀畫出來 | 日、月、山、水、鳥、馬 |
| 指事 | 視而可識，察而見意 | 用抽象符號表示觀念或部位 | 一、上、下、本、末、刃 |
| 會意 | 比類合誼，以見指撝 | 合併兩個以上的字，產生新義 | 武、信、休、明、林、森 |
| 形聲 | 以事為名，取譬相成 | 形符表類別＋聲符表讀音 | 江、河、錢、眼、格 |

- 前四種是{k:造字法}，後兩種是{k:用字法}（「四體二用」說）。
- 象形、指事是不可分割的「獨體文」；會意、形聲是由兩個以上部件組成的「合體字」。漢字中形聲字最多，約占八成以上。
@know 判斷六書的三步驟
- 第一步：{k:找聲符}。有一部分表示讀音 → 形聲（如：金＝土＋今聲；低＝人＋氐聲）。
- 第二步：{k:能否拆成兩個有意義的字}。能，且沒有聲符 → 會意（如：見＝目＋人；品＝三口）。
- 第三步：不能拆 → 看是{k:畫實物}（象形）還是{k:用符號}（指事）。
- 口訣：「有聲是形聲，無聲可拆是會意；不可拆者，實物象形、符號指事。」

@logic
1. 【審題】每個選項都舉了兩個例子，並用「皆」「都」作結論；只要其中一例不成立，整項就錯。
2. 【驗 A】「齒」本義是牙齒（名詞），「不齒」是不願與之並列、羞與為伍，作動詞；「櫛」本義是梳子（名詞），「櫛風」是以風梳髮，作動詞。兩例都是{k:名詞 → 動詞}的轉品。
3. 【驗 B、C、D 的第二例】(B)「可遠觀而不可褻玩焉」主語、動詞、賓語的次序正常，不是倒裝；(C)「去留」是「離開或留下」，兩個字的意思都保留；(D) 新詩句只是把天空比作桑葉、高樓比作蠶，沒有一語雙關。
4. 【結論】只有 (A) 兩例皆成立，選 (A)。
@ana A o
- 君子不「齒」：齒，本為名詞「牙齒」；因牙齒排列整齊，引申為動詞「並列、同列」。「不齒」即不屑與之同列，表示極度鄙視。
- 「櫛」風沐雨：櫛，本為名詞「梳子、篦子」；此處作動詞「梳理頭髮」。「櫛風沐雨」是以風梳髮、以雨洗頭，形容在外奔波辛勞。
→ 兩字都是名詞轉作動詞，說明正確。
@ana B x
- 「不患人之不己知」：語出《論語‧學而》。正常語序是「不知己」，因為是{k:否定句}且賓語「己」是{k:代詞}，文言習慣把賓語提到動詞前，成為「不己知」，是倒裝（賓語前置）。
- 「可遠觀而不可褻玩焉」：語出周敦頤〈愛蓮說〉。「可遠觀」與「不可褻玩」語序正常，句末「焉」是語氣助詞（一說兼有代詞「之」的作用），{k:不是倒裝句}。
→ 後句不合，應改為「前句為倒裝句，後句不是」。
@ana C x
- 肚皮沒一點「動靜」：指沒有懷孕的跡象，只取「動」的意思，「靜」字無義，是{k:偏義複詞}。
- 職位「去留」問題：指「離職或留任」，由院長在兩者之間決定，「去」與「留」兩個意思{k:都保留}，是一般的反義並列複詞，不是偏義複詞。
→ 後詞不合。
@ana D x
- 「若天空是桑葉，則高樓大廈就是，一節節的蠶了」：把天空比作桑葉、把高樓大廈比作一節節啃食桑葉的蠶，是{k:譬喻}；字面之外並沒有另一層諧音或詞義，{k:沒有雙關}。
- 「春蠶到死絲方盡，蠟炬成灰淚始乾」：李商隱〈無題〉名句。「絲」諧音「思」（相思），「淚」兼指蠟燭的燭淚與人的眼淚，是{k:雙關}；以春蠶吐絲、蠟燭流淚比喻至死不渝的思念，也含譬喻。
→ 前句沒有雙關，「都運用」的說法錯誤。
@trap
(C) 最容易誤判。判斷偏義複詞的方法是{k:刪字法}：把其中一個字刪掉，句意不變的才是偏義複詞。「肚皮沒一點動（靜）」→ 只說「動」就夠了；「職位的去（留）問題」→ 若只說「去」，就變成「一定要走」，與「由院長定奪」矛盾，可見兩義都需要。

=== Q 12
@type 複句關係的判別
@cat 語文應用
@tags 複句, 關聯詞, 轉折, 假設
@diff 3
@answer C
@stem
下列複句，包含有{b:轉折、因果、假設}等關係。請問，何項句與句間的關係，{y:與其他不同|找「一異」}？
@note red
方法：{c:補上關聯詞}
如果…就／雖然…但是
@opt A
少壯不努力，老大徒傷悲
@note blue
（如果）…（就）… → 假設
@opt B
人有見識，就不輕易發怒
@note blue
（如果）…就… → 假設
@opt C
天長地久有時盡，此恨綿綿{g:無絕期}
@note red
（雖然）…（但是）… → 轉折 ✓
「有時盡」↔「無絕期」
@opt D
所有的野獸都消失了，人類將死於心靈巨大的空虛寂寞。
@note blue
（如果）…（將）… → 假設
@cols 1
@key
(A)(B)(D) 都可補上「如果……就……」，前句是條件、後句是順著推出的結果；(C)「有時盡」與「無絕期」語意相反，要補「雖然……但是……」，是轉折關係。
@logic
1. 【審題】題幹已提示有轉折、因果、假設三種關係，要找出「與其他三項不同」的一項，也就是四選項中「三同一異」。
2. 【補關聯詞】這些句子都省略了關聯詞，把最通順的關聯詞補回去：(A)「{k:如果}少壯不努力，老大{k:就}只能傷悲」；(B)「人{k:如果}有見識，就不輕易發怒」；(D)「{k:如果}所有的野獸都消失了，人類{k:將}死於……」。
3. 【看語意方向】(A)(B)(D) 的後句都是{k:順著}前句推導出來的結果（順承）；(C) 前句說天地「有盡頭」，後句說此恨「沒有盡頭」，語意{k:逆轉}，應補「雖然……但是……」。
4. 【結論】(C) 是轉折，與其他三項不同，選 (C)。
@ana A x
語出漢樂府〈長歌行〉。意思是「年輕力壯時如果不努力，到老就只能白白悲傷」。前句提出假設的情況，後句說明在此情況下的結果，是{k:假設關係}。
@ana B x
語出《聖經‧箴言》。句中已有關聯詞「就」，可補成「人如果（只要）有見識，就不輕易發怒」。前句是條件，後句是順著條件得到的結果，屬{k:假設（條件）關係}。
@ana C o
語出白居易〈長恨歌〉結尾。「天長地久」雖然久遠，仍「有時盡」；「此恨」卻「綿綿無絕期」。前後兩句一「有盡」、一「無盡」，以天地之有限反襯長恨之無窮，語意相反，是{k:轉折關係}（雖然……但是……）。與其他三項不同，為本題答案。
@ana D x
意思是「如果所有的野獸都消失了，人類將會因心靈極度的空虛寂寞而死」。野獸消失是尚未發生的假設，「將」字表示推測未來的結果，是{k:假設關係}。此句常見於〈西雅圖酋長宣言〉的中文譯本，是環境保護的名言。
@trap
(B) 也可以理解成「因為有見識，所以不輕易發怒」（因果）；(A)(D) 也帶有「前因後果」的意味。這正是本題的設計：假設、條件、因果三種關係都是{k:順承}——後句順著前句的方向發展；只有轉折是{k:逆承}。遇到「何者不同」的複句題，先分「順」與「逆」兩大類，通常就能找出答案，不必為假設或因果爭辯。
@know 複句關係總表
| 關係 | 常用關聯詞 | 例句 |
| 並列 | 既…又…；一邊…一邊… | 他既會寫詩，又會作畫 |
| 承接 | 首先…然後…；於是 | 他推開門，走了進去 |
| 遞進 | 不但…而且…；甚至 | 他不但會說，而且做得到 |
| 選擇 | 不是…就是…；與其…不如… | 與其臨淵羨魚，不如退而結網 |
| 轉折 | 雖然…但是…；然而；卻 | 天長地久有時盡，此恨綿綿無絕期 |
| 因果 | 因為…所以…；由於…因此… | 因為下雨，所以比賽延期 |
| 假設 | 如果…就…；即使…也… | 少壯不努力，老大徒傷悲 |
| 條件 | 只要…就…；只有…才…；無論…都… | 只要功夫深，鐵杵磨成針 |

@know 沒有關聯詞的「意合複句」怎麼判斷？
- 古詩文與格言常省略關聯詞，稱為{k:意合}。判斷時用「補詞法」，把最通順的關聯詞補進去。
- 例：「不入虎穴，焉得虎子」→（如果）不入虎穴，（就）得不到虎子＝假設。
- 例：「金玉其外，敗絮其中」→（雖然）外表華美，（但是）內裡破敗＝轉折。
- 例：「山不在高，有仙則名」→ 山（不論）高不高，（只要）有仙（就）出名＝條件。

@key
借音表意是「只借字音、不用字義」：(A) 莫宰羊 1 個、(B) 0 個、(C) 奶雞 1 個、(D) 恰北北與熊熊 2 個，故 (D) 最多。
@logic
1. 【理解定義】題幹的例子「4＋」讀作「四加」，與「釋迦」音近；數字 4 和加號本身的意思（數量、加法）完全用不上。所以「借音表意」＝{k:只取其音、不取其義}。
2. 【檢驗方法】把可疑的詞語照字面解釋：講得通的不是借音；{k:字面講不通、要唸出來}才知道意思的，就是借音。
3. 【逐項計數】(A)「莫宰羊」字面是「不要殺羊」，實為臺語「不知道」→ 1 個；「竹筍炒肉絲」是用菜名比喻挨打，取的是形象。(B) 諺語各字都用本義 → 0 個。(C)「奶雞」是臺語「荔枝」的音 → 1 個；龍眼是本名。(D)「恰北北」（兇巴巴）、「熊熊」（突然）→ 2 個。
4. 【結論】(D) 有 2 個，最多，選 (D)。
@ana A x
- {k:莫宰羊}：借華語字音寫臺語「毋知影」（m̄ tsai-iánn），意思是「不知道」。借音，計 1 個。
- 竹筍炒肉絲：戲稱用竹枝、藤條打小孩——竹條是「竹筍」，被打的皮肉是「肉絲」。這是{k:借喻}（取形象的相似），不是借音。
→ 共 1 個。
@ana B x
「惜花連盆，疼子連孫」是臺灣諺語，意思是愛惜花就連花盆一起愛惜，疼愛兒子就連孫子一起疼愛。「惜、花、盆、疼、子、孫」每個字都用它本來的意義，沒有借音；「愛屋及烏」則是一般成語（語本《尚書大傳》「愛人者，兼其屋上之烏」）。
→ 0 個。
@ana C x
- {k:奶雞}：借華語字音寫臺語的「荔枝」（nāi-tsi）。由後文「楊貴妃愛吃」「大而紅」可推知。借音，計 1 個。
- 龍眼：水果的正式名稱，因果實圓而似眼得名，不是借音。「花枝招展」「含蓄淡雅」也都是照字面使用的詞語。
→ 共 1 個。
@ana D o
- {k:恰北北}：借華語字音寫臺語「刺耙耙」（tshiah-pê-pê），形容人兇悍、兇巴巴。與「恰好」「北方」的字義無關。
- {k:熊熊}：借華語字音寫臺語「雄雄」（hiông-hiông），意思是突然、猛然間。與動物「熊」無關。
- 其餘如「有一餐沒一餐」是照字面意思直說；「台北」是地名本字。
→ 共 2 個，為四個選項中最多，是正解。
@trap

- 朱光潛引介英國心理學家布洛（Edward Bullough）的「{k:心理距離}」說：欣賞或創作時，要把對象放在與實際利害有一段距離的地方，才能看見它的美。

- 魯迅接著寫道：希望「是不能抹殺的」，因為希望在於將來，不能用自己認定的「必無」去折服對方所說的「可有」，於是答應寫文章——這就是〈狂人日記〉的由來。

=== Q 18
@type 修辭手法的語境判斷
@cat 語文應用
@tags 象徵, 譬喻, 借代, 修辭辨析
@diff 3
@answer C
@stem
「『鐵屋子』就是傳統中國，像鐵鑄的屋子打、摔、敲、搥都不壞、不爛。魯迅以{b:《吶喊》為其小說第一集的名字}，□□{n:象徵}他在努力地、用力地叫喊著：醒來！快醒來！起來！快起來！因為外患大難臨頭了。」□□應該填入：
@note red
空格前：具體的{c:書名}
空格後：抽象的{c:精神}
→ 以具體表抽象
@opt A
比喻
@note blue
比喻：甲「像」乙，兩物相似
@opt B
借代
@note blue
借代：用相關物代稱本名
@opt C
{g:象徵}
@note red
具體事物 → 抽象意念 ✓
@opt D
映襯。
@note blue
映襯：兩相對比
@key
書名「吶喊」是具體的標誌，它所代表的是魯迅「努力喚醒國人」的抽象精神；用具體事物表現抽象的意念，就是象徵。
@logic
1. 【看空格前後】空格前是一個具體的事物——「以《吶喊》為書名」；空格後是它背後的意涵——「他在努力地叫喊：醒來！」。要填的詞必須能表示「{k:甲代表了乙這種精神}」。
2. 【代入檢驗】「象徵他在……叫喊著」語意通順：書名象徵著作者的呼喊。
3. 【排除比喻】比喻要有「喻體」和「喻依」兩個{k:不同類而相似}的事物（如前一句「鐵屋子……像鐵鑄的屋子」）。書名「吶喊」與「他在叫喊」不是兩種相似的東西，而是標誌與精神的關係。
4. 【排除借代、映襯】借代是「換個名稱來稱呼」，映襯是「兩相對比」，代入後語意都不通。選 (C)。
@ana A x
比喻（譬喻）是「借彼喻此」，利用兩件{k:不同事物的相似點}來說明，如「鐵屋子像傳統中國」。題幹前半句已用了「像」字作比喻；但書名《吶喊》與「魯迅在叫喊」之間並不是「甲像乙」的關係，「比喻他在努力地叫喊著」說不通。
@ana B x
借代是放棄事物的本名，改用{k:與它相關的事物}來代稱，如以「烽火」代戰爭、以「巾幗」代女子。借代是名稱的替換，後面不會接一整句說明性的話；「借代他在努力地叫喊著」不成句。
@ana C o
象徵是以{k:具體的形象}表現{k:抽象的觀念或情感}。書名《吶喊》是一個具體的符號，它所傳達的是魯迅急切喚醒昏睡國人的精神與企圖。「以《吶喊》為名，象徵他在努力地、用力地叫喊著：醒來！」文意完足，為正解。
@ana D x
映襯是把兩種相反或相對的事物並列對照，使意義更鮮明，如「朱門酒肉臭，路有凍死骨」。此處並沒有兩者對比，填入後語意不通。
@trap
象徵與比喻常被混淆。簡單的分辨法：比喻可以還原成「A 像 B」，A、B 都要說得出來，而且重在{k:外在或性質的相似}；象徵則是「看到 A 就聯想到某種精神、觀念」，重在{k:意義的代表}，被象徵的通常是抽象的東西（希望、和平、覺醒）。本題空格後接的是抽象的精神狀態，所以用「象徵」。
@know 比喻、借代、象徵比較表
| 修辭 | 定義 | 兩者關係 | 例子 |
| 比喻 | 借彼喻此 | 相似（A 像 B） | 鐵屋子像傳統中國；時間像流水 |
| 借代 | 借相關事物代替本名 | 相關（A 代 B，可直接替換） | 「布衣」代平民；「絲竹」代音樂；「杜康」代酒 |
| 象徵 | 以具體事物表現抽象觀念 | 聯想（A 代表某種精神） | 鴿子象徵和平；梅花象徵堅貞；《吶喊》象徵喚醒國人的呼聲 |
| 映襯 | 兩相對比 | 相反、相對 | 天長地久有時盡，此恨綿綿無絕期 |

- 魯迅第一本小說集名為《吶喊》，自序說是為了「聊以慰藉那在寂寞裡奔馳的猛士，使他不憚於前驅」而吶喊幾聲。

@ana A x

@ana B o

@ana C x

@translation
善於學習的人，老師教得輕鬆，效果卻加倍，學生還會把功勞歸於老師；不善於學習的人，老師教得辛苦，效果卻只有一半，學生還會埋怨老師。
善於發問的人，就像砍伐堅硬的木頭，先從容易下手的地方開始，然後才處理枝幹糾結的部分，時間久了，問題就在師生彼此愉悅的討論中得到解決；不善於發問的人，做法正好相反。
善於回答問題的人，就像撞鐘一樣：用小力敲它，就發出小的聲響；用大力敲它，就發出大的聲響；等撞鐘的人從容不迫地敲，鐘才把餘音完全發揮出來（比喻等發問的人把話從容說完，再詳盡地回答）。不善於回答問題的人，做法正好相反。
以上這些，都是增進學問的方法。只靠死記書本內容來準備應付學生發問的學問，是不夠資格當老師的；一定要能聽取學生的問題，再針對問題來解說才行啊！學生沒有能力提出問題時，老師才直接講給他聽；講了他還是不懂，即使暫時擱下不教，也是可以的。

## 文章結構：三組正反對比 ＋ 一段結論
| 層次 | 善者 | 不善者 | 譬喻 |
| 學（學生） | 師逸而功倍，又歸功於師 | 師勤而功半，又埋怨老師 | — |
| 問（學生） | 先易後難，久而相說以解 | 反此（先難後易，或不知從何問起） | 攻堅木 |
| 待問（老師） | 依所問大小回應，待其從容而盡其聲 | 反此（答非所問、不問也講、不等問完） | 撞鐘 |
- 結論：「記問之學，不足以為人師，必也其聽語乎」——老師不能只是知識的倉庫，而要{k:聽學生怎麼問，再決定怎麼教}。
## 讀出貫串全文的字：「問」
- 「問」字在短短一段中出現六次：善問、不善問、待問、答問、記問、不能問。連老師的「教」，也被稱為「待問」（等待、對待學生的提問）。
- 由此可知，本文把學生的{k:提問}看作教與學的樞紐：學生問得好，老師才答得好；學生「力不能問」，老師才直接講述。
## 字詞補充
- 「相說以解」：說，音ㄩㄝˋ，通「悅」，指師生都感到喜悅而疑難得解；另有一說「說」通「脫」，指木頭的節目自然脫落分解，承上「攻堅木」之喻。兩說皆通。
- 「待其從容」：等對方從容不迫。古注（鄭玄）則把「從容」讀為「舂容」，解作撞擊。考試時依上下文理解為「等發問者從容地問完」即可。
@know 《禮記‧學記》——中國最早的教育專論
- 《禮記》是儒家經典，與《周禮》、《儀禮》合稱「{k:三禮}」。今本四十九篇，相傳由西漢戴聖編定，又稱《小戴禮記》。
- 〈大學〉、〈中庸〉原是《禮記》中的兩篇，南宋朱熹把它們抽出，與《論語》、《孟子》合為「{k:四書}」。
- 〈學記〉專論教育的目的、制度、原則與方法，是中國最早有系統的教育論著。

=== Q 20
@type 文言論說文的主旨歸納
@cat 文言閱讀

@diff 3
@answer B
@stem
全文從師生雙方教與學來討論，認為「{y:學習成敗的關鍵|找貫串全文的字}」在於：
@note red
全文「問」字出現六次

@opt A
學生是否{x:選擇良師}
@note blue

@key
全文以「問」字貫串：學生要「善問」，老師的教是「待問」，結論更說「必也其聽語」「力不能問，然後語之」——教學以學生的提問為樞紐。
@logic
1. 【看結構】文章談了三件事：善學、善問、善待問。前兩件的主語是學生，第三件是老師。
2. 【看老師如何「教」】老師像一口鐘——「叩之以小者則小鳴，叩之以大者則大鳴」，鐘響多大，取決於{k:敲的人}（學生）怎麼敲。可見老師的回應是被學生的提問帶動的。
3. 【看結論句】「記問之學，不足以為人師，必也其{k:聽語}乎！{k:力不能問，然後語之}」：好老師要先聽學生問；只有學生「沒有能力發問」時才主動講述。提問是常態，講授是不得已。
4. 【刪去】(A) 擇師、(C) 老師的品德修養，文中都沒有提；(D) 傾囊相授與「撞鐘」之喻相反。選 (B)。
@ana A x
文中雖然提到「師逸」「師勤」，但談的是學生善學與否造成的教學效果，並沒有討論學生應該如何選擇老師。無中生有。
@ana B o
- 「善問者，如攻堅木，先其易者，後其節目，及其久也，相說以解」：會發問，疑難才能逐步解開。
- 「善待問者，如撞鐘」：老師的回答隨學生的提問而定。
- 「必也其聽語乎！力不能問，然後語之」：教學的理想方式是「學生問、老師答」。
三處都指向同一件事——學生能不能問、會不會問，決定了學習的成效。正確。
@ana C x
「進德修業」指增進品德、修習學業。文中對老師的要求是「不可只有記問之學」「要能聽語」，談的是{k:教學方法}，不是老師個人的品德修養。
@ana D x
「傾囊相授」是把所知全部教給學生。文中的好老師恰恰不是這樣：小問題就小答，大問題才大答；學生不能問才講，講了不懂還可以「舍之」（暫時不教）。重點在{k:因問施教、適可而止}，不是毫無保留地灌輸。
@trap
(D) 是最常見的誤選：一般認為好老師就該「傾囊相授」。但本文的觀點不同——老師像鐘，{k:不敲不響}；一股腦兒全倒給學生，是「不善答問者」。作答時要以文本的觀點為準，不要用自己的常識代替作者的意思。

=== Q 21
@type 經典名句與文意對應
@cat 文言閱讀
@tags 論語, 啟發式教學, 名句對應, 孔子
@diff 3
@answer C
@stem
下列文句描述最接近「{y:善待問者|主語是「老師」}」的選項是：
@note red
善待問者＝會回應提問的{c:老師}
→ 找「談教法」的句子
@opt A
業精於勤，荒於嬉
@note blue
談學生用功（韓愈）
@opt B
學如不及，猶恐失之
@note blue
談求學態度
@opt C
{g:不憤不啟，不悱不發}
@note red

老師才啟發 ✓
@opt D

@note blue

@cols 2
@key
「善待問者」是善於回應學生的老師，像鐘一樣「不叩不鳴」；「不憤不啟，不悱不發」說的正是等學生苦思不得、欲言不能時才加以啟發，同屬教學方法。
@translation
(A) 學業因為勤奮而精進，因為嬉戲而荒廢。
(B) 求學要像追趕什麼卻唯恐趕不上那樣（急切），（學到了）還擔心會失去它。
(C) 不到學生苦苦思索卻想不通的時候，不去開導他；不到學生心裡明白卻說不出來的時候，不去啟發他。
(D) 每天知道一些自己原本不懂的，每月不忘記自己已經學會的。
@logic
1. 【確定主語】「善待問者」的「待問」是對待、回應別人的提問，主語是{k:老師}。所以要找一句談「老師怎麼教」的話。
2. 【分類選項】(A)(B)(D) 講的都是{k:學習者}應有的態度（勤奮、急切、溫故知新）；只有 (C) 是站在{k:教導者}的立場說話。
3. 【比對內容】撞鐘之喻的重點是「叩之……則鳴」：學生先有動作，老師才回應。(C)「不憤不啟，不悱不發」也是學生先有「憤」「悱」的狀態，老師才「啟」「發」。兩者都主張等待學生主動，再順勢引導。
4. 【結論】選 (C)。
@ana A x
語出韓愈〈進學解〉「業精於勤，荒於嬉；行成於思，毀於隨」。說的是學業的精進靠勤奮，是對學生的勉勵，與老師如何回答問題無關。
@ana B x
語出《論語‧泰伯》。孔子形容求學應有的迫切心情：好像追趕不上，學到了又怕失去。這是{k:學習者}的態度，可對應文中的「善學者」，而非「善待問者」。
@ana C o
語出《論語‧述而》：「不憤不啟，不悱不發；舉一隅不以三隅反，則不復也。」依朱熹的解釋，「憤」是心裡想弄通卻還沒弄通，「悱」（ㄈㄟˇ）是嘴上想說卻說不出來。孔子主張等學生達到這種狀態才去點撥，這就是「啟發」一詞的來源。老師不主動灌輸，而是{k:等待學生的需求再回應}，與「叩之以小者則小鳴，叩之以大者則大鳴」「力不能問，然後語之」精神一致。正確。
@ana D x
語出《論語‧子張》，是子夏的話：「日知其所亡，月無忘其所能，可謂好學也已矣。」亡，通「無」，指自己所沒有的知識。說的是{k:好學}的表現：每天學新的、每月複習舊的。主語仍是學習者。
@trap
四個選項都與「學習」有關，三個出自《論語》，容易讓人逐句細想而浪費時間。其實只要先問「{k:這句話是說給誰聽的}」——說給學生聽（A、B、D）還是說給老師聽（C）——就能一步到位。
@know 孔子的教學方法
| 方法 | 出處 | 內容 |
| 啟發誘導 | 《論語‧述而》「不憤不啟，不悱不發」 | 等學生有求知的迫切感再點撥 |
| 舉一反三 | 《論語‧述而》「舉一隅不以三隅反，則不復也」 | 要求學生類推，不能類推就暫不再教 |
| 因材施教 | 《論語‧先進》「求也退，故進之；由也兼人，故退之」 | 依學生個性給不同的指導 |

| 循循善誘 | 《論語‧子罕》顏淵讚孔子「夫子循循然善誘人」 | 有步驟地引導 |
- 「舉一隅不以三隅反，則不復也」與〈學記〉「語之而不知，雖舍之可也」意思相通：學生還沒準備好，就先不勉強教。
@know 東西方的「問答教學」
- 〈學記〉的「撞鐘」與孔子的「不憤不啟」，都強調{k:學生主動、老師回應}。

2. 【審題】題目要選「不正確」的詮釋，所以與「忍」的基調不合者就是答案。
3. 【比對】(B) 逆來順受、(D) 準備承擔，都是「忍」；(C) 說的是詩人的態度（同情），從「有淚」「往心裡咽」的用字可以感受到。只有 (A) 出現「反抗」，與全詩不合。
4. 【檢查詞語】「橫豎」是「反正、無論如何」的意思：不管車裝得多滿，牠反正一聲不吭。「無言以對」則是「被問得沒有話可以回答」，也不適合形容老馬。選 (A)。
@ana A x
詮釋不正確，為本題答案。「橫豎」意為反正、無論如何；「橫豎不說一句話」是說無論主人裝多少，老馬都{k:一聲不吭、默默承受}。這是隱忍，不是反抗——如果是反抗，下一句就不會是「把頭沉重的垂下」。此外，「無言以對」指理屈或驚愕而答不出話來，與老馬的處境也不相合。可改為「表示老馬默默承受、有苦難言」。
@ana B o
車上的重量「往肉裡扣」，老馬的回應只是把頭沉重地垂下，沒有嘶鳴、沒有掙扎。「逆來順受」（以順從的態度接受惡劣的待遇）正是此意；垂下頭仍然撐住重擔，則見其韌性。詮釋恰當。
@ana C o
馬不會說話，「有淚」「往心裡咽」其實是詩人設身處地的想像：連流淚的自由都沒有，只能把委屈吞下去。這樣的寫法已帶有強烈的憐憫，詩人的同情溢於言表。詮釋恰當。
@ana D o
「眼裡飄來一道鞭影」表示鞭子即將落下；老馬「抬起頭望望前面」，是認命地準備繼續往前拉車。前面的路還長，牠沒有倒下，仍要走下去——可說是頑強地準備承擔。詮釋恰當。
@trap
有人覺得 (B)「逆來順受」是消極的，(D)「頑強」是積極的，兩者互相矛盾，必有一錯。其實「忍受」本身就同時包含{k:順從}（不反抗）與{k:堅韌}（不倒下）兩面，並不衝突。真正與全詩牴觸的只有 (A) 的「反抗」。
@know 詞語辨析：「橫豎」與「無言以對」
| 詞語 | 意義 | 例句 |
| 橫豎 | 反正、無論如何（副詞） | 橫豎都要去，不如早點出發 |
| 無言以對 | 沒有話可以回答（多因理虧或驚訝） | 面對鐵證，他無言以對 |
| 逆來順受 | 以順從的態度接受惡劣環境或不合理待遇 | 她對婆婆的刁難一向逆來順受 |
| 忍辱負重 | 忍受屈辱，承擔重任 | 他忍辱負重，終於完成使命 |

@know 新詩鑑賞三步驟
- 第一步：{k:抓意象}——詩中出現了哪些具體事物？（大車、壓力、鞭影、垂下的頭）
- 第二步：{k:定基調}——這些意象給人的共同感受是什麼？（沉重、壓迫、隱忍）
- 第三步：{k:問象徵}——詩人只是寫這件東西嗎？牠可能代表誰？（受苦的農民、被生活壓迫的人）
- 作答時，凡是與基調相反的詮釋（如把隱忍說成反抗、把沉重說成輕快），多半就是錯誤選項。
@know 「託物言志」與「象徵」
- {k:託物言志}：借描寫某一事物，寄託作者的情感、志向或對人生的看法。如于謙〈石灰吟〉借石灰寫堅貞、周敦頤〈愛蓮說〉借蓮寫君子。
- 〈老馬〉通篇寫馬，不提一個「人」字，卻讓人處處想到受壓迫的人，是新詩中託物寄意的名作。

@translation

@logic
1. 【審題】題目問「並非以馬喻人」。先釐清「以馬喻人」的條件：詩中的馬必須{k:帶有人的志向、才能或遭遇}，讀者能從馬讀出「人」來。
2. 【檢查每匹馬】(A) 馬渴望「金絡腦」「踏清秋」——想被重用、一展長才；(C) 馬有「萬里姿」卻被拴住而悲鳴——有才而不得其主；(D) 老馬被留用「不必取長途」——年老仍有價值。三者都是人的心事。
3. 【找出例外】(B)「汗馬逐風嘶」與「荒雞隔水啼」對仗，雞啼、馬嘶都是戰地的聲音；後兩句「終日隨征斾，何時罷鼓鼙」是從軍者的感嘆。馬只是場景的一部分，沒有被賦予人的志向。

@ana A x

@ana B o
中唐令狐楚〈從軍詞五首〉其一（見《全唐詩》）。「荒雞」是半夜啼叫的雞，「汗馬」是奔馳出汗的戰馬，「征斾」（斾同「旆」）是軍旗，「鼓鼙」是軍中戰鼓，借指戰事。全詩寫征人日夜行軍、盼望戰爭早日結束的心聲；雞啼馬嘶是眼前耳邊的{k:實景}，用來烘托軍旅的艱苦。馬並不代表某個人，不是以馬喻人，為本題答案。
@ana C x
杜甫〈述古三首〉其一的前四句。赤驥是傳說中周穆王的八匹駿馬之一；「頓長纓」是被韁繩所困，「非無萬里姿」是說牠本有日行萬里的才具。良馬悲鳴落淚，質問「駕馭我的是誰」——比喻{k:賢才所遇非人、不得施展}。該詩後文即直接談到「古時君臣合」，可見是以馬喻人。
@ana D x
杜甫〈江漢〉的後四句。「落日」「秋風」暗示年老多病，但「心猶壯」「病欲蘇」；末二句用「老馬識途」的典故（《韓非子‧說林上》：管仲隨齊桓公出征，回程迷路，放老馬帶路而得返）：自古留養老馬，是用牠的智慧，不必要牠去奔跑長途。杜甫{k:以老馬自比}，表示自己雖老，仍有可用之處。屬以馬喻人。
@trap
(B) 的後兩句「終日隨征斾，何時罷鼓鼙」如果把主語看成「汗馬」，似乎也能說是馬在厭戰。但首句「荒雞」與「汗馬」並列，兩者同為景物；若馬是比喻，雞又比喻什麼？由此可知詩人只是用雞啼、馬嘶渲染戰地氣氛，抒情的主體是征人。判斷「喻」與「不喻」，要看該物{k:是否被單獨賦予人的品格或命運}。

@diff 3
@answer D
@stem
□□□□、○○○○和△△△△，{y:依序|三格都要對}要填入的詞語應該是：
@note red
每一格都回原文
找{c:呼應的字詞}
@opt A
{x:菲才寡學}／{x:矯情飾詐} ／鴻案相莊
@note blue
菲才寡學＝才疏學淺

@opt B
{x:菲才寡學}／禮多必詐／{x:心照神交}
@note blue
心照神交 → 形容知己朋友
@opt C
落拓不羈／{x:矯情飾詐} ／{x:心照神交}
@note blue
矯情飾詐：沒有「禮」字
接不上芸的回話
@opt D
{g:落拓不羈}／{g:禮多必詐}／{g:鴻案相莊}。
@note red
爽直→不羈｜禮、詐｜夫妻 ✓
@cols 1
@key
「性爽直」配「落拓不羈」，並與芸的「迂拘多禮」相對；芸回答「恭而有禮，何反言詐」，可知俗語是「禮多必詐」；形容夫妻二十三年，用梁鴻、孟光典故的「鴻案相莊」。
@logic
1. 【第一格：看對比】「余性爽直，□□□□；芸若腐儒，迂拘多禮」是夫妻性格的對照。空格要與「爽直」同類、與「迂拘多禮」相反 → {k:落拓不羈}（灑脫不受拘束）。「菲才寡學」是謙稱才學淺薄，談的不是性情。刪 (A)(B)。
2. 【第二格：看回話】沈復引俗語之後，芸立刻反問「恭而有{k:禮}，何反言{k:詐}？」可見那句俗語裡同時有「禮」和「詐」→ {k:禮多必詐}。「矯情飾詐」沒有「禮」字，也不是「語曰」所引的俗諺。刪 (C)。
3. 【第三格：看對象】「△△△△廿有三年，年愈久而情愈密」說的是夫妻共同生活 → 用夫妻典故的{k:鴻案相莊}；「心照神交」形容朋友相知。
4. 【結論】落拓不羈／禮多必詐／鴻案相莊，選 (D)。
@ana A x
第一格「菲才寡學」（才能小、學識淺）是自謙才學的話，與上文「性爽直」談性情不相稱，也無法與芸的「迂拘多禮」形成對比。第二格「矯情飾詐」（掩飾真情、作假騙人）雖有「詐」字，卻沒有「禮」字，接不上芸的回話；用來指責妻子也太重，不像玩笑話。只有第三格正確。
@ana B x
第一格「菲才寡學」不當，理由同上。第三格「心照神交」指彼此心意相通、不必言語就能了解，多用於{k:朋友}之間的相知；此處說的是夫妻二十三年的共同生活，以「鴻案相莊」為宜。只有第二格正確。
@ana C x
第一格「落拓不羈」正確。第二格「矯情飾詐」、第三格「心照神交」皆不當，理由見 (A)(B)。
@ana D o
- {k:落拓不羈}：性情疏放，不受拘束。與「爽直」並列，寫沈復的個性。
- {k:禮多必詐}：俗語，禮數過多，其中必有虛偽。沈復用來打趣妻子，才引出芸「恭而有禮，何反言詐」的反駁。
- {k:鴻案相莊}：鴻案，指東漢梁鴻、孟光「舉案齊眉」的故事；莊，莊重、敬重。比喻夫妻相敬如賓。
三格皆與上下文呼應，為正解。
@trap
第一格容易誤選「菲才寡學」，因為文言文中作者常自謙。但要注意句子的主語是「余{k:性}」——談的是性情，後面只能接描寫個性的詞。另外，「落拓」一詞有兩義：一是「窮困失意」（落拓江湖），一是「豪放不拘」（落拓不羈），此處是後者。
@know 本題六個詞語釋義
| 詞語 | 意義 | 適用對象 |
| 落拓不羈 | 性情疏放，不受拘束；也作「落魄不羈」 | 形容個性 |
| 菲才寡學 | 才能小、學識淺 | 自謙才學 |
| 禮多必詐 | 禮數太多，必有虛假 | 俗諺 |
| 矯情飾詐 | 掩飾真情，以假面目欺騙人 | 批評人虛偽 |
| 鴻案相莊 | 夫妻互相敬重 | 夫妻 |
| 心照神交 | 彼此心意相通，不必言說 | 知己朋友 |
@know 梁鴻與孟光：「舉案齊眉」的故事
- 東漢隱士梁鴻品行高潔，娶了貌醜而賢德的孟光。兩人隱居，梁鴻替人舂米為生；每次回家，孟光備好飯食，不敢抬頭直視，把盛飯菜的托盤（案）高舉到與眉毛齊平，恭敬地送上。事見《後漢書‧逸民傳》。
- 衍生詞語：{k:舉案齊眉}、{k:鴻案相莊}、{k:孟光舉案}，都用來稱美夫妻相敬相愛，常見於結婚賀詞。
- 注意「案」的古義是有短腳的托盤，不是今天的桌子——這也是古今異義。

| 複述詞 | 下文會重複或回應空格中的字 | 「恭而有禮，何反言詐」→ 禮、詐 |

=== Q 25
@type 文言短文的主旨與人物關係
@cat 文言閱讀
@tags 浮生六記, 夫妻之情, 主旨判斷, 成語辨析
@diff 4
@answer B
@stem
關於作者的{y:夫妻相處之道|第二段是重點}，敘述{c:最適當}的選項是：
@note red
每個選項四個短語
逐一回原文核對
@opt A
{x:吵吵鬧鬧，在所難免}；相互諒解，和樂融融
@note blue
只拌過一次嘴
且是玩笑
@opt B
{g:我行我素，如入無人}；{g:兩人世界，樂在其中}
@note red
同行並坐，久則不以為意
不期然而然 ✓
@opt C
用情專一，{x:不欺暗室}；{x:效法父母}，白頭偕老
@note blue
暗室相逢 ≠ 不欺暗室
父母只是芸舉的例子
@opt D
{x:愛在心底，外冷內熱}；{x:修身齊家}，相敬如賓。
@note blue
兩人是內外皆親暱
@cols 1
@key
「同行並坐，初猶避人，久則不以為意」「彼此皆不覺其所以然……繼成不期然而然」——夫妻親暱到不在意旁人眼光，沉浸在兩人世界裡，最接近 (B)。
@logic
1. 【定位】「相處之道」主要寫在第二段：暗室相逢必握手、同行並坐、芸見夫至便挪身讓坐。關鍵句是「{k:初猶避人，久則不以為意}」與「{k:不期然而然}」。
2. 【歸納】兩人的親暱起初還怕人看見，後來完全不在乎別人的眼光，成為自然而然的習慣 → 不受外界影響（我行我素）、旁若無人（如入無人）、只有彼此（兩人世界）、甘之如飴（樂在其中）。
3. 【逐項找硬傷】(A)「吵吵鬧鬧」：全文只有一次因玩笑引起的小誤會，且「年愈久而情愈密」。(C)「不欺暗室」是指獨處時也不做虧心事，與「暗室相逢」無關；「效法父母」文中沒有。(D)「愛在心底，外冷內熱」與兩人在人前並坐的親暱相反；「修身齊家」文中未提。
4. 【結論】(B) 四個短語都有原文依據，選 (B)。
@ana A x
「相互諒解，和樂融融」尚可，但「吵吵鬧鬧，在所難免」不合文意。第一段的「禮多必詐」之爭，沈復自己說是「前言戲之耳」，並立刻安撫妻子；事後「豈敢」「得罪」還成了兩人的口頭禪。作者要表現的是閨房情趣，而不是夫妻時常爭吵；文中更明說「年愈久而情愈密」。
@ana B o
- 我行我素：不受外界影響，照自己的方式行事 ←「同行並坐……久則不以為意」。
- 如入無人：好像旁邊沒有別人 ← 芸正與人坐談，見丈夫來了就挪身，沈復便靠過去並坐。
- 兩人世界：眼中只有彼此 ←「彼此皆不覺其所以然者」。
- 樂在其中 ←「年愈久而情愈密」；末段更以老年夫婦「相視如仇」反襯自己的幸福。
四者皆有依據，是最適當的敘述。
@ana C x
- 「不欺暗室」：指在沒有人看見的地方，也不做違背良心的事（形容人光明磊落）。文中的「暗室相逢」只是說在家中昏暗處相遇，兩者只有字面相同，{k:意義無關}。
- 「效法父母」：文中的「至親莫如父母」是芸用來反駁「恭敬在心，不在虛文」的例子，並沒有說夫妻相處要效法父母。
- 「白頭偕老」：是「或曰」評論老年夫婦的話，作者還以「斯言誠然歟」表示懷疑。
@ana D x
- 「愛在心底，外冷內熱」：形容感情內斂、不形於外。但沈復夫婦是握手相問、同行並坐，親暱表現在外；主張「恭敬在心，不在虛文」的是沈復談「禮」，不是談「愛」。
- 「修身齊家」：文中沒有相關內容。
- 「相敬如賓」：雖與「鴻案相莊」意思相近，但前三個短語都不合，整項不適當。
@trap
本題有兩個容易上當的地方。第一，(C)「不欺暗室」、(D)「相敬如賓」都能在原文找到「看起來相關」的字眼（暗室、鴻案相莊），但選項是四個短語的組合，{k:只要有一個不合就要捨棄}。第二，「我行我素」在現代常帶貶義（不聽勸告、一意孤行），考生可能覺得用來形容恩愛夫妻不妥；此處取其中性的意思「不因外界眼光而改變」，在四個選項中仍是「最適當」的。
@know 成語辨析：望文生義的陷阱
| 成語 | 容易誤解為 | 正確意義 |
| 不欺暗室 | 在暗處不欺負人 | 獨處時也心地光明，不做虧心事。唐‧駱賓王〈螢火賦〉有「入暗室而不欺」之語 |
| 我行我素 | 一定是任性妄為 | 語本《禮記‧中庸》「君子素其位而行」；指不受外界影響，照自己平素的方式行事 |
| 如入無人之境 | 走進沒人的地方 | 原指作戰勇猛、無人能擋；也用來形容旁若無人 |
| 相敬如賓 | 夫妻感情冷淡、像客人 | 夫妻互相尊敬，如對待賓客 |
@know 寫作手法：反襯與反詰
- {k:反襯}：用相反的事物來襯托主體。本文末尾提出「老年夫婦相視如仇」，是為了對照自己與芸「年愈久而情愈密」。
- {k:反詰}（激問）：答案在問題的反面。「斯言誠然歟？」（這話真是如此嗎？）其實是說「我不這麼認為」。
- 同樣以問句作結的課文：〈愛蓮說〉「蓮之愛，同予者何人？」、〈賣油翁〉「此與莊生所謂解牛、斲輪者何異？」
@know 「語助詞」原來是個玩笑
- 語助詞是沒有實義、只表示語氣的虛詞，如文言的「之、乎、者、也、矣、焉、哉、耳」。
- 文中說「豈敢」「得罪」「竟成語助詞矣」，是沈復的幽默：這兩個詞被夫妻倆掛在嘴邊，說的時候已經不帶原來的意思，就像語助詞一樣——可見當初的爭執早已化為兩人之間的小情趣。
- 本文還有幾個句末語助詞可留意：「卿欲以禮縛我{k:耶}」（疑問）、「前言戲之{k:耳}」（罷了）、「竟成語助詞{k:矣}」（了）、「焉得白頭偕老{k:哉}」（反問）、「斯言誠然{k:歟}」（疑問）。
