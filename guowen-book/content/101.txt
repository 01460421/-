@know 詞語背後的文化常識
- {k:涇渭分明}：涇水、渭水在今陝西境內會合，一濁一清，同流而不混，比喻人品優劣或事物是非界線分明。
- {k:芻蕘}：《詩經‧大雅‧板》「先民有言，詢于芻蕘」，意思是古代賢者連割草打柴的人都願意請教——比喻不恥下問。

@note blue

@opt C

@note green

@key

@logic
1. 【審題】字音已給，問的是「字形」是否相同；而且是「共有幾組」的計數題，任何一組判斷錯誤，答案就會錯，所以五組都要實際寫出國字。
2. 【以義定形】用詞義推部首：工程「完畢」→ 立部的竣；山勢「高陡」→ 山部的峻。「勞累成疾」→ 疒部的瘁。「不足」→ 糸部的絀。「光彩鮮明」→ 火部的煥；「美輪美奐」的奐是「盛大」，沒有火字旁。身形「乾枯」→ 木部的槁；「文稿」→ 禾部的稿。
3. 【計數】相同：乙（瘁／瘁）、丙（絀／絀）；不同：甲、丁、戊。共二組。
4. 【結論】選 (B)。
@ana A x
只算一組是少算了。常見原因是把「左支右絀」誤寫成「左支右拙」或「左支右黜」，以為丙組不同。
甲組：如期「{k:竣}」工——竣，完畢；山勢險「{k:峻}」——峻，高而陡峭。兩字同音ㄐㄩㄣˋ而部首不同，不算。
@ana B o
乙組：心力交「{k:瘁}」、鞠躬盡「{k:瘁}」，同為「瘁」（勞累）。「心力交瘁」指精神、體力都疲憊不堪；「鞠躬盡瘁」指恭敬謹慎、竭盡心力，語本諸葛亮〈後出師表〉。
丙組：相形見「{k:絀}」、左支右「{k:絀}」，同為「絀」（不足）。「相形見絀」是互相比較之下顯得不足；「左支右絀」原指射箭時左臂撐弓、右臂屈曲扣弦，語本《戰國策‧西周策》，後形容顧此失彼、窮於應付。
→ 共二組，正解。
@ana C x
算成三組是多算了。最常多算的是丁組：「{k:煥}」然一新（煥，光彩鮮明）與美輪美「{k:奐}」（奐，盛大、文彩鮮明）。「美輪美奐」語本《禮記‧檀弓下》「美哉輪焉，美哉奐焉」，形容房屋高大華美，「奐」不可加火字旁。
@ana D x
算成四組，多半是連戊組也算進去。形容枯「{k:槁}」：槁，草木乾枯，引申為乾瘦；語出《楚辭‧漁父》「顏色憔悴，形容枯槁」，其中「形容」是形體容貌。打好草「{k:稿}」：稿本指禾稈，引申為文字、圖畫的底本。木部與禾部不同字。
@trap
「美輪美奐」是錯別字題的常客：常被誤寫成「美倫美煥」「美輪美煥」。記法——輪指高大（輪囷），奐指盛大，都在形容{k:建築物}，所以這個成語只能用來稱讚房屋，不能形容風景或人。另外「鞠躬盡瘁」不可寫成「鞠躬盡粹／盡悴」。

→ 先想「本義」

@opt D

@note red
刊＝削除、修改
不刊＝不可更改 ✓
@key
「不刊之論」指不可刪改、不可磨滅的言論，用來形容古聖先賢的嘉言正確；其餘三個成語都被「望文生義」誤用。
@logic
1. 【審題】四個成語都帶有容易誤解的字：桑榆、觚、睫、刊。這類題目不能照字面猜，要先回想成語的{k:本義與使用對象}。
2. 【A：對象錯】「桑榆」是日落時餘光所照之處，比喻人的晚年；句中卻拿來指半夜的星空景色。
3. 【B：範圍錯】「操觚」是拿著木簡寫字，成語只用於「寫文章」；特技拋接與寫作無關。
4. 【C：一字之差】「目不見睫」是看不見自己的睫毛，比喻沒有自知之明；日夜不睡地照顧病人應是「目不交睫」或「衣不解帶」。
5. 【D：正確】「刊」是削除，古人寫在竹簡上，寫錯就用刀削去；「不刊」即不可更改，正合「古聖先賢的嘉言」。
@ana A x
{k:桑榆晚景}：桑榆，桑樹與榆樹，日落時夕陽餘暉照在桑榆樹梢，因此借指日暮，再比喻{k:人的晚年}，也作「桑榆暮景」。本句寫的是「夜半群星、涼風輕拂」的景色，把成語當成「夜晚的景致」，是望文生義。可改為「星河燦爛」「良辰美景」。
@ana B x
{k:率爾操觚}：率爾，不加思索、輕率的樣子；觚（ㄍㄨ），古人用來書寫的木簡；操觚即執筆寫作。語本晉陸機〈文賦〉「或操觚以率爾，或含毫而邈然」。本指不假思索、提筆成文，後多用來形容寫作態度草率。它的使用範圍只限於{k:寫文章}，不能形容特技表演。可改為「信手拈來」「得心應手」。
@ana C x
{k:目不見睫}：眼睛看不見自己的睫毛，比喻人沒有自知之明，或只見遠而不見近。語本《韓非子‧喻老》「智之如目也，能見百步之外，而不能自見其睫」。句中要表達的是日夜照顧、不曾闔眼，應改為「{k:目不交睫}」（上下睫毛不相交，即不睡覺）或「{k:衣不解帶}」。後半「服侍湯藥，未曾廢離」化用李密〈陳情表〉「臣侍湯藥，未曾廢離」。
@ana D o
{k:不刊之論}：刊，削除、刪改。古代文字寫在竹簡木牘上，有誤就用刀削去，故「不刊」指不可刪改；「不刊之論」即確鑿不移、不可磨滅的言論。語本漢揚雄〈答劉歆書〉「是懸諸日月不刊之書也」。用來形容歷久彌新的聖賢嘉言，完全正確。
@trap
「不刊之論」最常被誤解成「不值得刊登的言論」（貶義），因而不敢選 (D)。記住：現代的「刊登」是後起義；成語裡的「刊」是{k:削、改}，「不刊」是「不可改」，為高度褒義。同類的還有「不易之論」（易＝改變）。
@know 本題四個成語的「字面陷阱」

@ana B x

@ana C x

詞句相傳為宋末黃公紹〈青玉案〉（年年社日停針線；一說無名氏作）：黃昏在芳草岸邊卸下馬鞍，有花無人為我戴，有酒無人勸我飲，醉了也無人照管。寫{k:遊子漂泊的孤寂}，與「有所得」相反。
@ana D o

@trap
(C) 的「流瀉」很有吸引力，若只憑甲段作答容易誤選。填空題有兩格時，要找{k:線索最硬}的那一格下手：乙段有提示語、有下文呼應，可以確定答案，不必在甲段的語感上糾結。

@type 文句排序（散文）
@cat 語文應用
@tags 排序, 關聯詞, 簡媜
@diff 2
@answer B
@stem
下列是一段現代散文，請依文意選出{y:排列順序最恰當|找綁定句}的選項：
@note red
先找{c:固定搭配}：
「不管…或是…」
@box lines

甲、{b:插在甕裡}，恁意伸展

戊、{c:或是}幾朵盛放的小花
別有一番虛心承受的古意。（簡媜〈聆聽〉）
@note green
丁→乙：先有甕，才能刷洗甕
@note red
丙→戊：不管A或是B（綁定）
@note blue
甲：草、花「插」進甕
→ 接結尾「別有…古意」
@note purple
恁意：此處作「任意」解
@opt A
丙戊丁乙甲
@opt B
{g:丁乙丙戊甲}
@opt C
乙丁甲丙戊
@opt D
丁{x:丙乙}戊甲
@note blue
D 把「不管…或是…」拆開了
@key
「在聆聽之前，必須…（丁）」開頭；有甕才能刷洗（丁→乙）；「不管…或是…」相連（丙→戊）；草與花「插在甕裡」後接結尾（甲）。
@logic
1. 【找首句】開頭「在聆聽之前，」是時間狀語，後面要接「該做什麼」→ 帶有「必須」的丁最順。乙「把…刷洗乾淨」缺少刷洗的對象，不能當首句 → 刪 (C)；丙「不管…」也接不上「之前」→ 刪 (A)。
2. 【找綁定句】丙「不管…莽草」與戊「或是…小花」是選擇關係的關聯詞，必須{k:丙戊相連}。(D) 的順序是丁丙乙戊，把丙、戊拆開 → 刪 (D)。
3. 【理順邏輯】丁（變成甕）→ 乙（把甕裡的灰塵刷乾淨）→ 丙戊（不管聽到的是莽草或小花）→ 甲（都插在甕裡任它伸展）→「別有一番虛心承受的古意」。
4. 【結論】丁乙丙戊甲，選 (B)。
@ana A x
丙戊放最前面，成為「在聆聽之前，不管聽來的是…」——還沒聽就說「聽來的」，時間順序矛盾；而且「甕」尚未出現，後面的丁乙才說要變成甕、刷洗甕，敘述次序顛倒。
@ana B o
還原後全文：「在聆聽之前，必須讓自己變成一只寬口大腹的甕，把陳年的灰塵泥垢刷洗乾淨，不管聽來的是一把帶刺的莽草，或是幾朵盛放的小花，插在甕裡，恁意伸展，別有一番虛心承受的古意。」
先準備容器（丁乙）→ 再說放進去的東西（丙戊）→ 最後說放進去的樣子（甲），條理分明。
@ana C x
乙當首句，「把陳年的灰塵泥垢刷洗乾淨」沒有交代刷洗什麼；甲「插在甕裡」排在丙戊之前，草和花還沒出現就先「插」，主語落空；而以戊「或是幾朵盛放的小花」接結尾「別有一番…古意」也不通。
@ana D x
首句丁正確，但丁之後接丙，再插入乙，變成「不管聽來的是一把帶刺的莽草，把陳年的灰塵泥垢刷洗乾淨，或是幾朵盛放的小花」——「不管…或是…」被硬生生拆開，語意中斷。
@know 排序題的四個檢查點
| 步驟 | 作法 | 本題應用 |
| 找首句 | 看題目給的開頭要接什麼成分 | 「在聆聽之前，」→ 接「必須…」 |
| 找綁定 | 關聯詞、代詞、重複詞語必相連 | 「不管…或是…」；「甕」→「刷洗」 |
| 找尾句 | 看題目給的結尾需要什麼主語 | 「別有…古意」的主語是插在甕裡的花草 |
| 代回去唸 | 整段讀一遍檢查語氣 | 丁乙丙戊甲 通順 |

| 意象 | 象徵 |
| 寬口大腹的甕 | 虛心、有容量的聆聽者 |

@logic
1. 【審題】選「有誤」者。四個選項的結構相同：引一句古文 → 解釋它指的時間 → 再給一個別稱。前後兩段都要檢查，命題者常把錯誤藏在{k:後半的「又稱」}。

@ana A x

@ana B o

@ana C o

=== Q 10
@type 文學史常識的推論判斷
@cat 國學常識
@tags 正史體例, 章回小說, 古體詩, 詞曲
@diff 2
@answer A
@stem
下列敘述，{y:正確|看「所以」推得對不對}的選項是：
@note red
四項都是「因為甲，{c:所以}乙」
→ 檢查有無以偏概全
@opt A
{g:正史都是以紀傳體編寫}，所以二十五史都是紀傳體
@note green
正史＝紀傳體，定義如此 ✓
@opt B
明清盛行章回小說，所以明清的小說{x:都是}章回小說
@note blue
反例：《聊齋》、三言二拍
@opt C
古體詩是相對於唐代近體詩而言，所以唐以後{x:就沒有古體詩了}
@note blue
反例：文天祥〈正氣歌〉
@opt D
宋詞、元曲皆入樂可歌，所以元以後{x:詞便消失了}
@note blue
反例：清詞中興（納蘭性德）
@cols 1
@key
「正史」專指紀傳體的官修史書，二十五史全為紀傳體；(B)(C)(D) 都由「盛行」「相對而言」推出「全部」「消失」，犯了以偏概全的錯。
@logic
1. 【看句型】四個選項都是「前提，所以結論」。前提大致都對，要檢查的是{k:結論有沒有說過頭}——特別留意「都是」「就沒有」「便消失」這類絕對語氣。
2. 【找反例】(B) 明清也有短篇的文言小說與話本；(C) 唐代以後的詩人照樣寫古體詩；(D) 元明清都有人填詞，清代還號稱詞的「中興」。只要舉得出一個反例，絕對式的結論就不成立。
3. 【確認 A】自《隋書‧經籍志》以來，「正史」就是指以帝王本紀為綱的紀傳體史書；二十五史從《史記》到《新元史》（或《清史稿》）全是紀傳體。
4. 【結論】選 (A)。
@ana A o
「{k:正史}」之名起於《隋書‧經籍志》，專指仿《史記》、《漢書》體例，以本紀、列傳為主幹的{k:紀傳體}史書；清代乾隆年間欽定「二十四史」為正史，民國以後加入《新元史》（或《清史稿》）而稱二十五史。因此二十五史全為紀傳體，敘述正確。
@ana B x
錯在「都是」。明清固然是章回小說的黃金時代（《三國演義》、《水滸傳》、《西遊記》、《紅樓夢》、《儒林外史》），但同時還有：①白話短篇小說（擬話本），如馮夢龍「三言」、凌濛初「二拍」；②文言短篇小說，如蒲松齡《聊齋誌異》、紀昀《閱微草堂筆記》。應改為「明清小說以章回小說為主流」。
@ana C x
錯在「唐以後就沒有古體詩了」。「古體詩」是唐人為了與講究格律的近體詩區別而起的名稱，指{k:不受格律限制}的詩，是「體裁」的分別，不是「時代」的斷限。唐代李白〈蜀道難〉、杜甫〈兵車行〉、白居易〈長恨歌〉都是古體詩；唐以後如南宋文天祥〈正氣歌〉也是五言古詩。
@ana D x
錯在「元以後詞便消失了」。詞在元、明兩代雖然衰微，但創作不曾中斷；到了清代更出現納蘭性德、朱彝尊、陳維崧等名家，號稱詞的「{k:中興}」。一種文體盛極而衰，是「不再是主流」，並非「消失」。
@trap
本題是「邏輯題」多於「背誦題」。看到「所以」不要急著判斷前提，先問：{k:前提能不能推出這麼絕對的結論？}「盛行」推不出「全部」，「相對於」推不出「之後沒有」，「皆可歌」推不出「另一個消失」。

末句「今人臣之處官者，皆是類也」點明以「嫁女」比「做官」：女兒私積聚而被休，正如人臣私自聚斂終將被逐，選 (D)。
@translation
衛國有個人，嫁女兒時教導她說：「一定要私下積攢財物。做人家的媳婦而被休棄，是常有的事；能夠白頭到老，那是僥倖。」他的女兒於是私下積攢財物，她的婆婆認為她私心太重、私藏太多，就把她休了。這個女兒帶回娘家的財物，比她出嫁時帶去的嫁妝多了一倍。她的父親不責怪自己教導女兒的方法錯誤，反而自以為聰明，覺得家裡更富有了。現在那些做官的臣子，都是這一類人啊！
@logic
1. 【找點題句】先秦諸子的寓言，寓意通常由作者在結尾{k:自己說破}。本文最後一句「今人臣之處官者，皆是類也」就是鑰匙：這個故事是在講「當官的人」。
2. 【建立類比】把故事對回官場：出嫁的女兒＝出仕的臣子；夫家＝國家（君主）；私積聚＝利用職位聚斂私財；被出＝被罷黜驅逐；父親自以為智＝做錯事還沾沾自喜。

4. 【結論】只有 (D) 同時扣住「人臣」「私自斂聚」「被逐」三個要素。
@ana A x
錯在「替國家」。故事的關鍵字是「{k:私}積聚」「多{k:私}」——女兒是把夫家的財物攢成自己的私房；類比到官場，是官員把公家的利益變成自己的，恰與「使府庫充盈」相反。
@ana B x
故事表面上是婆媳、父女的家務事，但韓非的目的不是談家庭倫理。末句已經把話題轉到「人臣之處官」，寓意必須落在{k:君臣關係與為官之道}。只讀故事、不讀點題句，就會誤選此項。
@ana C x

@ana D o
女兒聽從父親「必私積聚」的教導 → 婆婆「以為多私而出之」：因私聚而被逐。韓非說當時的人臣「皆是類也」——做官只想著撈取私利，抱著「遲早會被罷免，不如先撈一筆」的心態，結果必然不見容於君國，而且像那位父親一樣不知反省、還自以為得計。本項把「私積聚」對應「私自斂聚財物」、「出之」對應「唾棄放逐」，最切合寓意。
@trap

@ana C o

@ana D o

@trap

@key
①②③⑤ 都是表結果的連詞「因此」；④「日思所以不能盡孝處」是「所＋以」，指「不能盡孝的原因」，故相同者四個。
@logic
1. 【先分類】「所以」有兩大用法：(1) 連詞，放在句首，承接上文原因、引出結果，等於「因此」；(2)「所＋以」的結構，放在句子中間，意思是「…的原因」或「用來…的方法」。
2. 【代換法】把五處都換成「因此」讀讀看：①「自以為大不孝，因此能孝」通；②③⑤ 同樣通順。④「日思因此不能盡孝處」不通——這裡的「所以不能盡孝處」整個是「思」的賓語，意思是「（我）不能盡孝的原因、地方」。
3. 【看位置】①②③⑤ 的「所以」都在{k:分句開頭}，前面有逗號，上句是因、下句是果；④ 的「所以」在{k:動詞「思」之後}，位置不同也是線索。
4. 【結論】意義相同的是 ①②③⑤，共四個，選 (C)。
@ana A x
只算二個，通常是只認出最前面成對的 ①②（所以能孝／所以不能慈），漏掉後半段結構相同的 ③「所以愈不能慈」與 ⑤「所以愈能孝」。這四句都是「前因，所以後果」的句型。
@ana B x
算成三個，多半是把 ⑤ 誤歸到 ④ 那一類。其實 ⑤「日思…處，所以愈能孝」是說：因為天天反省，{k:因此}更能盡孝，仍是表結果的連詞。
@ana C o
①「舜常自以為大不孝，所以能孝」、②「瞽瞍常自以為大慈，所以不能慈」、③「尚謂自家能慈，所以愈不能慈」、⑤「日思所以不能盡孝處，所以愈能孝」——四處都是「因此」。
④「日思{k:所以}不能盡孝處」＝天天思考「自己之所以不能盡孝的緣故」，「所以」表{k:原因}。
→ 相同者四個，正解。
@ana D x

@trap
現代人看到「所以」就直覺是「因此」，這正是本題的陷阱。先秦兩漢的文言裡，「所以」幾乎都是「所＋以」（用來…的方法／…的原因）；表示「因此」的連詞用法是後起的。本文出自明代語錄，文白夾雜，所以{k:兩種用法同時出現}。
@know 「所以」的三種用法
| 用法 | 意義 | 例句 |
| 所＋以（以＝用） | 用來…的方法、憑藉 | 「師者，所以傳道、受業、解惑也」（韓愈〈師說〉） |
| 所＋以（以＝因） | …的原因 | 「親賢臣，遠小人，此先漢所以興隆也」（諸葛亮〈出師表〉）；本文④ |
| 連詞 | 因此（表結果） | 本文①②③⑤；現代白話 |
- 第 11 題「其子所以反者，倍其所以嫁」屬第一類：「所以反者」＝帶回來的（財物），「所以嫁」＝出嫁時帶去的（嫁妝）。
- 判斷口訣：「所以」後面若能補出「的原因／的方法」，就是「所＋以」；若能換成「因此」，就是連詞。
@know 虛詞題的兩個工具
- {k:代換法}：用一個現代詞語（因此、的原因）代入，句子通順才算同義。
- {k:位置法}：連詞多在分句開頭；「所＋動詞（介詞）」結構則常在句中，作主語或賓語。
- 類似的古今異義雙音詞：「於是」（在這時／在這裡）、「以為」（把…當作）、「可以」（可以用來）、「其實」（它的果實）、「因為」（於是寫作）。

@know 「舉爾所知」與「內舉不避親」

@logic
1. 【A：看「奪」】「可以理奪，難以情求」是對比句：理 ↔ 情、可以 ↔ 難以。意思是「可用道理說服，難用感情哀求」。選項卻說成「不宜講理、要動之以情」，{k:完全顛倒}。
2. 【B：看「尋」】「尋還」的主語是許允，「尋」是時間副詞「不久」。選項把「尋」當成動詞「尋找」，主語也換成了太太。
3. 【C：看「所知」】許允的邏輯是：聖人說要舉薦自己了解的人 → 同鄉是我了解的人 → 所以我用他們；而且敢請皇帝查核。可見他自認用人有憑有據。
4. 【D：看人物】明帝查核後即釋放並賜衣，是明君；許允敢說「若不稱職，臣受其罪」，不庸懦；妻子煮粥等待，不冷漠。
5. 【結論】選 (C)。
@ana A x
「奪」在此是「使人改變原來的心意」，「理奪」即以道理說服、折服對方。許允的妻子判斷魏明帝是明主，所以叮囑丈夫：{k:要講道理，不要求情}。後文許允果然不哭不求，只引經據典、請求查核，正是照妻子的話去做。選項把「理奪」誤解為「強詞奪理」，並把「難以情求」說成「動之以情方可奏效」，與原意相反。
@ana B x
「{k:尋}」是副詞「不久、隨即」，如〈桃花源記〉「未果，尋病終」。「勿憂，尋還」是說：不用擔心，（他）不久就會回來。這是她對情勢的{k:判斷}，不是「承諾去把人找回來」。
@ana C o
「舉爾所知」出自《論語‧子路》。許允引用聖人之言作為依據，說明自己任用同鄉並非徇私，而是因為同鄉是「臣所知」——才能品行都經過自己的了解與考察；接著又主動請皇帝「檢校為稱職與不」，查核結果「皆官得其人」。敘述正確。
@ana D x
魏明帝：聽說用人不公就查辦，查明稱職就釋放，還體恤地賜新衣，是「明主」，並非「聽邪任諛」（聽信邪說、任用諂媚之人）。
許允：用人唯才，敢以身家擔保，並非「徇私庸懦」。
許允婦：「慧黠」（聰明機靈）可以成立，但她的「自若」是胸有成竹的鎮定，「作粟粥待」更見體貼，並不「冷漠」。
@trap
(A) 利用現代成語「強詞奪理」的印象誤導你，(B) 利用「尋」的常見義「尋找」誤導你。文言文的單字常有{k:與現代不同的義項}，一定要放回句子裡，看主語是誰、與前後文是否通順。

@know 本文的文言句式

- {k:新婦}：魏晉時稱已婚婦女或媳婦，不一定指新娘。

@know 文言句式提醒
- {k:子欲子之王之善與}：第一個「子」是你；「子之王」是你的君王；第二個「之」放在主語和謂語之間，無義；「與」同「歟」，疑問語氣詞。

| 我對別人有恩 | 不可不忘 | 一定要忘掉 | {k:不居功、不驕傲} |
## 三、主旨
- 前三項都是鋪墊，重點在第四項：{k:施恩於人，不可掛在心上}。信陵君立了大功，若以恩人自居，必定招來趙王的不快與猜忌；唐且在他得意的關頭及時提醒。
- 寫法上，唐且不直接說「您別驕傲」，而是先講一套聽來玄妙的道理，等信陵君主動發問才揭曉——這是戰國策士常用的{k:說話藝術}。
@know 背景：竊符救趙
- 西元前 257 年，秦軍圍攻趙都邯鄲。趙國平原君的夫人是魏國信陵君的姊姊，向魏求救。魏王派將軍晉鄙率兵十萬救趙，卻畏懼秦國而按兵不動。
- 信陵君（魏無忌，魏王之弟）採用門客侯嬴的計策，請魏王寵妃如姬偷出兵符，又由力士朱亥椎殺晉鄙，奪取兵權，終於擊退秦軍、保全趙國。事見《史記‧魏公子列傳》。
- 所以本文開頭說「殺晉鄙，救邯鄲，破秦人，存趙國」。

@know 《戰國策》與唐雎
- 《戰國策》：記戰國時代策士遊說各國的言論與謀略，由西漢{k:劉向}整理編訂並定名；按國別編排，屬{k:國別體}史書。文章鋪張揚厲、善用寓言，如「鷸蚌相爭」「狐假虎威」「畫蛇添足」「南轅北轍」「驚弓之鳥」皆出於此。

- 可對讀東漢崔瑗〈座右銘〉：「{k:施人慎勿念，受施慎勿忘}。」意思與本文「吾有德於人也，不可不忘也；人之有德於我也，不可忘也」完全相同。

=== Q 20
@type 史傳文句的文意理解
@cat 文言閱讀
@tags 戰國策, 文句解釋, 施恩勿念
@diff 3
@answer C
@stem
關於本文的敘述，{y:何者正確|分清「誰對誰」}？
@note red
四句各有兩個角色：
人→我？我→人？
@opt A
唐且在文中告誡信陵君，要{x:謹記趙王的德澤，切勿忘恩負義}
@note blue
方向反了：是信陵君
有德於趙，要「忘」
@opt B
「事有不可知者，有不可不知者」，是說對於事情，{x:不能強不知以為知}
@note blue
指的是「憎」讓不讓人知
@opt C
「吾憎人也，不可得而知也」，是說{g:不可使人知道我憎恨別人}
@note red
得而知＝被人得知 ✓
@opt D
「人之有德於我也，不可忘也」，是說人要{x:以德報怨}
@note blue
是「德」不是「怨」
→ 知恩不忘
@key
「吾憎人也，不可得而知也」意思是：我憎恨別人，不可以讓人知道。唐且全篇的重點則是勸信陵君忘掉自己對趙國的恩德。
@logic
1. 【釐清方向】本文四句都在講「人」與「我」的關係，要先分清{k:誰對誰}：人憎我、我憎人、人有德於我、我有德於人。
2. 【對照文末】唐且最後說「此大德也……臣願君之忘之也」：是{k:信陵君}對{k:趙國}有大恩，要信陵君「忘」。(A) 說成記住趙王的恩，方向相反。
3. 【回原文找解釋】(B) 的那句話，唐且自己已經解釋了——指的是「人憎我」與「我憎人」，與求知態度無關；(D) 那句是別人對我有「德」，談不上「怨」。
4. 【確認 C】「不可得而知」＝不可以（被人）得知，主語是「吾憎人」這件事。選 (C)。
@ana A x
文中有恩於人的是信陵君（救了趙國），受恩的是趙王。唐且勸的是「吾有德於人也，不可不忘也」——{k:自己施的恩要忘掉}，不要在趙王面前居功。選項說成要信陵君記住「趙王的德澤」，施恩者與受恩者顛倒了。
@ana B x
「不可知」「不可不知」的內容，下文明白解釋為：別人憎恨我，不可不知；我憎恨別人，不可讓人知。談的是{k:處世}時對「憎惡」的處理，並非《論語》「知之為知之，不知為不知」那種求知的誠實態度。
@ana C o
「吾憎人也，不可得而知也」：我憎恨別人，不可以讓（別人）得知。把對他人的憎惡表露出來，只會結怨招禍，所以要藏在心裡。選項的解釋與原意相符，正解。
@ana D x
「人之有德於我也，不可忘也」：別人對我有恩德，不可以忘記——這是{k:知恩圖報}（以德報德）。「以德報怨」是用恩惠回報別人的怨恨，前提是對方對我有「怨」，與此句無關。
@trap
(A) 的敘述看起來很「正向」（不要忘恩負義），而且原文確實有「人之有德於我也，不可忘也」這句話，所以很多人誤選。但這句只是唐且列舉的四項之一，不是他對信陵君的{k:具體勸告}；具體勸告在文末的「臣願君之忘之也」。讀說理文一定要看{k:最後落在哪一句}。
@know 「以德報怨」與「以直報怨」
| 說法 | 出處 | 意思 |
| 以德報怨 | 《老子》第六十三章作「報怨以德」 | 用恩惠回報怨恨 |
| 以直報怨，以德報德 | 《論語‧憲問》 | 用公正回報怨恨，用恩惠回報恩惠 |
| 以怨報德 | — | 用怨恨回報恩惠，即忘恩負義、恩將仇報 |
- 有人問孔子：「以德報怨，何如？」孔子反問：「何以報德？」可見孔子並不主張以德報怨。這是常考的觀念題。
@know 文言中的「德」
- 名詞「恩惠」：人之有德於我也（本文）；大恩大德。
- 動詞「感激」：然則德我乎？（《左傳》）
- 名詞「品德」：德不孤，必有鄰（《論語‧里仁》）。
- 本文的「德」都是「恩惠」；「有德於人」＝對別人有恩。
@know 本文的句式
- {k:何謂也}：「謂何也」的倒裝，問「說的是什麼意思」。
- {k:臣願君之忘之也}：第一個「之」在主謂之間，無義；第二個「之」是代詞，指「救趙的大德」。
- {k:謹受教}：恭敬地接受教誨，是接受勸告時的客氣話。

@key
「卒然」的「卒」通「猝」，音ㄘㄨˋ，是「突然」；(B) 為「終於」、(C) 為「死」、(D) 為「士兵」，只有 (A)「卒而遇飢虎」可解作突然。
@translation
【A】單豹背離世俗，……活到七十歲，還有孩童一般的容色，卻突然遇上餓虎，被老虎咬死吃掉了。
【B】世人都稱讚孟嘗君能夠得到賢士，賢士因此歸附他，而他終於依靠賢士的力量，從虎豹一般凶殘的秦國逃脫出來。
【C】褒禪山也叫做華山。唐代的和尚慧褒當初在山腳下築屋居住，死後就葬在這裡，因此後人把這座山叫做「褒禪」。
【D】楚軍趁夜突襲，在新安城南活埋了二十多萬秦兵。
@logic
1. 【定題幹義】「卒然見趙王」——「卒」後面接「然」，是形容詞、副詞的詞尾，「卒然」即「猝然」，突然、一下子。此義讀{k:ㄘㄨˋ}。
2. 【代換法】把「突然」代入四個選項：(A) 突然遇上餓虎——通；(B) 突然依靠其力——不通，應是「終於」；(C) 突然葬在那裡——不通，與上句「始」相對，是「死」；(D) 秦突然二十餘萬人——不通，是「士兵」。
3. 【看詞性與位置】(D) 在名詞「秦」之後、數量詞之前 → 名詞；(B)(C) 在動詞前 → 副詞或動詞；(A) 的「卒而」後面接的是意外事件「遇飢虎」。
4. 【結論】選 (A)。
@ana A o
出自《淮南子‧人間訓》。單豹隱居山林、善於養生，七十歲還容顏如童，卻「卒而遇飢虎」。「{k:卒}」通「{k:猝}」，突然；養生有成卻猝然死於虎口，說明只顧養內而不防外患的偏失。與「卒然」的「卒」同義，正解。
@ana B x
出自王安石〈讀孟嘗君傳〉。「卒賴其力」的「{k:卒}」是副詞「終於、最後」，音ㄗㄨˊ。指孟嘗君靠著門客（雞鳴狗盜之徒）的幫助，最後得以逃離秦國。
@ana C x
出自王安石〈遊褒禪山記〉。「始舍於其址，而卒葬之」：「始」與「卒」相對，「{k:卒}」是動詞「死」，音ㄗㄨˊ，指慧褒生前住在這裡，死後葬在這裡。
@ana D x
出自《史記‧項羽本紀》。「秦卒」的「{k:卒}」是名詞「士兵」，音ㄗㄨˊ。「坑」是活埋。項羽在新安坑殺秦降卒二十餘萬，是他失去關中民心的原因之一。
@trap
(A) 的「卒而遇飢虎」，也有注本把「卒」解作「最後、終究」，如此就會與 (B) 的「終於」同義。但本題 (B)(C)(D) 的意思都很確定（終於／死／士兵），而 (A) 接的是突如其來的禍事，命題者取「卒＝猝」之義，官方答案為 (A)。考場上遇到這種情況，用{k:刪去法}：先排除確定不合的三項。
