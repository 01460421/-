@know 「虎兕出柙」的出處與用法
- 《論語‧季氏》記季氏將攻打顓臾，孔子責備擔任家臣的冉有、子路：「虎兕出於柙，龜玉毀於櫝中，是誰之過與？」——老虎犀牛逃出籠子、龜甲寶玉毀在匣中，是{k:看守者的過失}。
- 後以「虎兕出柙」比喻主事者失職、有虧職守。句中的「柙」（獸籠）與「櫝」（木匣，如「買櫝還珠」）都是容器，常一起考字形字義。
@know 容易讀錯、寫錯的「盱」
- {k:盱}（ㄒㄩ）：從目，張目上視。常見詞只有「盱衡」（盱衡時局、盱衡全局），以及地名江蘇「盱眙」（ㄒㄩ ㄧˊ）。
- 寫字時留意部首是「目」不是「日」；讀音不可因右邊是「于」而念成ㄩ。

=== Q 3
@type 一字多義辨析
@cat 形音義
@tags 字義, 成語, 代換法
@diff 3
@answer A
@stem
下列各組文句「」內的字，{y:前後意義相同|考字義}的是：
@note red
{c:代換法}：同一個解釋
代入兩句都要通
@opt A
移風「易」{n:改變}俗／更弦「易」{n:改變}轍
@note red
易＝改變、更換 ✓
@opt B
安步「當」{nb:當作}車／「當」{nb:面對、把握}機立斷
@opt C
不「勝」{nb:盡}枚舉／不「勝」{nb:禁得起}其擾
@note blue
勝ㄕㄥ：①盡 ②承受
@opt D
完璧「歸」{nb:歸還}趙／眾望所「歸」{nb:歸向}
@cols 1
@key
「移風易俗」「更弦易轍」的「易」都是「改變、更換」；其餘三組一為「當作／面對」、一為「盡／承受」、一為「歸還／歸向」。
@logic
1. 【審題】比字義。最可靠的方法是{k:代換法}：替「」內的字找一個白話解釋，同時代入前後兩句，兩句都通順才是同義。
2. 【代換 A】移風「改」俗、更弦「改」轍——兩句都通，而且「移／易」「更／易」各自是同義詞並列，結構也一樣。
3. 【檢驗 BCD】(B) 安步「當作」車 ✓、「當作」機立斷 ✗；(C) 不「盡」枚舉 ✓、不「盡」其擾 ✗；(D) 完璧「還」趙 ✓、眾望所「還」✗。
4. 【結論】只有 (A) 前後同義。
@ana A o
移風「易」俗：易，改變。轉移風氣，改良習俗。語出《孝經‧廣要道》「移風易俗，莫善於樂」。

丙甲丁乙戊：把「讀者浮在扁舟上」放在最後，變成讀者先被打沉、抬高之後才上船，前後顛倒；且戊的「而」字失去承接首句的作用。
@ana B x
丙戊丁乙甲：丙、丁被戊拆開，「一個巨浪打過來」沒有結果；末尾以甲「再一個巨浪掀起」作結，有動作卻沒有下文，也無法與「又可以將讀者抬高」搭配。
@ana C x
戊丙甲丁乙：戊的位置正確，但「一個巨浪打過來，再一個巨浪掀起」連寫兩個浪之後才說結果，「可以令讀者下沉」的主語變得含混（是哪一個浪？），不如一浪一果來得清楚。
@ana D o
戊丙丁甲乙：書是巨浪／而讀者在扁舟上／一個巨浪打過來，可以令讀者下沉數十百丈／再一個巨浪掀起，又可以將讀者抬高數十百丈——主語清楚、因果成對、節奏一落一起，並與末句「起伏」呼應。正解。
@trap
(C) 與 (D) 只差中間兩句的順序，是本題的「誘答組」。兩者在文法上都勉強讀得通，判斷的關鍵是{k:語意搭配的緊密度}：「打過來」是向下壓的力量，配「下沉」；「掀起」是向上托的力量，配「抬高」。排序題遇到兩個選項都通時，選「動作與結果貼在一起」的那一個。
@know 文句排序的四條線索
| 線索 | 說明 | 本題的例子 |
| 關聯詞 | 而、但、因此、於是、又、也…… | 「而讀者」承上；「又可以」必在「可以」之後 |
| 先後詞 | 一個／再一個；首先／其次；起初／後來 | 丙「一個」→ 甲「再一個」 |
| 主語與指代 | 代詞、省略的主語要找得到前文 | 丁、乙省略主語「巨浪」，必須緊跟在丙、甲之後 |
| 首尾銜接 | 與題目給的首句、末句相呼應 | 首句「巨浪」→ 戊；乙「抬高」→ 末句「起伏」 |
@know 文中的譬喻
- 「《天龍八部》是千百個掀天巨浪」：本體《天龍八部》、喻詞「是」、喻體「巨浪」，屬{k:隱喻（暗喻）}。
- 接著把讀者比作「浮在汪洋大海的一葉扁舟」，再以浪的打落、掀起比喻情節的大起大落——用同一組意象連續設喻，稱為{k:博喻式的延伸譬喻}，是評論文字常見的生動寫法。
@know 金庸與《天龍八部》
- 金庸，本名查良鏞，武俠小說家。他把十四部長篇小說書名的首字編成一副對聯：「{k:飛雪連天射白鹿，笑書神俠倚碧鴛}」，其中「天」即《天龍八部》。
- 《天龍八部》書名出自佛經，原指八類護法的神道眾生；小說以北宋為背景，主角為蕭峰（喬峰）、段譽、虛竹。
- 倪匡是金庸的好友，以「衛斯理」系列科幻小說聞名，著有多冊評論金庸小說的《我看金庸小說》系列。

2. 【第一關：是不是譬喻】譬喻是用{k:性質不同但有相似點}的事物來說明。(A)「不如」是比較優劣；(B) 是直接下判斷。兩者都沒有喻體，刪。

4. 【結論】(D)「把讀書當作敲門磚」：讀書只是敲開功名之門的工具，門開了就丟掉。選 (D)。
@ana A x
「讀萬卷書不如行萬里路」是把「讀書」與「遠行」兩件事{k:比較高下}，強調親身閱歷的重要，屬於比較（映襯）而非譬喻。原說法為「讀萬卷書，行萬里路」，本指兩者並重，語本明代董其昌《畫禪室隨筆》。
@ana B x

@ana C x

@ana D o

@trap

@know 譬喻的四種類型
| 類型 | 結構 | 例句 |
| 明喻 | 本體＋喻詞（像、如、似、彷彿）＋喻體 | 讀書要像心痛／人生如寄 |
| 隱喻（暗喻） | 本體＋喻詞（是、為、成為、當作）＋喻體 | 把讀書當作敲門磚／每一樹梅花都是一樹詩 |
| 略喻 | 本體＋喻體（省略喻詞） | 書籍，人類進步的階梯 |
| 借喻 | 只出現喻體 | 「鬱鬱澗底松，離離山上苗」（以松、苗借喻寒士與貴族子弟） |
- 判斷口訣：先找「誰像誰」，{k:被說明的是本體，拿來打比方的是喻體}。
@know 「讀書像心痛」的來歷
- 黃永武的說法化用自明代王陽明的話。《傳習錄》記載：「持志如心痛，一心在痛上，豈有工夫說閒話、管閒事？」原本談的是「立志」，要像心痛時全神貫注在痛處那樣專一。
- 黃永武把它移來談讀書的{k:專注}，與本卷第 13–14 題袁枚「借者之用心專」的主張可以互相參照。
@know 「四書」與科舉
- 四書：《論語》《孟子》《大學》《中庸》。南宋朱熹為四書作注，合為《四書章句集注》。
- 元代以後科舉以四書命題、以朱注為標準；明清以八股文取士，文章格式僵化，「敲門磚」即是對這種功利讀書的諷刺。
- 五經：《詩》《書》《禮》《易》《春秋》。

(D) 用了「前者／後者」的句式，要先在腦中代換清楚：前者＝散曲、後者＝雜劇，再判斷。這類題目最常見的錯法就是{k:前後對調}，或把另一種文體（明傳奇）的特色偷渡進來。

=== Q 10

@tags 諸子百家, 人性論, 儒墨道法

@answer C
@stem
閱讀下文，推斷□內最適合填入的{y:思想學派依序|先填最確定的格}為：
@note red
四個策士＝四家
抓各家{c:關鍵詞}
@box
羋月下馬，細看門口懸的木牌，方看出是「四方館」三字。進得四方館內，但聞人聲鼎沸，庭院中、廳堂上往來之人，均是各國士子衣著，到處辯論之聲。
就聽一策士高聲道：「人之初，{g:性本善}，此乃人之本性也，當{g:以善導之}，自可罷兵止戰，天下太平。」羋月聽其言論，顯然這是個□{n:儒}家的策士。
但見另一策士卻哂然一笑：「敢問閣下可有見幼童喜折花摧葉，奪食霸物否？ 此乃{b:人性本惡}也，唯有{b:以外力相束}，知其惡制其惡，天下方能嚴整有序，{b:令行禁止}。」顯然這是□{n:法}家的策士。
又有一策士搖頭道：「天下熙熙皆為利來，天下攘攘皆為利往，兩位說得這般熱鬧，{o:誰又能夠犧牲自我}成就大道？ 以我師看來，世人謀利，無利則罷兵止戰，有利則灑血斷頭。所以你們兩家都應該從我派之言！」聽其言，自然是□{n:道}家弟子。
又見一策士道：「胡扯！ 人性本無善惡，{y:世間如染缸，入蒼則蒼入黃則黃}。治國之道，尤不可聽亂言。人之異於禽獸者，乃人能{y:互助互援}，學說制度乃為減少不平，爭取公平而立。{y:為大義者，雖死猶生}……」這言論自然便是□{n:墨}家之說。
羋月素日雖亦習過諸子百家之言論，但卻只是自己一卷卷地看，一字字地理解，此刻聽得各家策士爭相推銷自家學說之長，攻擊其他學派之短，與自己所學一一相印證，只覺得原本有些茫然不懂之所在，忽然便明悟了。她站在那兒，不禁聽得入神，興奮之處，眼睛都在閃閃發亮。（改寫蔣勝男《芈月傳》）

@opt A
儒／{x:名}／{x:法}／{x:儒}
@opt B
{x:墨}／法／道／{x:儒}
@opt C
儒／法／道／墨
@opt D
{x:墨}／{x:名}／{x:法}／墨
@cols 2
@key
性善、以善導之→儒；性惡而以外力、法令約束→法；染絲之喻、互助、為義而死→墨。第一格儒、第四格墨，只有 (C) 符合。
@logic
1. 【先填最有把握的】第四位策士說「入蒼則蒼，入黃則黃」，直接化用《墨子‧所染》；「互助互援」即兼愛，「為大義者雖死猶生」即貴義。第四格＝{k:墨}，刪 (A)(B)。
2. 【再看第一格】「性本善」「以善導之」是孟子性善、重教化的主張。第一格＝{k:儒}，(D) 第一格為墨，刪。答案已確定為 (C)。
3. 【驗證第二格】主張性惡的荀子雖屬儒家，但策士的解方是「以外力相束」「令行禁止」，不談禮義教化而講強制約束，是{k:法}家路數；且選項只有「名／法」可選，名家談的是名實邏輯（白馬非馬），與此無關。
4. 【理解第三格】策士否定有人肯「犧牲自我」，主張順著人人為己的本性——接近「拔一毛而利天下，不為也」的楊朱一派，一般歸入{k:道}家。
@ana A x
第一格「儒」正確，其餘皆錯。名家（惠施、公孫龍）專門辨析名與實的關係，不討論人性善惡與治國；第四格的染絲、互助、大義是墨家，不是儒家。
@ana B x
第二、三格（法、道）正確，但首尾顛倒：「性本善」是儒家孟子之說，不是墨家；「入蒼則蒼」是墨家之說，不是儒家。
@ana C o
儒（性善、教化）／法（性惡、以法令外力約束）／道（楊朱一派，重己、不為天下犧牲）／墨（所染、兼愛、貴義）。四格皆合，正解。
@ana D x
第四格「墨」正確，但第一格把性善說歸給墨家、第二格填名家，皆誤。
@trap
本題有兩個容易卡住的地方，官方答案並無爭議，但要知道如何判斷：
- **第二格「性惡」≠ 一定是法家**：性惡說出自{k:荀子}，荀子是儒家，主張以「禮義師法」教化人性。此處因為策士講的是「外力相束」「令行禁止」，選項又只有名、法可選，才判為法家（法家的韓非、李斯正是荀子的學生）。
- **第三格單看內容不易判斷**：「人皆好利」的觀察也很像法家韓非；命題者設定為「道」，應是取「不肯犧牲自我」這一點，對應主張「為我」「貴己」的楊朱。作答時不必在這一格糾結——{k:先抓最確定的第一、四格}，答案自然出現。
- 另外，「人之初，性本善」是後世《三字經》的句子，小說借來表達孟子的性善說，並非戰國時代的原話。
