@ana A x
孜孜矻「{k:矻}」：矻，音ㄎㄨˋ。「孜孜矻矻」形容勤勉不懈怠，語出韓愈〈爭臣論〉「孜孜矻矻，死而後已」。
銀貨兩「{k:訖}」：訖，音ㄑㄧˋ，完畢、終了。指錢已付清、貨已點收，交易完成。
→ ㄎㄨˋ ≠ ㄑㄧˋ。
@ana B x
如蟻附「{k:羶}」：羶，音ㄕㄢ，羊身上的腥臊味。像螞蟻附著在有羶味的東西上，比喻趨炎附勢、爭逐名利。語本《莊子‧徐无鬼》「蟻慕羊肉，羊肉羶也」。
季節遞「{k:嬗}」：嬗，音ㄕㄢˋ，更替、演變。「遞嬗」指交替轉換。
→ 一聲 ≠ 四聲。
@ana C x
不「{k:悱}」不發：悱，音ㄈㄟˇ，心裡想說卻說不出來的樣子。語出《論語‧述而》「不憤不啟，不悱不發」，是孔子的啟發式教學原則。
「{k:緋}」聞纏身：緋，音ㄈㄟ，本指紅色（緋紅）；「緋聞」指感情、婚姻方面的傳聞。
→ 三聲 ≠ 一聲。
@ana D o
提綱「{k:挈}」領：挈，音ㄑㄧㄝˋ，提起。抓住網的大繩、提起衣服的領子，比喻掌握事情的重點。
「{k:鍥}」而不舍：鍥，音ㄑㄧㄝˋ，刻。不斷刻下去而不停止，比喻努力不懈。語出《荀子‧勸學》「鍥而不舍，金石可鏤」。
→ 同讀ㄑㄧㄝˋ，為正解。
@trap
「羶／嬗」「悱／緋」唸起來很像，容易誤以為同音。字音題的標準是{k:聲母、韻母、聲調三者全同}；作答時務必把聲調符號寫出來。另外「鍥而不舍」的「舍」讀ㄕㄜˇ，通「捨」，不讀ㄕㄜˋ。

=== Q 2
@type 成語錯別字訂正
@cat 形音義
@tags 錯別字, 成語用字, 計數比較
@diff 2
@answer A
@stem
下列各組成語中，錯別字{y:最少|比數量}的一組是：
@note red
不是問「沒有」錯字！
每個錯字都{c:圈出來}
再{c:數一數}各組幾個
@opt A
人才輩出／趨之若鶩／察{x:顏}{n:言}觀色
@note red
只錯 1 字 → 最少 ✓
@opt B
迫不{x:急}{n:及}待／味同嚼蠟／{x:接步}{n:按部}就班
@note blue
「接」「步」都錯
→ 共 3 字
@opt C
推心置腹／一{x:愁}{n:籌}莫展／禮{x:上}{n:尚}往來
@note blue
籌＝計策；尚＝注重
→ 2 字
@opt D
寧缺勿{x:爛}{n:濫}／勝{x:卷}{n:券}在握／未雨綢繆
@note blue
券＝憑證（刀部）
→ 2 字
@cols 1
@key
題目問「最少」不是「沒有」：(A) 僅「察顏觀色」錯 1 字（應作「言」），(B) 錯 3 字，(C)(D) 各錯 2 字，故選 (A)。
@logic
1. 【審題】四組都有錯字，要比的是「誰錯得最少」。看到 (A) 有錯就急著刪掉，是本題最常見的失誤。
2. 【以義辨形】用成語的意思回推用字：觀察「言語」和臉色 → 言；來不「及」等待 → 及；依照「部」門、歸入「班」列 → 按部；一點計「策」也施展不出 → 籌；禮「崇尚」往來 → 尚；寧缺而不浮「濫」→ 濫；握有勝利的「憑證」→ 券。
3. 【計數】(A) 1 字；(B) 急、接、步共 3 字；(C) 愁、上共 2 字；(D) 爛、卷共 2 字。
4. 【結論】錯字最少的是 (A)。
@ana A o
人才輩出：正確。輩，一批接一批。
趨之若鶩：正確。鶩（ㄨˋ），鴨子；像成群的鴨子般跑過去，形容爭相趨附。
察「顏」觀色 → 察「{k:言}」觀色：觀察人的言語、神情而窺知對方心意。「言」與「色」相對，不是「顏色」。
→ 共 1 個錯字，為四組中最少，是本題答案。
@ana B x
迫不「急」待 → 迫不「{k:及}」待：情況急迫，來不及再等。
味同嚼蠟：正確。像嚼蠟一樣沒有味道，形容文章或言語枯燥無味。
「接步」就班 → 「{k:按部}」就班：語本陸機〈文賦〉「選義按部，考辭就班」，原指寫文章時依類安排文義、詞句，後指做事依照一定的層次、條理。一個成語就錯了兩字。
→ 共 3 個錯字。
@ana C x
推心置腹：正確。語本《後漢書‧光武帝紀》「推赤心置人腹中」，比喻真心誠意待人。
一「愁」莫展 → 一「{k:籌}」莫展：籌，計策。一點計策也施展不出來。
禮「上」往來 → 禮「{k:尚}」往來：尚，注重。語本《禮記‧曲禮上》「禮尚往來」。
→ 共 2 個錯字。
@ana D x
寧缺勿「爛」→ 寧缺勿「{k:濫}」：濫，浮濫、過度。寧可缺少，也不要不顧品質只求數量。教育部辭典「寧缺毋濫」「寧缺勿濫」兩種寫法皆收，故「勿」字不算錯。
勝「卷」在握 → 勝「{k:券}」在握：券，憑證；握有勝利的憑據，比喻很有把握。
未雨綢繆：正確。語本《詩經‧豳風‧鴟鴞》，比喻事先預備。
→ 共 2 個錯字。
@trap
兩個容易算錯的地方：①「接步就班」要改成「按部就班」，{k:一詞兩錯}（接→按、步→部），所以 (B) 是 3 字不是 2 字；②「寧缺勿濫」的「勿」不是錯字（可作「毋」或「勿」），只有「爛」錯。不過無論怎麼算，(A) 都只錯 1 字，答案不受影響。
@know 本題七組「音同形異」字辨析
| 正字 | 誤字 | 判斷依據 | 相關詞語 |

@know 「錯別字計數題」的作答方式
- 題幹若問「最少／最多／共幾個」，每個選項都要{k:算出數字}寫在旁邊，不可只憑「有錯就刪」。

@type 成語運用（否定題）
@cat 詞語成語
@tags 成語, 語境判斷, 望文生義
@diff 3
@answer A
@stem
下列文句「」中的成語，運用{y:不恰當|選錯的}的是：
@note red
先想成語{c:本義}
再看形容的{c:對象}
@opt A
小明成天為非作歹，任由親友「{x:錦心繡口}」{u:勸說}，卻仍然不肯悔改
@note red
錦心繡口＝文思好、詞藻美
勸人要用{y:苦口婆心}
@opt B
積累的功夫是學術研究者所必備的，「{g:集腋成裘}」自然有所成就
@note green
積少成多 ✓
@opt C
有「{g:囹圄生草}」的良好社會環境才容易吸引外國觀光客一遊
@note green
監獄長草＝沒有犯人
→ 治安好 ✓
@opt D
阿華是個「{g:頭角崢嶸}」的人才，難怪會當選傑出青年
@note green
年輕人才華出眾 ✓
@key
「錦心繡口」形容文思優美、詞藻華麗，不能用來形容「勸說」的懇切；勸人應說「苦口婆心」。
@logic
1. 【審題】選「不恰當」者。成語題的檢查順序：①本義 ②使用對象 ③褒貶色彩。
2. 【拆字解義】錦、繡都是華美的織品 → 錦心繡口＝心思與言辭像錦繡一樣美，是稱讚{k:文才}；腋＝狐狸腋下的毛皮，裘＝皮衣 → 積少成多；囹圄＝監獄，監獄長草 → 無人坐牢；崢嶸＝山勢高峻 → 才能突出。
3. 【對照語境】(A) 的語境是「親友再三勸他改過」，需要的是「懇切」而不是「詞藻華麗」→ 用詞不當。
4. 【結論】(B)(C)(D) 的本義與語境皆吻合，選 (A)。
@ana A x
錦心繡口：語本李白〈冬日于龍門送從弟京兆參軍令問之淮南覲省序〉：「兄心肝五臟皆錦繡耶？不然，何開口成文，揮翰霧散？」形容人{k:文思巧妙、詞藻華美}。句中要表達的是親友懇切地再三規勸，應改為「{k:苦口婆心}」（以懇切真摯的態度竭力勸告）或「好說歹說」。運用不當，為本題答案。
@ana B o

@ana C o

@ana D o

=== Q 4
@type 新詩意象與情感詮釋
@cat 詩詞曲賞析
@tags 新詩, 擬人, 襯托, 陳克華
@diff 3
@answer B
@stem
「{b:沸騰}的夜，／將{y:她|擬人}{p:最燙}的一塊皮膚／{u:貼在我頰上}。　　我{p:疼出淚來}，說：{c:不}，／這裡{g:不是我最需要溫暖的位置}。」（陳克華〈夜〉）
@note blue
沸騰、最燙
＝夜的喧鬧熱烈
@note red
轉折在「不」！
最需要溫暖的是{y:心}
@stem
依據上詩，下列說明詮釋{y:不正確|選「錯的」}的是：
@note red
選項的每個詞都要在
詩裡{c:找得到依據}
@opt A
以{g:擬人}的方式表示夜的{g:主動性}
@note green
「她」「將…貼在」✓

@opt D

@cols 1
@key
詩中的熱來自「夜」，淚是被燙「疼」出來的；全詩沒有「世人」，更沒有「虛偽」，(B) 是無中生有的過度詮釋。
@logic
1. 【審題】選「不正確」的詮釋。新詩詮釋題的判準：說法必須{k:在詩句中找得到依據}，不能憑空添加人物或評價。
2. 【讀意象】主角是「夜」：用「她」稱呼、有「皮膚」、會主動「貼」上來 → 擬人；「沸騰」「最燙」→ 夜的喧囂與熱烈。
3. 【抓轉折】「我疼出淚來，說：不」——夜的熱情帶來的不是舒適而是灼痛；「這裡不是我最需要溫暖的位置」——臉頰不需要，真正需要溫暖的是{k:內心}，言外之意是心裡孤寂寒冷。
4. 【比對】(A) 擬人、主動 ✓；(C) 發燙 → 疼 ✓；(D) 外在越熱鬧、內心越寂寞 ✓；(B)「世人的虛偽熱情」「心痛」於詩無據 ✗。
@ana A o
詩人稱夜為「她」，並寫她「將最燙的一塊皮膚貼在我頰上」，夜有性別、有皮膚、有動作，是{k:擬人}（轉化）手法；「將……貼在」是夜主動靠近，而非詩人去靠近夜，故說「表示夜的主動性」正確。
@ana B x
詩中給予熱度的是「夜」，並沒有出現「世人」；詩人拒絕的理由是「這裡不是我最需要溫暖的位置」——位置不對，而不是指責這份熱是「虛偽」的。此外，淚是因為「疼」（被燙）而流，屬於感官上的灼痛，選項說成為他人的虛偽而「心痛」，{k:主語、原因都與詩句不合}。詮釋不正確，為本題答案。
@ana C o
「沸騰」「最燙」貼在臉頰上，結果是「我疼出淚來」，可見夜的熱度對詩人而言是一種{k:不適、難以承受}的刺激。詮釋正確。
@ana D o
「沸騰的夜」可理解為燈火通明、喧囂熱鬧的夜晚（題目選項將它具體詮釋為都市的夜）；詩人卻說最需要溫暖的地方不在臉頰，暗示內心另有寒冷空虛之處。以外在的「熱」{k:襯托}內在的「冷」，更顯寂寞。詮釋合理。
@trap
(B) 之所以誘人，是因為「熱情卻讓人流淚」很容易聯想成「虛情假意」。但詩人只說「位置不對」，沒有說「熱是假的」。新詩題最忌{k:自行腦補}：選項中凡是詩裡找不到對應字句的人物（世人）、評價（虛偽），都要打問號。
@know 這首詩怎麼讀：三個層次
| 層次 | 詩句 | 讀法 |
| 意象 | 沸騰的夜／最燙的一塊皮膚 | 夜被寫成一個熱烈的女子（擬人＋觸覺摹寫） |
| 動作 | 貼在我頰上 → 我疼出淚來 | 熱情過度反成傷害 |
| 轉折 | 不，這裡不是我最需要溫暖的位置 | 真正寒冷的是內心；以熱寫冷、以鬧寫寂 |
- 全詩只有兩節、五行，卻有完整的「靠近—受傷—拒絕」情節，結尾留白，不直接說出「心」字。
@know 修辭複習：擬人與「以反面襯托」

=== Q 5
@type 五言律詩格律與詩意推敲
@cat 詩詞曲賞析
@tags 五言律詩, 押韻, 對仗, 常建
@diff 2
@answer B
@stem
閱讀下引詩句，最適合填入□內的語詞{y:依序|順序}是：
@note red
填字三把鑰匙：
①{y:押韻}②{y:對仗}③詩意
@box poem
「清晨入古寺，初日照高{b:林}。曲徑通{g:幽}處，禪房花木{n:深}。
山光{n:悅}{g:鳥性}，潭影{n:空}{g:人心}。萬籟此俱寂，惟聞鐘磬{b:音}。」 (常建〈破山寺後禪院〉)
@note blue
韻腳：林、□、心、音
→ 第一格要押ㄣ韻
@note green
頸聯對仗：
山光□鳥性
潭影□人心
@note purple
禪院 → 「空」是佛家語
@opt A
{x:生}/照/醉
@opt B
{g:深}/{g:悅}/{g:空}
@opt C
{x:清}/知/淨
@opt D
森/{x:映}/{x:覺}
@note blue
生、清是ㄥ韻 → 刪 A、C
@note red
「映鳥性」「覺人心」不成義
@cols 2
@key
第一格在偶數句末，須與「林、心、音」押韻 →「深」；頸聯「悅鳥性」「空人心」皆為「使……悅／空」的使動用法，對仗工整且合於禪院的幽寂意境。
@translation
清晨我走進這座古老的寺院，初升的太陽照耀著高高的樹林。彎曲的小路通向幽靜的深處，禪房就掩映在繁茂幽深的花木之中。山中的風光使鳥兒也怡然歡悅，清潭的倒影讓人心中的雜念一掃而空。此時萬物的聲響都沉寂了，只聽見敲鐘擊磬的聲音在迴盪。
@logic
1. 【押韻】五言律詩偶數句必押韻。韻腳為林、□、心、音（同屬平聲侵韻，今讀ㄣ、ㄧㄣ），第一格須押韻：「深」「森」可；「生」「清」屬ㄥ韻，不可 → 刪 (A)(C)。
2. 【對仗】頸聯（五、六句）須對仗：「山光□鳥性」對「潭影□人心」，空格應為同類動詞。(B)「悅／空」都是形容詞作{k:使動}用——使鳥性悅、使人心空；(D)「映／覺」：山光「映」鳥性、潭影「覺」人心，語意不通。
3. 【詩意】上句「曲徑通幽處」已點出「幽」，下句接「花木深」正寫幽深；「空」是佛家語，扣合「禪院」，寫心中雜念盡除。
4. 【結論】深／悅／空，選 (B)。
@ana A x
「生」讀ㄕㄥ，與林、心、音不押韻，憑格律即可刪去。且「山光照鳥性」的「照」與首聯「初日照高林」用字重複；「醉人心」偏於濃烈陶醉，也與結尾「萬籟俱寂」的清空境界不合。
@ana B o
深：押韻，且承「幽」字寫花木繁茂幽深。
悅：使……歡悅。山光明媚，使鳥兒自在歡愉。
空：使……空明。潭水清澈，倒影澄明，使人心中塵念盡消。
三格皆合格律與詩意，為正解。
@ana C x
「清」讀ㄑㄧㄥ，不押韻，可先刪去。「知鳥性」「淨人心」單看似乎可通，但「花木清」不成詞，整體不如原作。
@ana D x
「森」雖然押韻，但「森」多形容樹木高聳陰森，與「花」木搭配不如「深」字能呼應上句的「幽」；更關鍵的是「映鳥性」「覺人心」語意不通（「性」是抽象的本性，無法被「映」照）。
@trap
(B) 與 (D) 的第一格都押韻，不能只靠韻腳決勝負，必須再用{k:頸聯對仗與語意}判斷。另外，本詩的韻腳依古音同屬「侵」韻，今音「林、心、音」讀ㄧㄣ，「深」讀ㄣ，韻母略有出入但仍相近；「生、清」是ㄥ韻，古今都不同韻。
@know 作品賞析：常建〈題破山寺後禪院〉
- 常建，盛唐詩人，開元年間進士，仕途不得意，詩多寫山水田園與方外之趣。
- 破山寺即今江蘇常熟虞山的興福寺。全詩由「入寺 → 穿徑 → 到禪房 → 觀山光潭影 → 聞鐘磬」依遊蹤寫來，由外而內、由動入靜，末聯{k:以聲襯靜}（只剩鐘磬聲，更顯萬籟俱寂）。
- 成語「{k:曲徑通幽}」「{k:萬籟俱寂}」皆出自本詩。
- 版本異文：「曲徑」一作「竹徑」；「俱寂」一作「都寂」；「惟聞」一作「但餘」「惟餘」。題目所引為其中一種版本。
@know 五言律詩格律與本詩的特殊處
| 項目 | 一般規定 | 本詩 |

- 解填空律詩的順序：{k:先韻腳、再對仗、後詩意}。

## 作者的旅行觀
- 作者自稱「{k:門外漢}」，一語雙關：既是謙稱外行人，也是「常站在門外看」的人。

@know 「暴殄天物」的字音字形
- {k:殄}，音ㄊㄧㄢˇ，「歹」部，意為滅絕；不可寫成「珍」，也不可讀成ㄓㄣ。
- 「暴」在此指糟蹋、損害，與「自暴自棄」的「暴」同義。
- 古今義不同：古義＝殘害萬物（指商紂暴虐）；今義＝浪費、不愛惜物品。
@know 成語填空題三步驟

- ② 判{k:褒貶}：看「最易」「不免」「難怪」「堪稱」等提示詞，決定要填正面或負面詞。
- ③ 驗{k:立場}：答案不可與作者在文中已表明的態度相衝突。

@know 「總—分—總」結構的讀法
- 總說句常在段首，並帶有概括性的詞語（本文「凡此等等，太多太多」）。
- 分說部分常用「有些……有些……至若……最……」逐項列舉，讀的時候在每個例子旁標上序號。
- 總結句常以「故」「總之」「可見」開頭，是主旨題與填空題最重要的依據。

孔子點破言外之意：智慧不足、看不清事理的人才需要「數卜」；三年只卜一次的文仲最能自己決斷，所以最賢。
@translation
孔子問漆雕馬人說：「你事奉過臧文仲、臧武仲、孺子容，這三位大夫誰比較賢能？」漆雕馬人回答：「臧家有一隻占卜用的大龜，名叫『蔡』。文仲主政時，三年用牠占卜一次；武仲主政時，三年占卜兩次；孺子容主政時，三年占卜三次。這是我親眼看見的。至於三位大夫賢或不賢，我就不知道了。」孔子說：「真是位君子啊，漆雕家的這個人！他稱述別人的優點，說得含蓄卻很明白；他談論別人的過失，說得隱微卻很清楚。一個人的智慧想不到、眼光看不清，能夠不屢次占卜嗎？」
@logic
1. 【讀表面】漆雕馬人不直接回答「誰賢」，只報告一組數字：文仲三年卜一次、武仲兩次、孺子容三次，然後說「賢不賢我不知道」。
2. 【讀孔子的評語】孔子卻稱讚他「言人之美，隱而顯；言人之過，微而著」——可見漆雕馬人{k:其實已經評了}，褒貶就藏在占卜次數裡。
3. 【找判準】末句「智不能及，明不能見，得無數卜乎」：智慧與明察不足的人，才不得不屢屢占卜。所以{k:占卜越多，越不賢}。
4. 【排序】文仲（1 次）＞武仲（2 次）＞孺子容（3 次）。最賢的是文仲，選 (A)。
@ana A o
文仲在位三年只占卜一次，表示遇事多能憑自己的智慧判斷，很少需要求神問卜。這就是漆雕馬人「隱而顯」地稱述的「人之美」。孔子認為三人中他最賢。
@ana B x
武仲三年占卜兩次，比文仲多、比孺子容少，賢德居中，不是「最」賢德者。
@ana C x
孺子容三年占卜三次，次數最多。依孔子「智不能及，明不能見，得無數卜乎」的說法，他正是智慧、明察最不足的一位，是漆雕馬人「微而著」地指出的「人之過」。
@ana D x
孔子說漆雕馬人既「言人之美」又「言人之過」，可見三人{k:有褒有貶、高下有別}，並非皆賢。漆雕馬人說「賢不賢，馬人不識也」只是不願直言的謙退之辭，不能據此認為他對三人評價相同。
@trap
最容易的誤判是認為「占卜越勤，越謹慎、越敬天」，於是選 (C)。但題幹問的是「{k:孔子認為}」，而孔子明白把「數卜」歸因於「智不能及，明不能見」。文言推論題一定要以文中人物{k:自己說出的判準}為依據，不要代入自己的價值觀。
@know 「隱而顯、微而著」——委婉含蓄的說話藝術
- 漆雕馬人不直接批評舊主，只陳述事實，讓聽者自行領會，既不失厚道，又把話說清楚了，所以孔子讚他是「君子」。

- 修辭學上稱為「{k:婉曲}」：不直說本意，用委婉含蓄的話暗示出來。

@know 「聽聲辨景」的寫法：估客晝眠知浪靜，舟人夜語覺潮生
- 詩人不直接寫「浪靜」「潮生」，而是透過{k:旁人的反應}來寫：商人睡得安穩 → 浪靜；船夫半夜起來說話 → 漲潮了。這是{k:側面烘托}（側寫）。

- 同類寫法：「春眠不覺曉，處處聞啼鳥。夜來風雨聲，花落知多少」（孟浩然〈春曉〉）由聲音推知花落。

- 「思家步月」「歸心對月明」：月照兩地，最易引起鄉思，如杜甫〈月夜憶舍弟〉「露從今夜白，月是故鄉明」。

1. 【判起式】口訣：{k:首句第二字}為平聲 → 平起式；為仄聲 → 仄起式。甲「洛{k:城}一別」、乙「雲{k:開}遠見」，城、開皆為平聲（國語二聲、一聲），兩首都是平起式 → (A) 說甲是仄起，錯。

@ana C x

@opt A

@key

@logic
1. 【找主語】把每句縮成「誰＋怎麼樣」：(B) 老張……成為……廠房；(C) 火車、站務人員……放棄休假。主語與謂語一對照，毛病立現。
2. 【查贅詞】(A)「下旬」已是一段時間（二十一日到月底），「前後」用在時間點（如「二十日前後」），兩者疊用，不合理。
3. 【驗正解】(D)「調查顯示＋（許多網路遊戲具暴力內容，會……影響……健康）」，主語「網路遊戲」貫串到底，搭配無誤。

@ana A x
{k:語意重複、範圍不明}。「下旬」指每月二十一日至月底，本身就是一個時段；「前後」表示某個時間點的稍早或稍晚。說「下旬前後」等於「一段時間的前後」，不知所指。可改為「本月下旬」或「本月二十日前後」。
@ana B x
{k:主語偷換、成分殘缺}。前兩個分句的主語是「老張」，第三個分句卻說「成為亞洲規模最大的廠房」——人不可能成為廠房；且「積極開發」缺少賓語（開發什麼？）。可改為「老張當上電子公司董事長後，積極開發新產品，使公司成為亞洲規模最大的電子廠」。
@ana C x
{k:主謂搭配不當}。並列主語「全數火車、站務人員」中，「火車」是交通工具，無法「放棄休假」「堅守崗位」；「全數」多用於計數的事物，用來指人也不妥。可改為「全體列車乘務人員與站務人員」。另外「岡位」應作「{k:崗位}」（崗，音ㄍㄤˇ），是錯別字。
@ana D o
句子結構完整：「一項調查」（主語）＋「顯示」（述語）＋後面兩個分句（賓語）；賓語中「許多網路遊戲」既是「具暴力內容」的主語，也是「會嚴重影響青少年身心健康」的主語，前後一致，沒有語病。
@trap
(D) 可能有人覺得「許多網路遊戲……會嚴重影響……」推論太武斷而懷疑它。但題目問的是「{k:語病}」（文法、邏輯結構上的毛病），不是內容立場是否周延；只要主語一致、搭配得當、沒有贅詞，就是沒有語病。
@know 常見語病六大類
| 類型 | 說明 | 病句 → 修改 |

@ana D x

- 一位老婦人等待出海未歸的親人，一等就是半個世紀。船早已「成了大海的野餐」（遇難），她眼裡卻始終有一張帆。

（甲）春風一夜之間吹到了衡陽，北方的故鄉遠隔著楚地的江水、燕地的山嶺，有萬里之長。別怪我春天一到就要回去，江南雖然美好，終究是他鄉。
（乙）想探問秋天的情懷，卻沒有人知道；我背著手、喃喃自語，來叩問東籬下的你：你品格孤高、傲視世俗，能和誰一同隱居呢？同樣是開花，你為什麼開得這樣遲？
（丙）像撐著翠綠傘蓋的美人臨水而立，臉上的脂粉不均勻，被香汗沾溼了。一陣風吹來，碧綠的葉浪翻動，珍珠般的水珠紛紛滾落，難以收拾。
（丁）灞水岸邊天氣放晴，送別的人頻頻到來；枝條相依相偎，彷彿承受不住濃濃的春意。自己的飛絮尚且飄泊無定，又怎麼懂得垂下絲條去牽絆遠行的人呢？
（戊）喝的是露水，身子多麼潔淨；迎風鳴唱，聲韻更加悠長。夕陽下千樹萬樹，卻沒有一處能躲開螳螂。
（己）本來就沒有一點塵俗之氣，自在地生長在水雲之鄉；姿態清秀、潔淨得像擦拭過一樣，亭亭玉立，散發出美妙的清香。
（庚）像一輪明月來到我懷中，姑且再用它整理一下已經插不住簪子的頭髮。

@ana D x

1. 【抓句型】六組排比都是「有人學到 A，卻少了／失去／誤會了 B」。A 是模仿者學到的{k:表面}，B 是周作人真正具備、模仿者卻沒有的{k:內涵}。
2. 【分清主語】「少了」「失去」「誤會」「以為」的主語全是{k:模仿者}；作者（楊牧）的立場是推崇周作人、批評模仿者。
3. 【逐項檢驗】(A) 把模仿者的缺點說成周作人的特色；(B) 把模仿者的「以為」當成作者的主張；(D) 多加了原文沒有的「必然」。
4. 【結論】(C) 主語（學的人）、行為（以戲謔取勝）、評價（誤會）三者都與原文一致。
@ana A x
原文：「有人學到他的淡漠，卻少了一份熾熱參與社會和關懷人生的心腸。」意思是周作人的淡漠底下{k:本來有}熾熱的心腸，模仿者只學到淡漠的外表。選項卻說「少了心腸」才「形成」周作人的淡漠，因果與主語都顛倒了。
@ana B x
原文：「以為順口的俗套歇後語之類，只要帶上北京和北京城郊的腔調，便可奏效。」這是模仿者{k:錯誤的想法}，作者稱之為將雍容文雅「隨手惡化」。選項把被批評的做法說成學習的「關鍵」，與作者看法相反。
@ana C o
原文：「有人學到他以文字語法委婉突兀所企及的幽默，卻誤會了那幽默背後的無奈和嘲諷，反而以戲謔取勝。」周作人的幽默帶有無奈與嘲諷的深度，模仿者不懂，只會嘻笑逗趣。選項敘述與原文相符。
@ana D x
原文末句說這些雜文是「大師{k:不期然}孕育的餘孽」。「不期然」是意料不到，即選項的「不預期」；但原文並沒有說這是「必然」的結果——劣質模仿是模仿者自己的責任，不是周作人散文必然導致的。多了「必然」二字，即屬過度推論。
@trap

@translation
南海的帝王名叫儵，北海的帝王名叫忽，中央的帝王名叫渾沌。儵和忽時常在渾沌的地方相會，渾沌待他們非常好。儵和忽商量著要報答渾沌的恩德，說：「人人都有七個孔竅，用來看、聽、飲食、呼吸，唯獨他沒有，我們試著替他鑿開吧。」於是每天鑿一個孔竅，到了第七天，渾沌就死了。
@logic
1. 【讀出寓意】渾沌沒有七竅卻活得好好的，儵、忽出於好意替他「鑿」竅，結果七竅成而渾沌死。莊子藉此說明：{k:自然的本來狀態最完整，人為的加工（即使出於善意）反而是傷害}。
2. 【提煉關鍵詞】自然、純樸、無為 ↔ 人為、感官、智巧。
3. 【逐句對應】(A) 嬰兒＝純樸未鑿；(B) 五色五音＝耳目感官（七竅）帶來的禍害；(C) 任自然、無為無造＝不妄加造作。三者都落在「自然 ↔ 人為」這條軸線上。

@ana A o

@ana B o

@ana D x

@key
「爾」作指示代詞，意為「此」；「自爾」即「從此、從這時起」。其餘三項：陽眠是假睡、所幸是所寵愛的、左右是身邊的侍從。
@logic
1. 【代回原句】把選項的解釋代入原文，看通不通：(A)「後在白天睡覺」——與下文「亦不自覺」的謊言被揭穿無關，且曹操何時睡並非重點；(B)「幸好人竊以被覆之」——語法不通；(C)「附近莫敢近者」——「附近」不能當「不敢靠近」的主語。
2. 【辨詞性】「所＋動詞」構成名詞性詞組：「所幸」＝所寵愛的（人），「幸」是動詞。「左右」在此作名詞，指在身邊伺候的人。
3. 【確認 D】「自爾每眠」＝「自此每眠」，從這時（這件事）以後每次睡覺。「爾」解作「此時」可通。
4. 【結論】選 (D)。
@ana A x
「陽」通「{k:佯}」，假裝。「陽眠」是假裝睡覺，不是在白天睡覺。這個字是全文的關鍵（見第 18 題）。古書中「陽」作「佯」的例子很多，如「陽狂」（裝瘋）、「陽為不知」。
@ana B x

@ana C x
「左右」指{k:在身邊侍候的人}（近侍、隨從）。上文「左右宜深慎此」也是曹操對身邊侍從的告誡。解作「附近」是現代常用義，代入原句則缺少「不敢靠近」的主語。
@ana D o
「爾」是指示代詞，相當於「此、這」。「自爾」即「自此」「從此」，全句意為「從這時起，每當他睡覺……」。解作「此時」正確。
@trap
(D) 的「此時」乍看有點彆扭（我們習慣說「從此」），有人因此不敢選。其實題目只解釋引號內的「爾」字：爾＝此（時），加上「自」才是「從此」。另三項都是明顯的{k:以今義解古詞}，用刪去法也能得到 (D)。

3. 【檢驗】(A) 自由、(C) 過往、(D) 未來，都是「此時此地」以外的東西，合乎瞻望的方向，也合乎失去自由者的心理。(B)「自在」與囚禁矛盾；「現在的歲月」就是鐵窗生活，無須伸長脖子去望。

@ana A o

@ana B x
「自在」是無拘無束、安閒舒適，與囚犯被監禁、以至於脖子都望長了的處境完全牴觸；「現在的歲月」是他們正在忍受的牢獄日子，不是「瞻望」（遠望、盼望）的對象。此項最不可能，為本題答案。
@ana C o

@ana D o

@trap

1. 【讀懂定義】題幹用四個例子說明：螢會「奔跑」「以為」「呆呆地站」「認得」——都是{k:人才有的動作或心理}。所以要找的是「非人之物＋人的動詞／心理詞」。
2. 【逐句找動詞】(A) 烏「食」——鳥吃東西是本能；(B) 落木「下」、長江「來」——自然現象；(D) 香風「透」、暮雨「掩」——景物的自然狀態；(C) 春風「不解」（不懂）、「禁」（管束），楊花「亂撲」行人——有心理、有意志。
3. 【結論】選 (C)。

@trap
- 就廣義的美學概念而言，「移情」可以泛指一切情景交融，(B)(D) 也都「景中有情」。但本題題幹已經給了{k:操作型定義}——「把人的行為或情感投射在非人的事物上」，並以四個擬人句為例，因此要以「物是否被寫成有人的行為、心理」為判準，只有 (C) 符合。
- 作答原則：{k:題幹自己下的定義優先}於你原本學到的定義。
- 原卷題幹末尾「是：是：」為重複誤植；所引「流螢以為」「呆呆地」與上文「流螢會以為」「呆呆的」略有出入，皆不影響作答。
@know 移情作用、擬人與「有我之境」
| 概念 | 出處 | 要點 |
| 移情作用 | 美學用語；朱光潛《談美》有專章介紹 | 把自己的情感移到外物身上，彷彿外物也有同樣的情感 |
| 轉化（擬人） | 修辭學 | 把物當作人來寫，使物有人的動作、情感、言語 |
| 有我之境 | 王國維《人間詞話》 | 「以我觀物，故物皆著我之色彩」 |
- 三者角度不同而相通：移情是{k:心理過程}，擬人是{k:修辭結果}，有我之境是{k:作品呈現的境界}。
- 經典例句：「我見青山多嫵媚，料青山見我應如是」（辛棄疾〈賀新郎〉）；「相看兩不厭，只有敬亭山」（李白〈獨坐敬亭山〉）；「蠟燭有心還惜別，替人垂淚到天明」（杜牧〈贈別〉）。
@know 轉化修辭完整分類
| 類型 | 定義 | 例句 |
| 擬人（以物擬人） | 把物當作人來寫 | 春風不解禁楊花，濛濛亂撲行人面（晏殊） |
| 擬物（以人擬物） | 把人當作物來寫 | 在天願作比翼鳥，在地願為連理枝（白居易〈長恨歌〉） |
| 擬物（以物擬物） | 把此物當作彼物來寫 | 流螢的事，潮汛泛起（把螢火寫成潮水） |
| 形象化（以虛擬實） | 把抽象的事物寫成具體的 | 不識歲月的容顏，不知歲月的籍貫（商禽〈長頸鹿〉）；剪不斷，理還亂，是離愁（李煜〈相見歡〉） |
- 轉化與譬喻的分別：譬喻有「喻體、喻依」兩物相比（螢光{k:像}蓮燈）；轉化是{k:直接}讓甲物具有乙物的性質（螢光「奔跑」），不出現「像」字，也不出現喻依。

@adv 文學批評：王國維《人間詞話》重點整理
| 主題 | 說法 | 王國維所舉例句 |
| 境界說 | 「詞以境界為最上。有境界則自成高格，自有名句。」 | — |
| 有我之境 | 以我觀物，故物皆著我之色彩 | 「淚眼問花花不語，亂紅飛過秋千去」；「可堪孤館閉春寒，杜鵑聲裡斜陽暮」（秦觀〈踏莎行〉） |
| 無我之境 | 以物觀物，故不知何者為我，何者為物 | 「採菊東籬下，悠然見南山」（陶淵明〈飲酒〉）；「寒波澹澹起，白鳥悠悠下」（元好問〈潁亭留別〉） |
| 景語與情語 | 「一切景語皆情語也」 | — |
| 成大事業、大學問的三種境界 | 第一境：立志高遠 | 「昨夜西風凋碧樹，獨上高樓，望盡天涯路」（晏殊〈蝶戀花〉） |
| | 第二境：執著追求 | 「衣帶漸寬終不悔，為伊消得人憔悴」（柳永〈鳳棲梧〉） |
| | 第三境：豁然有得 | 「眾裡尋他千百度，驀然回首，那人卻在，燈火闌珊處」（辛棄疾〈青玉案〉） |

@adv 進階演練（本書自編）
- 題目：下列詩句，將人的情感或行為投射於物（擬人）的選項是（多選）：
- (A) 蠟燭有心還惜別，替人垂淚到天明
- (B) 相看兩不厭，只有敬亭山
- (C) 大漠孤煙直，長河落日圓
- (D) 多情只有春庭月，猶為離人照落花
- (E) 兩個黃鸝鳴翠柳，一行白鷺上青天
- 答案：(A)(B)(D)。
- 解析：(A) 蠟燭「有心」「惜別」「垂淚」；(B) 山與人「相看」而「不厭」；(D) 月「多情」，特地「為」離人照花，皆賦予物以人的情感。(C) 王維〈使至塞上〉、(E) 杜甫〈絕句〉都是客觀的寫景，屬摹寫與對偶，沒有擬人。
