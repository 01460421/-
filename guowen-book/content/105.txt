@logic
1. 【審題】題目要找「完全正確」的句子，所以只要抓到一個錯字就能刪去，不必整句讀完再回頭。
2. 【先查成語與固定詞】把每句容易出錯的詞圈出來：奇異思想、相左、斡旋、米珠薪桂、怨聲戴道、頂極、仿間。
3. 【以義辨形】用詞義檢查用字：怨恨的聲音「充滿」道路 → {k:載}；最高「等級」→ {k:級}；「街市之間」→ {k:坊}；彼此「不同」才會衝突 → {k:歧}。
4. 【確認正解】(B) 的「相左」是互相違異，「斡旋」是居中調解，都是冷僻但正確的寫法，選 (B)。
@ana A x
「奇異」思想 → 「{k:歧異}」思想。「奇異」本身是一個詞（奇特、不尋常），所以這個錯字最隱蔽；但句意是「不同的思想彼此衝突，要能包容」，應該用表示「分歧、不相同」的「歧異」。判斷的線索是後面的「衝突」與「包容」：意見不同才會衝突，才需要包容。
@ana B o
全句無錯別字。「相左」：左，違背、不合；意見相左即意見不一致。「斡旋」：音ㄨㄛˋ ㄒㄩㄢˊ，居中周旋、調解。「斡」字右下是「斗」，常被誤寫成「幹」，也常被誤讀成ㄍㄢˋ。
@ana C x
怨聲「戴」道 → 怨聲「{k:載}」道。載，音ㄗㄞˋ，充滿；怨恨的聲音充滿道路，形容群眾普遍不滿。「戴」是把東西頂在頭上（戴帽子、披星戴月）。
同句的「米珠薪桂」用字正確：米貴如珍珠，柴貴如桂木，比喻物價昂貴，語本《戰國策‧楚策三》「楚國之食貴於玉，薪貴於桂」。
@ana D x
本句有兩個錯字：
- 頂「極」→ 頂「{k:級}」：最高的等級。「極」是盡頭、頂點，用於「登峰造極」「極品」。
- 「仿」間 → 「{k:坊}」間：坊，街市、里巷；坊間指市面上、街市之間。「仿」是模仿（仿冒、仿造）。
@trap
最容易漏看的是 (A)。「奇異」是日常用詞，單看詞語本身沒有錯，必須放回句子裡，才看得出與「衝突」「包容」搭配的應該是「歧異」。這類題目提醒我們：錯別字不一定是「寫不出來的字」，更常是{k:同音而詞義不合語境}的字。

@type 文言一字多義辨析
@cat 形音義
@tags 字義, 文言虛詞, 課內文言
@diff 3
@answer D
@stem
下列各組「」內的{y:字義，前後相同|用代換法比對}的選項是：
@note red
八句幾乎都是{c:課文}
逐句翻成白話再比
@opt A
得不「為」{nb:被}司馬懿{u:所}擒乎／吾若「為」{nb:是}司馬懿，必不便退也
@note blue
「為…所…」＝被動句
@opt B
大禹之聖，「且」{nb:尚且}惜寸陰／北山愚公者，年「且」{nb:將近}九十，面山而居
@note blue
且＋數字 → 將近
@opt C
以君之力，「曾」{nb:竟然}不能損魁父之丘／所以動心忍性，「曾」{nb:通「增」}益其所不能
@note blue
曾益＝增益（通假）
@opt D
西蜀之「去」{n:距離}南海，不知幾千里／我以日始出時「去」{n:距離}人近，而日中時遠
@note red
後面接{y:遠近、里數}
→ 都是「距離」✓
@cols 1
@key
兩個「去」後面分別接「幾千里」與「近、遠」，都是「距離」；其餘三組一為實詞一為虛詞，或一為通假，意義皆不同。
@translation
(A) 能不被司馬懿捉住嗎？／我如果是司馬懿，一定不會立刻退兵。
(B) 以大禹那樣的聖人，尚且愛惜每一寸光陰。／北山有位叫愚公的人，年紀將近九十歲，面對著山居住。
(C) 憑你的力氣，連魁父這樣的小土丘都削減不了。／藉此來震動他的心志、堅韌他的性情，增加他原本沒有的能力。
(D) 四川西部距離南海，不知道有幾千里遠。／我認為太陽剛出來時距離人近，到中午時距離人遠。
@logic
1. 【審題】比較字義，用{k:代換法}：把同一個白話解釋代入前後兩句，兩句都通才算相同。
2. 【看句式】(A) 前句是「為……所……」的被動句式，「為」是「被」；後句「吾若為司馬懿」是假設「我是司馬懿」，不同。
3. 【看搭配】(B)「且」後面接動詞「惜」是「尚且」，接數字「九十」是「將近」；(C)「曾不能」是加強否定語氣的「竟然、連……都」，「曾益」是通假字「增」。
4. 【確認正解】(D) 兩個「去」後面都在談遠近：「不知幾千里」「近／遠」，代入「距離」皆通，選 (D)。
@ana A x
得不「為」司馬懿所擒乎：{k:被}。出自《三國演義》第九十五回（國中課文〈空城計〉），孔明說明若棄城而逃，必定跑不遠，會被司馬懿擒住。
吾若「為」司馬懿，必不便退也：{k:是}。同一回中孔明說：我如果是司馬懿，絕不會馬上退兵。
→ 被 ≠ 是。
@ana B x
大禹之聖，「且」惜寸陰：{k:尚且}。出自清代李文炤〈勤訓〉：「大禹之聖，且惜寸陰；陶侃之賢，且惜分陰。」
年「且」九十：{k:將近}。出自《列子‧湯問》「愚公移山」。
→ 尚且 ≠ 將近。
@ana C x
「曾」不能損魁父之丘：{k:竟然、連……都}，副詞，加強否定語氣，音ㄗㄥ。出自《列子‧湯問》，是愚公之妻質疑愚公的話。
「曾」益其所不能：{k:通「增」}，增加。出自《孟子‧告子下》「生於憂患，死於安樂」章。
→ 竟然 ≠ 增加。
@ana D o
西蜀之「去」南海：{k:距離}。出自清代彭端淑〈為學一首示子姪〉，蜀地窮和尚與富和尚的故事。
日始出時「去」人近：{k:距離}。出自《列子‧湯問》「兩小兒辯日」。
→ 兩者皆為「距離」，正解。
@trap
「去」是典型的{k:古今異義}字：現代說「去學校」是「前往」，文言的「去」卻是「離開」或「距離」，方向正好相反。看到文言的「去」，先試「離開」「距離」兩個解釋，不要直接用現代的「前往」去讀。
@know 「為」的常見用法
| 讀音 | 用法 | 例句 |
| ㄨㄟˊ | 是 | 吾若「為」司馬懿／知之「為」知之（《論語‧為政》） |
| ㄨㄟˊ | 被（常與「所」搭配） | 得不「為」司馬懿所擒乎／不「為」酒困（《論語‧子罕》） |
| ㄨㄟˊ | 做、擔任、成為 | 化而「為」鳥（《莊子‧逍遙遊》） |
| ㄨㄟˋ | 替、給 | 「為」人謀而不忠乎（《論語‧學而》） |
| ㄨㄟˋ | 對、向 | 不足「為」外人道也（陶淵明〈桃花源記〉） |
| ㄨㄟˋ | 因為、為了 | 不「為」五斗米折腰 |
@know 「且」的常見用法
| 意義 | 例句 | 出處 |
| 尚且 | 大禹之聖，「且」惜寸陰 | 李文炤〈勤訓〉 |
| 尚且 | 臣死「且」不避，卮酒安足辭 | 《史記‧項羽本紀》 |
| 將近、將要 | 年「且」九十 | 《列子‧湯問》 |
| 將近、將要 | 不出，火「且」盡 | 王安石〈遊褒禪山記〉 |
| 暫且 | 存者「且」偷生 | 杜甫〈石壕吏〉 |
| 而且、又 | 河水清「且」漣猗 | 《詩經‧魏風‧伐檀》 |
@know 「去」的古今義
- {k:距離}：西蜀之去南海／去人近（本題）。
- {k:離開}：「去國懷鄉」（范仲淹〈岳陽樓記〉）——離開國都，不是「前往國都」。
- {k:除去}：去蕪存菁、去偽存真。
- {k:過去的}：去年、去歲。
- 現代常用義「前往」是後起的意思；文言表示「前往」多用「之」「往」「適」「如」。

=== Q 3
@type 量詞運用與諧趣雙關
@cat 詞語成語
@tags 量詞, 雙關, 成語用字
@diff 3
@answer A
@stem
下列文章中，☆所代表的字，{y:依序|五格全對才選}應該是：
@note red
每句都是「一＋量詞」
的{c:對比}：前褒後貶
或前重後輕
@box
對飲者來說，喝一缸酒算是{b:海量}，喝一盅酒則是☆{n:雅}量。對學生而言，一落書籍可謂沉重，一☆{n:刀}稿紙更是{u:痛苦}。自然界中的一道彩虹，令人覺得如夢似幻；一☆{n:彎}{g:新月}，讓人對明天充滿希望。有人說你打得一手好球，是褒你；讚你打得一☆{n:口}好球，是{y:損你|反話！}！一支部隊，讓人有非常機動的感覺，而一☆{n:鼓}{b:作氣}，令人感到雷霆萬鈞的氣勢。
@note red
先填最確定的：
一{y:鼓}作氣 → 刪 (C)(D)
@note blue
一刀＝紙一百張
「刀」又暗扣「痛苦」
@note green
新月如鉤 → 彎
滿月如盤 → 輪
@note purple
一口好球＝只會
用嘴巴說，所以是損
@opt A
雅／刀／彎／口／鼓
@opt B
酌／尺／輪／坨／鼓
@opt C
雅／尺／輪／坨／股
@opt D
酌／刀／彎／口／股
@cols 2
@key
「一鼓作氣」是固定成語，先刪 (C)(D)；新月要用「彎」、稿紙的量詞是「刀」、光說不練是「一口好球」，選 (A)。
@logic
1. 【找最確定的一格】五格之中，第五格「一☆作氣」是成語「{k:一鼓作氣}」，不能寫成「股」→ 刪去 (C)(D)。
2. 【比較 A、B】剩下「雅／酌」「刀／尺」「彎／輪」「口／坨」四組，只要確定一組即可。「新月」是月初彎彎的月牙，量詞用「彎」；「輪」是圓的，只能說「一輪明月」→ 選 (A)。
3. 【回頭驗證】文章的趣味在「一＋量詞」的對照：一缸／一盅、一落／一刀、一道／一彎、一手／一口、一支／一鼓。「一手好球」是真功夫，「一口好球」是只會嘴上說，所以「是損你」；「一刀稿紙」既是紙的量詞，又讓人聯想到「挨一刀」的痛苦。五格皆通。
@ana A o
- 雅量：與上句「海量」（酒量大）相對。一盅只是一小杯，文中借現成詞語「雅量」來對「海量」，取其「淺酌、斯文」的趣味。
- 一刀稿紙：刀，計算紙張的單位，一百張為一刀。要寫滿一百張稿紙，對學生當然「更是痛苦」；「刀」字又暗含挨刀之痛，一語雙關。
- 一彎新月：新月形如彎鉤，量詞用「彎」。
- 一口好球：仿「一手好球」而來，指只會用嘴巴「打球」，光說不練，所以是「損你」。
- 一鼓作氣：語出《左傳‧莊公十年》。
五格皆合，為正解。
@ana B x

@know 常見量詞整理
| 對象 | 量詞 | 說明 |

@know 「一鼓作氣」的出處
> 夫戰，勇氣也。一鼓作氣，再而衰，三而竭。彼竭我盈，故克之。
- 出自《左傳‧莊公十年》的「曹劌論戰」：齊、魯長勺之戰，曹劌等齊軍擊鼓三次、士氣衰竭後才下令反擊，大敗齊軍。
- 原指作戰時擊第一通鼓最能鼓起士氣；後比喻{k:趁著氣勢旺盛，一口氣把事情做完}。
- 同出此文的成語：再衰三竭、彼竭我盈、轍亂旗靡。
@know 「海量」與「雅量」
- {k:海量}：①酒量很大；②寬宏的度量，如「還請海量包涵」。
- {k:雅量}：①寬宏的氣度，如「有容人的雅量」；②也用來稱人善於飲酒。
- 本文把兩個原本意思相近的詞拆開，讓「海」對「缸」、「雅」對「盅」，是利用字面形象製造的{k:諧趣}——這種把詞語「別解」的手法，常見於幽默小品。

@know 洛夫小檔案

@ana C o

| 線索 | 說明 | 本題應用 |

@ana C o
「夫束修自好者，豈無其人？」是反問句，意思是「當然有這種人」；「經濟自期，抗懷千古者，亦所在多有」更直接說這種人到處都有。符合。
@ana D x
「好官我自為之」語本《宋史‧鄧綰傳》「笑罵從汝，好官須我為之」，形容為了官位不顧廉恥、任人譏罵。選項把它和「不慕名利」放在一起，前後矛盾；而原文對讀書人的看法是「好人為壞人所累」「於民大不便」，從頭到尾沒有稱許讀書人淡泊名利。最不符合，為本題答案。
@trap
(B) 的「笑罵由人」和 (D) 的「好官我自為之」其實出自同一句俗語，命題者把它拆成兩半：前半句剛好對應原文的「只得捱人笑罵」，後半句則是文中沒有的內容。另外，(A) 是對文意的{k:概括}，不是原文字句，容易讓人覺得「文中沒寫」；但與 (D) 相比，(A) 找得到依據，(D) 則完全找不到，「最不符合」要選差距最大的那一項。
@know 鄭燮與《板橋家書》
- 鄭燮，字克柔，號板橋，江蘇興化人，清代書畫家、文學家，「{k:揚州八怪}」之一。乾隆年間進士，曾任山東范縣、濰縣知縣，為官清廉、關心民間疾苦，後去官回揚州賣畫為生。
- 詩、書、畫皆精，世稱「三絕」：書法自創「六分半書」，繪畫以蘭、竹、石最著名；「難得糊塗」是他流傳最廣的題字。
- 《板橋家書》是他寫給堂弟鄭墨的書信，談讀書、做人、治家，文字淺白懇切。本題引文出自在范縣任上所寫的一封，信中主張「天地間第一等人，只有農夫，而士為四民之末」，痛批當時讀書人一心只想做官發財。
@know 「四民」與本文的排序

@ana A x

@ana B o

@ana C o

@ana D o

(C) 的「像是」是「好像、似乎」的意思，描述人們自身的感受，沒有拿另一種事物來比方；其餘三項都是以「等於」「是」為喻詞的暗喻。
@logic
1. 【審題】否定型：找「沒有」譬喻的。譬喻成立的條件是：{k:用乙事物來比方甲事物，甲乙本質不同而有相似點}。
2. 【拆解三要素】逐項找喻體（被說明的）、喻詞、喻依（拿來比方的）：(A) 認識朋友／等於／讀好書；(B) 村舍與樹林／是／棋子；(D) 有些事／是／過眼雲煙。三項都找得到喻依。
3. 【檢查 C】「人們像是滌淨了疲勞」：主語「人們」後面接的是人們自己的狀態，並沒有另一個事物作喻依。「像是」在這裡等於「彷彿、似乎」，表示一種不十分確定的感受。
4. 【結論】(C) 有「像」字卻不是譬喻，選 (C)。
@ana A o
喻體「多認識朋友」，喻詞「等於」，喻依「多讀好書」。交朋友和讀書是兩件不同的事，相似點是都能增長見識。喻詞為「是、為、等於、成了」等繫詞時，屬於{k:暗喻}（隱喻）。有使用譬喻。
@ana B o
出自徐志摩〈我所知道的康橋〉。把平原比作棋盤（地盤），把「村舍與樹林」比作「棋子」，喻詞為「是」，屬暗喻，寫出村舍、樹林疏密有致地散布在原野上的景象。有使用譬喻。
@ana C x
本句寫夜晚暑氣消散，人們感覺一天的疲勞好像都被洗淨了。「像是」修飾的是整個動作「滌淨了……疲勞」，意思是「似乎」，句中沒有出現用來比方的另一種事物，不是譬喻。（「滌淨疲勞」把抽象的疲勞當成可以洗去的污垢，是{k:轉化}中的形象化。）沒有使用譬喻，為本題答案。

@ana D o

@trap
判斷譬喻最常犯的兩個錯：
- {k:看到「像」就說是譬喻}：(C) 的「像是」只是表示推測、感覺。
- {k:沒看到「像」就說不是譬喻}：(A)(B)(D) 用的是「等於」「是」，照樣是譬喻（暗喻）。
正確的方法是找「喻依」：句子裡有沒有一個{k:本質不同}的事物被拿來比方。
@know 譬喻的四種類型
| 類型 | 喻體 | 喻詞 | 喻依 | 例句 |
| 明喻 | 有 | 像、如、似、彷彿、好比 | 有 | 彎彎的月亮像一艘小船 |
| 暗喻（隱喻） | 有 | 是、為、成了、等於 | 有 | 村舍與樹林是這地盤上的棋子 |
| 略喻 | 有 | 省略 | 有 | 一寸光陰一寸金 |
| 借喻 | 省略 | 省略 | 有 | 天邊掛著一把彎彎的鐮刀（鐮刀＝月亮） |
- 記法：由明喻到借喻，{k:省略的成分愈來愈多}，只有「喻依」永遠不能少。
@know 「像」字不等於譬喻
| 用法 | 例句 | 是否譬喻 |
| 打比方 | 她的笑容像陽光一樣溫暖 | 是（明喻） |
| 推測、感覺 | 天色像是要下雨了／人們像是滌淨了疲勞 | 否 |
| 舉例 | 像蘋果、香蕉這類水果，都很容易買到 | 否 |
| 同類相比 | 他長得很像他爸爸 | 否（同類事物比較，不是譬喻） |
@know 課文連結：徐志摩〈我所知道的康橋〉
- 徐志摩，新月派代表詩人，作品有詩〈再別康橋〉、〈偶然〉，散文〈我所知道的康橋〉、〈翡冷翠山居閒話〉等。

=== Q 9
@type 四種基本句型的判別

@translation
(A) 富貴人家的酒肉多到發臭。／路邊卻有凍死者的屍骨。

1. 【審題】四種句型的區別在{k:謂語}（說明主語的部分）：動詞敘述動作 → 敘事句；「有／無」→ 有無句；「是／非／為／乃」等繫詞解釋主語 → 判斷句；形容詞描寫性質狀態 → 表態句。
2. 【識破陷阱】本題八句中有三個「有」、兩個「是」，但不一定就是有無句、判斷句：「十有五」的「有」通「又」；「是人」的「是」是指示代詞「這」；「當是」的「是」是形容詞「正確」。
3. 【逐句判斷】(A) 臭（形容詞）→ 表態／有（存在）→ 有無。(B) 知（動詞）→ 敘事／辛苦 → 表態。(D) 降（動詞）→ 敘事／是（正確）→ 表態。
4. 【結論】(C)「朋……來」「吾……志於學」都以動詞為謂語，同屬敘事句，選 (C)。
@ana A x
朱門酒肉臭：主語「朱門酒肉」，謂語「臭」是形容詞，描寫狀態 → {k:表態句}。
路有凍死骨：「路」有「凍死骨」，表示存在 → {k:有無句}。
出自杜甫〈自京赴奉先縣詠懷五百字〉。前後不同。
@ana B x
誰知盤中飧：主語「誰」，謂語動詞「知」→ {k:敘事句}。
粒粒皆辛苦：主語「粒粒」，謂語「辛苦」描寫性質 → {k:表態句}（也有人把它看成省略「是」的判斷句：每一粒都是辛苦的成果；但無論如何都不是敘事句）。
出自李紳〈憫農〉。前後不同。
@ana C o
有朋自遠方來：敘述「朋友從遠方來」這件事，主語「朋」，謂語動詞「來」；句首的「有」只是引出不特定的對象（有個朋友），並非表示擁有 → {k:敘事句}。出自《論語‧學而》。
吾十有五而志於學：「十有五」即「十又五」，十五歲；主語「吾」，謂語動詞「志」（立志）→ {k:敘事句}。出自《論語‧為政》。
前後相同，為正解。
@ana D x
天將降大任於是人也：主語「天」，謂語動詞「降」→ {k:敘事句}。「是人」的「是」為指示代詞，這。出自《孟子‧告子下》。
廷尉當是也：「當」是判決、判處，「廷尉當」即廷尉的判決，為主語；「是」是形容詞「對、正確」→ {k:表態句}。出自《史記‧張釋之馮唐列傳》，漢文帝終於承認張釋之依法判決是對的。
前後不同。
@trap
「有朋自遠方來」是本題的爭議點。有些文法書把這種「有＋名詞＋動詞」的句子分析為有無句與敘事句套疊的「兼語句」（有朋／朋自遠方來），若依此說，它就不是單純的敘事句。不過就本題而言，(A)(B)(D) 三組前後句型明顯不同，只有 (C) 可以解釋為「同屬敘事句」，故以 (C) 為答案。作答這類題目要記得：{k:先看謂語的詞性，不要被句中的「有」「是」字面牽著走}。
@know 四種基本句型
| 句型 | 謂語的核心 | 作用 | 例句 |
| 敘事句 | 動詞 | 敘述動作、行為、事件 | 孔子登東山而小魯／誰知盤中飧 |
| 有無句 | 有、無 | 表示擁有或存在 | 路有凍死骨／山不在高，有仙則名 |
| 判斷句 | 是、非、為、乃、即（文言常用「……者，……也」） | 解釋主語是什麼、屬於什麼 | 陳勝者，陽城人也／此誠危急存亡之秋也 |
| 表態句 | 形容詞 | 描寫主語的性質、狀態 | 山高月小／朱門酒肉臭 |
- 判別口訣：{k:做什麼 → 敘事；有沒有 → 有無；是什麼 → 判斷；怎麼樣 → 表態}。
@know 句中有「有」，不一定是有無句
| 「有」的用法 | 例句 | 句型 |
| 擁有、存在 | 路有凍死骨／家有一老，如有一寶 | 有無句 |
| 通「又」，用於整數與零數之間 | 吾十有五而志於學／爾來二十有一年矣（〈出師表〉） | 依謂語而定 |
| 引出不特定的人或事 | 有朋自遠方來／有顏回者好學（《論語‧雍也》） | 多視為敘事句 |
@know 句中有「是」，不一定是判斷句
| 「是」的用法 | 例句 | 說明 |
| 指示代詞：這、此 | 天將降大任於是人也／是可忍也，孰不可忍也（《論語‧八佾》） | 文言最常見 |
| 形容詞：對、正確 | 廷尉當是也／自以為是 | 表態 |
| 繫詞：是 | 問今是何世（陶淵明〈桃花源記〉） | 判斷句，中古以後漸多 |
- 先秦文言的判斷句通常{k:不用「是」}，而用「……者，……也」或直接以名詞作謂語。

@logic
1. 【先刪明顯錯誤】成語的{k:褒貶}最容易判斷：「沐猴而冠」是譏諷人虛有其表，「尖嘴猴腮」是形容長相醜陋，兩者都是貶義，不可能是賀詞 → 刪 (C)(D)。

3. 【判斷小夫】甲午年是馬年、丙申年是猴年，干支都沒錯；但「馬上封侯」的吉祥寓意來自「侯」與「猴」諧音（傳統圖案是猴子騎在馬背上），猴年同樣適用，不能只歸給馬年。

@ana A x
小夫的話可以拆成三點檢查：
- 干支：甲午年（如民國 103 年）是馬年，丙申年（民國 105 年，即本次考試當年）是猴年，正確。
- 「猴來居上」：仿「後來居上」的諧音賀詞，猴年可用。
- 「馬上封侯」：這是小夫說法的問題所在。這句吉祥話的畫面是「馬」背「上」有一隻「猴（侯）」，寓意立刻升官受封；它既有馬又有猴，題幹問的是「猴年新春祝賀詞」，把它說成馬年的吉祥話並以「猴來居上」取代，並不周延。

@ana B o
「齊天獻瑞」仿自「祥龍獻瑞」「金猴獻瑞」一類賀詞。「齊天」是「齊天大聖」的省稱，為《西遊記》中美猴王孫悟空自封的名號；不直接說「猴」，而借與猴相關的著名名號來代稱，是{k:借代}修辭。說法正確，為本題答案。
@ana C x
「沐猴而冠」：沐猴即獼猴，猴子戴上帽子裝成人的樣子，比喻人徒具衣冠而本性粗鄙，或譏諷人虛有其表。語出《史記‧項羽本紀》「人言楚人沐猴而冠耳，果然」，是有人譏笑項羽的話。這是罵人的成語，與「拔得頭籌」「名列前茅」毫無關係。阿珠是望文生義，以為「冠」是「冠軍」。
@ana D x

@know 借代與借喻的分別
| 修辭 | 兩者的關係 | 例句 |
| 借代 | {k:相關}：用與本體有關的名稱、特徵、部分來代替 | 何以解憂，唯有杜康（以造酒者代酒）／齊天獻瑞（以名號代猴） |
| 借喻 | {k:相似}：用另一種有相似點的事物來比方，本體不出現 | 天上掛著一把鐮刀（以鐮刀喻彎月） |
- 判斷方法：問「它們是哪裡像？」答得出相似點的是借喻；答不出相似點、只是「有關係」的是借代。
