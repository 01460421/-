@logic
1. 【審題】題目要找「完全正確」的句子，所以只要抓到一個錯字就能刪去，不必整句讀完再回頭。
2. 【先查成語與固定詞】把每句容易出錯的詞圈出來：奇異思想、相左、斡旋、米珠薪桂、怨聲戴道、頂極、仿間。
3. 【以義辨形】用詞義檢查用字：怨恨的聲音「充滿」道路 → {k:載}；最高「等級」→ {k:級}；「街市之間」→ {k:坊}；彼此「不同」才會衝突 → {k:歧}。
4. 【確認正解】(B) 的「相左」是互相違異，「斡旋」是居中調解，都是冷僻但正確的寫法，選 (B)。
@ana A x
「奇異」思想 → 「{k:歧異}」思想。「奇異」本身是一個詞（奇特、不尋常），所以這個錯字最隱蔽；但句意是「不同的思想彼此衝突，要能包容」，應該用表示「分歧、不相同」的「歧異」。判斷的線索是後面的「衝突」與「包容」：意見不同才會衝突，才需要包容。
@ana B o
全句無錯別字。「相左」：左，違背、不合；意見相左即意見不一致。「斡旋」：音ㄨㄛˋ ㄒㄩㄢˊ，居中周旋、調解。「斡」字右下是「斗」，常被誤寫成「幹」，也常被誤讀成ㄍㄢˋ。
@ana C x
怨聲「戴」道 → 怨聲「{k:載}」道。載，音ㄗㄞˋ，充滿；怨恨的聲音充滿道路，形容群眾普遍不滿。「戴」是把東西頂在頭上（戴帽子、披星戴月）。
同句的「米珠薪桂」用字正確：米貴如珍珠，柴貴如桂木，比喻物價昂貴，語本《戰國策‧楚策三》「楚國之食貴於玉，薪貴於桂」。
@ana D x
本句有兩個錯字：
- 頂「極」→ 頂「{k:級}」：最高的等級。「極」是盡頭、頂點，用於「登峰造極」「極品」。
- 「仿」間 → 「{k:坊}」間：坊，街市、里巷；坊間指市面上、街市之間。「仿」是模仿（仿冒、仿造）。
@trap
最容易漏看的是 (A)。「奇異」是日常用詞，單看詞語本身沒有錯，必須放回句子裡，才看得出與「衝突」「包容」搭配的應該是「歧異」。這類題目提醒我們：錯別字不一定是「寫不出來的字」，更常是{k:同音而詞義不合語境}的字。

@type 文言一字多義辨析
@cat 形音義
@tags 字義, 文言虛詞, 課內文言
@diff 3
@answer D
@stem
下列各組「」內的{y:字義，前後相同|用代換法比對}的選項是：
@note red
八句幾乎都是{c:課文}
逐句翻成白話再比
@opt A
得不「為」{nb:被}司馬懿{u:所}擒乎／吾若「為」{nb:是}司馬懿，必不便退也
@note blue
「為…所…」＝被動句
@opt B
大禹之聖，「且」{nb:尚且}惜寸陰／北山愚公者，年「且」{nb:將近}九十，面山而居
@note blue
且＋數字 → 將近
@opt C
以君之力，「曾」{nb:竟然}不能損魁父之丘／所以動心忍性，「曾」{nb:通「增」}益其所不能
@note blue
曾益＝增益（通假）
@opt D
西蜀之「去」{n:距離}南海，不知幾千里／我以日始出時「去」{n:距離}人近，而日中時遠
@note red
後面接{y:遠近、里數}
→ 都是「距離」✓
@cols 1
@key
兩個「去」後面分別接「幾千里」與「近、遠」，都是「距離」；其餘三組一為實詞一為虛詞，或一為通假，意義皆不同。
@translation
(A) 能不被司馬懿捉住嗎？／我如果是司馬懿，一定不會立刻退兵。
(B) 以大禹那樣的聖人，尚且愛惜每一寸光陰。／北山有位叫愚公的人，年紀將近九十歲，面對著山居住。
(C) 憑你的力氣，連魁父這樣的小土丘都削減不了。／藉此來震動他的心志、堅韌他的性情，增加他原本沒有的能力。
(D) 四川西部距離南海，不知道有幾千里遠。／我認為太陽剛出來時距離人近，到中午時距離人遠。
@logic
1. 【審題】比較字義，用{k:代換法}：把同一個白話解釋代入前後兩句，兩句都通才算相同。
2. 【看句式】(A) 前句是「為……所……」的被動句式，「為」是「被」；後句「吾若為司馬懿」是假設「我是司馬懿」，不同。
3. 【看搭配】(B)「且」後面接動詞「惜」是「尚且」，接數字「九十」是「將近」；(C)「曾不能」是加強否定語氣的「竟然、連……都」，「曾益」是通假字「增」。
4. 【確認正解】(D) 兩個「去」後面都在談遠近：「不知幾千里」「近／遠」，代入「距離」皆通，選 (D)。
@ana A x
得不「為」司馬懿所擒乎：{k:被}。出自《三國演義》第九十五回（國中課文〈空城計〉），孔明說明若棄城而逃，必定跑不遠，會被司馬懿擒住。
吾若「為」司馬懿，必不便退也：{k:是}。同一回中孔明說：我如果是司馬懿，絕不會馬上退兵。
→ 被 ≠ 是。
@ana B x
大禹之聖，「且」惜寸陰：{k:尚且}。出自清代李文炤〈勤訓〉：「大禹之聖，且惜寸陰；陶侃之賢，且惜分陰。」
年「且」九十：{k:將近}。出自《列子‧湯問》「愚公移山」。
→ 尚且 ≠ 將近。
@ana C x
「曾」不能損魁父之丘：{k:竟然、連……都}，副詞，加強否定語氣，音ㄗㄥ。出自《列子‧湯問》，是愚公之妻質疑愚公的話。
「曾」益其所不能：{k:通「增」}，增加。出自《孟子‧告子下》「生於憂患，死於安樂」章。
→ 竟然 ≠ 增加。
@ana D o
西蜀之「去」南海：{k:距離}。出自清代彭端淑〈為學一首示子姪〉，蜀地窮和尚與富和尚的故事。
日始出時「去」人近：{k:距離}。出自《列子‧湯問》「兩小兒辯日」。
→ 兩者皆為「距離」，正解。
@trap
「去」是典型的{k:古今異義}字：現代說「去學校」是「前往」，文言的「去」卻是「離開」或「距離」，方向正好相反。看到文言的「去」，先試「離開」「距離」兩個解釋，不要直接用現代的「前往」去讀。
@know 「為」的常見用法
| 讀音 | 用法 | 例句 |
| ㄨㄟˊ | 是 | 吾若「為」司馬懿／知之「為」知之（《論語‧為政》） |
| ㄨㄟˊ | 被（常與「所」搭配） | 得不「為」司馬懿所擒乎／不「為」酒困（《論語‧子罕》） |
| ㄨㄟˊ | 做、擔任、成為 | 化而「為」鳥（《莊子‧逍遙遊》） |
| ㄨㄟˋ | 替、給 | 「為」人謀而不忠乎（《論語‧學而》） |
| ㄨㄟˋ | 對、向 | 不足「為」外人道也（陶淵明〈桃花源記〉） |
| ㄨㄟˋ | 因為、為了 | 不「為」五斗米折腰 |
@know 「且」的常見用法
| 意義 | 例句 | 出處 |
| 尚且 | 大禹之聖，「且」惜寸陰 | 李文炤〈勤訓〉 |
| 尚且 | 臣死「且」不避，卮酒安足辭 | 《史記‧項羽本紀》 |
| 將近、將要 | 年「且」九十 | 《列子‧湯問》 |
| 將近、將要 | 不出，火「且」盡 | 王安石〈遊褒禪山記〉 |
| 暫且 | 存者「且」偷生 | 杜甫〈石壕吏〉 |
| 而且、又 | 河水清「且」漣猗 | 《詩經‧魏風‧伐檀》 |
@know 「去」的古今義
- {k:距離}：西蜀之去南海／去人近（本題）。
- {k:離開}：「去國懷鄉」（范仲淹〈岳陽樓記〉）——離開國都，不是「前往國都」。
- {k:除去}：去蕪存菁、去偽存真。
- {k:過去的}：去年、去歲。
- 現代常用義「前往」是後起的意思；文言表示「前往」多用「之」「往」「適」「如」。

=== Q 3
@type 量詞運用與諧趣雙關
@cat 詞語成語
@tags 量詞, 雙關, 成語用字
@diff 3
@answer A
@stem
下列文章中，☆所代表的字，{y:依序|五格全對才選}應該是：
@note red
每句都是「一＋量詞」
的{c:對比}：前褒後貶
或前重後輕
@box
對飲者來說，喝一缸酒算是{b:海量}，喝一盅酒則是☆{n:雅}量。對學生而言，一落書籍可謂沉重，一☆{n:刀}稿紙更是{u:痛苦}。自然界中的一道彩虹，令人覺得如夢似幻；一☆{n:彎}{g:新月}，讓人對明天充滿希望。有人說你打得一手好球，是褒你；讚你打得一☆{n:口}好球，是{y:損你|反話！}！一支部隊，讓人有非常機動的感覺，而一☆{n:鼓}{b:作氣}，令人感到雷霆萬鈞的氣勢。
@note red
先填最確定的：
一{y:鼓}作氣 → 刪 (C)(D)
@note blue
一刀＝紙一百張
「刀」又暗扣「痛苦」
@note green
新月如鉤 → 彎
滿月如盤 → 輪
@note purple
一口好球＝只會
用嘴巴說，所以是損
@opt A
雅／刀／彎／口／鼓
@opt B
酌／尺／輪／坨／鼓
@opt C
雅／尺／輪／坨／股
@opt D
酌／刀／彎／口／股
@cols 2
@key
「一鼓作氣」是固定成語，先刪 (C)(D)；新月要用「彎」、稿紙的量詞是「刀」、光說不練是「一口好球」，選 (A)。
@logic
1. 【找最確定的一格】五格之中，第五格「一☆作氣」是成語「{k:一鼓作氣}」，不能寫成「股」→ 刪去 (C)(D)。
2. 【比較 A、B】剩下「雅／酌」「刀／尺」「彎／輪」「口／坨」四組，只要確定一組即可。「新月」是月初彎彎的月牙，量詞用「彎」；「輪」是圓的，只能說「一輪明月」→ 選 (A)。
3. 【回頭驗證】文章的趣味在「一＋量詞」的對照：一缸／一盅、一落／一刀、一道／一彎、一手／一口、一支／一鼓。「一手好球」是真功夫，「一口好球」是只會嘴上說，所以「是損你」；「一刀稿紙」既是紙的量詞，又讓人聯想到「挨一刀」的痛苦。五格皆通。
@ana A o
- 雅量：與上句「海量」（酒量大）相對。一盅只是一小杯，文中借現成詞語「雅量」來對「海量」，取其「淺酌、斯文」的趣味。
- 一刀稿紙：刀，計算紙張的單位，一百張為一刀。要寫滿一百張稿紙，對學生當然「更是痛苦」；「刀」字又暗含挨刀之痛，一語雙關。
- 一彎新月：新月形如彎鉤，量詞用「彎」。
- 一口好球：仿「一手好球」而來，指只會用嘴巴「打球」，光說不練，所以是「損你」。
- 一鼓作氣：語出《左傳‧莊公十年》。
五格皆合，為正解。
@ana B x

@know 常見量詞整理
| 對象 | 量詞 | 說明 |

@know 「一鼓作氣」的出處
> 夫戰，勇氣也。一鼓作氣，再而衰，三而竭。彼竭我盈，故克之。
- 出自《左傳‧莊公十年》的「曹劌論戰」：齊、魯長勺之戰，曹劌等齊軍擊鼓三次、士氣衰竭後才下令反擊，大敗齊軍。
- 原指作戰時擊第一通鼓最能鼓起士氣；後比喻{k:趁著氣勢旺盛，一口氣把事情做完}。
- 同出此文的成語：再衰三竭、彼竭我盈、轍亂旗靡。
@know 「海量」與「雅量」
- {k:海量}：①酒量很大；②寬宏的度量，如「還請海量包涵」。
- {k:雅量}：①寬宏的氣度，如「有容人的雅量」；②也用來稱人善於飲酒。
- 本文把兩個原本意思相近的詞拆開，讓「海」對「缸」、「雅」對「盅」，是利用字面形象製造的{k:諧趣}——這種把詞語「別解」的手法，常見於幽默小品。

@know 洛夫小檔案

@ana C o

| 線索 | 說明 | 本題應用 |

@ana C o
「夫束修自好者，豈無其人？」是反問句，意思是「當然有這種人」；「經濟自期，抗懷千古者，亦所在多有」更直接說這種人到處都有。符合。
@ana D x
「好官我自為之」語本《宋史‧鄧綰傳》「笑罵從汝，好官須我為之」，形容為了官位不顧廉恥、任人譏罵。選項把它和「不慕名利」放在一起，前後矛盾；而原文對讀書人的看法是「好人為壞人所累」「於民大不便」，從頭到尾沒有稱許讀書人淡泊名利。最不符合，為本題答案。
@trap
(B) 的「笑罵由人」和 (D) 的「好官我自為之」其實出自同一句俗語，命題者把它拆成兩半：前半句剛好對應原文的「只得捱人笑罵」，後半句則是文中沒有的內容。另外，(A) 是對文意的{k:概括}，不是原文字句，容易讓人覺得「文中沒寫」；但與 (D) 相比，(A) 找得到依據，(D) 則完全找不到，「最不符合」要選差距最大的那一項。
@know 鄭燮與《板橋家書》
- 鄭燮，字克柔，號板橋，江蘇興化人，清代書畫家、文學家，「{k:揚州八怪}」之一。乾隆年間進士，曾任山東范縣、濰縣知縣，為官清廉、關心民間疾苦，後去官回揚州賣畫為生。
- 詩、書、畫皆精，世稱「三絕」：書法自創「六分半書」，繪畫以蘭、竹、石最著名；「難得糊塗」是他流傳最廣的題字。
- 《板橋家書》是他寫給堂弟鄭墨的書信，談讀書、做人、治家，文字淺白懇切。本題引文出自在范縣任上所寫的一封，信中主張「天地間第一等人，只有農夫，而士為四民之末」，痛批當時讀書人一心只想做官發財。
@know 「四民」與本文的排序

@ana A x

@ana B o

@ana C o

@ana D o

(C) 的「像是」是「好像、似乎」的意思，描述人們自身的感受，沒有拿另一種事物來比方；其餘三項都是以「等於」「是」為喻詞的暗喻。
@logic
1. 【審題】否定型：找「沒有」譬喻的。譬喻成立的條件是：{k:用乙事物來比方甲事物，甲乙本質不同而有相似點}。
2. 【拆解三要素】逐項找喻體（被說明的）、喻詞、喻依（拿來比方的）：(A) 認識朋友／等於／讀好書；(B) 村舍與樹林／是／棋子；(D) 有些事／是／過眼雲煙。三項都找得到喻依。
3. 【檢查 C】「人們像是滌淨了疲勞」：主語「人們」後面接的是人們自己的狀態，並沒有另一個事物作喻依。「像是」在這裡等於「彷彿、似乎」，表示一種不十分確定的感受。
4. 【結論】(C) 有「像」字卻不是譬喻，選 (C)。
@ana A o
喻體「多認識朋友」，喻詞「等於」，喻依「多讀好書」。交朋友和讀書是兩件不同的事，相似點是都能增長見識。喻詞為「是、為、等於、成了」等繫詞時，屬於{k:暗喻}（隱喻）。有使用譬喻。
@ana B o
出自徐志摩〈我所知道的康橋〉。把平原比作棋盤（地盤），把「村舍與樹林」比作「棋子」，喻詞為「是」，屬暗喻，寫出村舍、樹林疏密有致地散布在原野上的景象。有使用譬喻。
@ana C x
本句寫夜晚暑氣消散，人們感覺一天的疲勞好像都被洗淨了。「像是」修飾的是整個動作「滌淨了……疲勞」，意思是「似乎」，句中沒有出現用來比方的另一種事物，不是譬喻。（「滌淨疲勞」把抽象的疲勞當成可以洗去的污垢，是{k:轉化}中的形象化。）沒有使用譬喻，為本題答案。

@ana D o

@trap
判斷譬喻最常犯的兩個錯：
- {k:看到「像」就說是譬喻}：(C) 的「像是」只是表示推測、感覺。
- {k:沒看到「像」就說不是譬喻}：(A)(B)(D) 用的是「等於」「是」，照樣是譬喻（暗喻）。
正確的方法是找「喻依」：句子裡有沒有一個{k:本質不同}的事物被拿來比方。
@know 譬喻的四種類型
| 類型 | 喻體 | 喻詞 | 喻依 | 例句 |
| 明喻 | 有 | 像、如、似、彷彿、好比 | 有 | 彎彎的月亮像一艘小船 |
| 暗喻（隱喻） | 有 | 是、為、成了、等於 | 有 | 村舍與樹林是這地盤上的棋子 |
| 略喻 | 有 | 省略 | 有 | 一寸光陰一寸金 |
| 借喻 | 省略 | 省略 | 有 | 天邊掛著一把彎彎的鐮刀（鐮刀＝月亮） |
- 記法：由明喻到借喻，{k:省略的成分愈來愈多}，只有「喻依」永遠不能少。
@know 「像」字不等於譬喻
| 用法 | 例句 | 是否譬喻 |
| 打比方 | 她的笑容像陽光一樣溫暖 | 是（明喻） |
| 推測、感覺 | 天色像是要下雨了／人們像是滌淨了疲勞 | 否 |
| 舉例 | 像蘋果、香蕉這類水果，都很容易買到 | 否 |
| 同類相比 | 他長得很像他爸爸 | 否（同類事物比較，不是譬喻） |
@know 課文連結：徐志摩〈我所知道的康橋〉
- 徐志摩，新月派代表詩人，作品有詩〈再別康橋〉、〈偶然〉，散文〈我所知道的康橋〉、〈翡冷翠山居閒話〉等。

=== Q 9
@type 四種基本句型的判別

@translation
(A) 富貴人家的酒肉多到發臭。／路邊卻有凍死者的屍骨。

1. 【審題】四種句型的區別在{k:謂語}（說明主語的部分）：動詞敘述動作 → 敘事句；「有／無」→ 有無句；「是／非／為／乃」等繫詞解釋主語 → 判斷句；形容詞描寫性質狀態 → 表態句。
2. 【識破陷阱】本題八句中有三個「有」、兩個「是」，但不一定就是有無句、判斷句：「十有五」的「有」通「又」；「是人」的「是」是指示代詞「這」；「當是」的「是」是形容詞「正確」。

@know 四種基本句型
| 句型 | 謂語的核心 | 作用 | 例句 |
| 敘事句 | 動詞 | 敘述動作、行為、事件 | 孔子登東山而小魯／誰知盤中飧 |

| 判斷句 | 是、非、為、乃、即（文言常用「……者，……也」） | 解釋主語是什麼、屬於什麼 | 陳勝者，陽城人也／此誠危急存亡之秋也 |
| 表態句 | 形容詞 | 描寫主語的性質、狀態 | 山高月小／朱門酒肉臭 |
- 判別口訣：{k:做什麼 → 敘事；有沒有 → 有無；是什麼 → 判斷；怎麼樣 → 表態}。

| 「有」的用法 | 例句 | 句型 |

| 「是」的用法 | 例句 | 說明 |

- {k:會意和指事}：指事字是在象形字上加抽象符號（本、末、刃、上、下），囚、休、采是「兩個獨立的字」組合起來，屬會意。
@know 六書一覽

@type 語病判斷
@cat 語文應用

@stem

@box lines

乙：不法商人昧著良心{x:仿造}{u:贋品}，以此牟取暴利。

甲：疲勞 →「消除」

@note blue

@note blue

@opt A

@opt C

@opt D

@cols 4
@key
甲「疲勞恢復」搭配不當；乙「仿造贗品」不合邏輯；丙「囊括」九取五用詞不當；丁「奄奄一息的罹難者」前後矛盾——四句都有語病。
@logic
1. 【審題】題目問「有語病的共有哪些」，選項是組合，必須四句全部判斷，不能看到兩句有錯就選。
2. 【查搭配】甲：主語「疲勞」配謂語「恢復」——恢復是回到原來的好狀態，疲勞只能「消除」。丙：動詞「囊括」是把全部包羅在內，賓語卻是「九項中的五面」。
3. 【查邏輯】乙：贗品本身就是偽造的東西，「仿造贗品」變成模仿假貨。丁：「罹難」是遭遇災難而死亡，死者不可能「奄奄一息」。
4. 【結論】甲乙丙丁皆有語病，選 (D)。
@ana A x
甲、丁確實有語病，但乙、丙也有，選項不完整。
- 甲：{k:主謂搭配不當}。可改為「他的疲勞頓時消除」或「他的體力頓時恢復」。
- 丁：{k:語意矛盾}。「奄奄一息」是只剩微弱的一口氣，表示還活著；「罹難者」是已經死亡的人。可改為「挖出許多奄奄一息的受困者」，或「挖出許多罹難者的遺體」。
@ana B x
乙、丙確實有語病，但甲、丁也有，選項不完整。
- 乙：{k:動賓搭配不合邏輯}。「贗品」（贋為異體字）是偽造的物品，是「仿造」的結果，不是仿造的對象。可改為「製造贗品」或「仿造名牌商品」。
- 丙：{k:用詞不當}。「囊括」是包羅、席捲一切，九項競賽只拿到五面金牌，不能說囊括。可改為「奪得九項競賽中的五面金牌」；若九面全拿，才能說「囊括九面金牌」。
@ana C x
甲、乙、丁皆有語病，但漏了丙。丙句最容易被放過：「勇冠三軍」用來比喻班級表現最英勇，並無不妥，問題出在後面的「囊括……五面金牌」。
@ana D o
四句皆有語病：甲（搭配不當）、乙（不合邏輯）、丙（用詞不當）、丁（前後矛盾）。為正解。
@trap
這類「共有哪些」的組合題，最怕{k:只找到明顯的就收手}。丁的矛盾最明顯，甲次之，所以很多人會選 (A)；乙、丙的語病要對詞義夠敏感才看得出來。建議每一句都強迫自己問兩個問題：「這個動詞能配這個名詞嗎？」「前後的意思有沒有打架？」
@know 常見語病類型
| 類型 | 說明 | 例句（→ 修改） |
| 搭配不當 | 主語與謂語、動詞與賓語、修飾語與中心語不能配合 | 他的疲勞恢復了 → 疲勞消除了 |
| 語意矛盾 | 句中前後意思互相衝突 | 奄奄一息的罹難者 → 奄奄一息的受困者 |

=== Q 14
@type 關聯詞的修改與銜接
@cat 語文應用
@tags 關聯詞, 讓步, 轉折, 假設
@diff 3
@answer B
@stem
下列文章中畫底線的詞語，{y:都是不正確的|四處都要改}，遂使文句上下不銜接。{y:正確修改}的選項是：
@note red
先判斷前後句的{c:關係}
再看選項改得對不對
@box
植物天生地予人穩定心情的力量，__（甲）原來__{n:但}{u:也得}靠個人去追尋，否則__（乙）除非__{n:縱使}有一整排落葉繽紛的樹林圍繞著你，甚至一整座森林，你{y:也}容易視而不見。尋找自然的方法很簡易，也很直接。內心裡寸草不生的人，__（丙）反而__{n:當然}所處的環境{b:也會}寸草不生。__（丁）因此__{n:如果}你想和一株樹成為朋友，最重要的{g:前提}，是你必須看得見她。（王家祥＜遇見一株樹＞）
@note red
乙：後面有「也」呼應
→ 縱使…也…（讓步）
@note blue
甲：有力量↔得自己找
→ 轉折（但、然而）
@note blue
丙：內心荒蕪→環境也
荒蕪，是順承不是相反
@note blue
丁：「前提」是條件
→ 假設（如果、倘若）
@opt A
（甲）改為：{x:以致}
@opt B
（乙）改為：{g:縱使}
@opt C
（丙）改為：{x:或者}
@opt D
（丁）改為：{x:儘管}
@note blue
以致：因果／或者：選擇
儘管：事實讓步，
後面要接轉折
@cols 2
@key
（乙）後文有「你也容易視而不見」，「縱使……也……」是固定的讓步句式；其餘三項改了之後前後關係仍然不通。
@logic
1. 【審題】四個畫線詞都是錯的，題目問哪一個選項「改對了」。做法是先自己判斷每一處應有的{k:邏輯關係}，再對照選項。
2. 【甲】「植物予人穩定心情的力量」與「也得靠個人去追尋」語意轉折 → 應為「但、然而」。(A)「以致」表示因果，不對。
3. 【乙】「否則□□有一整排樹林圍繞著你……你也容易視而不見」：即使條件再好，結果仍然不變 → 讓步關係，「縱使／即使……也……」。(B) 正確。
4. 【丙、丁】丙：內心寸草不生 → 環境也寸草不生，是順理成章的推論 → 「當然、自然」，(C)「或者」表選擇，不對。丁：「你想和樹成為朋友」是假設的條件 → 「如果」，(D)「儘管」表讓步，後面必須有轉折，不對。選 (B)。
@ana A x
「以致」用在因果句的後半，表示由前面的原因造成（多半不好的）結果，如「他熬夜成習，以致體力大不如前」。本句前後是轉折關係：植物雖有安定人心的力量，{k:但}仍得靠個人去追尋。改成「以致」反而變成「因為植物有力量，所以得靠個人追尋」，不通。
@ana B o
「縱使」表示假設的讓步，常與「也」「仍」搭配。「否則縱使有一整排落葉繽紛的樹林圍繞著你，甚至一整座森林，你也容易視而不見」——就算樹林就在身邊，不用心的人還是看不見。前後呼應，語意通順。原來的「除非」表示唯一條件，須與「才」「否則」搭配，放在這裡不通。為正解。
@ana C x
「或者」表示選擇關係（A 或者 B）。本句只有一種情況：內心荒蕪的人，所處的環境{k:自然也}荒蕪，前後是順承、推論的關係。原來的「反而」表示與預期相反，同樣不通；應改為「當然」「自然」一類的詞。
@ana D x
「儘管」表示承認某個事實，後面必須接轉折（儘管……還是／卻……）。本句「你想和一株樹成為朋友」是尚未發生的假設，後面接「最重要的前提是……」說明條件，應改為「如果」「倘若」。原來的「因此」表示結論，但上文並沒有推出「你想和樹做朋友」的原因。
@trap
(B)「縱使」與 (D)「儘管」都常被歸為「讓步」，容易混淆。差別在於：{k:縱使＝就算（假設的情況），後接「也」；儘管＝雖然（已有的事實），後接「還是、卻、但」}。把 (D) 代回原文：「儘管你想和一株樹成為朋友，最重要的前提，是你必須看得見她」——後半句沒有轉折，讀起來就不順。

## 寓意
- 表面寫貓，其實談的是{k:用人}：有真本領的人即使有些小毛病，仍可「舍其病而用其能」；但如果徒有威武的外表，沒有才能卻又為害，就是「棄才」，不值得姑息。
- 貓「形魁然大，爪牙銛且利」的外表，與「一無所為」的實際形成強烈{k:對比}，諷刺虛有其表、尸位素餐的人。
## 寫作特色
- {k:第一人稱}「余」敘事，依時間先後{k:順敘}，以「既而」「已則」推進情節。
- 寫貓的無能，不直接下判斷，而是透過群鼠由「不敢出」到「為暴如故」的變化來{k:側面烘托}。
- 「有能者必有病」出現兩次：第一次是主人為貓開脫，第二次是家人據以定罪，前後呼應而結論相反。
@know 文體常識：「說」
- 「說」是古代一種{k:議論性}的文體，可以直接說理，也可以先敘述一件事、描寫一種物，再引出道理，寫法自由。
- 常見篇目：韓愈〈師說〉、〈馬說〉，柳宗元〈捕蛇者說〉，周敦頤〈愛蓮說〉，薛瑄〈貓說〉。
- 藉動物、故事來寄託道理的「說」，性質與{k:寓言}相近：前面的故事是「喻體」，後面點出的道理是「寓意」。
@know 對讀：〈貓說〉與柳宗元〈黔之驢〉
| 比較 | 薛瑄〈貓說〉 | 柳宗元〈黔之驢〉 |
| 主角的外表 | 形魁然大，爪牙銛且利 | 龐然大物 |
| 對手的初步反應 | 群鼠「類有能者」，月餘不敢出 | 老虎「以為神」，躲在林間偷看 |
| 對手的試探 | 潛視 → 窺之益熟 | 稍近益狎，蕩倚衝冒 |
| 對手的結論 | 「彼無為也」 | 「技止此耳」 |
| 結局 | 鼠為暴如故，貓被笞而放 | 虎斷其喉、盡其肉 |
| 寓意 | 無能而有害者是棄才 | 外強中乾者終將敗露 |
- 柳宗元在〈黔之驢〉結尾感嘆驢子「形之龐也類有德，聲之宏也類有能」，與本文的「類有能者」用語相近：兩篇都在諷刺{k:外表唬人、實無本領}的角色。
@know 作者薛瑄

@answer D
@stem

@note red
適＝恰好、偏巧
獨…乎＝難道…嗎
@opt A
正／{x:徒}
@note blue
徒＝只、白白地
@opt B
{x:如}／{x:殆}
@note blue
殆＝大概、恐怕
@opt C
{x:垂}／{x:得}

@cols 4
@key
「適」是恰巧、偏巧；「獨……乎」是反問句式，「獨」等於「難道」，可換成同樣表反問的「寧」，選 (D)。
@logic
1. 【先解原句】「適睹出殼雞雛」：貓剛被解開，{k:恰好}看見小雞。「獨無捕鼠之能乎」：句末有「乎」，是反問——{k:難道}沒有捕鼠的本領嗎？
2. 【先看把握大的】第二個字較容易分辨：四個選項中，能表示反問語氣「難道」的只有「寧」（如「王侯將相寧有種乎」）。「徒」是只、「殆」是大概、「得」是能夠，都不是反問。
3. 【回頭驗證】「偏」有「偏巧、恰巧」的意思，代入「偏睹出殼雞雛」（偏偏剛好看見小雞）語意相通。
4. 【結論】選 (D)。
@ana A x
「正」可以替換「適」（正好看見），前半正確。但「徒」是「只、僅僅」或「白白地」，代入成「徒無捕鼠之能乎」，意思變成「只是沒有捕鼠的本領嗎」，不合主人為貓辯護的語氣。後半錯誤。
@ana B x
「如」作動詞是「往、到」，另有「像、如果」等義，都不是「恰好」。「殆」是「大概、恐怕」，代入成「恐怕沒有捕鼠的本領吧」，與主人相信貓有本領的原意{k:正好相反}。
@ana C x
「垂」是「將近、快要」（垂老、功敗垂成），不是「恰好」。「得」是「能夠」；文言雖有「得無……乎」的說法，但那是「該不會……吧」的推測語氣，且不是單一個「得」字，不能替換「獨」。
@ana D o
「偏」：偏巧、恰巧，表示事情湊巧發生，與「適」相通。「寧」：副詞，豈、難道，用於反問，如《史記‧陳涉世家》「王侯將相寧有種乎」。「寧無捕鼠之能乎」＝難道沒有捕鼠的本領嗎，與原句語意相同。為正解。
@trap
(A) 的「正」其實比 (D) 的「偏」更容易想到，很多人看到「正」就直接選 (A)。這類{k:兩格配對}的題目，一定要兩格都代回原句：「獨」在現代只剩「單獨、唯獨」的意思，與「徒（只）」看似相近，但原句句末的「乎」已經提示這是反問句，「獨」必須解作「難道」。
@know 表示反問的文言副詞

@logic

@ana A x

@ana B x

@ana C o

@know 文言文的主語省略
- 文言敘事常承前省略主語，同一段中主語可能悄悄轉換。以第一段為例：
> （余）以其未馴也，（余）縶維以飼，候其馴焉。群鼠聞其聲，（群鼠）相與窺其形，（貓）類有能者，（群鼠）屏不敢出穴者月餘日。

@type 寓言的寫作手法
@cat 文言閱讀
@tags 貓說, 敘事觀點, 寫作手法, 寓意
@diff 2
@answer C
@stem

@note red
每個選項有兩個分句
兩句都要查
@opt A
以{g:第一人稱}觀點，敘述個人的經歷
@note green
全文以「余」敘述
@opt B
按照{g:時間的順序}，安排事件的發展

既而 → 已則 → 既而
@opt C
描繪主人的心思，{x:寄寓人貓的情誼}
@note red
寄寓的是「用人之理」
文中沒有情誼
@opt D
藉由群鼠的評論，表達對貓的定位
@note green
「彼無為也」
@cols 1
@key
本文藉貓諷刺無能而有害的「棄才」，寄寓的是用人的道理；主人最後把貓「笞而放之」，並沒有人貓情誼，(C) 不正確。
@logic
1. 【審題】否定型：選「不正確」的。四個選項都是「手法＋作用」兩個分句，前後都對才算正確。
2. 【查 A、B】全文以「余」自稱 → 第一人稱；「既而」「已則」「既而」依序推進 → 順敘。兩項正確。
3. 【查 D】群鼠「歷穴相告曰：彼無為也」，用老鼠的話替貓下了評語 → 正確。
4. 【查 C】前半「描繪主人的心思」有依據（余私計、余方怪甚）；但後半「寄寓人貓的情誼」不合：主人對貓只有期待、寬容、疑惑，結局是鞭打、放逐，全文的寓意在「棄才」二字。選 (C)。
@ana A o
文中敘述者自稱「余」：「余家苦鼠暴」「余私計」「余曰」「余方怪甚」「余之家人」，是以第一人稱敘述自己家中養貓的經過。正確。
@ana B o
得貓 → 拴養月餘 →「既而」解繩噬雛 →「已則」一無所為 →「既而」群鼠復出、貓再噬雛 → 家人責貓放逐。全文依事情發生的先後順序敘述，屬{k:順敘}。正確。
@ana C x
前半句正確：文中確實寫出主人的心理變化——「私計鼠暴當不復慮」（期待）、「獨無捕鼠之能乎」（寬容）、「方怪甚」（疑惑）。後半句錯誤：這些心思是為了襯托貓的名不副實，最後貓被「笞而放之」，作者要表達的是對{k:無能而有害者}的批判，而不是人與貓之間的感情。不正確，為本題答案。
@ana D o
作者不直接說貓無能，而是讓群鼠經過「不敢出 → 潛視 → 窺之益熟」的觀察後，自己說出「彼無為也」。連老鼠都看穿了，貓的無用不言可喻。這是藉他者之口下評語的{k:側面描寫}。正確。
@trap
(C) 的前半句是對的，而且「描繪主人的心思」正是本文的特色，容易讓人讀到一半就認定正確。選項若由兩個分句組成，命題者最常{k:把錯誤藏在後半句}。另外，本文雖用第一人稱，卻寫出了群鼠的想法（「以為彼將匿形致己」），這是寓言常見的擬人、虛構筆法，並不影響 (A) 的正確性。

@know 「非 A 即 B」與相近句式
| 句式 | 關係 | 例句 |
| 非 A 即 B（不是 A 就是 B） | 選擇：兩者必居其一 | 非張，即鄉土／非黑即白 |

| 即 A 即 B | 等同、同時 | 即知即行 |
| A 即 B | 判斷：A 就是 B | 民之所欲，即政之所向 |

## 閱讀提醒
- 第二段的「或許……但這不過是……其實……」是全文最重要的轉折：作者先承認一種常見說法（警醒），再指出真正的主因。第 23 題 (D) 就是考有沒有讀出這層輕重。
- 第六段筆調一變，由客觀說明轉為「我」的冥思與自嘲（莞爾），第 24 題要接的就是這股語氣。
@know 嘉義舊監獄
- 位於嘉義市區，興建於日治時期，是臺灣保存相當完整的日治時期監獄建築，現為國定古蹟，並設有「獄政博物館」供民眾參觀。
- 建築以「中央台」（中央監視塔）為核心，舍房呈放射狀向外延伸，管理者在中央即可監看各條舍房走道；舍房等建築大量使用檜木，所以文中說「檜木的豪華氣味」。
- 對嘉義的考生來說，這是一篇寫在地景點的文章；閱讀時若有實地參觀的經驗，更容易想像文中的空間。
@know 「全景敞視」是什麼
- 「全景敞視監獄」（Panopticon，又譯圓形監獄）是十八世紀英國哲學家邊沁提出的監獄構想：囚室環繞四周，中央設一座瞭望塔，少數管理者就能看見所有囚犯；囚犯卻看不到塔裡的人，不知道自己何時被監視，只好時時自我約束。
- 二十世紀法國思想家傅柯在《規訓與懲罰》中，用這種建築說明現代社會如何透過「被看見」來管理人。
- 文中「為了展現封閉空間與『不自由人』的權力關係」「高高在上的中心」，以及第 24 題 (D)「權力展演場」「被馴化與被控制身體」等語，都來自這一套觀念。
@know 唐太宗的「三鏡」
> 夫以銅為鏡，可以正衣冠；以古為鏡，可以知興替；以人為鏡，可以明得失。
- 出自《舊唐書‧魏徵傳》，是魏徵去世後唐太宗感嘆失去一面鏡子的話。
- 本文省去「以銅為鏡」，另加一句「以監獄為鏡，可知自由之可貴」，屬於{k:仿擬}（套用名句的格式而翻出新意）。
- 相關成語：{k:以古為鑑}、{k:前車之鑑}、{k:殷鑑不遠}——「鑑」就是鏡子，引申為可供警惕、借鏡的事。

@know 拆字說理：「非的上頭有個四」
- 「罪」字上半是「罒」（形似「四」），下半是「非」，所以作者說「非的上頭有個四」，再把「四非」解釋為四種不該做的事。這種把字拆開來發揮的手法，修辭學稱為{k:析字}。
- 佛教以殺生、偷盜、邪淫、妄語為四種根本大戒，一般簡稱「殺、盜、淫、妄」；原卷作「忘」，疑為同音誤植。
- 「諸惡莫作，眾善奉行」也是佛教常用語，下接「自淨其意，是諸佛教」。
- 其他常見的拆字說法：人言為「信」、止戈為「武」、心上一把刀是「忍」、人在草木間是「茶」。這些說法有的合乎造字本義（如信），有的只是後人的趣味聯想，寫作時可以借用，考六書時則要以字源為準。
@know 「贖罪券」的典故
- 歐洲中世紀後期，教會發行「贖罪券」，宣稱信徒購買後可以減免罪罰。
- 一五一七年，德國神學家馬丁‧路德發表〈九十五條論綱〉抨擊販售贖罪券的做法，揭開{k:宗教改革}的序幕。
- 作者站在曾經供奉神明的監視塔裡，聯想到「神已遠去」「贖罪券是否仍有效」，是借西方宗教史的典故，對「懺悔能否真的贖罪」開了一個帶著自嘲的玩笑，所以說「不禁自我莞爾」。
