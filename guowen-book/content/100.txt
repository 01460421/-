→ 聲符同≠讀音同
@opt A

@note blue
妣＝亡母；仳離＝離異
@opt B

@note blue

@opt C

@note purple

@opt D

@note red
同讀ㄙㄨˋ ✓
蔌＝蔬菜（〈醉翁亭記〉）
@cols 1
@key
妣ㄅㄧˇ／仳ㄆㄧˇ、涇ㄐㄧㄥ／逕ㄐㄧㄥˋ、柝ㄊㄨㄛˋ／坼ㄔㄜˋ 都不同音；只有「簌」「蔌」同讀ㄙㄨˋ。
@logic
1. 【審題】「兩兩相同」是指每組的前後兩字同音；聲母、韻母、{k:聲調}三者都要一樣才算。
2. 【看出命題手法】四組都是「聲符相同的形近字」：比（妣／仳）、巠（涇／逕）、斥（柝／坼）、欶（簌／蔌）。命題者就是要考「{k:有邊讀邊}會不會出錯」。
3. 【逐組標音】(A) 一讀ㄅ、一讀ㄆ；(B) 一聲與四聲之別；(C) 聲母韻母全不同；(D) 皆為ㄙㄨˋ。
4. 【結論】選 (D)。若對「蔌」不熟，可由課文〈醉翁亭記〉「山肴野蔌」回想讀音。
@ana A x
如喪考「{k:妣}」：妣，ㄅㄧˇ，對已故母親的稱呼；「考」是已故的父親。成語形容像死了父母一樣悲痛，語出《尚書‧舜典》「百姓如喪考妣」。
夫妻「{k:仳}」離：仳，ㄆㄧˇ，分別。「仳離」原指分離，後多指夫妻離異，語出《詩經‧王風‧中谷有蓷》「有女仳離」。
→ ㄅㄧˇ ≠ ㄆㄧˇ（聲母不同）。
@ana B x
「{k:涇}」渭分明：涇，ㄐㄧㄥ，涇水。涇水流入渭水時清濁不相混，比喻界限清楚、是非分明。
大相「{k:逕}」庭：逕，ㄐㄧㄥˋ，小路；庭，堂前的院子。比喻兩者相差極遠，語本《莊子‧逍遙遊》「大有逕庭，不近人情焉」。
→ ㄐㄧㄥ ≠ ㄐㄧㄥˋ（聲調不同）。這一組最容易被誤判為同音。
@ana C x
朔氣（傳）金「{k:柝}」：柝，ㄊㄨㄛˋ，古代巡夜打更用的木梆。語出〈木蘭詩〉「朔氣傳金柝，寒光照鐵衣」，指北方的寒氣中傳來打更聲。
天崩地「{k:坼}」：坼，ㄔㄜˋ，裂開。形容重大的變故或巨大的聲響。
→ ㄊㄨㄛˋ ≠ ㄔㄜˋ。兩字右旁同為「斥」，一從木（木梆）、一從土（地裂），以部首辨義。
@ana D o
「{k:簌}」簌流淚：簌簌，ㄙㄨˋ ㄙㄨˋ，紛紛落下的樣子，如「簌簌淚下」。
山肴野「{k:蔌}」：蔌，ㄙㄨˋ，蔬菜。語出歐陽脩〈醉翁亭記〉「山肴野蔌，雜然而前陳者，太守宴也」，指山中的野味與野菜。
→ 同讀ㄙㄨˋ，為正解。
@trap
(B)「涇／逕」只差聲調，快速默唸時最容易漏看。字音題的「相同」包含聲調；凡是「只差一個聲調」的選項，要特別放慢確認。另外，(C)「朔氣金柝」在原詩中作「朔氣傳金柝」，原卷少一「傳」字，不影響作答。

3. 【刪去】(B) 遞嬗（女部，更替）／獨擅（手部，專擅）；(C) 冤枉（木部）／罔顧（网部）；(D) 耳濡（水部，沾染）／儒雅（人部）。部首不同，字自然不同。

→ 兩者皆為「幅」，且都由「布帛寬度」的本義引申而來，為正解。
@ana B x

獨「{k:擅}」勝場：擅，獨攬、專長。「獨擅勝場」比喻技藝高超，獨占優勢。
→ 嬗 ≠ 擅。
@ana C x
冤「{k:枉}」好人：枉，本義為彎曲，引申為冤屈、使人受屈。

@ana D x

=== Q 3
@type 成語運用（語境與褒貶）
@cat 詞語成語
@tags 成語, 望文生義, 褒貶義
@diff 3
@answer B
@stem
下列「 」中的成語，何者{y:使用最恰當|兩個成語都要對}？
@note red
每句有{c:兩個}成語，一個錯就刪
@opt A
他最近狀況不佳，面對接連幾次考試都「{x:屢試不爽}」，只好「坐以待斃」了
@note blue
爽＝差錯
屢試不爽＝每次試驗都靈
@opt B
他做事公正負責，為人「{g:嶔崎磊落}」、「{g:行不由徑}」，博得眾人的讚譽
@note red
人品高潔＋光明正大 ✓
與「讚譽」呼應
@opt C
地震引發海嘯，造成了「摧枯拉朽」的破壞力，令人「{x:嘆為觀止}」
@note blue
嘆為觀止＝讚美！
不可用於災難
@opt D
皇室的世紀婚禮正「緊鑼密鼓」展開籌備活動，人民也隨著「{x:沾沾自喜}」
@note blue
沾沾自喜＝自鳴得意（貶）
@key
「嶔崎磊落」形容人品高潔有骨氣，「行不由徑」比喻行事光明正大，與「公正負責、博得讚譽」的語境完全相合。
@logic
1. 【審題】每個選項有兩個成語，必須{k:兩個都恰當}才能選；找到一個誤用即可刪去。
2. 【抓望文生義】(A)「屢試不爽」的「爽」是「差錯」，不是「爽快」；「試」是試驗，不是考試。整個成語是「屢次試驗都沒有差錯」，句中卻當成「屢次考試都不順利」。
3. 【抓褒貶錯置】(C)「嘆為觀止」是讚美所見事物好到極點，不能用於災難；(D)「沾沾自喜」是自以為了不起而得意，帶貶義，不能形容人民同感歡欣。
4. 【確認正解】(B) 兩個成語皆為褒義，且與上下文「公正負責」「讚譽」一致。
@ana A x
「{k:屢試不爽}」：爽，差錯。指屢次試驗，結果都相同、沒有差錯，如「這個方法屢試不爽」。句中用來表示「考試屢屢失利」，是把「試」解為考試、「不爽」解為不順利的望文生義，應改為「屢戰屢敗」「連連失利」。
「坐以待斃」：坐著等死，比喻面臨危難而不積極設法。用在考試失利也嫌過重，可改為「束手無策」。
@ana B o
「{k:嶔崎磊落}」（ㄑㄧㄣ ㄑㄧˊ ㄌㄟˇ ㄌㄨㄛˋ）：原形容山勢險峻多石，比喻人品高潔、有骨氣。《儒林外史》第一回即以「嶔崎磊落」形容王冕。
「{k:行不由徑}」：徑，小路。走路不抄小路，比喻行事光明正大、不投機取巧。語出《論語‧雍也》，子游稱讚澹臺滅明「行不由徑，非公事，未嘗至於偃之室也」。
兩者皆為褒義，使用恰當。
@ana C x

@ana D x

@trap

@type 詠物小詩的意象判讀
@cat 詩詞曲賞析
@tags 新詩, 詠物, 譬喻, 雙關
@diff 2
@answer D
@stem
(甲)、 「{y:懸空的|吊在半空}／{c:神經}／{g:拉扯兩岸|連接兩端}／真實的／風景」
(乙)、「這裡{y:我最大}／管你{b:大車小車黑頭車}／都要{g:看我眼色|燈號的「顏色」}」
以上兩首詠物詩，請斟酌所歌詠對象的特色、性質的描寫，依(甲)、(乙)序選出最適切的選項：
@note red
詠物詩＝{c:猜謎}
找「形狀＋位置＋功能」
@note green
甲：懸空＋細長＋兩岸
→ 吊橋
@note green
乙：指揮所有車輛＋「眼色」雙關 → 紅綠燈
@opt A

@opt B

@opt C

@note blue

@key
「懸空」「拉扯兩岸」是吊橋的形貌與功能；「車輛都要看我眼色」以「眼色」雙關燈號顏色，寫的是紅綠燈。
@logic
1. 【把詠物詩當謎語】詠物詩不直說名稱，而是描寫物的{k:形狀、位置、功能}。先圈出每首詩的關鍵特徵。
2. 【解甲詩】「懸空的」→ 吊在半空；「神經」→ 細長、繃緊的線狀物（譬喻）；「拉扯兩岸」→ 兩端固定在兩岸。三個條件同時成立的只有吊橋。
3. 【解乙詩】「這裡我最大」「都要看我眼色」→ 能指揮所有車輛；「眼色」表面是「看人臉色」，實指燈號的「顏色」。答案是紅綠燈。
4. 【結論】甲＝吊橋、乙＝紅綠燈，選 (D)。兩首可互相驗證：只要確定其中一首，就能刪去其他選項。
@ana A x
渡船雖往來兩岸，但浮在水面，不是「懸空」，也不會同時「拉扯」兩岸。人行道供行人行走，不能叫車輛「看眼色」。
@ana B x
搖籃或許懸吊，卻與「兩岸」「風景」無關。斑馬線雖然也要求車輛禮讓，但它畫在地面、沒有「顏色變化」，無法呼應「眼色」的雙關。
@ana C x
鐘擺懸空擺動，但只有一端固定，談不上「拉扯兩岸」。安全帶在車內約束乘客，並不管「大車小車黑頭車」的行止。
@ana D o
吊橋以鋼索懸在半空，兩端繫於兩岸，像一條繃緊的神經把兩邊的風景「拉」在一起；紅綠燈立在路口，不論什麼車都得依它的燈「色」行止。兩者皆吻合，為正解。
@know 讀懂這兩首小詩的修辭
| 詩句 | 修辭 | 說明 |
| 懸空的／神經 | 譬喻（隱喻） | 以「神經」比喻細長、繃緊、敏感的吊橋 |
| 拉扯兩岸／真實的／風景 | 轉化（擬人） | 橋本是靜物，卻說它主動「拉扯」兩岸 |

| 都要看我眼色 | 雙關 | 「眼色」既指臉色示意，又指紅、黃、綠的燈色 |
| 大車小車黑頭車 | 類疊、借代 | 「黑頭車」借指有權勢者的座車——連權貴也得聽它的 |
@know 雙關的三種類型
| 類型 | 說明 | 例子 |
| 字音雙關 | 利用同音或近音字 | 「東邊日出西邊雨，道是無晴卻有晴」（晴／情，劉禹錫〈竹枝詞〉） |
| 詞義雙關 | 一個詞同時兼有兩種意思 | 本題「看我眼色」（臉色／燈色） |
| 句義雙關 | 整句話表面一義、實際另有所指 | 朱慶餘〈近試上張水部〉「畫眉深淺入時無」（表面問妝容，實問文章合不合考官心意） |

- 古典詠物詩多「{k:託物言志}」；現代詠物小詩則常以新鮮的譬喻、雙關製造趣味，解題時都要先抓住物的特徵。
@know 轉化的三種類型
| 類型 | 說明 | 例句 |
| 擬人（物 → 人） | 把物當作人來寫，賦予人的動作、情感 | 本題「拉扯兩岸」「這裡我最大」；龔自珍「落紅不是無情物，化作春泥更護花」 |
| 擬物（人 → 物） | 把人當作物來寫 | 白居易〈長恨歌〉「在天願作比翼鳥，在地願為連理枝」 |
| 形象化（抽象 → 具體） | 把抽象的情思寫成看得見、摸得著的東西 | 李清照〈武陵春〉「只恐雙溪舴艋舟，載不動許多愁」 |
- 轉化與譬喻的差別：譬喻有「喻體」與「喻依」兩個事物（吊橋像神經）；轉化只有一個事物，直接把它{k:當成}另一類來描寫（吊橋會拉扯）。

@adv 進階辨析：意象、譬喻與象徵
| 概念 | 說明 | 例子 |
| 意象 | 「意」是情思，「象」是具體物象；詩人把情思寄託在物象上 | 余光中〈鄉愁〉以郵票、船票、墳墓、海峽四個意象寫鄉愁 |
| 明喻 | 喻體＋喻詞（像、如、似）＋喻依 | 鄭愁予〈錯誤〉「你底心如小小的寂寞的城」 |
| 隱喻（暗喻） | 喻詞改用「是、為、成了」 | 徐志摩〈再別康橋〉「那河畔的金柳，是夕陽中的新娘」 |
| 略喻 | 省略喻詞，喻體與喻依直接並列 | 「歲月，一把無情的刻刀」 |
| 借喻 | 只出現喻依，喻體、喻詞都省略 | 本題甲詩通篇不提「吊橋」，只說「懸空的神經」；《論語》「歲寒，然後知松柏之後凋也」以松柏借喻君子 |
| 象徵 | 以具體事物代表抽象觀念，通篇貫串，不必有喻詞 | 周敦頤〈愛蓮說〉以蓮象徵君子 |

@adv 進階演練（本書自編）：詠物小詩
- 題目：「把黑夜／一口一口／吃成光亮／自己／卻越來越矮」這首詠物小詩所寫的對象最可能是：(A) 月亮　(B) 蠟燭　(C) 鬧鐘　(D) 路燈
- 答案：(B)
- 解析：「把黑夜吃成光亮」表示它在夜裡發光；「自己卻越來越矮」是關鍵——發光的同時自身不斷消耗、變短，只有蠟燭符合。月亮有圓缺而非變矮；路燈發光但不會變矮；鬧鐘與光亮無關。全詩以擬人手法（吃）寫燃燒，並暗含「犧牲自己、照亮別人」的寓意，與李商隱「蠟炬成灰淚始乾」相通。

=== Q 5
@type 題辭的對象與場合
@cat 語文應用
@tags 題辭, 應用文, 婚嫁慶弔
@diff 4
@answer C
@stem
下列「 」內的常用題辭，{y:用法完全正確|兩個都要對}的選項是：
@note red
題辭兩查：
①{c:賀或輓}？②{c:對象}對不對？
@opt A
「雀屏妙選」、「之子于歸」－祝賀嫁女

@opt B

@opt D
「{x:福壽全歸}」{n:輓辭}、「松柏長青」－賀男子壽誕
@note blue

@cols 1
@key
(B) 誤把賀嫁女的「宜其室家」用於新居、(D) 混入輓辭「福壽全歸」；本書所採解答版本為 (C)，與 (A) 的爭議見易錯提醒。
@logic
1. 【審題】「完全正確」表示兩則題辭都必須符合破折號後的場合。題辭題的基本檢查是：①它是{k:慶賀}還是{k:哀輓}？②適用的{k:對象、場合}是否相符？
2. 【先刪確定錯的】(D)「福壽全歸」的「歸」是歸去、去世，為輓高壽者之辭，絕不可賀壽；(B)「宜其室家」出自《詩經‧桃夭》，是賀女子出嫁之辭，與新居無關。兩項確定錯誤。
3. 【比較 A、C】(A)「雀屏妙選」「之子于歸」在常見的題辭分類表中都列於「賀嫁女」；(C)「絃歌不輟」是賀學校、教育界的用語，「德業永昭」則須斟酌——辭典所收的近似詞「德業長昭」多用於男喪哀輓。
4. 【結論】本書依所採用的解答版本作 (C)；學校原始答案卷此題標示為 (A)。兩者的依據請對照「選項詳解」與「易錯提醒」，重點是學會判斷的方法。
@ana A o
「{k:雀屏妙選}」：典出《新唐書‧后妃傳》——竇毅為女兒擇婿，在屏風上畫孔雀，約定射中孔雀眼睛者許婚，李淵（後來的唐高祖）兩箭各中一目而中選。後以「雀屏中選」指被選為女婿，「雀屏妙選」則稱美女方擇得佳婿，一般題辭表列於「賀嫁女」。
「{k:之子于歸}」：語出《詩經‧周南‧桃夭》「之子于歸，宜其室家」。之子，這位女子；于歸，出嫁。為最常見的賀嫁女題辭。
就通行的題辭分類而言，兩者用於「祝賀嫁女」皆無誤。
@ana B x
「里仁為美」：語出《論語‧里仁》「里仁為美，擇不處仁，焉得知」，原指居住在有仁德風氣的地方才好，題辭用於{k:賀遷居}，與居室相關，尚屬可通。
「{k:宜其室家}」：與「之子于歸」同出《詩經‧桃夭》，指女子出嫁後能使家庭和順，是{k:賀嫁女}之辭。把「室家」望文生義當成「房屋」而用來賀新居，錯誤。賀新居落成應用「美輪美奐」「堂構更新」等。
@ana C o
「{k:絃歌不輟}」：絃歌，依琴瑟而歌詠，指禮樂教化；輟，停止。孔子弟子子游治理武城，以禮樂教民，孔子到武城時「聞弦歌之聲」（《論語‧陽貨》）。後用來稱頌學校教育綿延不絕，是賀學校、賀校慶的常用題辭，用法正確。
「{k:德業永昭}」：字面意思是「德行與功業永遠昭著」。須留意的是，教育部《重編國語辭典》未收「德業永昭」，所收的是「{k:德業長昭}」，釋為「形容德澤功業永垂不朽，後多用為男喪哀輓之辭」。本書採用的解答版本以本項為正解，是就「德業永昭」的字面義，視為稱頌學校德業之語；若依辭典「德業長昭」的用法，則本項含有哀輓語而不宜賀校慶。
@ana D x
「{k:福壽全歸}」：歸，指去世。稱年高有福者得享天年而善終，是{k:輓高壽者}的題辭，絕不可用於祝壽。
「松柏長青」：比喻壽如松柏、長青不衰，是賀（男）壽的題辭，用法正確。
一輓一賀，本項錯誤。
@trap

@logic
1. 【先攻有典故的空格】第三格前有「女媧煉石也無法彌補」。女媧煉五色石是為了{k:補天}，所以被補的東西必須是「天的裂口」→「天裂」。光憑這一格即可鎖定 (C)。
2. 【用搭配驗證第二格】修飾「白雲」：悠悠（悠遠、飄浮自在）最自然，崔顥〈黃鶴樓〉有「白雲千載空悠悠」。皎皎多形容月光，澄澄形容水或天色清澈，迢迢形容路途、星河遙遠。
3. 【用語境驗證第一格】「露出一塊□□的空白」：原本三棵並立的柏樹少了中間一棵，留下突兀的缺口。「楞楞」（同「愣愣」）把空白寫得像人發呆一樣，直挺挺、空蕩蕩。漫漫（無邊無際）與「一塊」矛盾；盈盈（充滿、清澈）與「空白」矛盾。
4. 【回讀全句】楞楞的空白 → 悠悠白雲 → 無法彌補的天裂：由眼前的缺口，推到天上的裂痕，再暗指好友逝去後{k:心中永遠補不回的缺憾}。答案 (C)。
@ana A x
漫漫：長遠、無邊無際，如「長夜漫漫」，與量詞「一塊」不合。皎皎：潔白明亮，多形容月光、星光，如「皎皎河漢女」。光輝：與「女媧煉石」「彌補」完全無法搭配——光輝不需要彌補。
@ana B x
盈盈：充滿、清澈或儀態美好的樣子，如「盈盈一水間」，用來形容「空白」自相矛盾。澄澄：清澈明淨，常形容水色、天色，不用於白雲。坎坷：道路不平，比喻不得志，也不是女媧所補之物。
@ana C o
楞楞：呆愣、突兀的樣子，寫出缺口空蕩蕩立在眼前的感覺。悠悠：悠遠飄浮的樣子，為白雲的習慣搭配。天裂：呼應女媧補天的神話，把樹間的缺口提升為「連神話中的補天之石也補不了」的缺憾。三者皆合，為正解。
@ana D x
淒淒：淒涼悲傷，直接點明情緒，反而不如「楞楞」含蓄傳神。迢迢：遙遠的樣子，如「迢迢牽牛星」，不形容白雲的姿態。縫隙：雖可「彌補」，但格局太小，撐不起「女媧煉石」這樣的大典故；且前文稱「一道」，是天上的一道裂痕。
@trap
(D) 的「淒淒／縫隙」乍看也通，是本題最強的誘答。破解關鍵有二：其一，「女媧煉石」是補天的專屬典故，後面接「縫隙」屬{k:大典小用}；其二，「迢迢白雲」不成搭配。填空題只要有一格確定不合，就應整組刪去。
@know 作品背景：白先勇〈樹猶如此〉

=== Q 7
@type 格言短句的涵義推論
@cat 白話閱讀
@tags 格言, 反諷, 自省, 木心
@diff 3
@answer B
@stem
「{y:沒有自我|缺乏自省}的人的{c:自我感覺}都特別{u:良好}。」(木心《十朋之龜》)
這句話的涵義與下列何者{y:最接近}？
@note red
兩個「自我」意思不同！
前＝獨立思考、自省的能力
後＝對自己的評價
@note purple
語氣：{c:反諷}
→ 反過來想：要有自省力，才看得見缺點
@opt A
能知足的人，常保快樂不自私自利
@opt B
要有{g:反省力}，方可{g:看見自己的缺失}
@note red
把原句「反過來說」✓
@opt C
不心存成見，才能夠無入而不自得
@note blue
把「沒有自我」誤當成褒義的「無我」
@opt D
能破除私慾，服務眾人才感到心安
@note blue
「沒有自我」≠「無私」
@key
「沒有自我」指缺乏自省與獨立思考；這種人看不見自己的不足，才會「自我感覺良好」。反面立說即 (B)：有反省力才能看見缺失。
@logic
1. 【拆關鍵詞】句中出現兩次「自我」。前一個「自我」是名詞，指{k:獨立的人格、清醒認識自己的能力}；後一個「自我感覺」是對自己的主觀評價。
2. 【判斷語氣】「特別良好」不是稱讚，而是{k:反諷}：正因為沒有能力檢視自己，才會覺得自己樣樣都好。
3. 【換句話說】原句＝「不會反省的人，看不到自己的缺點」。把它反過來說＝「懂得反省的人，才看得見自己的缺點」。
4. 【比對選項】(B) 正是原句的反面立說。(A) 談知足、(C) 談不存成見、(D) 談無私，都把「沒有自我」讀成了褒義，方向相反。
@ana A x
原句談的是「能否認識自己」，與「知足」「自私與否」無關。「自我感覺良好」在句中是被嘲諷的對象，不是「常保快樂」的正面狀態。
@ana B o
「沒有自我」者缺少反省力，所以「感覺良好」；反過來說，具備反省力的人才能看見自己的缺失。與原句涵義最接近，為正解。
@ana C x
「無入而不自得」語出《中庸》「君子無入而不自得焉」，指君子無論處於什麼境遇都能安然自在，是修養有成的境界。原句的「自我感覺良好」卻是盲目的自滿，兩者一褒一貶。此項把「沒有自我」誤解為「不存成見、放下我執」。
@ana D x
此項把「沒有自我」理解為「破除私慾、無私奉獻」，但原句的「沒有自我」是貶義（沒有主見、不會自省），並非道德上的無私。
@trap
最大的陷阱是把「沒有自我」讀成佛、道思想中正面的「無我」「忘我」，因而選 (C) 或 (D)。判斷的線索在後半句——「自我感覺都特別良好」是當代口語中帶有{k:嘲諷}意味的說法，可知全句是批評而非讚美。

| 步驟 | 做法 | 本題應用 |

@know 「自知」主題的名言

@adv 進階辨析：倒反、反諷與矛盾語
| 手法 | 特徵 | 例子 |
| 倒反 | 一句話的字面意思與真意恰好相反 | 朱自清〈背影〉：「那時真是太聰明了！」 |
| 反諷 | 表面的陳述（或情節）與實際情況有落差，藉此達到諷刺效果；不一定是「反話」 | 本題：沒有自我的人，卻「自我感覺良好」；《儒林外史》胡屠戶對女婿范進中舉前後的兩副嘴臉 |
| 矛盾語（悖論） | 把兩個看似衝突的概念放在一起，表面矛盾，實則含有深意 | 《老子》「大音希聲，大象無形」；成語「大智若愚」「欲速則不達」 |

- 學測考短句涵義時，常要求先辨認語氣（正說、反說、諷刺），再選出「意旨相近」的名句。語氣判斷錯誤，整題就會選到相反的方向。

@adv 進階演練（本書自編）：名句意旨對應
- 題目：《老子》：「自見者不明，自是者不彰。」這兩句話所要告誡的道理，與下列何者最接近？(A) 滿招損，謙受益　(B) 學而不思則罔　(C) 工欲善其事，必先利其器　(D) 歲寒，然後知松柏之後凋也
- 答案：(A)
- 解析：「自見」是自我表現，「自是」是自以為是；老子認為這樣的人反而不能明達、不能顯揚，重點在告誡人{k:不可自滿自是}。(A)「滿招損，謙受益」（《尚書‧大禹謨》）指自滿招致損害、謙虛得到益處，意旨相同。(B) 談學習與思考並重；(C) 談做事前要先準備好工具；(D) 談逆境見節操，皆與自滿無關。

@key
首句與丁是對偶的判斷句，各接一個「而…之」：國家的急務配「俗吏慢之」（丙），天下的大事配「庸君忽之」（甲）；乙戊再接「然後知」收尾。
@logic
1. 【找對偶】首句「教化，國家之急務也」與 (丁)「風俗，天下之大事也」句型完全相同，都是「A，B 之 C 也」的判斷句。兩句後面應各接一個以「而」開頭的轉折句（甲、丙）。所以結構是：首句＋而□ → 丁＋而□。
2. 【定收尾】(乙)「夫惟明智君子」的「夫」是{k:發語詞}，表示另起一層議論；(戊)「深識長慮」是修飾君子的謂語；題末「然後知…」需要一個「有見識的主語」。故「乙戊」必在最後 → 刪 (A)(D)。
3. 【比較 B、C】差別只在甲、丙的位置。「國家」的急務由官吏執行，配「俗吏」；「天下」的大事由君主主持，配「庸君」。由{k:國家→天下、吏→君}，範圍與層級由小而大。故為「丙丁甲」。
4. 【通讀驗證】教化…而俗吏慢之；風俗…而庸君忽之。夫惟明智君子，深識長慮，然後知其為益之大而收功之遠也。文氣順暢，選 (C)。
@ana A x
以 (乙)「夫惟明智君子」開頭，但首句「教化，國家之急務也，」以逗號作結，後面應接轉折的「而…」；且「乙戊」移到前面後，題末「然後知…」失去了主語。
@ana B x
「乙戊」收尾正確，但把「庸君忽之」配教化、「俗吏慢之」配風俗，與原文相反。就文理而言，「國家—吏」「天下—君」的對應更為工整：官吏是具體推行教化的人，君主才是移風易俗、主持天下大事的人。
@ana C o
丙（俗吏怠慢教化）→ 丁（風俗是天下大事）→ 甲（庸君忽視風俗）→ 乙戊（只有明智君子，見識深遠）→ 然後知其益大功遠。前四句兩兩對偶，後三句總結，為正解。
@ana D x
(丁) 緊接首句，使兩個判斷句疊在一起，各自的轉折句（甲、丙）卻被甩到最後，題末「然後知…」前面變成「而俗吏慢之」，語意不通。
@translation
教化，是國家的緊要事務，可是庸俗的官吏卻怠慢它；風俗，是天下的大事，可是昏庸的君主卻忽視它。只有明智的君子，見識深刻、思慮長遠，然後才知道教化與風俗的益處有多麼大、所收的功效有多麼久遠。
@trap
(B) 與 (C) 只差「甲、丙」互換，單看句型兩者皆通，是本題的鑑別點。記住文言對偶句講究{k:層次對應}：國家對天下（小→大）、急務對大事、俗吏對庸君（臣→君）、慢對忽。把同一層級的詞放在一起，順序自然浮現。
@know 文言排序常用的「虛詞路標」

| 夫 | 句首發語詞，引出議論 | 夫惟明智君子…（本題）；夫戰，勇氣也（《左傳》） |

- {k:忽}：忽略、不重視，不是「忽然」。如「忽視」「疏忽」。

@adv 進階演練（本書自編）：文言排序
- 題目：下列是《荀子‧勸學》的一段文字，請依文意選出排列順序最恰當的選項：「積土成山，風雨興焉；／甲、而神明自得，聖心備焉／乙、積水成淵，蛟龍生焉／丙、無以至千里／丁、故不積跬步／戊、積善成德／不積小流，無以成江海。」(A) 乙戊甲丁丙　(B) 乙甲戊丁丙　(C) 丁丙乙戊甲　(D) 戊乙甲丙丁
- 答案：(A)
- 解析：首句「積土成山，風雨興焉」與 (乙)「積水成淵，蛟龍生焉」句型完全相同，必緊接其後。(戊)「積善成德」是條件，(甲)「而神明自得，聖心備焉」是結果，「而」字不能出現在條件之前，故戊在甲前。(丁)「故不積跬步」與 (丙)「無以至千里」合成一句，正好與末句「不積小流，無以成江海」對偶；「故」字表示結論，應在前面三組比喻之後。順序為乙戊甲丁丙。原文先以土、水兩個自然現象起興，再說到人的「積善」，最後以「故」總結——由物到人、由喻到理。

@know 聯綿詞：不能拆開解釋的雙音詞

@ana A o

@translation
信州鉛山縣有一處苦泉，泉水流出來匯成山澗。舀取澗水來熬煮，就會得到膽礬；再烹煉膽礬，就能得到銅；熬煮膽礬的鐵鍋，用久了也會變成銅。
@know 用國中理化讀懂這段話
| 原文 | 科學解釋 |
| 苦泉 | 含有硫酸銅的礦泉水，味苦，故名 |
| 挹其水熬之，則成膽礬 | 加熱蒸發水分，析出藍色的硫酸銅晶體（膽礬）——結晶 |
| 烹膽礬則成銅 | 進一步冶煉，把銅從化合物中還原出來 |
| 熬膽礬鐵釜久之亦化為銅 | 鐵的活性比銅大，鐵與硫酸銅溶液反應，生成硫酸亞鐵與銅，銅附著在鐵鍋表面 |

- 嚴格說，鐵鍋並非整個「變成」銅，而是表面被置換出的銅所覆蓋——古人描述現象，今人解釋原理。

- 題目：沈括《夢溪筆談》：「方家以磁石磨針鋒，則能指南，然常微偏東，不全南也。」關於這段文字，下列敘述最恰當的是：(A) 說明指南針的製法是把磁石磨成細針　(B) 指出磁針所指的方向並非正南，而是略為偏東　(C) 認為磁針偏東是工匠製作不精所造成的誤差　(D) 主張應改良磁針，使其指向正南

@type 尺牘小品的文意與修辭

@key

@logic
1. 【審題】題幹「最不恰當」是否定題，先找三個有依據的敘述。
2. 【讀懂結構】「遊興發不？」（問候）→「雖無錢…然尚有酒、茶、太湖、洞庭」（開出招待清單）→「不大落寞也」（保證不無聊）→「如何？」（徵求意見）。這是一封{k:邀請信}。
3. 【檢查修辭】「一勺水」「一塊石」把大說小，是謙虛又風趣的說法；「酒可醉，茶可飲，水可遊，石可登」句式整齊，是排比。
4. 【找出錯誤】「倒反」是表面意思與真意相反。若「不大落寞」是倒反，真意就成了「會非常落寞」，與前面列舉的種種樂事矛盾，也不合邀請信的目的。(D) 錯，為答案。
@ana A o
「遊興發不」「如何」都是邀約的口吻；「茂苑主人」與「客子」相對，是作者以東道主自居的自稱。茂苑是蘇州一帶的古稱，袁宏道當時在蘇州府吳縣擔任知縣，故自稱「茂苑主人」。敘述恰當。
@ana B o
太湖是煙波浩渺的大湖，洞庭山是太湖中的名山（不是湖南的洞庭湖），作者卻輕描淡寫地說成「一勺水」「一塊石」。把自己轄地的名勝說得很小，是主人的謙詞，也帶著幽默。敘述恰當。
@ana C o

@ana D x
「落寞」是寂寞、冷清。「不大落寞也」承接上文，意思是「（你來這裡）不至於太冷清無聊」，是正面的保證，字面義與真意一致，不是倒反。至於「作者非常落寞、想念」，文中並未以反話表達。敘述不恰當，為答案。
@translation

@trap
(D) 之所以誘人，是因為它「聽起來很有深度」——把平實的話解讀成弦外之音。判斷倒反有一個簡單的檢驗法：把字面意思{k:整個反過來}，看看與上下文是否更通順。本句反過來變成「你來了會很落寞」，顯然不通。另外，(B) 的「洞庭」容易誤以為是洞庭湖；與「太湖」並提、又說「一塊石可登」，可知是太湖中的洞庭山。
@know 倒反、誇飾與謙詞的分辨
| 修辭 | 定義 | 例句 |
| 倒反 | 表面的意思與作者真意相反 | 朱自清〈背影〉：「唉，我現在想想，那時真是太聰明了！」（其實是說自己太不懂事） |
| 誇飾（縮小） | 故意把事物說得比實際小 | 本題「太湖一勺水」「洞庭一塊石」 |
| 誇飾（放大） | 故意把事物說得比實際大 | 李白「白髮三千丈」 |
| 謙詞 | 貶抑自己一方以示客氣 | 寒舍、拙作、薄酒、敝縣 |

@know 文言疑問句末的「不」與「無」
- 「不」置於句末表疑問，通「{k:否}」，讀ㄈㄡˇ：「近歲遊興發不？」；《世說新語》「尊君在不？」（〈陳太丘與友期行〉）。
- 「無」置於句末，也相當於「否、嗎」：白居易〈問劉十九〉「能飲一杯無？」（本卷第 12 題）；朱慶餘「畫眉深淺入時無？」
- 看到句末的「不」「無」「未」加問號，先試著翻成「…嗎？」「…了沒有？」。

=== Q 12
@type 借代修辭（以容器代內容物）
@cat 語文應用
@tags 借代, 修辭, 量詞, 論語
@diff 3
@answer A
@stem
「晚來天欲雪，能飲一『杯』無？」的『杯』原指酒杯，在此則指一杯酒。{y:既為物具，又可指為所承載的東西|容器 → 內容物}。下列詞語中的「」，同樣屬於這種用法的選項是：
@note red
兩個條件都要有：
①本身是{c:器具}
②指的是{c:裡面裝的東西}
@opt A
譬如為山，未成一「{g:簣}」{n:一筐土}。止，吾止也
@note red
簣＝盛土的竹筐
→ 指筐裡的「土」✓
@opt B
為學如不能增廣見聞，則如井底之蛙般，以「管」{nb:竹管本身}窺天
@note blue
管是工具，沒有裝東西
@opt C
當時孔明身邊並無大將，只有一「班」{nb:量詞：一群}文官
@note blue
班不是器具
@opt D
望不見康河的蹤跡，你只能循著那錦帶似的林木想像那一「流」{nb:量詞：一道}清淺
@note blue
借代的是「清淺」（＝水），不是「流」
@cols 1
@key
「簣」是盛土的竹筐，「未成一簣」指只差一筐「土」；和「杯」指杯中的酒一樣，都是以容器代替所盛之物。
@logic
1. 【讀懂定義】題幹給了明確的定義：這個字①本來是{k:器物}，②在句中實際指{k:器物裡承載的東西}。兩個條件缺一不可。
2. 【逐項檢查「是不是器物」】簣（竹筐）、管（竹管）是器物；班（群體）、流（水流）不是器物 → 先刪 (C)(D)。
3. 【再檢查「是否指內容物」】(A)「未成一簣」：堆山只差最後一筐——差的是筐裡的土，不是筐子本身 ✓。(B)「以管窺天」：透過竹管看天，用的就是竹管這個工具本身，沒有內容物 ✗。
4. 【結論】選 (A)。
@ana A o
語出《論語‧子罕》：「譬如為山，未成一簣，止，吾止也；譬如平地，雖覆一簣，進，吾往也。」{k:簣}（ㄎㄨㄟˋ），盛土的竹筐。「未成一簣」是說堆土成山，只差最後一筐土沒有倒上去。「簣」由器具轉指筐中之土，與「一杯」指酒相同，為正解。
@ana B x
「以管窺天」：透過竹管的小孔看天，比喻見識狹小。「管」就是竹管本身，是觀看的{k:工具}，並沒有用來指稱管中承載的東西。
@ana C x
語本《三國演義》第九十五回（空城計）。「班」是計算人群的{k:量詞}，相當於「一群、一批」，本身不是盛裝物品的器具。
@ana D x
語出徐志摩〈我所知道的康橋〉。「流」是計算水流的{k:量詞}，相當於「一道、一條」，不是器具；句中真正運用借代的是「清淺」——以河水「又清又淺」的特徵代替河水本身，屬於「以特徵代本體」。
@translation
白居易〈問劉十九〉：「綠螘新醅酒，紅泥小火爐。晚來天欲雪，能飲一杯無？」
語譯：新釀的米酒還浮著綠色的酒渣，紅泥做的小火爐燒得正旺。天色將晚，看來就要下雪了，能不能來喝上一杯呢？
@trap
(D) 最容易誤選：句中確實有借代，但借代的字是「清淺」而不是引號內的「流」。作答時務必只看{k:引號裡的那個字}是否同時符合「器具」與「指內容物」兩個條件。
@know 借代的常見類型
| 類型 | 例句 | 說明 |

@know 《論語》「為山」章的道理
- 「譬如為山，未成一簣，止，吾止也」：堆山只差一筐土而停下來，是我自己停下來的；「譬如平地，雖覆一簣，進，吾往也」：在平地上即使只倒下第一筐土，只要繼續做，也是我自己在前進。
- 孔子藉此說明：為學的成敗{k:操之在己}，貴在堅持不懈。
- 相關成語「{k:功虧一簣}」出自《尚書‧旅獒》「為山九仞，功虧一簣」，比喻事情只差最後一點努力而未能完成。
@know 量詞的文學效果
- 一般量詞只是計數（一條河、一群官員）；文學語言常選用{k:帶有形象的量詞}：「一流清淺」讓河水有了流動感，「一彎新月」「一葉扁舟」「一泓秋水」同理。
- 徐志摩〈我所知道的康橋〉以穠麗的文字描寫劍橋的自然之美，「康河」即流經劍橋大學的 River Cam；同一題材的詩作是〈再別康橋〉。

@type 六書造字法的判斷

@stem
「古代的野蠻人，因為知識蒙昧的緣故……只好說太陽，就畫太陽（{y:日}字）；要說烏龜，就畫烏龜（{y:龜}字）；要說『歇腳』，就畫{g:一個人靠在樹底下}（休字）；要說『下山』，就畫{g:兩隻腳向下，而旁邊再畫一座山}（降字）；要說『看見』，就在{g:身體之上畫一隻大眼睛}（見字）；要說『救人』，就畫{g:一個人掉在坑裡，兩隻手拉他出來}（丞字，即拯）」(錢玄同《國語羅馬字》)

@key
日、龜是畫出實物輪廓的象形；休（人＋木）、降（阜＋雙足）、見（目＋人）、丞（人＋坑＋雙手）都是合併圖形來表達新意的會意。
@logic
1. 【把例字分兩類】引文前兩例是「說什麼就畫什麼」——{k:一個字畫一個實物}（日、龜）。後四例要表達的是動作或情境（歇腳、下山、看見、救人），無法只畫一個東西，於是{k:把幾個圖形組合起來}。
2. 【對應六書】畫出實物 → 象形；組合兩個以上的形體、會合其意 → 會意。
3. 【檢查有無其他】指事要有{k:抽象的指示符號}（如「上」「下」「本」「刃」上的一點一橫），引文沒有；形聲要有{k:表示讀音的聲符}，引文所描述的六個字都純粹以圖表意，沒有提到聲音。
4. 【結論】只有甲（象形）、丙（會意），選 (B)。
@ana A x
甲（象形）正確；但引文沒有指事的例子。指事是在象形的基礎上加抽象符號或純用符號表示抽象概念，如「上」「下」「本」「末」「刃」。
@ana B o
日、龜 → 象形；休、降、見、丞 → 會意。與引文六個例字完全對應，為正解。
- 休：人倚著樹木休息。
- 降：山阜旁有兩隻向下的腳，表示從高處走下來。
- 見：人的身體上頂著一隻大眼睛，表示看見。
- 丞：人陷在坑中，上方有兩隻手把他拉上來，是「拯」的本字。
@ana C x
引文沒有形聲字。形聲字由「形符（表意）＋聲符（表音）」組成，如「江」「河」「湖」「拯」（从手，丞聲）。注意：後起的「拯」是形聲字，但引文所說的是它的本字「丞」，屬會意。
@ana D x

@trap
「降」字是本題的陷阱。許慎《說文解字》依小篆字形把「降」分析為「从阜，夅聲」的形聲字；但錢玄同這段話描述的是更早的古文字構形——山阜加上兩隻朝下的腳，是標準的會意。題幹問的是「{k:以上引文所舉的例子}」運用了哪些造字法，所以要{k:以引文的描述為準}，不可拿另外背的說法來推翻文本。另外，題幹「那些造字法」的「那」，今日規範用字作「哪」；早期白話文「那」「哪」常通用，照原卷著錄。
@know 六書一覽表
| 六書 | 許慎的定義 | 白話說明 | 例字 |
| 象形 | 畫成其物，隨體詰詘 | 照實物的輪廓畫出來 | 日、月、山、水、龜、馬 |
| 指事 | 視而可識，察而見意 | 用抽象符號，或在象形字上加記號 | 上、下、一、本、末、刃 |
| 會意 | 比類合誼，以見指撝 | 合併兩個以上的字，會合出新意 | 休、明、信、武、森、見 |
| 形聲 | 以事為名，取譬相成 | 形符表意＋聲符表音 | 江、河、拯、問、花 |
| 轉注 | 建類一首，同意相受 | 同部首、意義相通的字互相解釋 | 考、老 |
| 假借 | 本無其字，依聲託事 | 借用同音字來記錄另一個詞 | 令、長 |
- 出自東漢{k:許慎《說文解字‧敘》}。前四種是造字的方法，後兩種是用字的方法（「四體二用」）。
- 象形、指事是不可再拆的「{k:獨體文}」；會意、形聲是由兩個以上部件組成的「{k:合體字}」。
@know 象形、指事、會意、形聲的快速判別
| 問自己 | 是 → | 否 → |
| ① 這個字能拆成兩個以上的字嗎？ | 會意或形聲（看②） | 象形或指事（看③） |
| ② 其中有一個部件表示讀音嗎？ | 形聲（如「問」从口，門聲） | 會意（如「休」人＋木） |
| ③ 它畫的是具體的東西嗎？ | 象形（如「日」） | 指事（如「上」） |
- 常考的易混字：「刃」（刀上加一點指出刀鋒處）是指事；「明」（日＋月）是會意；「聞」（从耳，門聲）是形聲。
@know 錢玄同與漢字改革
- 錢玄同（1887–1939），浙江吳興人，文字音韻學家，新文化運動的健將，曾任教於北京大學、北京師範大學。
- 積極提倡白話文、新式標點、漢字簡化與「國語羅馬字」（用拉丁字母拼寫國語的方案）；本題引文即是他說明「漢字起源於圖畫」的一段話。
- 文學史上的小故事：他曾化名「王敬軒」寫信攻擊新文學，再由劉半農撰文逐一反駁，演出一場「雙簧」以引起社會對文學革命的注意；魯迅開始寫小說，也是受到他的鼓勵（〈吶喊自序〉中的「金心異」即指錢玄同）。

@key
(A)(B)(D) 都是答案藏在問題反面的激問；(C)「不知何處吹蘆管」是真的不知笛聲來自何方，沒有反面的答案，不屬於激問。
@logic
1. 【定義題幹的語氣】「天下哪有學不會的事？」＝「天下沒有學不會的事。」問句只是形式，答案早已確定，而且{k:在問題的反面}。這種設問叫「激問」（反問、反詰）。
2. 【檢驗法】把每個問句改寫成意思相反的直述句，若與作者原意相符，就是激問。
3. 【逐項改寫】(A) 何陋之有 → 一點也不簡陋 ✓；(B) 汝輩焉知 → 你們是不會懂的 ✓；(D) 愁何在 → 憂愁全都不見了 ✓；(C) 不知何處吹蘆管 → 「知道何處吹蘆管」？不通。它只是說不曉得笛聲從哪裡傳來。
4. 【結論】(C) 不是激問，為答案。
@ana A o

@ana B o
《三國演義》第九十五回空城計，司馬懿見城門大開，疑有埋伏，對主張進攻的部下說的話。「焉」是「哪裡、怎麼」；「汝輩焉知」＝你們哪裡懂得？→ 你們不懂。屬激問。（通行本原文作「我兵若進，中其計也。汝輩豈知？宜速退。」）
@ana C x

@ana D o

@translation

@trap
(C) 句中有疑問詞「何處」，原卷又加了問號，看起來最像問句，反而最不是激問。判斷設問的類型不能只看有沒有「何」「？」，而要問：{k:作者心裡有沒有答案？答案是不是在反面？}另外，(C)「回樂峰」一作「回樂烽」（烽火臺），兩種版本並行。

## 寫作背景
- 2011 年，美國耶魯大學法學院華裔教授蔡美兒（Amy Chua）出版《虎媽的戰歌》，描述自己以嚴格的「中國母親」方式教養兩個女兒，在美國引發東、西方教養方式的大論戰。王鼎鈞這篇文章即針對此事而發，文中加引號的「中國母親」，指的是這一種{k:嚴格要求、強力介入}的教養類型。

## 讀這段文字的三個重點
- 作者{k:肯定}教育的作用與必要的強制，但用語留有餘地：「較多的」自主能力、「不能完全」委之於春風化雨、比例「因人而異」。
- 「意志」指父母必須堅持到底；「運氣」則承認努力未必有成果。這是{k:務實}的說法，既不神化教育，也不否定教育。
- 兩個反問句（「豈是全無作用？」「又有多大能耐左右環境？」）都是激問，答案在反面：教育有作用；我們難以左右環境。（激問的判斷法見第 16 題）

- 代表作：「人生三書」（《開放的人生》、《人生試金石》、《我們現代人》）、抒情散文集《碎琉璃》、《左心房漩渦》，以及回憶錄四部曲（《昨天的雲》、《怒目少年》、《關山奪路》、《文學江湖》）。

4. 【找出異類】(B) 的重點詞是「堅強實力」。文中從頭到尾沒有談母親的能力、學識或資源；作者甚至說教育稱不上「藝術」，靠的只是意志和運氣——言下之意正是「不靠什麼高明的本事」。(B) 最不適切。
@ana A o
「教育總有方向，總有人為和強制的成分」——母親為子女的教育設定方向並加以引導，可由文意推得。敘述適切。
@ana B x
「貫徹要求子女的學習」需要的是「意志」，原文並未提到「實力」。把「意志」（決心、毅力）替換成「實力」（能力、條件），是典型的{k:偷換概念}。況且篇名為〈「虎媽」的弱勢戰略〉，「弱勢」二字也暗示憑藉的不是雄厚實力。最不適切，為答案。
@ana C o
「孩子不是植物，不能完全委之於春風化雨」「總有人為和強制的成分」，加上「意志」一詞，可推知「中國母親」會強制督促、不放任。敘述適切。
@ana D o
「靠的是意志和{k:運氣}」：付出了意志，結果如何仍有運氣成分；前文也說「教育不能決定一切」。敘述適切。
@trap
(B) 的後半句「貫徹要求子女的學習」完全正確，問題出在前半句的「需有堅強實力」。閱讀題的錯誤選項常常是「{k:半句對、半句錯}」，而且錯的那半句只換掉一個詞。作答時要把選項拆成兩截，分別找原文依據。

@ana A x
原文是「只有教育，{k:我們}有較多的自主能力」——比起無法掌握的遺傳、難以左右的環境，父母在「教育」這一項上比較能作主。「自主能力」的主語是施教的父母，不是受教的孩子。此外，作者強調教育「總有人為和強制的成分」，與「充分尊重孩子自主」的方向也不同。
@ana B x
首句「你可以說…退出競賽…，絕不可以說退出競賽反而可以成為贏家」：作者只是{k:容許}有人選擇退出，並非鼓勵，更反對美化退出。「教育不能決定一切，沒錯」是讓步，緊接著的「但教育又豈是全無作用？」才是作者的重點。
@ana C x

@ana D o

@trap
- (D) 的「扭轉」語氣比原文的「彌補」強一些，有人會因此猶豫。但其餘三項都與原文明顯牴觸，(D) 是唯一方向正確的選項；「正確的選項」未必一字不差，只要是{k:合理的換句話說}即可。
- (A) 是「關鍵詞陷阱」：原文確實出現「自主能力」四個字，但主語被掉包了。看到選項與原文用詞相同時，更要回頭確認{k:是誰的、對誰說的}。
@know 讓步轉折句：重點永遠在後面
| 句型 | 本文例句 | 作者真正的意思 |
| A，沒錯，但 B | 教育不能決定一切，沒錯，但教育又豈是全無作用？ | 教育是有作用的 |
| 可以 A，不可以 B | 你可以說「人生貴適意」…絕不可以說退出競賽反而可以成為贏家 | 退出不等於贏 |
| 若說 A，那也 B | 若說教育子女是藝術，那也陳義過高 | 教育稱不上藝術 |
- 遇到「雖然、固然、誠然、沒錯、的確」等讓步詞，立刻往後找「但是、然而、卻、可是」，{k:轉折之後才是主張}。
@know 成語「春風化雨」
- 語本《孟子‧盡心上》：「君子之所以教者五：有如時雨化之者…」及時的雨水使草木生長，比喻良好教育的感化。今多用來稱頌師長的教誨，也是賀教育界的題辭（見第 5 題）。
- 本文取其「像自然界的風雨一樣，溫和、不加強制地讓孩子自己生長」之意；作者並未否定它，只說「不能{k:完全}委之於」它——因為「孩子不是植物」。
- 這是一組譬喻：把孩子比作植物（被否定的喻體）、把溫和的教育比作春風化雨、把人生比作三角形。

@translation
收藏書畫的人，大多只看重（作者的）虛名，偶然聽說某件作品是鍾繇、王羲之、顧愷之、陸探微的手筆，見到的人就爭相購買，這就是所謂的「耳鑑」——用耳朵來鑑賞。又有人看畫時用手去摸，相傳把「色不隱指」（原卷注：手指能摸得出顏色；一說指顏料平滑、摸起來不硌手）的當作好畫，這種方法又在耳鑑之下，叫做「揣骨聽聲」。
@guide
## 兩種「外行鑑賞法」的比較
| 項目 | 耳鑑 | 揣骨聽聲 |
| 做法 | 聽說是名家手筆就搶著買 | 用手摸畫面，憑觸感判斷好壞 |
| 憑藉的感官 | 耳朵（傳聞、名氣） | 手（觸覺） |
| 問題所在 | 只取「空名」，不看作品本身 | 連名氣都不管，用與繪畫無關的方式評畫 |
| 作者評價 | 不足取 | 「又在耳鑑之下」——更等而下之 |
## 命名的巧思
- 「耳鑑」：鑑賞書畫本應用{k:眼}看、用{k:心}體會，卻用「耳」——兩個字就點出荒謬。
- 「揣骨聽聲」：揣，摸；原是江湖相士替人摸骨、聽聲音以論斷命運的方術。沈括借這個名稱來嘲諷「摸畫的人」：像盲人相士一樣不用眼睛，玄之又玄而不可靠。
## 作者的言外之意
- 沈括在《夢溪筆談》同卷另有名言：「書畫之妙，當以神會，難可以形器求也。」真正的鑑賞要領會作品的神韻，不是靠名氣，更不是靠手摸。這一則短文表面記趣聞，實則批評當時收藏界{k:盲從名氣、不求真知}的風氣，正是沈括實事求是的科學態度。
@know 鍾、王、顧、陸是誰？
| 簡稱 | 人物 | 時代 | 成就 |
| 鍾 | 鍾繇 | 三國魏 | 書法家，擅楷書，與王羲之並稱「鍾王」 |
| 王 | 王羲之 | 東晉 | 人稱「書聖」，代表作〈蘭亭集序〉 |
| 顧 | 顧愷之 | 東晉 | 畫家，傳世摹本有〈女史箴圖〉、〈洛神賦圖〉；時稱才絕、畫絕、癡絕 |
| 陸 | 陸探微 | 南朝宋 | 畫家，與顧愷之並稱「顧陸」 |
- 前兩位是書法家，後兩位是畫家，所以原文說「書畫」、注釋說「書畫家」。
@know 文言字詞：「售」「傳」「鑑」
- {k:售}：今義多指「賣出」；文中「見者爭售」的主語是買家，意思是「爭著買」。文言中「售」可兼指買賣成交，須依主語判斷。
- {k:傳}：傳聞、聽說。「偶傳為…之筆」強調只是傳言，未經查證。
- {k:鑑}：本指鏡子，引申為審察、鑑別，如「鑑賞」「鑑定」「以古為鑑」。

2. 【理解比喻】「揣骨聽聲」原是相士不用眼睛、靠摸骨頭與聽聲音論斷命運的方術。用它稱呼摸畫的人，意思是：鑑賞繪畫不用眼睛看，反而用手摸，{k:玄之又玄、毫無道理}。

@ana B x

@ana D x

## 讀懂「不正而勢傾西北」
- 預浩不是把塔蓋壞了，而是{k:預先計算}：京城（汴京，今河南開封）地處平原，沒有山丘擋風，又常吹西北風。塔身先向西北（迎風面）傾斜，長年受風推擠，就會慢慢被「吹正」。
- 這正是文中「用心之精」的具體表現：好的工匠不只蓋出眼前端正的塔，還把未來百年的環境因素算進去。現代工程中也有預先留出變形量的類似做法。
## 補充史料
- 預浩，史書多作「喻皓」，五代末至北宋初的著名建築工匠。「都料匠」是掌管設計與施工的工匠首領，文中稱「預都料」是以職稱尊稱他。

@logic
1. 【審題】每組前一句出自本文，後一句出自其他名篇，要分別解釋再比較。
2. 【先刪明顯不同者】(A) 地「平」是平坦；「天下之平」是公平的準繩。(D)「行於世」是流傳；「行拂亂其所為」的「行」指所做的事。兩組詞性、意義都不同。

- 一般單選題只有一個答案，但本題 (B)(C) 兩組經逐字檢驗，意義都前後相同：「法」同為準則，「惟」同為只。命題時可能只設定其中一組為答案，閱卷時確認另一組亦無誤，故公布「B 或 C」皆給分。

@opt B

「國朝以來木工，一人而已」把預浩放在整個宋朝的木工之中，斷言只有他一人——是排除了所有其他人的最高評價。
@logic
1. 【審題】四個選項都是正面敘述，題目要比較{k:讚譽的高低}。可從三方面衡量：①稱讚的對象是作品還是人？②範圍是一件事還是一生的成就？③有沒有「最」「唯一」這類排他的字眼？
2. 【逐項定位層級】(A) 讚的是塔（作品）；(B) 讚的是這一次設計的用心（一事）；(D) 說後人都效法他（影響）；(C) 說開國以來的木工只有他一人（地位：唯一）。
3. 【比較】(A)(B) 範圍較小；(D)「為法」雖高，但被奉為準則的人可以不只一位；(C)「一人而已」直接否定了其他所有人，無以復加。
4. 【結論】選 (C)。
@ana A x
「最高」「甚精」形容的是{k:開寶寺塔}，是對作品的客觀描述。雖然間接顯示預浩技藝高超，但稱讚的對象不是人，範圍也限於京城的塔。
@ana B x
「其用心之精蓋如此」是作者對「預留偏移、借風正塔」這件事的評語，稱讚他思慮精細。範圍限於{k:一事一端}，尚未對他的整體成就下定論。
@ana C o
「國朝以來」把時間拉到整個本朝（宋朝開國以來），「木工」涵蓋全體同行，「一人而已」斷言只有他一人稱得上——等於說預浩是{k:本朝第一、無人可比}。這是全文最高的讚譽，為正解。
@ana D x
「至今木工皆以預都料為法」說明他{k:影響深遠}，後世工匠都奉為準則。這是很高的推崇，但它描述的是後人的態度；「一人而已」則是作者直接下的斷語，並且排除了其他所有人，層級更高。
@trap
(D) 是最強的誘答，因為「皆以…為法」也帶有「全體」的意味。兩者的差別在於：(D) 是「大家都學他」——{k:影響力}；(C) 是「只有他一人」——{k:獨一無二的地位}。評價語中若出現「一人而已」「無出其右」「古今第一」這類排他的說法，通常就是最高級。
@know 古人常用的「最高級」讚語
| 說法 | 意思 | 例子 |
| 一人而已 | 只有他一人 | 國朝以來木工，一人而已（本文） |
| 無出其右 | 沒有人能超過他 | — |
| 冠絕一時 | 在當代居於首位 | — |

@know 人物評價的四個層次
| 層次 | 本文句子 | 稱讚的重點 |
| 作品 | 塔在京師諸塔中最高，而制度甚精 | 成品的品質 |
| 才智 | 其用心之精蓋如此 | 思慮與技術 |
| 地位 | 國朝以來木工，一人而已 | 在同行中的排名 |
| 影響 | 至今木工皆以預都料為法；有《木經》三卷行於世 | 對後世的作用 |
- 歐陽脩寫預浩，由作品 → 才智 → 地位 → 影響，層層推高；讀人物筆記或傳記時，可用這四個層次整理作者的評價。
@know 句式：「…而已」
- 「而已」是句末語氣詞，相當於「罷了」，表示{k:限止}（僅止於此）。
- 表限止時可以是貶抑——「口耳之學而已」；也可以是極度推崇——「一人而已」（只有這一位，別無他人）。意義要看前面被限定的內容。
- 同類語氣詞：「耳」「爾」「而已矣」。如「無他，但手熟爾」（〈賣油翁〉）。

=== Q 25
@type 文本詮釋的適切性（否定題）
@cat 文言閱讀
@tags 過度推論, 寫作手法, 否定題
@diff 3
@answer C
@stem
關於本文的詮釋{y:__**最不恰當**__|選「說過頭」的}的選項是：
@note red
否定題！
詮釋題的錯多半是{c:過度推論}
@opt A
由文意推知，預浩的「都料匠」應是擔任建築的設計、和施工指揮
@note green
塔為其「所造」
又能解釋設計構想
@opt B
「塔初成，望之不正而勢傾西北」：作者先設置疑團懸念，揭出預浩構思的高明
@note green
人怪而問之 → 浩曰…
先疑後解
@opt C
「京師地平無山，而多西北風，吹之不百年，當正也」說明預浩也{x:精通氣象}
@note red
原文評語：「用心之精」
懂風向 ≠ 精通氣象
@opt D
「每臥則交手於胸為結構狀，如此逾年」敘述費盡心思，專心研究的精神
@note green
連躺著都在比畫構架
@cols 1
@key
預浩考慮京城的地勢與風向來設計塔身，作者的評語是「用心之精」；說他「精通氣象」是把建築上的周密考量誇大成另一門專業，屬過度推論。
@logic
1. 【審題】否定題。四個選項都是對原文的「詮釋」，要找出推論{k:超出文本}的一項。
2. 【以作者的評語為準繩】預浩那段話之後，作者緊接著評道：「其用心之精蓋如此。」——作者要我們看到的是他{k:設計時思慮周密}。
3. 【檢查 (C)】知道「京師多西北風」是對當地環境的了解，屬於建築設計的考量；「精通氣象」則是指通曉天氣變化的專門學問，文中沒有任何依據。
4. 【確認其餘】(A) 由「所造」及預浩能說明設計原理可推知；(B) 由「人怪而問之」的安排可知是懸念手法；(D) 由「每臥則…如此逾年」可見其專注。三者皆合理。選 (C)。
@ana A o
塔是都料匠預浩「所造」，他能說明塔身傾斜的設計用意，後世木工又奉「預都料」為準則，可推知「都料匠」並非一般工人，而是負責設計並統籌施工的工匠首領。詮釋恰當。
@ana B o
作者先寫名匠所造之塔竟然「不正」，讓人心生疑惑（「人怪而問之」），再由預浩親口說明原因，疑團解開的同時，也凸顯他的深謀遠慮。這是{k:先抑後揚、設置懸念}的筆法。詮釋恰當。
@ana C x
這段話顯示預浩把{k:地勢與風向}納入設計，預留偏移量，是「用心之精」的例證。但了解當地常吹什麼風，只是工匠應有的環境觀察，不能據此說他「精通氣象」。此項把一項設計上的考量誇大為另一門專業的造詣，{k:過度推論}，為答案。
@ana D o
連躺下休息時都把雙手交叉在胸前、比畫房屋構架，而且持續一年多，可見對建築結構的鑽研已到入迷的程度，因而寫成《木經》。選項沒有指明主語，只說這段文字表現了「費盡心思、專心研究的精神」，詮釋恰當。（依文意，「每臥…」的主語承上句，是預浩的女兒。）
@trap
- (C) 之所以迷惑人，是因為它「聽起來很合理」——能算出風把塔吹正，好像真的很懂氣象。判斷過度推論的方法是：{k:回頭找作者自己怎麼說}。作者的結論是「用心之精」，而不是「博學多能」；選項的結論若比作者說得更遠、更大，就要懷疑。
- (D) 的主語容易誤判為預浩本人。原文「世傳浩惟一女，年十餘歲。每臥則交手於胸…」中間沒有換主語，應是指他的女兒。幸好選項並未寫出主語，不影響判斷；但若題目改問「撰成《木經》者是誰」，就必須讀得這麼細。
@know 記敘文的「懸念」手法
| 步驟 | 說明 | 本文 |
| 設疑 | 先寫出違反常理的現象 | 名匠造塔，竟「望之不正而勢傾西北」 |
| 蓄勢 | 讓旁人或讀者提出疑問 | 人怪而問之 |
| 解疑 | 由當事人或作者揭曉原因 | 浩曰：「京師地平無山…當正也。」 |
| 點評 | 以評語點出人物特質 | 其用心之精蓋如此 |
- 國中課文〈賣油翁〉也用同樣的結構：陳堯咨善射而自矜（設疑：賣油翁為何只「微頷之」？）→ 賣油翁酌油（解疑）→「無他，但手熟爾」（點評）。兩篇都出自《歸田錄》，可以對讀。
@know 合理推論與過度推論
| 原文訊息 | 合理推論 | 過度推論 |
| 預浩說京師多西北風，塔會被吹正 | 他設計時考慮了風向與地勢 | 他精通氣象 |
| 至今木工皆以預都料為法 | 他對後世工匠影響很大 | 後世木工都是他的弟子 |
| 塔在京師諸塔中最高 | 這座塔規模宏大 | 這是全國最高的建築 |
- 口訣：推論只能{k:走一步}——從原文往外推一層，而且要能指出依據的句子；若需要再加上原文沒有的假設才能成立，就是過度推論。
@know 科學班視角：預浩的設計思維
- {k:考慮長期作用力}：風對高塔的推力雖小，日積月累卻足以改變塔身的姿態。預浩把「時間」當成設計的參數，是相當先進的工程觀念。
- {k:因地制宜}：「地平無山」表示沒有地形遮蔽，風力直接作用在塔上；設計必須配合當地的地形與氣候。
- 《木經》雖已失傳，沈括在《夢溪筆談》中記下它把房屋分為「上分」（梁以上）、「中分」（地面以上）、「下分」（臺階）三部分，各部分的尺寸彼此成比例——可見當時的營造已有{k:模數化}的觀念。這也是本卷把《歸田錄》與《夢溪筆談》放在同一份考卷裡的巧妙呼應。
