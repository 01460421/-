逐字標音再比
@opt A

@note blue
聲調不同：一聲 vs 三聲
@opt B

@note blue
征辟＝徵召 → ㄅㄧˋ
@opt C
一「幀」{nb:ㄓㄥˋ}照片／國之「禎」{nb:ㄓㄣ}祥
@note blue
ㄥ、ㄣ 要分清楚
@opt D

@note red

同讀ㄍㄨˇ ✓
@key
四組都是「聲符相同的形近字」：扳ㄅㄢ／阪ㄅㄢˇ、癖ㄆㄧˇ／辟ㄅㄧˋ、幀ㄓㄥˋ／禎ㄓㄣ 皆不同，只有罟、詁同讀ㄍㄨˇ。
@logic
1. 【審題】題目比的是「讀音」，而且四組都刻意挑{k:聲符相同}的字（反、辟、貞、古），目的就是引誘你「有邊讀邊」。
2. 【逐字標音】不要憑感覺，在每個字旁邊寫下注音（含聲調）：(A) 一聲／三聲；(B) ㄆ／ㄅ；(C) ㄥ／ㄣ；(D) 皆ㄍㄨˇ。
3. 【抓多音字】「辟」是多音字：作「徵召」解讀ㄅㄧˋ，作「刑法、開闢」解讀ㄆㄧˋ；「征辟」即「徵辟」，指朝廷徵召布衣出來做官，讀ㄅㄧˋ。
4. 【結論】只有 (D) 聲、韻、調完全相同，選 (D)。
@ana A x
「扳」回一城：扳，ㄅㄢ，挽回頹勢。比喻在落後的情況下贏回一局。
「阪」上走丸：阪，ㄅㄢˇ，山坡。在斜坡上滾動彈丸，比喻形勢發展迅速而順利，語出《漢書‧蒯通傳》。
→ ㄅㄢ ≠ ㄅㄢˇ，聲調不同。注意「扳」另有ㄆㄢ一讀（通「攀」），但「扳回」「扳手」「扳機」都讀ㄅㄢ。
@ana B x
特殊「癖」好：癖，ㄆㄧˇ，習性、嗜好（教育部辭典另收又音ㄆㄧˋ）。
舉薦征「辟」：辟，ㄅㄧˋ，徵召。「征辟」同「徵辟」，是漢代由朝廷或官府直接徵召名士任官的選才方式，常與「察舉」並稱。
→ 無論「癖」取哪一讀，聲母都是ㄆ，與ㄅㄧˋ不同。
@ana C x
一「幀」照片：幀，ㄓㄥˋ，量詞，計算照片、字畫的單位。
國之「禎」祥：禎，ㄓㄣ，吉祥、吉兆。《中庸》：「國家將興，必有禎祥；國家將亡，必有妖孽。」
→ ㄓㄥˋ ≠ ㄓㄣ，韻母（ㄥ／ㄣ）與聲調都不同。
@ana D o
牽「罟」捕魚：罟，ㄍㄨˇ，網的總稱。「牽罟」是臺灣沿海傳統的捕魚方式：用小船把漁網拖放到海中，再由岸上眾人合力把網拉回。
訓「詁」之學：詁，ㄍㄨˇ，用當代的話解釋古代的語詞。「訓詁學」是研究古書字詞意義的學問。
→ 同讀ㄍㄨˇ，為正解。
@trap
(C) 的「幀」，許多人口語讀成ㄓㄣ或ㄓㄥ，但教育部《重編國語辭典》標音為ㄓㄥˋ（四聲）；即使讀錯聲調，它與「禎」ㄓㄣ的韻母仍然不同，不影響作答。字音題若沒有十足把握，先找{k:聲母或韻母明顯不同}的選項刪去。

@note red
同音不稀奇，要看{c:寫出來}是不是同一個字
@opt A

@note blue

@note blue

@opt C

@note red

@opt D
事有蹊「ㄑㄧㄠ」{nb:蹺}／「ㄑㄧㄠ」{nb:敲}鑼打鼓
@note blue

@key

@logic
1. 【審題】比的是「字形」。字音既然已經用注音給定，解題動作就是{k:把每個注音寫回國字}。
2. 【以義定形】用成語的意思推國字：「破釜沉舟」是打破「鍋子」、鑿沉船隻；「班門弄斧」是在魯班門前耍「斧頭」；「河清海晏」是黃河水清、大海「平靜」。
3. 【比對】(A) 釜≠斧、(B) 宴≠晏、(D) 蹺≠敲；(C) 兩個都是「瀾」（大波浪）。
4. 【結論】選 (C)。
@ana A x
破「{k:釜}」沉舟：釜，鍋子。秦末項羽與秦軍戰於鉅鹿，渡河後鑿沉船隻、打破鍋甑，以示決一死戰，典出《史記‧項羽本紀》。比喻下定決心、義無反顧。
班門弄「{k:斧}」：班，魯班，古代巧匠。在魯班門前舞弄斧頭，比喻在行家面前賣弄本事、不自量力。
→ 釜 ≠ 斧。
@ana B x
大「{k:宴}」小酌：大桌宴席或小飲淺酌，也形容應酬很多。宴，宴席。
河清海「{k:晏}」：晏，平靜、安和。黃河水清、大海無浪，比喻天下太平，也作「海晏河清」。
→ 宴 ≠ 晏。
@ana C o
波「{k:瀾}」壯闊：瀾，大波浪。原指水面遼闊、波濤洶湧，比喻氣勢雄壯浩大。
力挽狂「{k:瀾}」：狂瀾，洶湧的大浪。語本韓愈〈進學解〉「障百川而東之，迴狂瀾於既倒」，比喻盡力挽回險惡的局勢。
→ 前後皆為「瀾」，正解。
@ana D x
事有蹊「{k:蹺}」：蹊蹺，ㄒㄧ ㄑㄧㄠ，怪異、違背常情，也說「蹺蹊」。
「{k:敲}」鑼打鼓：敲，擊打。敲打鑼鼓，也形容大肆宣揚。
→ 蹺 ≠ 敲。

=== Q 3
@type 錯別字訂正
@cat 形音義
@tags 錯別字, 成語用字, 同音字
@diff 2
@answer D
@stem
下列文句，{y:完全__沒有__錯別字|找「全對」的一句}的是：
@note red
先圈出每句的{c:四字格}，錯字多半藏在裡面
@opt A
這場球賽由於挑戰隊實力堅強，使得衛冕隊{x:殺}{n:鎩}羽而歸
@note blue
鎩＝傷殘；鳥翅受傷
@opt B
他的畫技高超，所畫的花鳥莫不栩栩如生，{x:耀}{n:躍}然紙上
@note blue
像要「跳」出紙面 → 躍
@opt C
做事專挑旁門{x:走}{n:左}道，妄想一步登天者，終必招來災禍
@note blue
左道＝邪道
@opt D
長時間處於下坡行車的時候，千萬不要一直踩著{g:煞車}
@note green
煞車 ✓（亦作「剎車」）
@key
(A) 鎩羽而歸、(B) 躍然紙上、(C) 旁門左道 各錯一字；(D) 沒有成語，「煞車」寫法正確。
@logic
1. 【定位】錯別字題先找{k:成語與固定詞語}：殺羽而歸、栩栩如生、耀然紙上、旁門走道、一步登天、煞車。
2. 【以義辨形】鳥的翅膀「受傷」才飛不高 → 鎩；畫中物像要「跳」到紙上 → 躍；不正派的路叫「左」道。
3. 【確認正解】(D) 是生活化的句子，沒有成語可藏錯字，需檢查的只有「煞車」：教育部辭典「煞車」「剎車」兩種寫法都收，皆正確。
4. 【結論】選 (D)。
@ana A x
「殺」羽而歸 → 「{k:鎩}」羽而歸。鎩，ㄕㄚ，摧殘、傷殘。「鎩羽」指鳥的羽毛殘落、不能高飛，比喻失意或受挫折而回。
@ana B x
「耀」然紙上 → 「{k:躍}」然紙上。躍然，活躍地呈現。形容描寫或刻畫得非常生動逼真，好像要從紙上跳出來。「耀」是光線照射（照耀、耀眼），與此無關。
@ana C x
旁門「走」道 → 旁門「{k:左}」道。「左道」指邪門、不正派的方術，語出《禮記‧王制》「執左道以亂政，殺」。成語指不正派的宗教或學術派別，引申為不正當的方法、途徑。
@ana D o
全句沒有錯別字。「煞車」指使車輛減速或停止的裝置與動作，也寫作「剎車」。長下坡一直踩煞車會使來令片過熱而失靈，應改用低速檔——這句話本身還是正確的行車常識。
@trap
有人看到「煞」字帶有「凶神惡煞」的負面意思，就懷疑「煞車」是錯字，改選別的選項。記住：「煞」有「止住、收束」之義（如「煞尾」「煞住」），「煞車」是標準寫法。
@know 「鎩／剎／煞／霎」辨析
| 字 | 讀音 | 意義 | 例詞 |
| 鎩 | ㄕㄚ | 傷殘；古兵器（長矛） | 鎩羽而歸 |

=== Q 6
@type 文句排序與篇章邏輯
@cat 語文應用
@tags 排序, 關聯詞, 論說文
@diff 3
@answer B
@stem
下列是一段現代散文，請依文意選出{y:排列順序最恰當|找首句、找綁定句}的選項：
@note red
首句是{c:問句} → 下一句要「回答」
@box lines
對民意的批判{y:從哪裡來}？
甲、如果民意指的是大多數人的意見，那麼批判當然得{g:來自少數人}

{c:但是}多數如果踐踏「尊重少數」的原則，它就是{u:另一個形式的暴力集團}，徹底違背了民主的基本精神。（龍應台〈我的十年回首〉）
@note green
甲：直接回答問句 → 首句
@note blue
丁→戊：先講原則，再講原則被遺忘
@note blue
乙→丙：丙的「它」＝多數的暴力
「因為」解釋「隱於無形」
@note red
尾句「另一個形式的暴力」
→ 前面要先談過暴力（乙丙）
@opt A
甲乙丙戊丁
@opt B
甲丁戊乙丙
@opt C
丁乙丙甲戊
@opt D
丁戊乙丙甲
@key
甲回答首句問題；丁→戊（原則→原則被遺忘）、乙→丙（多數暴力隱形→原因）兩組綁定，丙再接尾句「另一個形式的暴力集團」。
@logic
1. 【找首句】開頭是問句「批判從哪裡來？」，甲句「批判當然得來自少數人」直接作答，應緊接其後 → 刪去以丁開頭的 (C)(D)。
2. 【找綁定】丙句以「因為」開頭、用代詞「它」，必須接在某句之後作解釋：乙說多數的暴力「隱於無形」，丙解釋為何隱於無形（批判者自己就在多數之中）→ {k:乙丙}相連。丁提出「服從多數＋尊重少數」的完整原則，戊說後半句「被輕易遺忘」→ {k:丁戊}相連，且丁必在戊前。
3. 【排先後】(A) 把戊放在丁之前，等於先說原則被遺忘、才介紹原則，順序顛倒；(B) 甲（少數人）→丁戊（尊重少數被遺忘）→乙丙（多數成了隱形暴力），層層推進。
4. 【接尾句】尾句「它就是另一個形式的暴力集團」呼應乙句的「威權政府和暴力」，放在乙丙之後最順。選 (B)。
@ana A x
甲後直接接乙，話題從「少數人的批判」突然跳到「威權政府和暴力」，缺少過渡；更大的問題是戊在丁前：戊已經把「服從多數」「尊重少數」當成已知概念來談，丁卻到最後才交代這兩句話的來歷，邏輯倒置。
@ana B o
甲：批判來自少數人 → 丁：民主原則除了服從多數，還有尊重少數 → 戊：近十年後者被遺忘 → 乙：多數的暴力隱於無形 → 丙：因為批判者自己就是多數 → 尾句：多數踐踏少數，就是另一種暴力集團。由「問題—原則—現況—危險—結論」逐步收束，正解。
@ana C x
以丁開頭，首句的提問無人回答；且甲被排到後段，「批判來自少數人」反而成了乙丙之後的補充，文意鬆散。
@ana D x
同樣以丁開頭，未回應首句；又把甲放在最後、緊接尾句「但是多數如果……」，甲談的是「批判的來源」，與尾句的轉折無法銜接。
@know 排序題的四個固定動作
| 步驟 | 作法 | 本題示範 |
| ① 找首句 | 能承接題幹給定的開頭；不含代詞、不以關聯詞起頭 | 問句後接「甲」的回答 |
| ② 找綁定 | 代詞（它、這、此）與關聯詞（因為、但是、所以）一定黏著前一句 | 乙丙（因為、它）；丁戊 |
| ③ 排先後 | 先定義、後評論；先原因、後結果；先一般、後特殊 | 丁（原則）先於戊（被遺忘） |
| ④ 接尾句 | 用題幹給定的結尾檢查最後一句 | 丙（霸道粗暴）→ 暴力集團 |
- 技巧：有兩組「綁定」後，直接看選項中哪一個同時保留這兩組，往往就能秒殺。本題同時含「丁戊」「乙丙」且以甲開頭的只有 (B)。
@know 公民連結：「多數暴力」
- 民主政治以{k:多數決}運作，但若多數人挾人數優勢壓迫少數人的權利，就成了「多數暴力」（或譯「多數專制」）。十九世紀法國思想家托克維爾在《民主在美國》中即提出這項警告。
- 因此現代民主強調「服從多數、尊重少數」，並以憲法保障基本人權，使少數意見有發聲與被保護的空間——這正是龍應台此段文字的論點。
@know 作家小檔案：龍應台
- 1952 年生於高雄。1985 年出版《野火集》，以犀利的社會批評引起廣大迴響；曾任臺北市文化局長、文化部長。
- 代表作：《野火集》、《孩子你慢慢來》、《親愛的安德烈》、《目送》、《大江大海一九四九》。評論文字理性銳利，親情散文則溫柔細膩，兩種筆調都曾入選國、高中教材。

- 「比比」是「處處、每每」之意；「不勝（ㄕㄥ）枚舉」的「勝」是「盡」，指無法一一列舉。
@know 本文的譬喻手法
- 「自我缺陷感的{k:有毒氣體}」：把抽象的心理感受比作無形卻無所不在、不知不覺吸入的毒氣 → 強調它{k:無形、持續、傷害大}。
- 「自我缺憾的{k:鏡頭}」：把看待自己的方式比作相機鏡頭 → 鏡頭一偏，拍出來的整個世界都跟著扭曲。
- 「{k:禁錮}在……迷惘之中」：把心理狀態比作牢籠 → 強調難以脫身。
- 讀說明文時，譬喻往往就是作者對概念下的「形象化定義」，是出題的熱點。
@know 訊息檢核題的定位法
- 第一步：把每個選項濃縮成 2–4 字的「查核點」（時機／影響／價值／能否改變）。
- 第二步：回原文找對應句，在句旁標上選項代號。
- 第三步：判斷是「同義改寫」（○）、「合理推論」（○）、「與原文相反」（✗）還是「原文未提」（✗）。

@ana A o
跬步：半步（跨出一腳為跬，兩腳各跨一次為步）。此句出自〈促織〉篇末作者的評論：「天子偶用一物，未必不過此已忘；而奉行者即為定例。加以官貪吏虐，民日貼婦賣兒，更無休止。故天子一跬步，皆關民命，不可忽也。」意思是皇帝偶然的一點喜好，經下面的人層層奉行、貪虐加碼，就成了百姓的災難。與本文主旨完全相合。
@ana B x
語本《荀子‧王制》：「君者，舟也；庶人者，水也。水則載舟，水則覆舟。」唐人避太宗李世民諱，改「民」為「人」。意在提醒君主：人民能擁戴你，也能推翻你。本文的重點是上位者的嗜好殃及百姓，沒有寫到民心向背或人民反抗，主旨不同。
@ana C x

@ana D x

@trap
(B) 也是批評君主的名言，是本題最具誘答力的選項。區別在於{k:方向}：(A) 是「上 → 下」，君主的行為影響人民；(B) 是「下 → 上」，人民的力量可以顛覆君主。本文只寫到前者。
@know 〈促織〉的完整情節與諷刺

@know 轉折詞後才是重點

@know 篇名與用語的巧思
- {k:長短句}：本是「詞」的別稱（因句子長短不齊；其他別稱還有詩餘、曲子詞、倚聲）。篇名〈手機長短句〉把簡訊裡或長或短的句子比作一闋闋小詞，暗示簡訊也能是抒情的文學。
- {k:從眾如流}：仿擬成語「從善如流」（聽從好的意見像水往下流一樣自然，語出《左傳‧成公八年》），改一字而成自嘲之語。這種修辭叫{k:仿擬}。
- {k:弔詭}：語出《莊子‧齊物論》，原指奇異怪誕之談；今多用來指看似矛盾卻又成立的現象（如「越快速，越遙遠」）。
@know 作家小檔案：楊佳嫻
- 1978 年生，高雄人，詩人、散文家，任教於大學中文系。
- 詩集有《屏息的文明》、《你的聲音充滿時間》、《少女維特》；散文集有《海風野火花》、《雲和》等。作品善於把古典詩詞的語彙融入現代都會的情感經驗，本題「長短句」的用法即是一例。

@know 人物補充
- {k:荀奉倩}：荀粲，字奉倩，曹魏名臣荀彧之子，善談玄理。妻亡後他「不哭而神傷」，一年多後也去世，年僅二十九；後世詩文常以「奉倩神傷」作為悼亡的典故。
- {k:裴令}：一般認為指裴楷，西晉名士，曾任中書令，故稱「裴令公」。
