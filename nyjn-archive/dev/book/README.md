# 《量雨的人》

《重返未來：1999》的二創小說，以司辰的手提箱為敘事者。署名 Omega。體例照《巔峰集》分八卷：散文、語錄、問答、仿古、新詩、小說與戲劇、寓言、書信，前有序，後有後記。八卷各用一種文體，講的是同一段路，從一九八七年的牆外走到一九三五年的山裡。

成品是 `量雨的人.pdf`：A4 橫放的散葉四十九張，一張兩頁、右頁在前，共九十八頁，對摺後可以線裝。

## 重排

```
npm run book            # 等於 node dev/book/build.cjs
node dev/book/build.cjs --cols   # 另外列出每一頁用了幾欄
```

需要 Playwright 的 Chromium，並且連得上 Google Fonts。標題用 `dev/fonts/NiYu-Regular.otf`；內文用芫荽（Iansui，SIL OFL 1.1），芫荽沒有的字（目前只有「蟪」「胔」兩個）以同樣出自 Klee One 的霞鶩文楷 TC 補上。排完會印出字數、頁數、每一篇的起始頁，以及只有三欄以內的頁。

## 稿子的記號

```
=FRONT 標題|副題            序
=VOL 卷次|卷名|體裁|題辭     題辭用 / 換行
=PIECE 標題|副題|體裁        體裁：prose、poem、dialog、koan、play、letters
=BACK 標題                  後記
```

一行是一段。另外有幾個行首記號：

- `***`：分節（印成三個菱形）
- `>`：附註；句末沒有句號的當作落款，排在欄底
- `##`：小題（組詩裡的各首、每一封信的收件人）
- `#`：詩的分節數字
- 問答與戲：`名字｜話`；單獨一行的 `（……）` 是舞台指示
- 語錄：`〔題〕內文`
- 詩：一行一欄，空行分節

## 版式

照原書：每頁十七欄、每欄四十字，內文 11.4pt。每一篇另起一頁；卷首頁獨佔一頁。目錄分上下兩層，頁碼在排完之後才填。

分頁時守幾條規矩：句號、逗號、下引號不落在欄首；小題與分節記號後面至少跟兩欄；詩的一節不留孤行。一篇如果只多出一兩欄而另起一頁，會先試著收緊（拿掉題後的空欄、詩節之間改半欄），收得回來才採用。

## 所本

年份、地點與事件依館內 `assets/js/data.js` 整理的主線（序幕至第十三章）。主線沒有寫的地方不補寫：三場沒有正面描寫的雨、南極神殿裡的對話、維爾汀對瑞安儂說的那句話，書裡都留白。添寫的細節（卡森收行李的次序與那張清單、做傘的人和他的女兒、窗台上的柑橘、虛構集在末頁添的那一行等）在後記裡交代。

非官方、非營利的二次創作；《重返未來：1999》的權利屬於深藍互動（Bluepoch）。
