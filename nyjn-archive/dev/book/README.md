# 《量雨的人》

《重返未來：1999》的二創小說，以司辰的手提箱為敘事者。署名 Omega。體例照《巔峰集》分八卷：散文、語錄、問答、仿古、新詩、小說與戲劇、寓言、書信，前有序，後有後記。八卷各用一種文體，講的是同一段路，從一九八七年的牆外走到一九三五年的山裡。

成品有三份：

| 檔案 | 內容 |
| --- | --- |
| `量雨的人.pdf` | 散葉。A4 橫放四十九張，一張兩頁、右頁在前，共九十八頁；單面印出來，對摺就是一葉 |
| `量雨的人-線裝本.pdf` | 訂好的樣子，給螢幕上翻看用。深色書布、燙金的階梯框與倒著落的雨、行李牌、四眼縫線、包銅的角；內頁照線裝書翻開的順序兩兩相對，版心被摺線分成兩半露在書口。五十二頁：前書衣、五十個對開、後書衣 |
| `量雨的人-書衣與裝訂.pdf` | 動手訂的時候用。前書衣、後書衣各一張（和書葉一樣對摺），加一張裝訂說明 |

另有可編輯的兩份：`量雨的人.docx`（直排的 Word 檔，樣式都有名字）和 `量雨的人.txt`（純文字），由 `python3 dev/book/export.py` 從同一份稿子轉出來，需要 `python-docx`。

一頁一張的 PNG（封面、內文九十八頁、封底，共一百張，打成 zip）由 `python3 dev/book/pages.py` 產生，直接寫到 `book/liangyu-pages-png.zip`；需要 poppler 的 `pdftoppm` 和 ImageMagick。

網站上的下載頁在 repo 的 `book/`：`npm run book -- --publish` 把上面五個檔複製過去（檔名改成英數）。

## 重排

```
npm run book                    # 散葉
npm run book -- --bound         # 線裝本
npm run book -- --kit           # 書衣與裝訂說明
npm run book -- --all           # 三份都做
node dev/book/build.cjs --cols  # 另外列出每一頁用了幾欄
```

需要 Playwright 的 Chromium，並且連得上 Google Fonts。標題用 `dev/fonts/NiYu-Regular.otf`；內文用芫荽（Iansui，SIL OFL 1.1），芫荽沒有的字（目前只有「蟪」「胔」兩個）以同樣出自 Klee One 的霞鶩文楷 TC 補上。排完會印出字數、頁數、每一篇的起始頁，以及只有三欄以內的頁。

## 稿子的記號

```
=FRONT 標題|副題            序
=VOL 卷次|卷名|體裁|題辭     題辭用 / 換行
=PIECE 標題|副題|體裁        體裁：prose、poem、dialog、koan、play、letters
=BACK 標題                  後記
```

一行是一段。另外有幾個行首記號：

- `***`：分節（印成三個菱形）
- `>`：附註；句末沒有句號的當作落款，排在欄底
- `##`：小題（組詩裡的各首、每一封信的收件人）
- `#`：詩的分節數字
- 問答與戲：`名字｜話`；單獨一行的 `（……）` 是舞台指示
- 語錄：`〔題〕內文`
- 詩：一行一欄，空行分節

## 版式

照原書：每頁十七欄、每欄四十字，內文 11.4pt。每一篇另起一頁；卷首頁獨佔一頁。目錄分上下兩層，頁碼在排完之後才填。

分頁時守幾條規矩：句號、逗號、下引號不落在欄首；小題與分節記號後面至少跟兩欄；詩的一節不留孤行。一篇如果只多出一兩欄而另起一頁，會先試著收緊（拿掉題後的空欄、詩節之間改半欄），收得回來才採用。

## 線裝本怎麼排

散葉的一葉對摺之後，前半（原紙的右半）在書翻開時落在左頁，後半落在下一個對開的右頁。所以線裝本裡相對的兩頁，是第二、三頁，第四、五頁……和散葉上同一張紙的兩頁不一樣：目錄、序、後記在線裝本裡都剛好是一個完整的對開。

每一頁其實是同一張「虛擬的紙」被裁成一半來看，框線與版心沿用散葉的樣式，不另外畫。陰影和紙紋都先做成圖檔再貼上去；直接用 CSS 的模糊陰影，Chromium 會把每一頁各存一張整頁的點陣圖，檔案會大到九 MB。

線裝本的扉頁和行李牌上各蓋一枚藍色的郵戳（日期是第一場雨，一九九九年十二月三十一日）；散葉上沒有。

## 樣子

直排、雙框、版心的骨架照原書；裝飾和配色往《重返未來：1999》與館內的調子靠：

- 書衣是深青黑的布，燙金。框是一九二〇年代的階梯角；雨由一條地平線往上落，水滴在上、尖端朝下；題簽做成行李牌，用線繫在第一眼上；四個角包銅，因為敘事者是一只「四個包了銅的角」的箱子。
- 襯頁是書布的反面，滿版的倒雨。
- 內頁的框四角各有一個小小的階梯角；題上的圓點、分節的記號都換成倒著落的雨滴。
- 扉頁與每一卷的卷首頁腳有一行英文：斜體的 IM Fell English 配打字機的 Courier Prime 小字，和館內的拉丁字、標籤同一套。
- 戳記用館內唯一的顏色，藍印 `#22409a`。

## 所本

年份、地點與事件依館內 `assets/js/data.js` 整理的主線（序幕至第十三章）。主線沒有寫的地方不補寫：三場沒有正面描寫的雨、南極神殿裡的對話、維爾汀對瑞安儂說的那句話，書裡都留白。添寫的細節（卡森收行李的次序與那張清單、做傘的人和他的女兒、窗台上的柑橘、虛構集在末頁添的那一行等）在後記裡交代。
