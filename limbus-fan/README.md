# 邊獄巴士乘客手冊

網址：https://limbus-handbook.vercel.app （Vercel 專案 `limbus-handbook`，根目錄是這個資料夾）

《邊獄巴士》（Limbus Company，Project Moon）的非官方、非營利中文同好站。給剛上車的人看的一頁手冊：

- **乘客名冊**：十二位罪人的座位表，點座位看名字的文學出處；車頭是管理人但丁、嚮導維吉里烏斯和司機卡戎。
- **七宗罪**：七種罪的顏色和常搭配的異常狀態，還有一個可以排五格技能、看共鳴的小試驗。
- **路線圖**：序章到第十章、各間章，以及每一章的主角。
- **名字的來歷**：邊獄、但丁、維吉里烏斯、卡戎、梅菲斯托費勒斯、金枝這些名字從哪裡來。
- **車上用語**：二十幾個常見的詞，可以用中文或英文搜尋。
- **上車須知**：第一次玩的人照著走的幾步。

## 檔案

- `index.html`：頁面骨架。
- `assets/data.js`：**所有內容都在這裡**。新章節上線、譯名要改，只改這個檔。
- `assets/app.js`：把資料排上頁面的程式（座位表、共鳴小試驗、路線篩選、辭典搜尋）。
- `assets/emblems.js`：每位乘客的小圖示，照名字出處的作品畫成（翅膀、羽毛筆、風車……）。
- `assets/style.css`：版面。
- `og.png`：分享到社群時的預覽圖。
- `vercel.json`：快取與安全標頭。

沒有建置步驟，也沒有後端：用任何靜態伺服器打開資料夾就能看（例如 `python3 -m http.server`）。

## 資料來源與譯名

- 遊戲沒有官方中文。角色與章節的中文名稱參考玩家自發的翻譯計畫：都市零協會漢化組 LLC（簡體）與 LTM（繁體），轉成繁體字形；文學作品的書名用台灣出版常見的譯名。
- 罪人的號碼照劇情裡的編號：但丁是 10 號，所以辛克萊、奧提斯、格里高爾是 11、12、13 號。
- 章節與上線時間對照了 limbuscompany.wiki.gg、英文維基百科與遊戲新聞；第十章的中文譯名還沒有確定，暫時用英文。
- 七宗罪的顏色是照遊戲的彩虹順序調的近似色，不是官方色碼；罪與異常狀態的搭配寫的是最常見的組合。
