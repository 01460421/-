# 邊獄巴士乘客手冊

網址：https://limbus-handbook.vercel.app （Vercel 專案 `limbus-handbook`，根目錄是這個資料夾）

《邊獄巴士》（Limbus Company，Project Moon）的非官方、非營利中文同好站。每一個房間是一站：

| 房間 | 網址 | 內容 |
| --- | --- | --- |
| 總站 | `#/` | 發車看板、今天的乘客、你的車票、全線路線圖、第一次上車 |
| 乘客名冊 | `#/roster`、`#/sinner/<id>` | 座位表與一覽表；每位乘客的個人頁：在車上的樣子、原著、遊戲怎麼改寫原著、過去、幾個常見的人格 |
| 路線圖 | `#/route`、`#/canto/<n>` | 照季分段的路線；每一章的地點、劇情、和原著的關係、登場的人與勢力 |
| 都市 | `#/city` | 都市的結構、翼（區的看板）、五指、收尾人的等級、協會 |
| 車上用語 | `#/terms`、`#/terms/<id>` | 七十多個名詞，照類別篩、可以搜尋 |
| 書房 | `#/library`、`#/library/<id>` | 十三部原著的書架、每本書的頁面、自己的書單、名字的來歷 |
| 年表 | `#/timeline` | Project Moon 的三部遊戲與《邊獄巴士》的每一季 |
| 拼點教室 | `#/clash` | 照遊戲的規則精確算出拼點的勝率，也可以一枚一枚擲 |
| 乘車測驗 | `#/quiz` | 十道題，每次從資料重新出題 |
| 遊戲車廂 | `#/arcade/…` | 出處配對、章節排序、拼點對決 |
| 車票簿 | `#/tickets` | 印章與成就，可以做成一張車票的圖 |

## 劇透

設定裡選「看到第幾章」。之後章節的劇情、乘客的過去、和原著的對照都會先遮起來，按「仍要顯示」只打開那一段。

## 檔案

- `index.html`：頁首、選單、對話框（搜尋、設定、歡迎）。
- `assets/core.js`：路由、存檔（只在瀏覽器的 localStorage）、劇透閘門、名詞自動連結、印章、搜尋。
- `assets/shell.js`：頁首、選單、搜尋框、設定與第一次來的歡迎卡。
- `assets/rooms/*.js`：每個房間一個檔。
- `assets/data.js`：乘客、章節、七宗罪、名字的來歷、車上用語、上車須知。
- `assets/data/*.js`：`people.js`（個人頁）、`story.js`（各章劇情與各季）、`works.js`（書房）、`city.js`（都市）、`timeline.js`（年表）、`combat.js`（拼點的規則與數字）、`rooms.js`（房間、成就、關於）。
- `assets/emblems.js`：每位乘客的小圖示，照名字出處的作品畫成。

新章節上線時：在 `data.js` 的 `cantos` 加一站，在 `data/story.js` 加那一章的劇情、在 `seasons` 加一季，在 `data/timeline.js` 加開始的日期，必要時補 `data/people.js` 的人物。

沒有建置步驟，也沒有後端：用任何靜態伺服器打開資料夾就能看（例如 `python3 -m http.server`）。

## 資料來源與譯名

- 遊戲的事實對照 limbuscompany.wiki.gg、libraryofruina.wiki.gg、英文維基百科、Steam 的官方公告，以及 LLC 公開的遊戲文本（2026-11-14 版）。只有一個來源的內容會在那一段寫明，查不到的就不寫。
- 遊戲沒有官方中文。角色、章節和名詞的中文名稱參考玩家翻譯計畫 LLC（簡體）與 LTM（繁體），轉成繁體字形；LLC 和 LTM 的譯文採用 CC BY-NC-SA 4.0。文學作品的書名用台灣常見的譯名。
- 罪人的號碼照劇情（但丁是 10 號）。
- 拼點的規則：擲出正面的機率 50% + 理智值；攻擊等級每高 3 級拼點威力 +1；平手重擲（只有一個來源）。勝率是把每一種硬幣結果都算進去的精確值。
- 書房的開頭引文是手冊自己從原文譯的，只引已經進入公有領域的作品（卡繆與赫塞不引）。
- 七宗罪的顏色是照遊戲彩虹順序調的近似色。
