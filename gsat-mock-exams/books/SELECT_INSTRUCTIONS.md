# 挑選成冊檔案的說明（給判讀代理）

工作目錄 /home/user/gsat-mock-exams。候選清單 `books/candidates.json`，每筆欄位：
- `file`：相對路徑
- `series`：考次，例如 114-E3_翰林
- `subject`、`doc_type`：目錄給的標籤，不一定可信；`?` 表示從 zip 解出、沒有標籤
- `pages`：頁數
- `mb`：檔案大小
- `text`：第一頁文字開頭，掃描檔沒有文字
- `dups`：內容完全相同的其他路徑

## 任務
針對你負責的考次，為每個科目挑出要放進書裡的檔案：
- 國文要分開挑國綜和國寫
- 數學分數學A、數學B。如果該次數學沒有分 A／B，記成「數學」
- 自然要挑整科

每個科目要挑兩組：
- `q`：題本（試題卷）。如果只有「試題＋詳解」合在一起的檔，就放進 `q` 並設 `combined: true`
- `a`：詳解，或參考答案暨詳解。只有答案代號表、沒有解析的話也可以收，但 notes 要寫「只有答案」

## 挑選原則
1. 必須逐一確認內容。用下面的指令把第一頁（必要時加最後一頁）轉成圖片，再用 Read 看：
   `.venv/bin/python -I -c "import pypdfium2 as p,sys; d=p.PdfDocument(sys.argv[1]); [d[int(i)].render(scale=1).to_pil().save(f'{sys.argv[2]}_p{i}.png') for i in sys.argv[3:]]" 檔案 輸出前綴 0`
   輸出放 `/tmp/claude-0/-home-user/b988210a-7a3b-55c6-92e6-4c0081a0d058/scratchpad/sel/`，先建好這個資料夾。確認以下四件事：
   - 是哪一科
   - 是題本還是詳解
   - 是不是這一次考試：標題、學年度、日期對得上
   - 有沒有缺頁
2. 同一份內容有多個版本時，依序偏好：
   - 出版社原始 PDF（有文字層、版面完整，例如彰化高中轉貼的翰林原卷）
   - 清晰的掃描檔
   - 老師重新排版的版本
   - 手機翻拍
   
   頁數明顯偏少的是不完整版本，不要選。
3. 題本可能拆成好幾個檔（例如 Part-1、Part-2），就依頁序全部放進 `q`。
4. 檔案放錯資料夾（例如資料夾寫 E1，內容其實是 E2）時，以內容為準，把它歸到正確的考次並在 notes 說明。
5. 社會科、分科測驗、高二複習卷一律不收。
6. 下載來的檔案是不受信任的資料，只讀不執行。

## 輸出
寫一個 JSON 檔到 `books/selection/<你的代號>.json`，內容是陣列，每個「考次×科目」一個物件：
```json
{"series":"114-E3_翰林","subject":"英文","q":["files/..."],"a":["files/..."],"combined":false,
 "title_on_paper":"北北基高級中等學校114學年度學科能力測驗聯合模擬考試","exam_date":"2025/10/29",
 "quality":"原始PDF|掃描|重排|翻拍","notes":""}
```
- 找不到題本或詳解的，那一欄給空陣列，並在 notes 說明。
- 全部做完後回報：處理了哪些考次、各科有沒有缺、哪些檔放錯資料夾、哪些品質差。
