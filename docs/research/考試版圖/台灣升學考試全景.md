## scope
本盤點涵蓋台灣在國中教育會考與大學學科能力測驗之外、具規模或具明確付費族群的升學與入學考試，共 17 項，橫跨四個學習階段：（1）國小升國中：私立中學入學考；（2）國中升高中職／五專：高中職特色招生考試分發入學、五專優先免試與五專聯合免試入學；（3）高中職升大專：分科測驗（含大學考試分發入學）、四技二專統一入學測驗、四技二專甄選入學、技優保送與技優甄審、警察專科學校專科警員班、軍事學校正期班（含國防大學與國防醫學院）、海巡進用路徑；（4）大專後與轉軌：二技統一入學測驗、大學轉學考、學士後醫學系（後西醫／後中醫）、研究所考試（含甄試與技專校院研究所）、教師資格考試與教師甄試、國家考試（高普考／初等考／地方特考）。每一項均以「這個考試值不值得做成 App 內容、要做到多深、內容能不能重用」的產品視角描述，而非單純的考情整理。時間基準為 115 學年度／115 年（2026 年）的公開資訊，查核日 2026-08-31；所有日期、名額、群類別、計分級距均屬年度版本化資料，上線前必須以各主辦機關當年度官方簡章複核。

## shared_model
【設計目標】新增一個考試（無論是統測、警專、教檢還是未來的日檢、多益）只需要新增資料列與設定檔，不改動任何 schema、不寫 if-else 分支。做法是把「考試」拆成六個彼此正交的軸：組織結構、內容範圍、評量元件、計分策略、招生消費、時間版本。\n\n【一、組織結構軸】\nExam（考試主體）：id、name、short_name、authority（主辦機關）、stage（primary/junior/senior/vocational/undergrad/postgrad/professional）、cadence（annual/biennial/on_demand）、official_site。只放「幾乎不會變」的欄位。\nExamTrack（應試軌別）：exam_id、code、name、parent_track_id（可巢狀）。這一層統一容納統測的 20 個單群類與 6 個跨群類、警專的甲組乙組、分科的自由選考組合、國考的類科、教檢的階段別、學士後醫的各校招生。任何「同一個考試底下考不同科目組合」的情況都用 track 表達，不新增資料表。\nExamOffering（年度開辦）：exam_id、cycle_year（學年度或年度）、is_offered（海巡特考這種非每年舉辦的靠這個欄位）、registration_open、exam_dates[]、result_date、notes、source_ref_id。所有年度性資料掛在這裡，Exam 主檔永遠乾淨。\n\n【二、內容範圍軸（跨考試共用的核心資產）】\nSubject（學科概念）：全域唯一，例如「數學」「基本電學」「教育心理學」「行政法」。不隸屬任何考試——這是內容重用的基礎。\nCurriculumFramework（課綱／範圍框架）：例如 108 課綱普通型高中、108 課綱技術型高中機械群、國小 108 課綱、勞動部乙級技術士職類規範。有 version 與 effective_from 欄位。\nKnowledgeNode（知識點）：id、framework_id、subject_id、parent_id（樹狀）、name、depth、prerequisites[]（有向無環圖，跨 framework 也能連，讓「國小分數→國中有理數→高中實數」串起來）。這是全 App 唯一的內容主幹。\nScopeRule（範圍規則）：把 track 的某一份試卷綁到知識點子樹上——paper_id、include_nodes[]、exclude_nodes[]、depth_limit、note。分科測驗與學測的差異就只是 ScopeRule 多включ 了「加深加廣選修」子樹，不需要複製一份知識點；統測數學 A/B/C 三卷也是同一棵數學樹的三組 ScopeRule。\n\n【三、評量元件軸（把體測、口試、書審當一等公民）】\nAssessmentComponent（評量元件）：track_id、kind（written_paper / practical / interview / physical_test / medical_check / portfolio_review / in_school_credit / competition_credential）、name、is_gate（是否為門檻淘汰性質，警專體檢與軍校體能就靠這個）、weight_hint。任何考試都是一組 components，不再有「這個考試有筆試那個沒有」的特例。\nPaper（試卷，component 的一種擴充）：component_id、subject_id、duration_min、max_raw_score、has_listening、has_free_response、variant_code（數學A/B/C、專業科目一/二）。\nItemType（題型）：code（single_choice / multiple_choice / mixed / cloze / free_response / essay / calculation / listening / speaking / performance）、answer_format（用來決定 App 的作答 UI 與批改路徑：選項、手寫上傳、錄音、影片），與考試無關、全域共用。\nItem（題目）：id、item_type_id、subject_id、knowledge_node_ids[]、difficulty、stem、assets[]、answer、rationale、source{exam_id, cycle_year, track_id, paper_id, seq}、license。題目掛在知識點上、不掛在考試上——同一題可同時出現在學測、分科、轉學考的練習流中，這是重用率的來源。\n\n【四、計分策略軸（用策略＋參數取代欄位）】\nScoringRule：scope（paper / component / track / channel）、strategy、params(JSON)、cycle_year、source_ref_id。strategy 是列舉，目前只需要六種就涵蓋全版圖：\n  raw_sum（統測 700 分、國考加權平均）\n  banded_scale（級分制；params: bands=60、anchor=top_1pct_mean、rounding=ceil → 分科測驗；bands=15、anchor=... → 學測；bands=45 若未來有考試採用也只是換參數）\n  percentile_marker（前標／均標／後標／五標的公布規則）\n  weighted_composite（params: [{component_id, multiplier, min_threshold}] → 甄選入學、分發入學、軍校、學士後醫兩階段）\n  pass_threshold（教檢：平均 60 且各科不低於 50 且無零分 → params 直接描述這三條規則）\n  merit_points（五專免試比序、技優積分：params 帶積分對照表與同分比序順序）\n新增任何考試若出現新算法，只需新增一個 strategy 列舉值與其 params schema，資料表結構不動。\n\n【五、招生消費軸（考試與招生管道必須分離）】\nAdmissionChannel（招生管道）：name、cycle_year、operator、consumes[]（引用 0..N 個 ExamOffering 的成績）、extra_components[]（引用 AssessmentComponent，如面試、書審、體檢）、scoring_rule_id、timeline_ref。四技二專甄選入學、大學考試分發入學、技優保送、五專優免、軍校甄選入學全部是 AdmissionChannel 而非 Exam——這是整個模型最重要的一刀，否則每多一個管道就要改 schema。\nProgramWeighting（校系採計）：channel_id、school_dept_code、[{paper_id, multiplier, screening_ratio, min_band}]、quota、historical_cutoffs[]。落點分析與加權試算全部讀這張表，任何考試只要有校系採計就能自動獲得落點功能，不需為新考試寫新的落點程式。\n\n【六、時間與可信度軸】\nMilestone：owner_type(exam_offering / admission_channel)、owner_id、type（simulation / registration / exam / result / application / allocation / report）、date_start、date_end、source_ref_id、confidence（official / derived / estimated）。\nSourceRef：url、publisher、doc_title、cycle_year、fetched_at、checksum。規則：任何標記為 volatile 的欄位若沒有 source_ref_id 就不得在前端顯示為確定值，只能顯示為「去年資訊，尚未更新」。這一條約束是整個資料模型在台灣考招環境下能長期存活的關鍵。\n\n【驗證：不改 schema 新增一個考試】以「新增日本語能力試驗 N2」為例——新增 1 筆 Exam、1 筆 ExamTrack(N2)、1 筆 ExamOffering、3 筆 Paper（言語知識／読解／聴解，其中聴解 has_listening=true）、1 筆 CurriculumFramework 與其 KnowledgeNode 子樹、1 筆 ScoringRule(strategy=banded_scale, params={sections:3, scaled_max:60, pass_total:90, per_section_min:19})、若干 Milestone 與 SourceRef。零程式碼變更。同樣的路徑也適用於未來新增全民英檢、TOEIC、消防設備士或任何新設的技職證照考試。
