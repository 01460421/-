
## area
資料與素材來源盤點（台灣考試準備 App）

## summary
全站素材可用性由「授權」而非「找不找得到」決定。三條法律底線撐起整個架構：（一）著作權法第 9 條第 1 項第 5 款明定「依法令舉行之各類考試試題及其備用試題」不得為著作權標的，因此學測、分科測驗、國中教育會考、統測的**題幹、選項、標準答案本身**任何人可自由利用，含商業利用，這是本 App 最大的合法資產；（二）但第 9 條只免除「試題」本身，**試題內引用的第三方著作**（國文閱讀測驗的散文、英文長文、社會科的報導與圖表、照片）著作權仍在原作者手上，第 54 條的合理使用只涵蓋「機關學校辦理考試時重製」，**不涵蓋商業 App 事後的重製與公開傳輸**——這是全案最高的法律風險點，而不是題目本身；（三）大考中心／心測中心自行編寫的**試題分析、參考答案詳解、命題說明、寫作測驗評分規準與樣卷**具原創性，受完整保護，只能連結不能抄。

在此之上，素材依「可用強度」分四級落地：可完全重製並打包離線（政府資料開放授權條款 OGDL-1.0、教育部國語辭典 CC BY-ND、PhET CC BY、NASA/USGS 公有領域、CC0 館藏）＞可嵌入但不落地（PhET iframe、YouTube 官方播放器、Podcast RSS）＞只能連結加極短引用（均一／Khan／MIT OCW／OpenStax 等 NC 授權、泛科學、CASE 報科學、所有新聞媒體）＞完全禁區（出版社教科書與講義、補習班教材、他站題庫、有版權圖表）。特別提醒：**NC（非商業）授權對付費或含廣告的 App 一律等於「只能連結」**，均一（CC BY-NC-SA 3.0 TW）、Khan Academy、MIT OCW 全部落在這裡，這點常被誤判為「開放資源所以能用」。

素材與知識點的掛接不靠單一手段，採**課綱編碼為權威骨幹 → 術語詞典規則召回 → 向量語意檢索擴召 → LLM 關係裁決與理由生成 → 低信心進人工審核**的五段管線，人工掛接保留為黃金標準集用於評估。每則素材強制帶 license_code、usage_mode、freshness_class、credibility_tier 四個欄位，時事類素材強制設到期日並自動降權汰換。

# 一、法律底線（先於一切技術決策）

| # | 規則 | 依據 | 對 App 的實際意義 |
|---|---|---|---|
| L1 | 依法令舉行之考試試題不受著作權保護 | 著作權法 §9 I(5) | 學測／分科／會考／統測／統一入學測驗的**題幹、選項、答案**可自由重製、改編、商業使用，不需授權、不需付費 |
| L2 | 試題內引用的第三方著作，著作權不因入題而消滅 | §9 只免除試題本身；§54 僅及於「辦理考試」之重製 | 國文閱讀題組的散文、英文閱讀的原文、社會科引用的報導與統計圖、任何照片與插圖，**商業 App 重新公開傳輸沒有免責基礎**。必須改寫或替換 |
| L3 | 官方編寫的解析類內容受完整保護 | 具原創性之語文著作 | 大考中心試題分析、參考試卷詳解、心測中心寫作測驗評分規準與樣卷 → 只能連結，詳解一律自行撰寫 |
| L4 | NC（非商業）授權對商業 App 無效 | CC BY-NC-* 條款 | 有訂閱費、內購、廣告、或以之招攬付費服務者皆屬商業。均一／Khan／MIT OCW／CASE 全數降為 link_only |
| L5 | SA（相同方式分享）具傳染性 | CC BY-SA / BY-NC-SA | 一旦把 CC BY-SA 文字混入自製講義，該衍生作品整份須以相同授權釋出。專有內容不得與 SA 素材混編 |
| L6 | ND（禁止改作）禁止剪裁重組 | CC BY-ND | 可整篇原樣轉載，但不可摘要、不可節錄改寫、不可拆片段做導讀 |

**L2 的落地作法（最重要的一條工程規則）**：試題入庫時強制標記 `has_embedded_work`。凡國文、英文、社會、自然的「題組型長文」一律預設 true，進入改寫流程——保留題目與選項（不受保護），將引文替換為自撰短文、公有領域文本（作者歿滿 50 年）、或 OGDL/CC BY 素材，並在題目上標註「原文已替換，題型與測驗目標同原題」。純計算、純圖表推論、數理選擇題可標 false，直接原樣使用。

## 3.1 管線分類

| 批次檔下載 | 教育部辭典公眾授權網、樂詞網下載專區、OpenStax、Gutenberg、課綱 PDF | 版本化保存原始檔＋checksum；升版時 diff 比對 |
| 人工建置 | 大考中心／心測中心 PDF 試題、課綱條目結構化 | OCR 初稿＋雙人校對；數學式轉 LaTeX；圖表重繪 |

| 僅索引連結 | 均一、Khan、MIT OCW、泛科學、CASE、新聞 | 只存 URL、標題、發布日、自撰摘要、封面圖（若授權允許），**不存正文** |

## 3.2 爬蟲的界線

1. **robots.txt 是硬性門檻**：`Disallow` 路徑一律不爬，`Crawl-delay` 一律遵守。無 crawl-delay 時預設同網域 ≥1 req/s、夜間執行、帶可識別 User-Agent 與聯絡 email。
2. **robots.txt 允許 ≠ 著作權授權**。robots.txt 管的是存取，著作權管的是重製與公開傳輸。**兩者必須都通過**：允許爬取只代表可以讀，不代表可以入庫轉載。
3. **只擷取事實層，不擷取表達層**。可取：標題、作者、發布日期、URL、公開的統計數值、OpenGraph 摘要。不可取：正文全文、記者的敘述文字、原創圖表點陣圖。
4. **不繞過付費牆、不繞過登入、不偽造 Referer**。
5. **服務條款優先於技術可行性**。ctext 明示限制大量擷取；YouTube 服務條款禁止下載。技術做得到不代表可以做。
6. 每個爬取目標在 `source_registry` 留存：robots 檢查時間、tos_url、tos_reviewed_at、tos_reviewed_by、擷取欄位白名單。

## 3.4 快取與離線

- **離線可打包者僅限 `usage_mode = full_reuse`**：教育部辭典、OGDL 資料、公有領域文本、CC0 影像、CC BY 素材、法定考試試題（已通過 L2 改寫）、自製內容。
- `usage_mode = embed`（PhET、YouTube）：離線模式顯示「需連線」佔位卡，不預先下載資源。
- `usage_mode = link_only`：離線僅顯示自撰摘要與來源名稱，連結灰化。**正文永不入本機資料庫**。
- 快取分層：CDN（靜態素材，帶 immutable hash 檔名）→ 伺服器端 API 快取（依來源更新週期設 TTL）→ 客戶端（SQLite／IndexedDB，僅 full_reuse 素材，隨版本包更新）。
- 每個離線包內含 `ATTRIBUTIONS.json`，App 內建可查閱的「素材出處」頁，滿足 OGDL 與 CC 的標示義務。

## 3.5 失效連結偵測與替換

```
每週 link_health job：
  對每筆 asset (usage_mode in [link_only, embed])：
    HEAD → 逾時則 GET
    200            → last_ok = now；抓取 <title> 與正文雜湊
                     若標題／雜湊變動 > 門檻 → 標 content_drifted，進人工複核
    301/302        → 追隨一次；若落在同網域且標題相符 → 自動更新 canonical_url
                     跨網域或標題不符 → 標 needs_review
    404/410        → strike +1
    403/429        → 不計 strike（可能為反爬），改排隔日重試
    5xx            → 不計 strike，隔日重試
  strike >= 3（連續三週）→ 狀態轉 dead
```

`dead` 之後的處置階梯：
1. 若該知識點尚有其他 `active` 素材且數量達下限 → 直接下架，不阻斷使用者。
2. 若為該知識點唯一素材 → 進「補素材佇列」，由語意檢索在既有素材池中推薦替代，人工確認。
3. 對於 link_only 素材，**不以 Wayback Machine 作為內容來源**（存檔不改變授權狀態）；僅在管理後台提供存檔連結供編輯確認原內容以撰寫替代摘要。
4. 前端規則：`dead` 素材立即從所有卡片隱藏，不顯示破圖或死連結。

# 四、素材與知識點的掛接

## 4.1 資料模型

```
knowledge_point
  kp_id            主鍵，採課綱編碼（例：數S-10-3）
  subject / grade / strand
  title            對數的定義與運算
  description      供向量化的 120–200 字知識點描述（人工撰寫，非課綱原文）
  aliases[]        對數, logarithm, log, 常用對數, 自然對數
  prereq_kp[]      指數律、指數函數
  exam_codes[]     對應學測／會考的能力指標

asset
  asset_id, source_id, canonical_url
  title, author, published_at, fetched_at
  summary          自撰 60–120 字（link_only 素材唯一允許入庫的文字）
  body             僅 full_reuse 素材才有值
  content_hash, http_status, last_ok, strike_count, status(active/drifted/dead)
  license_code     OGDL-1.0 / CC-BY-4.0 / CC-BY-ND-3.0-TW / CC-BY-NC-SA-4.0 / PD-US / ARR ...
  license_url, attribution_text
  usage_mode       full_reuse | embed | quote_short | link_only
  has_embedded_work  bool（試題專用）
  freshness_class  evergreen | slow | time_bound
  expires_at       time_bound 必填
  credibility_tier T1–T4
  reading_level    國中 / 高一 / 高三
  media_type       article | video | sim | dataset | image | audio

kp_asset_link
  kp_id, asset_id
  relation         motivation | application | extension | misconception | history | cross_domain | data_source
  confidence       0–1
  rationale        一句話：為什麼這則素材能服務這個知識點
  method           manual | rule | vector | llm
  reviewed_by, reviewed_at
  status           approved | pending | rejected
```

## 4.2 五段掛接管線

**L0 權威骨幹**：知識點主鍵一律採課綱編碼，不自創體系。所有掛接掛在 kp_id 上，課綱改版時可沿編碼遷移。

**L1 人工掛接（黃金標準）**：編輯為每個知識點手動掛 3–5 則素材。目標不是覆蓋全庫，而是產出 500–1000 筆高品質 (kp, asset, relation) 樣本，作為後續自動化的評估集與 few-shot 範例。**沒有這一步，後面三步無法驗收。**

**L2 規則召回（高精確、低召回）**：以樂詞網學術名詞＋課綱關鍵詞＋知識點 aliases 建術語詞典，對素材標題與摘要做比對。命中 → 候選，`method=rule`。負責抓「文章標題直接寫著『對數』」這種確定案例。缺點是抓不到「芮氏規模」這類不含關鍵詞卻高度相關的素材。

**L3 向量語意檢索（高召回）**：
- 對每個 kp 的 `description` 做 embedding，存入向量庫。
- 對每則素材切 chunk（400–600 字，overlap 80）後 embedding。
- 素材入庫時，以其 chunk 對 kp 向量庫做 top-k（k=8）檢索，cosine ≥ 0.72 進候選池。
- **這是解決「芮氏地震規模 → 對數」的關鍵層**：兩者無共同關鍵詞，但語意空間鄰近。
- 中文建議用多語 embedding 模型並以繁體語料驗證；`description` 中刻意寫入應用場景詞（「地震規模、分貝、pH 值、複利」），大幅提升召回。

**L4 LLM 關係裁決**：對 L2∪L3 的候選 pair，餵入知識點描述＋素材標題摘要，要求輸出 JSON：
```json
{"relevant": true, "relation": "application", "confidence": 0.86,
 "rationale": "芮氏規模以對數尺度描述地震能量，可作為對數壓縮大範圍數值的真實案例",
 "target_grade": "高一"}
```
提示詞中明列 relation 六型定義與 L1 的 few-shot 範例。要求「無法確定就回 relevant:false」，抑制過度掛接。

**L5 人審閘門**：
- confidence ≥ 0.85 且 method 含 rule 或 vector → 自動 `approved`，抽樣 10% 事後複查。
- 0.60 ≤ confidence < 0.85 → `pending`，進編輯佇列，一鍵通過／退回。
- < 0.60 → 直接丟棄，不進佇列（避免佇列被雜訊淹沒）。
- 每個 kp 設「素材數上限 6 則」，超過時依 credibility_tier 與 confidence 排序取前 6，其餘留為候補（供 dead 替換用）。

**評估**：以 L1 黃金集算 Precision@5 與 Recall@10，上線門檻 P@5 ≥ 0.80。每次調整 embedding 模型或提示詞須重跑。

## 4.3 前端呈現規則（由 usage_mode 直接驅動）

| usage_mode | 卡片呈現 |
|---|---|
| full_reuse | App 內全文閱讀，底部標示 attribution_text |
| embed | 內嵌 iframe（PhET／YouTube），上方標示來源，離線顯示佔位卡 |

# 五、品質與時效

## 5.1 時效分級

| freshness_class | 定義 | expires_at | 到期處置 |
|---|---|---|---|
| evergreen | 數學定理、物理定律、古典文學、辭典詞條 | 無 | 僅隨連結存活檢查 |
| slow | 教科書級科普、統計方法、地理概況 | 建議 24 個月 | 到期進複查佇列，人工確認後展期 |
| time_bound | 新聞時事、當年統計、政策法規、選舉與國際情勢 | **強制填寫，預設 12 個月**；法規類綁定「下次修法可能日」 | 到期自動 `deprecated`：前端加「本則資料截至 YYYY-MM」灰標並降權排序；再過 3 個月自動下架 |

補充規則：
- 時事素材卡片**一律顯示發布日期**，不得只顯示「最近」。
- 引用統計數值的自製題目，題幹內強制內嵌年份（「依 2025 年主計總處資料」），使題目本身不會過期，只是資料變舊。
- 每年 8 月（新學年前）跑一次全庫 time_bound 盤點，產出汰換清單。
- 法規變動（如公民科的勞基法、憲法訴訟法）設關鍵字監看，命中即標 `needs_review` 而不等到期。

## 5.2 來源可信度分級

| Tier | 定義 | 範例 | 用途 |
|---|---|---|---|
| **T1 權威** | 官方機關、法定考試機構、同儕審查來源 | 國教院課綱、大考中心、心測中心、教育部辭典、data.gov.tw、中央氣象署、主計總處、NASA、USGS | 可作為**知識正確性的最終依據**；可用於題目與詳解的事實引用 |

| **T3 專業媒體／社群** | 有編輯台但非學術審查 | 泛科學、科學人、中央社、主流報系、Wikipedia | **僅作興趣引導與情境背景**，不得作為知識正確性依據；數字類主張須回溯 T1 原始出處 |
| **T4 未經審查** | 個人部落格、內容農場、UGC、AI 生成未校 | — | **不採用**。唯一例外：已由 T1/T2 原始出處驗證過的單一數值，且需標註驗證來源 |

- 每個知識點的素材集合中，**T3 素材占比不得超過 50%**，且不得為唯一素材。
- 任何進入題幹的事實或數據，其 credibility_tier 必須為 T1 或 T2，並在後台記錄原始出處 URL。
- 內容農場網域維護黑名單，爬取與檢索階段直接排除。

## 範例一：把「對數」掛到芮氏地震規模（跨關鍵詞的語意掛接，含可離線資料）

**情境**：知識點 `數S-10-3 對數的定義與運算`。學生問「學這個要幹嘛」。純關鍵詞比對永遠找不到答案，因為沒有任何一篇地震文章標題會寫「對數」。

**掛接過程**：
1. L2 規則召回：以 aliases（對數／logarithm／log／常用對數）掃素材庫 → 命中 3 則，全是數學教學文，無法回答動機問題。
2. L3 向量檢索：kp 的 description 刻意寫成「以對數尺度壓縮跨數量級的量，常見於地震規模、聲音分貝、pH 值、星等、複利成長」。中央氣象署地震報告資料集的 chunk 與此 cosine = 0.79，進候選。
3. L4 LLM 裁決輸出：`{"relevant": true, "relation": "application", "confidence": 0.88, "rationale": "芮氏規模每增加 1，釋放能量約增為 31.6 倍，是對數壓縮大範圍數值的教科書級真實案例"}`
4. confidence ≥ 0.85 → 自動 approved。

## 範例二：把「勞動基準法的工時與加班規範」掛到新聞時事（time_bound 素材的完整生命週期）

**情境**：知識點 `公Bd-V-2 勞動權益與勞資關係`。素養題需要真實情境，但新聞正文一個字都不能抄。

**掛接與改寫**：
1. 每日 cron 從勞動部 data.gov.tw 資料集（OGDL）抓取勞檢違規統計；從中央社等媒體僅抓標題、日期、URL、OG 摘要（欄位白名單阻擋正文）。
2. L3 檢索將該批素材與 `公Bd-V-2` 匹配，L4 判為 `relation: "application", confidence: 0.82` → 進 pending 佇列，編輯 30 秒內按通過。
3. 編輯**自行撰寫**命題情境（不引用記者文字）：「小美在便利商店打工，某週排班為週一至週五各 9 小時。依勞動基準法，雇主應如何計算其延長工時工資？」題幹末標註「依 2025 年 12 月修正條文」。

**素材紀錄**：

```json
{
  "asset_id": "cna-labor-2026-03-xx",
  "source_id": "cna",
  "title": "勞檢統計：違反工時規定居首（中央社，2026-03-14）",
  "license_code": "ARR",
  "usage_mode": "link_only",
  "summary": "（自撰 70 字，敘述事實，不沿用原文句式）",
  "credibility_tier": "T3",
  "freshness_class": "time_bound",
  "published_at": "2026-03-14",
  "expires_at": "2027-03-14",
  "law_watch_keywords": ["勞動基準法", "工時", "特別休假"]
}
```

**生命週期**：
- 上架期間卡片固定顯示「2026-03-14」，不顯示「最新」。
- 若 `law_watch_keywords` 命中修法公告 → 立即標 `needs_review`，不等到期。
- 2027-03-14 到期 → 自動 `deprecated`，卡片加灰標「本則資料截至 2026-03」並在排序中降權；由於 `公Bd-V-2` 尚有勞動部 OGDL 統計（evergreen, T1）撐著，使用者體驗不受影響。
- 2027-06-14 自動下架，補素材佇列以向量檢索推薦當年度新聞候補。

**關鍵設計**：題幹本身內嵌年份與法條版本，所以**題目不會過期，只有素材會過期**。新聞永遠只是可點的參考連結，不是題目的組成部分。

## pitfalls

 "把「開放教育資源」等同「可以用」。均一（CC BY-NC-SA 3.0 TW）、Khan Academy、MIT OCW 全部帶 NC，對任何有訂閱費、內購或廣告的 App 都等於只能連結。這是本清單中最常見、也最容易在 demo 階段就埋進去的誤判。",
 "以為法定考試試題免著作權，就能整份原樣搬。§9 只免除試題本身，國文閱讀題組的散文、英文長文、社會科引用的報導與圖表，著作權仍在原作者；§54 的考試合理使用不涵蓋商業 App 事後的重製與公開傳輸。整份搬 = 逐題累積侵權。",
 "把大考中心的「試題分析」「參考答案詳解」與試題混為一談。前者具原創性受完整保護，抄進 App 就是侵權。詳解一律自撰，只連結不引用。",
 "忽略 OGDL-1.0 的標示義務。條款明文規定未依規定標示提供機關者「視為自始未取得授權」——不是罰則而是授權根本不成立。標示是四行程式碼的事，漏掉卻讓整批政府資料的使用失去法律基礎。",
 "把 CC BY-SA 的維基百科文字整段併進自製講義。SA 具傳染性，會把整份衍生作品綁定為 CC BY-SA，等於被迫開放自家專有內容。維基百科應該只用來做事實查核與外部連結。",
 "誤解 ND（禁止改作）只是「不能亂改」。CASE 報科學為 CC BY-NC-ND 4.0，這代表連做摘要、節錄片段當導讀都不行——ND 阻斷的正是產品最想做的那件事（把長文濃縮成卡片）。",
