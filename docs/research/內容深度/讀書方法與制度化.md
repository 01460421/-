
## area
讀書方法的實證基礎，以及如何把它們制度化成 App 的預設值、提示與自動調整機制

## summary
真正有跨情境實證支撐的讀書方法只有一小把：檢索練習（測驗效應）、間隔重複、自我解釋／精緻化提問，加上有邊界條件的交錯練習與可欲難度。其餘廣為流傳的東西——康乃爾筆記、Zettelkasten、費曼技巧、SQ3R、錯題本、番茄鐘——本身並沒有魔力，它們有效的部分永遠是「裡面藏了多少檢索與解釋」，而學生最常做的正是把這些方法退化成抄寫與重讀。因此 App 的核心設計主張是：**不要教方法論，要把方法論寫進預設值**。學生只看到一個「今天要做的事」入口，背後由排程器決定他做的是新題、錯題重考、交錯混合還是口頭解釋；所有需要學生「自律地選對做法」的環節都改成系統預設或閘門（例如複習積壓時自動把新卡上限降為 0）。App 不做工具箱，只做一條主線加三個可被行為資料自動開關的模式；判斷依據不是學生自陳的偏好或「學習風格」，而是他的實際行為訊號：作答正確率曲線、錯題重犯率、卡片積壓量、連續中斷率、單題停留時間。最後，必須主動反制實證薄弱但直覺誘人的做法（學習風格配對、重複閱讀、螢光筆、錄音重聽），方式不是說教，而是在介面上讓它們變得不方便、並在學生做完後立刻給一次「你剛剛其實沒有記住」的反證體驗。

## spec
# 一、實證分級（本 App 採用的內部標準）

分四級，決定該方法在產品中的地位：**Tier A = 寫進預設值且不可關閉；Tier B = 預設開啟但可調；Tier C = 只保留其中的有效成分，重新設計外殼；Tier D = 主動反制。**

| 級別 | 判準 | 產品地位 |
|---|---|---|
| A | 多篇獨立統合分析、效果量穩定 g≥0.5、跨學科跨年齡、且在真實課堂複製成功 | 主線流程，學生無法「選擇不用」 |
| B | 統合分析支持但效果量中小或調節變項強（材料類型、學科、先備知識） | 依科目／依學生行為條件式啟用 |
| C | 方法本身未被單獨驗證，有效成分可歸因於 A/B 級機制 | 拆解重組：留下檢索與解釋，砍掉抄寫與美編 |
| D | 統合分析否證，或原始效果未能複製 | 介面上增加摩擦、提供即時反證 |

# 二、方法 → 產品機制完整對照表

## Tier A

### A1. 主動回憶 / 測驗效應（Retrieval Practice, Testing Effect）

| 項目 | 內容 |
|---|---|
| 實證強度 | **最高**。Rowland (2014) g≈0.50；Adesope et al. (2017) g≈0.61；200+ 比較的統合分析達 0.70；遷移到新題型 d≈0.40；課堂應用情境 g≈0.50。Dunlosky et al. (2013) 評為「高效用」兩者之一。1999–2022 已累積 1215 篇同儕審查文獻。 |
| 適用情境 | 幾乎全部。事實記憶、概念理解、程序技能、跨題型遷移都有效。低先備知識者需搭配回饋才不會固化錯誤。 |
| 常見誤用 | ①「看答案覺得自己會了」——用辨識取代回憶；②做完題目只對答案不重做；③把「寫題目」等同「回憶」，但邊寫邊翻課本其實是重讀；④測驗後不給回饋（無回饋時效果大幅縮水）。 |
| App 落實 | **答案預設遮蔽 + 強制先產出**：任何題目、任何卡片，答案區在使用者提交前一律不可見，且「看答案」按鈕在前 8 秒 disabled（灰底倒數）。**空白也算作答**：提供「想不出來」按鈕，按下後仍走完整回饋流程（見 pretesting）。**課本模式移除**：閱讀教材頁面不提供「邊看邊答」的分割畫面。**回饋強制**：作答後立刻顯示正解 + 一句話原理，不可跳過（最短停留 3 秒）。 |
| 預設值 | 遮蔽=on（不可關）、產出倒數=8s、回饋最短停留=3s、每個學習單元結束必接 3 題即時小考 |
| 文案 | 「先猜一個。猜錯比直接看答案更容易記住。」 |

### A2. 間隔重複（Spaced Repetition / FSRS）

| 項目 | 內容 |
|---|---|
| 實證強度 | **最高**。分散練習是 Dunlosky (2013) 另一個「高效用」策略；Cepeda 等人的間隔統合分析穩定支持；2025 年數學領域的 spacing + retrieval 統合分析再次確認。演算法層面，FSRS 已成為 Anki 官方內建排程器，相較 SM-2 在同樣工作量下達成更高留存。 |
| 適用情境 | 需要長期保留的一切：單字、公式、定義、年代、化學反應、法條、錯題重犯。**不適用**於尚未理解的內容——間隔重複不能取代理解。 |
| 常見誤用 | ①**新卡加太多**：社群公認的頭號死因。每張新卡在接下來一個月約帶來 7 次複習；每天 20 張新卡，一個月後每天要複習 140+ 張，兩週內就壓垮多數人。②積壓時繼續加新卡（正確做法是新卡歸零直到清空）。③一張卡塞一整段（違反 minimum information principle），必然變成 leech（Anki 預設 8 次 lapse 標記）。④把 desired retention 拉到 0.95–0.97：工作量呈指數上升，從 95% 到 97% 幾乎讓工作量翻倍，只換來 2%。⑤沒理解就做卡，變成背句子的形狀。 |
| App 落實 | **不讓學生碰排程參數**。內建 FSRS，desired retention 預設 0.90（可調範圍只開 0.85–0.93，兩個檔位：「穩」0.92／「省時間」0.87），並以「最小工作量」的邏輯自動推算個人最適值，而非讓學生自己填。**新卡閘門（不可關閉）**：`今日新卡上限 = clamp(0, 目標分鐘數 × 產能係數 − 今日到期複習量)`；當到期複習 > 目標時間的 120%，新卡自動 = 0 並顯示「今天先還債，明天再開新的」。**卡片原子化守門**：建卡時若正面 > 40 字或答案含 2 個以上獨立事實，直接擋下並提供「幫你拆成 3 張」的一鍵拆卡。**Leech 處理**：連續錯 4 次自動抽出到「卡關區」，強制走「重寫這張卡」流程（改成克漏字、加圖、加自己的例子），而不是繼續讓它輪迴。**上限 36500 天、複習不設上限、學習步驟 1m 10m** 全部寫死。 |
| 預設值 | retention=0.90、新卡上限=動態（起始 10/天）、最大間隔=100 年、leech 門檻=4、積壓判定=到期量 > 目標時間×1.2 |
| 文案 | 積壓時：「今天有 180 張到期。先不加新的——新卡是明天的債。」 |

### A3. 自我解釋（Self-Explanation）與費曼技巧

| 項目 | 內容 |
|---|---|
| 實證強度 | **高**。Bisra et al. (2018) 統合分析 64 篇報告 69 個效果量，隨機效果模型 g = 0.55，且在多數學科、宣告性與程序性知識皆成立。費曼技巧本身沒有獨立實證，它是自我解釋 + 檢索 + 找出知識缺口的民間包裝。 |
| 適用情境 | 有結構、有因果的材料最強：物理、化學機制、生物流程、數學證明、歷史因果。純任意連結（單字拼寫、年號）效果小。 |
| 常見誤用 | ①對著課本念一遍當成解釋（沒有闔上書就不是自我解釋）；②只解釋「怎麼做」不解釋「為什麼這樣做」；③解釋完沒有檢查缺口就結束，錯誤解釋被強化。 |
| App 落實 | **60 秒口說**：每個單元結束、每道大題訂正後，跳出錄音鍵：「闔上筆記，用你自己的話講給不會的人聽，60 秒。」語音轉文字後由模型比對教材，只輸出三件事：**你講到的關鍵點 / 你漏掉的關鍵點 / 你講錯的地方**，漏掉與講錯的自動變成明天的卡片。**不評分、不打星**（避免變成表演）。低頻寬替代方案：三個填空提示句「這一題的關鍵是＿／我一開始想錯的是＿／下次看到＿我就要想到＿」。 |
| 預設值 | 錄音長度上限 90 秒、每日至少 1 次、綁在「當天錯最多的那個主題」上而非讓學生選 |
| 文案 | 「講得出來才是你的。講不出來的地方，就是明天要練的地方。」 |

## Tier B

### B1. 交錯練習（Interleaving）與變異練習

| 項目 | 內容 |
|---|---|
| 實證強度 | **中，但邊界條件強**。Brunmair & Richter (2019) 統合分析：整體約 g≈0.4，然而**相似度是關鍵調節變項**——類別間高度相似時效果大（例如區辨畫家風格、區辨相似題型），差異太大時效果消失甚至為負。數學題目的交錯效果小且研究間變異極大（從顯著正到負都有）。Rohrer 等人的隨機對照試驗在「題型容易混淆」的數學單元上有明確正效果。 |
| 適用情境 | **只在「學生會混淆的相似題型之間」啟用**：三角函數各種公式選擇、化學計量各種題型、英文相似文法點、生物相似名詞。**不要**在初學單一技能、尚未達到基本正確率時交錯。 |
| 常見誤用 | ①把「隨機混所有科目」當交錯（那只是雜訊）；②在初學階段就交錯，導致連基本程序都建立不起來；③把交錯的低即時表現誤判為「這方法沒用」——這正是可欲難度的定義：練習期表現差、保留期表現好。 |
| App 落實 | **混淆矩陣驅動的交錯**：系統從全體與個人作答資料建立「題型混淆矩陣」（做 A 型題時誤用 B 型解法的機率）。當某兩題型混淆率 > 15%，才把它們排進同一組交錯練習，且**只在該題型單獨正確率 ≥ 70% 之後啟用**（先 blocked 後 interleaved）。**變異練習**以「同一概念換情境」的題目族群實作：同一物理原理配 5 種不同情境的題幹。**預期管理**：交錯練習組結束畫面明示「這一組你答對 6/10，比昨天低。這是刻意的——混著練當下比較差，兩週後比較好。」 |
| 預設值 | 混淆率門檻 15%、解鎖門檻 70%、交錯組每組 8–12 題、blocked:interleaved 比例隨熟練度由 8:2 滑向 3:7 |

### B2. 可欲難度（Desirable Difficulty）與預先測驗（Pretesting）

| 項目 | 內容 |
|---|---|
| 實證強度 | 可欲難度是框架而非單一效果，其具體形式（間隔、交錯、檢索、生成）各自有實證。**預先測驗效應**近年證據相當穩健：在學習前先測未學內容，即使答錯，只要接著給正解，最終記憶優於直接閱讀正解；效果在成年全年齡穩健，但**學生自己不相信它有用**。 |
| 適用情境 | 新單元開頭、有語意關聯的材料。 |
| 常見誤用 | ①難度為難而難（例如故意用模糊字體），沒有證據支持所有難度都有益；②猜錯後不給即時回饋（那就真的只是錯）。 |
| App 落實 | **每個新單元強制 3 題「先猜」**，答錯不計入任何統計、不進正確率、不扣任何點數，介面明說「這幾題你還沒學過，猜就好」。猜完直接進教材，教材中該考點高亮。 |
| 文案 | 「先猜三題。錯了完全不算。猜過再學，記得比較久。」 |

### B3. 精緻化提問（Elaborative Interrogation）

| 項目 | 內容 |
|---|---|
| 實證強度 | Dunlosky (2013) 評為「中度效用」——有效但跨情境證據不如檢索與間隔。對先備知識較高者效果較好。 |
| 適用情境 | 事實性但可解釋的內容（生物、地理、歷史因果）。 |
| 常見誤用 | 問「為什麼」但答案來自課本原句照抄。 |
| App 落實 | 卡片背面自動附掛一個「為什麼？」欄位，**只在該卡第 2 次複習成功後**出現一次（避免每次都問而變成噪音），且輸入框不接受複製貼上。 |

### B4. 刻意練習（Deliberate Practice）在應試上的翻譯

| 項目 | 內容 |
|---|---|
| 實證強度 | **被過度宣稱**。Macnamara et al. (2014) 統合分析：刻意練習在遊戲解釋 26%、音樂 21%、運動 18%、**教育僅 4%**、專業 <1% 的表現變異。結論是「重要，但遠不如流行說法宣稱的重要」。 |
| 適用情境 | 其真正可移植的內核是四件事：**明確界定的弱點子技能 / 高於現有水準的難度 / 立即回饋 / 立刻重做**。這四件事本身與檢索、可欲難度高度重疊。 |
| 常見誤用 | ①用「一萬小時」當口號，鼓勵學生堆時數（時數與成績關聯薄弱）；②「刻意練習」被翻譯成「多寫題目」，實際上是重複已經會的部分。 |
| App 落實 | **禁止顯示累積讀書時數為主要成就指標**。改為「本週攻克的弱點數」與「錯題重犯率下降」。**弱點顆粒度**：所有題目標記到「考點 × 錯因」的雙層 tag（例如「等比級數 × 公比正負號漏判」），練習組永遠由弱點 tag 生成而非章節生成。**即時回饋 + 立刻重做**：錯題訂正後 10 分鐘內排入一題同 tag 變異題（不是同一題）。 |
| 文案 | 「你這週寫了 240 題，其中 190 題是你早就會的。下面這 12 題才是差距。」 |

## Tier C：拆解重組（外殼沒用，內核有用）

| 方法 | 實證真相 | 保留的有效成分 | App 的重新設計 |
|---|---|---|---|
| **康乃爾筆記** | 支持證據多為小樣本、單一課堂、常與策略訓練混淆，方法本身缺乏強統合分析。有效的是右欄「線索問題」與底部「摘要」——那是檢索與自我解釋，不是版面。 | 線索欄 = 自我出題；摘要欄 = 自我解釋 | 筆記編輯器**不提供三欄版面模板**。改為：學生打完一段筆記，游標離開時側邊自動浮出「這段的考點問題是？」單行輸入框，寫下的問題直接變成排程卡片。頁尾強制 40 字摘要才能存檔。**筆記本身不可在複習模式中被完整顯示**——複習時只顯示線索問題。 |
| **Zettelkasten** | 沒有針對學生應試的實證。有效成分是「用自己的話重寫（生成效應）」與「建立連結（精緻化）」。對高中生應試的成本效益極差，容易變成蒐集癖。 | 用自己的話重寫、連結既有知識 | **不做卡片網絡**。只保留一個機制：新概念存檔時，系統推薦 2 張既有卡，要求一句話寫出關聯（「這跟＿的差別是＿」）。這句話成為交錯練習的混淆判別依據。 |
| **心智圖** | Dunlosky 體系中屬「意象法／組織圖」類，低到中度效用；作為**產出**（自己畫）有生成效應，作為**輸入**（看別人的圖）幾乎無效。 | 自己從空白畫出來的過程 | 提供「閉書畫關係圖」的單一功能：給節點但不給連線，要求學生連線並標註關係詞，系統比對標準結構圖給差異。**絕不提供漂亮的現成心智圖給學生看**。 |
| **SQ3R / PQ4R** | 整體閱讀策略，證據混雜；有效的是 Question 與 Recite 兩步（= 預先測驗 + 檢索），Survey 與 Review 貢獻小。 | Question、Recite | 教材閱讀頁的固定結構就是 SQ3R 的骨架，但學生看不到這個名字：進頁面先 3 題預測驗（Q）→ 讀 → 闔頁 60 秒口說（R）→ 3 題後測。**流程即方法，不教名詞。** |
| **費曼技巧** | 見 A3，本質是自我解釋 | 同 A3 | 同 A3 |
| **錯題本** | 東亞升學圈核心實踐，缺乏直接 RCT，但其有效成分（錯誤分析、metacognitive monitoring、重複檢索）各有實證支持。錯誤分析能觸發認知衝突並促進對知識缺口的覺察。關鍵發現：**低表現學生的自我校準特別差、傾向高估自己**，所以錯題本的價值不在題目，在強迫校準。 | 錯因歸類、間隔重考、變異題 | 見下方獨立段落 |
| **番茄鐘 / 時間箱 / 深度工作** | 2025 年比較自我調節、Pomodoro、Flowtime 三種休息方式的研究發現：Pomodoro 組疲勞上升較快、動機下降較快，但**最終在疲勞、動機、產出、完成度、心流上都沒有顯著差異**。有理論支持（外部提示比內部提示可靠、被中斷的任務較易恢復），但沒有「25 分鐘是最佳值」的證據。 | 外部計時提示、預先承諾 | 計時器存在但**不預設 25 分鐘**，預設為「一疊」——以任務量（12 張卡／8 題）而非時間為單位收尾，時間只顯示不強制。允許自訂長度，並在連續三次未做滿時自動下修建議長度。 |
| **環境設計 / 手機隔離** | 「手機在場就降低認知資源」的 Ward (2017) 原始效果**未能複製**（2022 直接複製失敗；2023 統合分析質疑其存在）。真正穩健的是**通知打斷與任務切換成本**。 | 阻斷通知、減少切換 | 不做「把手機放到另一個房間」這種無效說教。做的是：專注模式一鍵開啟系統勿擾、App 內全站通知靜音、切出 App 超過 20 秒回來時**不責備**，只顯示「回來了。剛剛那題你想到哪？」並直接回到原題。中斷次數只記錄不評分，用於調整下一次的建議時長。 |

## Tier D：流行但實證薄弱——App 必須主動反制

| 說法 | 為什麼無效 | App 的反制 |
|---|---|---|
| **學習風格（視覺／聽覺／動覺）配對** | 十五年以上研究一致顯示：把教法配合學生自稱的風格，對成績沒有影響。「大腦有分離的視覺／聽覺／動覺處理管道」是神經迷思。學習風格量表在高等教育仍廣泛流傳，但屬 myth。 | **不提供任何風格測驗、不做風格分流**。若學生在設定中搜尋「學習風格」，導向一頁說明：「這件事被測過很多次，配合風格教學不會提高成績。真正有差的是你有沒有主動回想。」並直接接一個 30 秒檢索練習示範。 |
| **重複閱讀（重讀）** | Dunlosky et al. (2013) 五個「低效用」策略之一。重讀提高熟悉感（流暢性錯覺）但不提高提取能力；學生因此高估自己的準備程度。 | 教材頁**記錄重讀次數**：同一頁第 3 次開啟時，不阻擋，但先跳出 2 題該頁考點小考。答對就直接跳過閱讀（「你已經會了，不用再讀」），答錯才進頁面。用行為證明比說教有效。 |
| **螢光筆／畫線** | 同屬「低效用」。畫線把注意力鎖在孤立句子上，妨礙整合，且畫的當下產生「我處理過了」的錯覺。 | 提供螢光筆，但**畫線的句子在複習模式中會被遮成填空**。學生畫得越多，複習時要回憶的越多——把畫線這個習慣的產物直接轉成檢索材料。 |
| **摘要（原文抄寫式）** | 低效用，除非受過訓練且是高度濃縮的重寫。 | 摘要輸入框禁止貼上、限 40 字、且要求至少 1 個教材未出現的詞。 |
| **上課錄音回聽** | 被動重聽等同聽覺版重讀，沒有檢索成分；且成本高（1 小時課要 1 小時聽）。 | 允許上傳錄音，但系統**不提供完整回放入口**，而是自動轉逐字稿→抽考點→生成 10 題。入口文案：「這堂課變成 10 題了。聽第二遍要 50 分鐘，做這 10 題要 6 分鐘。」 |
| **「一萬小時」／堆時數** | 教育領域刻意練習僅解釋 4% 變異。 | 首頁不顯示累積時數。 |
| **深夜苦讀** | 睡眠剝奪損害記憶形成（統合分析支持）；睡眠紡錘波與宣告性記憶鞏固中度相關（r≈0.52）。 | 見下方。 |

## 三、生理基礎：睡眠、運動、營養

| 項目 | 實證 | App 落實 |
|---|---|---|
| 睡眠 | 最穩健的非學習介入。睡眠剝奪對記憶形成有明確損害；紡錘波—慢波耦合是宣告性記憶鞏固的機制；小睡也有效。 | **睡前排程**：把當天新學內容的第一次複習排在「睡前 30 分鐘」與「隔天早上」兩個時點（而非隨機時刻）。**熄燈閘**：設定的就寢時間前 15 分鐘，App 自動關閉「新內容」入口，只留 5 分鐘輕量複習，並顯示「剩下的明天早上做，比現在硬撐有效」。**不做睡眠追蹤**（資料敏感、依從性低），只用學生自填的固定就寢時間。 |
| 運動 | 有氧運動與認知／海馬體相關證據中等，作為學習前後的節點有支持，但效果量不宜誇大。 | 只做一件事：連續坐超過 90 分鐘時，建議 10 分鐘走動並暫停排程，不記錄、不獎勵。 |
| 營養／水分 | 除嚴重缺乏外，補充劑對健康學生的記憶效果證據薄弱。 | **不做營養建議、不推薦補充劑**。唯一例外：長時段作答前提醒吃過東西沒有——且只是提醒，不追蹤。 |

## 四、模考的正確用法

模考在產品中的定位是**診斷工具，不是評量工具**。分數只是副產品。

| 環節 | 錯誤做法 | App 機制 |
|---|---|---|
| 考前 | 拿模考當「練習」，一週寫三份 | 頻率上限：每科每 3 週一份完整卷；其餘時間用弱點題組。超頻時直接擋下並說明理由 |
| 作答中 | 不計時、可翻書 | 強制計時、全螢幕、逐題記錄停留秒數與改答次數 |
| **作答後（核心）** | 對答案、算分數、訂正、收起來 | **錯因四分類**（強制，每題選一）：<br>① 完全不會（沒學過／忘光）<br>② 想得到方向但卡住（半熟）<br>③ 會但算錯／看錯／時間不夠（執行）<br>④ 猜對／蒙對（假會，**答對也要標**）<br>系統額外用停留時間與改答次數交叉驗證分類是否合理 |
| 診斷輸出 | 「你考了 62 分」 | 「**你的 62 分裡有 9 分是猜對的，真實水準約 53。失分結構：不會 18 分、半熟 11 分、粗心 9 分。粗心的 9 分裡有 7 分集中在最後 15 分鐘 → 這是配速問題不是能力問題。**」 |
| 後續處方 | 全部訂正一遍 | 依錯因分流：①→回教材 + 建卡；②→變異題組（同考點不同情境）×5；③→限時執行練習（只練速度與檢查程序）；④→**優先級最高**，立刻建卡並排 3 天內重考 |
| 校準 | 無 | 考前要求預測分數，考後顯示「你預測 75，實得 62，高估 13 分」。**低表現學生的校準特別差且長期不改善**，所以校準誤差本身要被追蹤成一條曲線，這是元認知訓練的主要介面。 |

## 五、錯題本方法論（東亞升學圈核心實踐的正確版本）

抄一遍題目沒有用——那是抄寫，不是檢索。有效的錯題本必須具備五個成分，缺一個效果就大幅衰減：

1. **錯因標記，不是題目抄寫**。價值在「我為什麼錯」的分類，不在題幹重現。
2. **一句話的「我當時想的是什麼」**。這是錯誤分析觸發認知衝突的關鍵，也是後續辨識同型錯誤的線索。
3. **間隔重考，而且要闔上答案重做**。看訂正筆記 = 重讀。
4. **重考的是變異題，不是原題**。原題重做會記住答案本身（形狀記憶）。
5. **重犯率追蹤**。一題「訂正過」不等於「會了」；只有連續兩次不同時點的變異題都對，才可退出錯題池。

**App 落實**：拍照 → OCR → 自動判定考點 tag → 學生只做兩件事（選錯因、口述 15 秒「我當時想的是」）→ 系統自動生成 1 張檢索卡 + 3 題變異題並排入 FSRS。**全程不要求學生抄題**。錯題卡的排程 desired retention 拉高到 0.93（錯題比新知識更值得高留存）。首頁只顯示一個數字：**本週錯題重犯率**。

## 六、讀書計畫：為什麼會失敗，以及會被執行的計畫

**失敗原因（依重要性排序）**

1. **規劃謬誤**：學生系統性低估每個任務的耗時，計畫從第 3 天開始就已經是負債表。
2. **計畫是「意圖」不是「情境觸發」**：「這週要複習物理」沒有指定何時何地，執行率極低。實作意圖（if-then 格式）在 642 個測驗的統合分析中 d 介於 .27–.66；Gollwitzer & Sheeran (2006) d≈0.65。效果在 if-then 格式、動機高、且計畫至少演練過一次時最大。
3. **全有全無心態**：破功一天就整份放棄。
4. **以時間為單位而非以產出為單位**：「讀 2 小時」可以靠重讀達成，「攻克 12 個弱點」不行。
5. **計畫由學生手工維護**：任何需要每天手動更新的計畫都會在兩週內死亡。

**產品原則**

| 原則 | 機制 |
|---|---|
| 計畫是系統產生的，不是學生排的 | 學生只輸入三件事：考試日期、每天可用時段（星期×時段格）、科目權重。其餘由排程器產生 |
| if-then 格式寫死在介面 | 每個時段卡片的標題就是「**週二 19:30，在書桌前，先做數學那疊（12 張）**」——地點欄位是必填的下拉選單 |
| 以「疊」為單位，不以小時 | 一疊 = 系統算好的 12–18 分鐘工作量；完成即打勾。學生看到的永遠是有限的、會結束的東西 |
| 自動重排，不累積罪惡感 | 漏掉的內容自動併入未來三天，**且不顯示「你欠了 X」**，只顯示今天要做什麼 |
| 保留 25% 空白 | 排程器只填滿學生宣稱可用時間的 75%。這不是浪費，是讓計畫有機會存活 |
| 破功復原路徑 | 中斷 ≥3 天回來時，不顯示積壓總量，直接給一疊 8 張的「回來題」（全部是他做對過的），文案：「先做這 8 張暖身。剩下的排好了，慢慢還。」 |

## 七、制度化的三條設計法則

**法則一：預設即教學法（Default as Pedagogy）**
學生不需要知道「檢索練習」四個字。他只需要：打開 App → 看到一疊 → 做完。方法論體現在「答案預設遮蔽」「新卡自動歸零」「錯題自動變卡」這些預設值裡。**每個需要學生主動選擇正確做法的地方，都是設計失敗。**

**法則二：一條主線，不做工具箱**
首頁**只有一個按鈕**：「開始今天的（3 疊，約 42 分鐘）」。所有方法都是排程器在後台的選擇，不是使用者的選項。錯題本、卡片、模考、筆記全部不是獨立的分頁，而是這條主線上會自然出現的環節。
- 判準：**任何功能如果需要「教學引導」才會被使用，就代表它應該被自動化，而不是被說明。**
- 進階功能一律走「解鎖」而非「陳列」：交錯練習不在選單裡，它會在混淆率超標時自己出現，並附一句話說明。

**法則三：行為即設定（Behavior over Self-Report）**
不問學生偏好、不做性格測驗、不做學習風格分類。所有個人化參數由行為訊號推導。

## 八、行為資料 → 模式判定 → 自動調整

**採集的訊號（全部是被動的，學生不需要填任何東西）**

| 訊號 | 定義 |
|---|---|
| `retention_true` | 到期卡首次作答正確率（滾動 14 天） |
| `backlog_ratio` | 到期複習量 ÷ 學生宣稱可用時間的產能 |
| `relapse_rate` | 錯題退出池後 30 天內再錯的比率 |
| `session_completion` | 開始的「疊」中做完的比例 |
| `interrupt_per_10min` | 每 10 分鐘離開 App 的次數 |
| `latency_profile` | 答對題的作答時間分佈（快而對 vs 慢而對） |
| `calibration_error` | 模考預測分 − 實得分 |
| `confusion_matrix` | 題型間的誤用矩陣 |
| `streak_break_pattern` | 中斷的長度與週期性 |

**模式判定與自動調整**

| 模式 | 觸發條件 | 自動調整 |
|---|---|---|
| **地基不穩型** | `retention_true` < 70% 且 `latency_profile` 偏慢 | 新卡上限降至 5；關閉交錯（回到 blocked）；卡片自動拆更細；加入「先看範例再做」的鷹架；desired retention 降到 0.87 減輕負擔 |
| **假熟練型** | `retention_true` > 92% 但模考 `calibration_error` > 10 分、且 `relapse_rate` > 25% | 判定為在 App 內用辨識取代回憶。**改用自由回憶題型**（不給選項、要求輸入）；提高遮蔽時間；增加口說解釋頻率；模考頻率上調 |
| **積壓崩潰型** | `backlog_ratio` > 1.5 連續 3 天 | 新卡 = 0；啟動「只做最高價值 40%」的分流（依 FSRS 遺忘機率 × 考點權重排序）；降 desired retention 至 0.87；文案改為還債敘事 |
| **粗心／執行型** | 錯題錯因 ③ 占比 > 40%，且 `latency_profile` 顯示快而錯 | 減少新知識比重，增加限時執行練習；引入「檢查程序」步驟卡；作答介面加入強制複查 3 秒 |
| **易中斷型** | `interrupt_per_10min` > 1.5 或 `session_completion` < 60% | 疊的大小自動縮到 6–8 題；啟動嚴格專注模式；建議時長下修；把難度較低的題排在疊的開頭（降低啟動成本） |
| **穩定進展型** | `retention_true` 85–92%、`backlog_ratio` < 0.9、`session_completion` > 85% | 提高新卡上限；啟動交錯；引入更多變異題與跨章節綜合題；解鎖 60 秒口說的進階版（要求連結兩個單元） |
| **考前衝刺型** | 距考試 < 21 天 | 停止新卡；全部資源轉向「遺忘機率 × 考點權重」最高的題；模考頻率上調；只做已學過內容的高強度檢索 |

**調整原則**：每個參數變動都要（a）有明確觸發條件與回退條件，（b）變動幅度受限（單次 ≤30%），（c）**對學生只以一句白話說明，不出現任何演算法術語**，（d）保留學生一次性的「不要這樣」否決權，否決三次則該規則對此人停用並記入產品分析。

## 功能設計一：「錯題 90 秒」——錯題本的正確版本

**設計目標**：把東亞學生本來就會做的錯題本，從「抄一遍」（10 分鐘、幾乎無效）改造成「錯因 + 口述 + 變異重考」（90 秒、有效成分齊全），且學生不需要知道任何方法論名詞。

**介面流程**

**Step 0 — 入口**
只有兩個地方會出現：①主線練習答錯時自動觸發；②首頁右下常駐的相機鈕（給紙本考卷用）。**沒有「錯題本」這個分頁**——錯題不是一個要去管理的地方，是一個會自己回來找你的東西。

**Step 1 — 拍照（15 秒）**
```
[相機取景框，自動偵測題目邊界]

對準題目就好，不用拍整張考卷

[快門]              [手動框選]
```
拍完立刻 OCR + 判定科目與考點，顯示：
```
數學 · 等比級數 · 公比判定
   不對？改考點
```

**Step 2 — 選錯因（10 秒，強制，四選一）**
```
這題你為什麼錯？

┌──────────────────────────┐
│  完全不會                  │
│  這個東西我沒學過或忘光了      │
├──────────────────────────┤
│  想得到方向，但卡住          │
│  知道要用什麼，但做不下去      │
├──────────────────────────┤
│  會，但算錯／看錯／沒時間      │
│  再給我一次我會對            │
├──────────────────────────┤
│  其實是猜的                 │
│  就算答對也選這個            │
└──────────────────────────┘
```
最後一項的副標是刻意的：**「猜對」是最危險的一類，因為它在成績上隱形，卻是真正的洞。** 主線練習中答對但停留時間異常長或改過答案的題，系統會主動跳出：「這題你答對了，但改了兩次。是猜的嗎？」

**Step 3 — 15 秒口述（核心，可跳過但預設不跳過）**
```
按住說話，15 秒

「我當時想的是……」

［■ 按住錄音］            略過
```
轉文字後只存一行，不做任何評分。這一行是後續辨識同型錯誤的線索，也是唯一能區分「兩題錯在同一個誤解」與「兩題只是碰巧同章節」的資料。

**Step 4 — 系統做剩下的（0 秒，學生只看到結果）**
```
好了。

已建立
  · 1 張回憶卡（3 天後第一次）
  · 3 題同觀念不同情境（明天、5 天後、12 天後）

你這個月在「公比判定」錯 3 次了。
已經把它排進本週重點。

                    [完成]
```

**Step 5 — 重考（自動出現在主線的疊裡，不另外通知）**
重考出現時**不是原題**，是同 tag 的變異題，且介面不顯示「這是你的錯題」——避免學生靠「哦這是錯題本的題」這個線索作答。只有作答完成後才揭露：
```
答對了。

這是 5 天前那題「公比判定」的變體。
上次你想的是「以為公比一定是正的」。
這次沒有犯。

再對一次就可以從錯題池畢業。
```

**退出規則**：必須在兩個不同時點、兩題不同變異題都答對才退出錯題池。之後 30 天內若再錯，重犯率上升並自動提高該考點權重。

**首頁只顯示一個相關數字**
```
本週錯題重犯率  12%
上週 21%  ↓
```
不顯示「錯題總數」——那只會製造焦慮並鼓勵刪除。

## 功能設計二：「今日一疊」——把整套方法論藏進一個按鈕

**設計目標**：學生打開 App 只看到一件事。間隔重複、交錯、可欲難度、時間箱、新卡閘門全部在後台運作，介面上一個字都不提。

**介面流程**

**Step 1 — 首頁（全部內容）**
```
        ●───────○───────○
         第 1 疊    第 2 疊    第 3 疊


          今天大約 38 分鐘


      ┌────────────────────┐
      │      開始           │
      └────────────────────┘


      本週錯題重犯率 12%  ↓
```
沒有選單、沒有科目分頁、沒有「我的卡片」、沒有累積時數。**如果學生想指定要練什麼**，長按「開始」才會出現三個選項（今天／某一科／考前衝刺），這是刻意的摩擦——預設路徑永遠是系統決定的。

**Step 2 — 疊的開頭（設定期望，不解釋方法）**
```
第 1 疊 · 14 題

前面幾題會有點雜，是故意的。

              [走]
```
這句「是故意的」就是可欲難度的全部說明。不出現「交錯練習」四個字。

**Step 3 — 作答（全站唯一容器）**
```
在 100 公尺賽跑中，甲的速度是乙的 1.2 倍……


  ［作答區］


  ─────────────────────
   看答案 (5)          想不出來
```
- 「看答案」前 8 秒 disabled，倒數可見。
- 「想不出來」永遠可按，且**按下去和答錯走完全一樣的流程**——這是為了讓學生不必為了保護正確率而亂猜。
- 作答後回饋畫面最短停留 3 秒，「下一題」按鈕在 3 秒後才亮。

**Step 4 — 疊的結尾（診斷式回饋，不是分數）**
```
第 1 疊完成 · 11 分鐘

10 / 14

這疊比昨天難，因為裡面混了兩種你會搞混的題型
（等比 vs 等差的公式選擇）。
答錯的 4 題有 3 題是選錯公式，不是算錯。

明天還會再混一次。

        [下一疊]      [今天先到這]
```
「今天先到這」是平等的選項，不是灰色小字——**讓學生體面地停止，比逼他做完更能保住明天的開啟率。**

**Step 5 — 新卡閘門觸發時（不同的敘事）**
```
今天全部是複習，沒有新的。

你有 187 張到期。先把這些顧好，
新的明天再開——新東西是明天的債。

        開始（3 疊，約 41 分鐘）
```
不出現「backlog」「積壓」「你落後了」。用「債」的比喻，因為它暗示可清償，而不是失敗。

**Step 6 — 中斷三天以上回來**
```
歡迎回來。

先做這 8 題暖身，都是你做對過的。

剩下的我重新排好了，
分到接下來六天，不會一次全壓上來。

              [開始]
```
**不顯示積壓總量。** 這是流失防治的關鍵決策：看到「你有 412 張到期」的學生，多數會直接關掉 App。

## 功能設計三：「模考解剖室」——把分數換成處方

**設計目標**：讓學生離開模考時帶走的不是一個數字，而是一份具體到「明天做什麼」的清單，同時訓練元認知校準。

**介面流程**

**Step 1 — 考前預測（強制，15 秒）**
```
開始前，猜一下你會考幾分。

     [ ── ── ── ●── ── ] 75


沒有人會看到這個數字，
它只是拿來跟你的實際分數比。

              [開始作答]
```

**Step 2 — 作答**
全螢幕、強制計時、逐題記錄停留秒數與改答次數。作答中不顯示答對與否。頂部只有剩餘時間，不顯示已答題數（避免焦慮驅動的亂答）。

**Step 3 — 逐題錯因標記（核心工作，約 6–8 分鐘）**
不是先看分數再訂正——**是先標記完才給分數**。
```
第 7 題  你選 (C)，正解 (B)

┌──────────────────────────┐
│  完全不會                  │
│  想得到方向但卡住            │
│  會，但算錯／看錯／沒時間      │
└──────────────────────────┘

              第 7 / 12 題需要標記
```
答對的題也會抽出停留時間異常的幾題問：
```
第 3 題你答對了，但花了 4 分 20 秒，
比你平常這類題慢 3 倍。

  □ 我其實是猜的
  □ 我會，只是慢
```

**Step 4 — 解剖報告（不是成績單）**
```
────────────────────────────
  62 分

  但其中 9 分是猜對的。
  你真正穩的大約是 53 分。
────────────────────────────

失分結構

  完全不會      18 分  ████████
  半熟卡住      11 分  █████
  執行失誤       9 分  ████
  猜對（不穩）   9 分  ████

────────────────────────────
配速

  前 60 分鐘  正確率 71%
  後 15 分鐘  正確率 24%

  你的執行失誤有 7 分集中在最後 15 分鐘。
  這是配速問題，不是能力問題。
```

**Step 6 — 頻率守門**
若學生在三週內想再開一份完整模考：
```
你 6 天前才寫過一份。

模考的用處是量出洞在哪。
洞還沒補，再量一次只會得到同一個答案。

你上次的處方還有 23 題沒做完。

    [先做那 23 題]      [我還是要考]
```
右邊那顆按鈕存在，但是次要樣式——**保留學生的自主權，同時讓正確選項成為阻力最小的路徑。**

## standards
[
 "每一個在產品中被實作的方法，都能指名至少一篇統合分析或多篇獨立 RCT，並在內部文件標註其 Tier 級別與效果量；沒有來源的方法一律不進產品。",
 "Tier D 清單（學習風格、重讀、螢光筆、被動錄音回聽、堆時數）在整個 App 中沒有任何一條路徑可以被當成主要學習行為使用；每一項都有對應的轉化或反證機制，且可指出實作位置。",
 "首頁在任何狀態下的主要行動只有一個；達成當日目標的最短路徑不需要學生做出任何「用哪種方法」的選擇。",
 "答案在使用者提交或明示放棄之前，在全站任何介面都不可見——包含教材頁、筆記頁、錯題頁、模考檢討頁。可用一份自動化測試逐頁驗證。",
 "新卡上限在 backlog_ratio > 1.2 時必為 0，且此規則沒有任何使用者可及的開關。可用單元測試覆蓋。",
 "任何進入排程的卡片，其正面長度 ≤ 40 字且答案只含一個獨立事實；違反者在建立當下被攔截，攔截率與拆卡採用率可被監測。",
 "錯題從建立到完成（含錯因標記與口述）的中位數操作時間 ≤ 90 秒，且流程中不要求學生輸入任何題目文字。",
 "錯題退出池必須通過「兩個不同時點 × 兩題不同變異題」的門檻；用原題重考不計入。",
 "模考流程中，學生必須先完成全部錯因標記才能看到分數；報告首屏包含真實水準估計、失分結構、配速分析、校準誤差四項，且每一項都對應到至少一條具體處方。",
 "校準誤差（預測分 − 實得分）對每位學生以時間序列追蹤，並在報告中呈現趨勢；產品目標是該誤差隨模考次數下降。",
 "每一項自動參數調整都具備：明確觸發條件、明確回退條件、單次幅度 ≤ 30%、一句不含術語的白話說明、以及學生的一次性否決權（否決三次即對該用戶停用該規則）。",
 "個人化完全不依賴自陳偏好：產品中不存在學習風格測驗、性格分類或「你喜歡怎麼學」類問卷。",
 "任何會造成即時表現下降的機制（交錯、間隔、預先測驗）在觸發時都伴隨預期管理文案，且該文案在 A/B 測試中不會使當日完成率下降超過 5%。",
 "中斷三天以上回歸的使用者，首屏不顯示任何積壓總量或連續天數歸零的訊息；回歸後首個工作單元的題目全部來自其歷史正確題。",
 "首頁不顯示累積讀書時數、不顯示錯題總數；健康指標以「錯題重犯率」與「真實留存率」為主。",
 "任何新功能上線前必須通過「工具箱測試」：若該功能需要教學引導、需要使用者主動尋找、或需要使用者理解方法論名詞才會被使用，則它必須被改寫成排程器的自動行為，否則不上線。",
 "預先測驗與「想不出來」的作答一律不計入正確率統計，且介面明確告知，避免學生為保護數字而亂猜或迴避。",
 "所有生理相關功能只做排程層介入（睡前熄燈閘、複習時點安排、久坐提醒），不做睡眠追蹤、不做飲食紀錄、不提供任何營養補充劑建議。"
]

## pitfalls
[
 "把方法論做成教學內容。學生不會讀「什麼是間隔重複」的說明頁，讀了也不會照做。方法論的正確位置是預設值與閘門，不是說明文件。",
 "做成工具箱。每多一個分頁（卡片庫、錯題本、筆記、計畫表、番茄鐘），主線的完成率就掉一截。多數學習 App 死於功能齊全而沒人知道從哪開始。",
 "讓學生自己調排程參數。開放 desired retention、新卡上限、學習步驟給學生，等於把間隔重複最大的失敗模式（新卡加太多、retention 拉太高）交還給最不適合做這個決定的人。",
 "把交錯當成「隨機混合」。交錯的效果高度依賴類別相似度，混不相關的內容效果會消失甚至為負。沒有混淆矩陣就不要做交錯。",
 "在學生還沒建立基本正確率時就啟用交錯與其他可欲難度。地基不穩的學生需要 blocked practice 與鷹架，過早的難度只會造成挫敗與流失。",
 "忽略可欲難度的產品風險。間隔與交錯必然讓當下表現變差，學生會直覺判斷「這 App 讓我變爛了」。沒有預期管理文案的可欲難度是流失製造機。",
 "把模考做成成績單。給分數不給結構的模考，只會強化學生的焦慮與高估傾向，完全浪費了模考最有價值的診斷資訊。",
 "錯題本要求學生抄題。抄寫是重讀的變體，沒有檢索成分。任何需要學生手動輸入題幹的錯題流程，都會在兩週內被放棄。",
 "錯題重考用原題。學生會記住答案的形狀而不是解法，造成「錯題本上都對，考場上還是錯」的經典失敗。",
 "積壓時把總量攤在使用者面前。「你有 412 張到期」是最有效的關閉 App 按鈕。積壓必須被重新分配並以有限的今日份量呈現。",
 "用連續天數（streak）當主要激勵。streak 一斷就全盤放棄，且會誘導學生用低品質的敷衍行為維持數字。獎勵應綁在「攻克的弱點數」與「重犯率下降」。",
 "用累積時數當成就指標。教育領域的刻意練習只解釋約 4% 的表現變異，堆時數與成績關聯薄弱，且鼓勵重讀這類低效但耗時的行為。",
 "以自陳問卷做個人化。學習風格配對已被反覆否證，性格測驗與「你偏好怎麼學」同樣沒有預測力。個人化只能建立在行為訊號上。",
 "把 25 分鐘番茄鐘當成有實證的參數。研究顯示 Pomodoro 相對自我調節休息在疲勞、動機、產出上都無顯著優勢，25 分鐘不是魔數。以任務量為單位比以時間為單位可靠。",
 "用「手機在旁邊會降低智商」當說服素材。該效果的原始研究複製失敗、統合分析亦有質疑。改用「通知打斷與任務切換成本」這個更穩健的理由。",
 "自動調整過於激進或不可解釋。參數一夜劇變會讓學生失去對系統的信任；沒有白話說明與否決權的自動化，會被當成「App 壞了」。",
 "把生理建議做成侵入式追蹤。睡眠追蹤、飲食紀錄的依從性極低且資料敏感；睡眠的價值可以只靠排程層（熄燈閘、睡前／隔日早晨複習時點）取得。",
 "對青少年使用者採集行為資料時未處理隱私與家長知情。所有行為訊號都應是為了排程而生的最小必要資料，且明確說明不會作為評價或對外分享的依據。",
 "相信「所有難度都是好難度」。可欲難度不等於任意增加困難；沒有證據支持模糊字體之類的操弄，加難度必須對應到具體有實證的機制（間隔、交錯、檢索、生成）。",
 "低估「猜對」的破壞力。答對但不穩的題在成績上完全隱形，卻是模考成績天花板的主因。不強制標記猜對，整套診斷的準確度就垮一半。"
]
