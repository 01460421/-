
## area
單元級深度講解內容規格（國中會考 × 高中學測）

## summary
「詳細」不是形容詞，是一份可被 lint 檢查的檔案規格。每個單元是一份 `.unit.md` 原始檔，含 YAML front matter 與 14 個編號固定的區塊（S01–S14），每個區塊有明確目的、必要欄位、字數區間與禁止事項；三種閱讀深度（3 分鐘／30 分鐘／深挖）不是三份文件，而是同一份原始檔用「層級標記 + 單調包含」投影出來的三個視圖；例題不是題目加答案，而是一個帶「特徵辨識」與「為什麼想得到這一步」欄位的資料物件。寫完即可自動產出速記卡、決策樹與知識圖譜邊。凡是結論就必須有推導、有出處，或明確標示為「約定」，三者缺一即不得上架。

## spec
## A. 檔案與識別

**A1 原始檔**：一個單元 = 一份 `.unit.md`（Markdown + YAML front matter）。禁止一個檔案寫兩個單元，也禁止一個單元拆成多檔（拆分即代表切割點沒想清楚）。

**A2 單元 ID**：`{科目}-{學段}-{領域}-{主題}-{序號}`，例：`MATH-H-ALG-QUAD-01`、`CHIN-J-CLASSIC-FUNCWORD-01`。學段 `J` = 國中會考範圍、`H` = 高中學測範圍。ID 一旦發布永不變更，改名只改 `title`。

**A3 front matter 必填欄位**：

```yaml
id, title, stage, subject, course, strand
exam: [會考] | [學測] | [會考, 學測]
prereq: [單元 ID…]        # 先備節點，至少 1 個（起始節點填 ROOT）
next: [單元 ID…]          # 後續節點，至少 1 個
estimate: {L1: 3, L2: 30, L3: 75}   # 分鐘
misconceptions: [MC-…]    # 對應迷思概念庫代碼
exam_tags: [考點碼…]      # 對應題庫標籤，用於自動抓歷屆
assets: [圖檔 ID…]
version, authors, reviewed: {subject, pedagogy, editorial}
```

**A4 單元顆粒度判準**（三條全中才算一個單元）：(1) L2 讀完時間落在 25–40 分鐘；(2) 有一個能用一句話講完的核心概念；(3) 至少能撐起 7 道以上不同型態的例題。超過就拆，不足就併。

## B. 標準結構：14 個區塊

區塊順序、編號、標題文字固定，不得增刪或改順序；某區塊在該科不適用時，寫 `（本單元不適用：理由）`，不得留白。

| 代號 | 區塊 | 預設層級 | 字數 | 必要元素 |
|---|---|---|---|---|
| S01 | 一句話定位 | L1 | 60–150 | 一句核心敘述 + 知識地圖座標（上游/下游節點）+ 一句「為什麼要學」 |
| S02 | 先備知識檢核 | L1 | 150–350 | 3–5 題 30 秒自測、每題附答案與「答錯請回哪個節點」 |
| S03 | 直覺建立 | L1+L2 | 400–900 | 生活類比 ≥1、視覺化 ≥1 張圖、概念起源（歷史或原始問題）≥1 段 |
| S04 | 正式定義與符號 | L2 | 300–700 | 嚴謹定義、符號讀法表、常見誤寫 ≥3 條 |
| S05 | 推導與證明 | L2/L3 | 500–1500 | 明確分「必須懂（L2）」與「知道就好（L3）」兩層，每層獨立小標 |
| S06 | 核心結論與必背清單 | L1 | 200–500 | 表格：結論／背 or 推／若選推則寫出推法的第一步 |
| S07 | 例題階梯 | L2/L3 | 不設上限 | 基礎→標準→進階→跨章整合四級，每級 ≥2 題（跨章 ≥1），每題七欄位齊全 |
| S08 | 常見錯誤與迷思概念 | L2 | 400–900 | 每條含「錯誤示範（真的寫出錯解）＋ 診斷句 ＋ 修正」，掛 MC 代碼 |
| S09 | 變式與陷阱 | L2 | 300–700 | 同一考點的偽裝清單，每條寫「表面長相 → 實際考點」 |
| S10 | 解題決策樹 | L1 | 圖 + 200 內 | 以「看到什麼特徵」為節點文字，葉節點指向 S07 題號 |
| S11 | 跨科連結 | L3 | 200–500 | ≥2 科，每條寫「該科怎麼用它、符號差在哪」 |
| S12 | 課外延伸 | L3 | 200–600 | ≥2 則，每則標示 `[科普/時事/應用/閱讀]` 與可信來源連結 |
| S13 | 考點對照 | L2 | 表格 | 題型分佈表、頻率（必須由題庫查詢產生，見 F 節）、典型題幹句式 |
| S14 | 速記卡與一頁總結 | L1 | ≤ 300 | 5–8 張卡（正/反面）＋ 一頁總結（可單獨列印） |

**S07 例題七欄位**（缺一不得上架）：
1. `題目`（含來源標註：自製／改編自 XX 年 XX 題）
2. `特徵辨識`：這題長什麼樣、哪三個字是訊號
3. `想法起點`：**為什麼想得到這一步**。必須寫成可遷移規則（「看到 A 就試 B，因為 B 能把 A 的 C 消掉」），禁止寫「憑經驗」「熟能生巧」
4. `完整解`：每一步都要有理由，不得跳步
5. `檢驗`：怎麼確認答案沒錯（代回、量綱、極端值、圖形合理性）
6. `變式提示`：若把某條件改成 X，解法會怎麼變
7. `標籤`：考點碼、難度（1–5）、時間預算（分鐘）

## C. 分層閱讀：一份原始檔，三個視圖

**C1 三層定義**
- **L1 速覽（3 分鐘）**：讀完能說出這個單元在幹嘛、核心結論、最容易錯的一件事。定位、先備自測、直覺的第一段、核心結論表、決策樹、速記卡。
- **L2 紮實（30 分鐘）**：加上正式定義、必須懂的推導、基礎與標準例題、常見錯誤、變式、考點對照。這是「上考場夠用」的完整版。
- **L3 深挖**：加上延伸證明、進階與跨章例題、跨科連結、課外延伸、歷史脈絡的長版。

**C2 標記方式（核心設計：預設繼承 + 單調包含）**

區塊標題後以屬性宣告預設層級：

```markdown
## S05 推導與證明 {#s05 layer=2}
```

區塊內要局部升層，用容器語法，可巢狀，內層覆寫外層：

```markdown
::: L3
（只有深挖視圖看得到的段落）
:::
```

**單調包含律**：`L1 ⊂ L2 ⊂ L3`。標 L1 的內容一定出現在三個視圖，標 L2 出現在 L2/L3，標 L3 只出現在深挖。因此每段文字只寫一次，投影引擎依視圖過濾即可，**不存在寫三遍**。

**C3 壓縮替身（唯一例外）**：某段 L2 內容在速覽視圖需要更短的說法時，可加一句替身，僅限一句、僅限有完整 L2 版本的段落：

```markdown
::: L1 alt
配方就是把 $ax^2+bx+c$ 改寫成 $a(x-h)^2+k$，好一眼看出頂點。
:::
::: L2
（完整推導段落…）
:::
```

投影規則：L1 視圖取 `alt`，L2/L3 視圖取完整版並丟棄 `alt`。全單元 `alt` 數量上限 5 個，超過表示 L1 骨架沒設計好。

**C4 L1 自足性**：抽出 L1 後不得出現懸空指涉（「如上所述」「見下方推導」「同前例」）。交互參照一律用具名錨點 `[頂點式](#s05-vertex)`，且需標 `{optional}`，投影時若目標不在該視圖則自動降級為純文字。lint 規則 `L1-DANGLING` 會擋下違規。

**C5 例題的層級**：基礎/標準題 = L2；進階/跨章 = L3。每題內部的「想法起點」永遠與題目同層，不得被過濾掉——只給題目不給思路的視圖不存在。

## D. 寫作準則

**D1 句長與段落**
- 平均句長 ≤ 40 字；單句上限：國中 50 字、高中 60 字。超長句必須拆，或拆成條列。
- 一段 ≤ 5 句；連續三段以上純文字必須插入圖、表、公式或條列。
- 定義句可超長，但其後必須跟一句「白話說就是…」的重述。

**D2 術語**
- 首次出現格式：`中文（英文, 符號）`，接一句白話解釋，並連結節點 ID。例：**判別式**（discriminant, $D$）：一個只看係數就能判斷「有沒有實根」的數。
- 同一單元第二次出現不再解釋；跨單元一律重新視為首次。
- 禁止使用未定義的補習班黑話（「秒殺」「大絕」）；口訣可以用，但必須同時給出原理連結。

**D3 什麼時候必須配圖**（命中任一條就是必須，不是可選）
1. 描述三個以上物件的空間或順序關係
2. 有參數變動（「a 變大時圖形怎麼變」）
3. 流程有 3 個以上分支（決策樹一律配圖）
4. 二維以上的資料或對應關係
5. 該概念在 S08 有「圖像型迷思」

圖規範：SVG 優先，深淺色模式各驗一次；必須有 `alt`（描述內容，非「一張圖」）與 `caption`；**caption 必須寫「這張圖要你看到什麼」**，不得只寫標題。圖中文字最小 12px，不靠顏色單獨傳達資訊。

**D4 數學式排版**
- 行內用 `$…$`，展示式 `$$…$$` 獨立成行，前後不空行以外的裝飾。
- 多行推導一律用 `aligned`，等號對齊；每行右側可加 `\quad\text{(配方)}` 標註該步依據。
- 變數斜體、函數名與運算子正體（`\sin`、`\log`、`\max`）、單位用 `\,\mathrm{m/s}`。
- 行內禁用 `\dfrac`、禁用高度超過兩層的分式（改寫或改成展示式）。
- 中文與數學式之間**不由作者手動加空白**，由渲染層統一處理。
- 每個展示式若在後文被引用，必須編號 `\tag{1}`。

**D5 口吻**（讀者 13–18 歲）
- 第二人稱「你」；推導過程可用「我們」表示一起做。
- 禁止：語尾裝可愛（「喔」「啦」「呦」）、顏文字、過量驚嘆號、純勵志空話。
- 禁止：「顯然」「很簡單」「不難看出」「大家都知道」——這些字眼是把讀者的困難說成他的錯。要寫的是「這一步的理由是…」。
- 允許且鼓勵：直白的難度預告（「這裡是本單元最多人錯的地方，慢一點看」）、明確的取捨建議（「這個證明學測不考，趕時間可以跳過，但它解釋了為什麼…」）。
- 國中稿再加一條：不使用未在國中出現的符號（如 $\Leftrightarrow$、$\forall$），改用文字。

**D6 語文／社會科的映射**：S05「推導與證明」在非數理科不是刪除，而是換成**判準的推導**——說明「為什麼可以用這個方法判斷」，例如虛詞用位置與前後詞性判斷的結構理由。S06「必背 vs 可推」對應「必須記憶的封閉清單 vs 可由句構推出的判斷」。

## E. 迷思概念與例題的資料化

**E1 迷思概念庫**：每條迷思有全站唯一代碼 `MC-{主題}-{序號}`，欄位為：錯誤陳述、為什麼會這樣想（來源直覺）、錯誤示範（完整寫出錯解）、診斷題（一題就能驗出）、修正說明、關聯單元。S08 只是引用，主體存於庫中，可跨單元重用、可驅動錯題診斷。

**E2 例題與題庫**：S07 每題以 YAML 區塊或前端表格呈現七欄位，並掛考點碼；題庫中的歷屆題以相同考點碼標記，S13 的頻率統計由查詢即時產生。

## F. 考點統計的真實性規則

S13 的所有數字（次數、比例、年份分佈）**一律以模板變數寫入**，例如 `{{qbank:count(exam=學測, tag=QF-RANGE-INTERVAL, years=2015..2025)}}`，由題庫查詢在建置時填值。**作者不得手寫任何統計數字**。定性描述（哪些題型必考、怎麼包裝）可由作者撰寫，但必須附至少 2 個真實歷屆題號作為證據。查無資料時顯示「資料建置中」，不得留下估計值。

## G. 產製與審查流程

1. 作者填 front matter → 骨架 lint 通過（14 區塊齊全）
2. 撰寫 L2 主線 → 再標 L1 骨架 → 最後補 L3
3. 三審：**學科審**（正確性、推導無誤）、**教學審**（想法起點是否可遷移、迷思是否命中真實學生錯誤）、**編輯審**（D 節寫作準則、圖與排版）
4. 自動檢查：句長、術語首現、L1 自足性、公式渲染、圖 alt/caption、統計變數、例題欄位完整性
5. 上架後每個考季重跑 S13 統計並標記 `reviewed.exam_data` 日期

## H. 投影輸出

同一份原始檔產出：L1 卡片流（App 首屏）、L2 長文（主閱讀模式）、L3 全文（含摺疊）、S14 匯出的離線速記卡（Anki 格式）、S10 匯出的獨立決策樹圖、S02/S08 匯出的診斷題庫。任何視圖都由投影產生，禁止手工維護副本。

## S01 一句話定位 {#s01 layer=1}

二次函數是你遇到的第一個「會彎」的函數，也是高中第一個能回答「什麼時候最大、什麼時候最小」的工具。

在知識地圖上，它的上游是國中的一元二次方程式（解出兩個數）；它把問題從「求解」升級成「看整條曲線」。下游接三個方向：二次不等式（看曲線在 x 軸上方還是下方）、高次多項式函數（同一套配方與對稱的想法）、以及未來微積分的極值問題（二次函數是唯一不用微分就能求極值的非線性函數）。

**為什麼要學**：學測裡真正要你「求最大值」的題目，超過一半最後都會被化成一個二次函數。它不是一個章節，是一種收尾方式。

## S03 直覺建立 {#s03 layer=1}

::: L1
把水管朝斜上方噴出去，水柱的形狀就是拋物線；它先上升、變慢、停住、再落下。二次函數就是在描述這種「有一個轉折點，然後對稱地回來」的變化。整個單元只有一個核心動作：**把式子改寫成看得出轉折點的樣子**。
:::

::: L2
### 生活裡的拋物線

投籃的球、噴泉的水柱、車頭燈的反射面、小耳朵天線的碟盤，全都是拋物線（或拋物面）。它們的共同點是：**有一個極端位置，而且左右對稱**。

這個對稱不是巧合。二次函數 $f(x)=ax^2+bx+c$ 中，$x^2$ 對正負號一視同仁——$(-3)^2$ 和 $3^2$ 一樣大。所以只要把座標原點搬到「對稱中心」，函數就變成純粹的 $y=aX^2$。**配方法做的就是這件事：搬原點。**

### 為什麼需要頂點式

$y=x^2-6x+5$ 和 $y=(x-3)^2-4$ 是同一條曲線，但第二個寫法多告訴你兩件事：轉折點在 $x=3$，最低點的高度是 $-4$。第一個寫法把這些資訊藏在係數裡。

所以本單元的所有技巧，都可以看成同一句話的變奏：**先變成頂點式，再讀答案。**

::: L3
### 概念的起源

拋物線比二次函數早了將近兩千年。古希臘的阿波羅尼奧斯（Apollonius, 約西元前 200 年）研究用平面切圓錐，切出的曲線依角度分成橢圓、拋物線、雙曲線——「parabola」這個字就是他取的。那時候完全沒有座標，拋物線是一條幾何曲線，用「到定點與到定直線的距離相等」定義。

真正把它和運動連起來的是伽利略。他在斜面實驗中發現水平方向等速、垂直方向等加速，兩者合成的軌跡恰好是拋物線。到了笛卡兒的座標幾何出現，這條幾何曲線才被寫成代數式 $y=ax^2+bx+c$。

**這段歷史的用處**：拋物線的「幾何定義（等距）」和「代數定義（二次式）」是兩件事被證明為同一件事。學測不考等距定義，但知道這件事，你才不會覺得「拋物面天線為什麼能聚焦」是另一個世界的知識。
:::

## S04 正式定義與符號 {#s04 layer=2}

**定義**：設 $a,b,c\in\mathbb{R}$ 且 $a\neq 0$，則

$$f(x)=ax^2+bx+c \tag{1}$$

稱為 $x$ 的**二次函數**（quadratic function）。定義域為全體實數 $\mathbb{R}$，其圖形稱為**拋物線**（parabola）。

白話說就是：最高次是 2 次、而且那個 2 次項真的存在（$a$ 不能是 0）的函數。

**頂點式**（vertex form）：

$$f(x)=a(x-h)^2+k \tag{2}$$

其中 $(h,k)$ 為**頂點**（vertex），$x=h$ 為**對稱軸**（axis of symmetry）。

**交點式**（factored form），僅當有實根時存在：

$$f(x)=a(x-r_1)(x-r_2) \tag{3}$$

### 符號讀法

| 符號 | 讀法 | 注意 |
|---|---|---|
| $f(x)$ | 「f of x」／「f 在 x 的值」 | 不是 $f$ 乘以 $x$ |
| $a\neq 0$ | 「a 不等於 0」 | 這是定義的一部分，不是附註 |
| $D=b^2-4ac$ | 判別式（discriminant） | 有些課本寫 $\Delta$，同一個東西 |
| $(h,k)$ | 頂點座標 | $h$ 是位置，$k$ 是值 |

### 常見誤寫

1. **寫成方程式**：題目問「二次函數 $f(x)=x^2-4x$」，答題時寫 $x^2-4x=0$。函數是一整條曲線，方程式是在問「哪裡等於 0」，這是兩件事。
2. **交點式漏掉 $a$**：已知兩根為 1、5 就寫 $f(x)=(x-1)(x-5)$。通過同樣兩個根的拋物線有無限多條，$a$ 不能省。
3. **頂點式的符號**：頂點在 $(3,-4)$ 卻寫成 $(x+3)^2-4$。式子裡是 $x-h$，$h=3$ 時要寫 $(x-3)^2$。
4. **把 $f(x)$ 和 $y$ 混用後又對 $y$ 移項**：$y=(x-3)^2-4$ 寫成 $y+4=(x-3)^2$ 沒問題，但接著說「頂點是 $(3,4)$」就錯了。

## S05 推導與證明 {#s05 layer=2}

### 必須懂（L2）

#### 配方：從一般式到頂點式 {#s05-vertex}

$$
\begin{aligned}
f(x) &= ax^2+bx+c \\
     &= a\left(x^2+\frac{b}{a}x\right)+c &&\quad\text{(把 } a \text{ 提出來，只留純 } x^2\text{)}\\
     &= a\left(x^2+\frac{b}{a}x+\frac{b^2}{4a^2}-\frac{b^2}{4a^2}\right)+c &&\quad\text{(補上一次項係數一半的平方)}\\
     &= a\left(x+\frac{b}{2a}\right)^2-\frac{b^2}{4a}+c \\
     &= a\left(x+\frac{b}{2a}\right)^2+\frac{4ac-b^2}{4a}
\end{aligned}\tag{4}
$$

因此：

$$\text{對稱軸}: x=-\frac{b}{2a},\qquad \text{頂點}: \left(-\frac{b}{2a},\ \frac{4ac-b^2}{4a}\right)\tag{5}$$

**這段推導要你記住的不是結果，是動作**：提係數 → 補一次項係數一半的平方 → 補回去。$k$ 的公式 $\frac{4ac-b^2}{4a}$ **不需要背**，把 $h=-\frac{b}{2a}$ 代回原式算 $f(h)$ 更快也更不容易錯。

#### 為什麼對稱軸是兩根的中點

若 $f(x)=0$ 有兩實根 $r_1,r_2$，由根與係數關係 $r_1+r_2=-\frac{b}{a}$，則

$$\frac{r_1+r_2}{2}=-\frac{b}{2a}=h$$

**這條在解題上比公式更好用**：只要你看得出兩個根（哪怕是「與 $y=3$ 交於兩點」的那兩點），對稱軸立刻就是它們的平均。不必配方。

#### 判別式與圖形

令 $D=b^2-4ac$。由 (4) 式，$f(x)=0$ 等價於 $\left(x+\frac{b}{2a}\right)^2=\frac{D}{4a^2}$，右邊分母恆正，所以：

| $D$ | 與 $x$ 軸 | 頂點位置（$a>0$ 時） |
|---|---|---|
| $D>0$ | 兩交點 | 頂點在 $x$ 軸下方 |
| $D=0$ | 一交點（相切） | 頂點在 $x$ 軸上 |
| $D<0$ | 無交點 | 頂點在 $x$ 軸上方 |

#### 最大最小值

$a>0$ 時 $a(x-h)^2\ge 0$，故 $f(x)\ge k$，**在 $x=h$ 有最小值 $k$，無最大值**；$a<0$ 時反過來。

**但這只在定義域為全體實數時成立。** 若限制在區間 $[m,n]$，頂點可能根本不在區間裡——這是 S07 進階題與整個單元最大的失分點。

::: L3
### 知道就好（L3）

#### 所有拋物線都相似

$y=ax^2$ 的圖形，把座標軸縮放 $|a|$ 倍後就變成 $y=x^2$：令 $X=ax,\ Y=ay$，則 $y=ax^2 \Rightarrow \frac{Y}{a}=a\left(\frac{X}{a}\right)^2=\frac{X^2}{a}\Rightarrow Y=X^2$。

所以**所有拋物線在幾何上都相似**（就像所有圓都相似）。$a$ 看起來讓圖形變胖變瘦，其實只是你的尺寸標記變了。這解釋了一件反直覺的事：拋物線沒有「形狀」上的分類，只有一種拋物線。

#### 幾何定義與焦點

固定一點 $F$（焦點）與一條不過 $F$ 的直線 $L$（準線），所有「到 $F$ 的距離 = 到 $L$ 的距離」的點所成的圖形，就是拋物線。取 $F=(0,p)$、$L: y=-p$，設點 $(x,y)$：

$$\sqrt{x^2+(y-p)^2}=|y+p| \Rightarrow x^2+y^2-2py+p^2=y^2+2py+p^2 \Rightarrow y=\frac{x^2}{4p}$$

於是 $y=ax^2$ 的焦點是 $\left(0,\frac{1}{4a}\right)$。這條性質讓平行入射的光線全部反射到焦點——車頭燈、衛星小耳朵、太陽能聚光爐都靠它。**學測數學不考，但物理與生活情境題會用到這個事實。**

#### 三點決定唯一的二次函數

給定三個 $x$ 座標相異的點，代入 $y=ax^2+bx+c$ 得到三元一次聯立方程式，其係數矩陣為凡德蒙型，行列式為 $\prod_{i<j}(x_j-x_i)\neq 0$，故解唯一。這就是為什麼題目給三個點你就一定解得出來，而給兩個點必須額外給頂點或對稱軸。
:::

## S06 核心結論與必背清單 {#s06 layer=1}

| 結論 | 背還是推 | 若選推，第一步是 |
|---|---|---|
| 對稱軸 $x=-\dfrac{b}{2a}$ | **背** | — |
| 頂點的 $y$ 值 $\dfrac{4ac-b^2}{4a}$ | **推** | 直接算 $f\!\left(-\frac{b}{2a}\right)$ |
| $a>0$ 開口向上有最小值；$a<0$ 開口向下有最大值 | **背** | — |
| $D>0,\,=0,\,<0$ ↔ 兩交點、相切、不相交 | **背** | — |
| 對稱軸 = 兩根的中點 | **背**（極好用） | — |
| 頂點式 $a(x-h)^2+k$、交點式 $a(x-r_1)(x-r_2)$ | **背形式** | — |
| 區間 $[m,n]$ 上的極值 | **推**（絕不可背公式） | 比較 $h$ 與 $[m,n]$ 的位置，再畫圖 |
| 根與係數 $r_1+r_2=-\frac{b}{a},\ r_1r_2=\frac{c}{a}$ | **背** | — |
| 兩根都落在某區間的條件 | **推** | 判別式、端點值符號、對稱軸位置三件套 |

**分界原則**：只有「查表式、無中間步驟」的事實才進背誦區；任何需要判斷情境的（尤其是區間極值），背公式一定會錯，因為公式沒有涵蓋你眼前的情境。

## S07 例題階梯 {#s07 layer=2}

### 【基礎 1】讀出頂點 `難度 1｜2 分鐘｜QF-VERTEX`

**題目**：求 $f(x)=2x^2-8x+5$ 的對稱軸、頂點與最小值。

**特徵辨識**：一般式、係數是具體數字、問頂點——這是純執行題。

**想法起點**：看到「求頂點」就配方或用 $-\frac{b}{2a}$。這裡選公式再代回，因為 $a=2$ 提出來會出現分數，公式路線步驟少。

**完整解**：
$$h=-\frac{b}{2a}=-\frac{-8}{2\cdot 2}=2$$
$$k=f(2)=2(4)-8(2)+5=8-16+5=-3$$
對稱軸 $x=2$，頂點 $(2,-3)$。因 $a=2>0$ 開口向上，故最小值為 $-3$（無最大值）。

**檢驗**：把 $f(x)$ 配方 $2(x-2)^2-3$，展開得 $2x^2-8x+8-3=2x^2-8x+5$，與原式相同。

**變式提示**：若改成 $f(x)=-2x^2+8x+5$，$h$ 不變（$-\frac{8}{-4}=2$），但開口向下，$-3$ 變成最大值——注意 $k$ 也會變號嗎？自己算一次。

### 【基礎 2】判別式讀交點 `難度 1｜2 分鐘｜QF-DISCRIM`

**題目**：$y=x^2-6x+10$ 與 $x$ 軸有幾個交點？圖形在 $x$ 軸的哪一側？

**特徵辨識**：問「與 $x$ 軸交點個數」= 判別式；問「哪一側」= 判別式 + 開口方向。

**想法起點**：交點個數只跟 $D$ 有關，不必解方程式。位置關係則要「$D$ 的結論」加上「$a$ 的正負」才能定案——只有 $D$ 不夠。

**完整解**：$D=(-6)^2-4(1)(10)=36-40=-4<0$，無實根，故無交點。又 $a=1>0$，開口向上且不與 $x$ 軸相交，因此整條曲線都在 $x$ 軸上方，即對所有 $x$ 恆有 $y>0$。

**檢驗**：配方 $y=(x-3)^2+1\ge 1>0$，一致。

**變式提示**：若題目改問「$y=x^2-6x+m$ 恆正的 $m$ 範圍」，就是把 $D<0$ 當條件解：$36-4m<0\Rightarrow m>9$。

---

### 【標準 1】選對式子的形式 `難度 2｜4 分鐘｜QF-VERTEX`

**題目**：拋物線頂點為 $(1,-2)$ 且通過 $(3,6)$，求其方程式。

**特徵辨識**：題目給的是「頂點」而不是「三個點」。

**想法起點**：**題目給什麼資訊，就用能直接吃下這個資訊的形式。** 給頂點用頂點式（(2) 式），給兩根用交點式（(3) 式），給三個雜點才用一般式解聯立。用一般式做這題要解三元聯立，是用錯工具。

**完整解**：設 $f(x)=a(x-1)^2-2$。代入 $(3,6)$：
$$6=a(3-1)^2-2 \Rightarrow 6=4a-2 \Rightarrow a=2$$
故 $f(x)=2(x-1)^2-2=2x^2-4x$。

**檢驗**：$f(1)=-2$ ✓，$f(3)=18-12=6$ ✓。

**變式提示**：若條件改成「對稱軸為 $x=1$ 且過 $(3,6)$、$(0,0)$」，仍設頂點式 $a(x-1)^2+k$，兩個未知數配兩個點。

### 【標準 2】區間上的最大最小 `難度 3｜5 分鐘｜QF-RANGE-INTERVAL`

**題目**：$f(x)=x^2-4x+3$，$0\le x\le 3$，求最大值與最小值。

**特徵辨識**：**題目附了範圍。** 只要看到定義域被限制，最大最小就不能直接抄頂點。

**想法起點**：先算頂點在哪，再問一句「頂點在範圍裡嗎？」在，最小值就是頂點值；最大值一定在兩端點之一（開口向上時，離對稱軸越遠函數值越大，所以比較兩端點誰離 $h$ 遠）。

**完整解**：$h=-\frac{-4}{2}=2$，$f(2)=4-8+3=-1$。$2\in[0,3]$，故最小值 $-1$。
端點：$f(0)=3$，$f(3)=9-12+3=0$。$|0-2|=2>|3-2|=1$，故 $x=0$ 較遠，最大值 $f(0)=3$。
最小值 $-1$（$x=2$），最大值 $3$（$x=0$）。

**檢驗**：值域應為 $[-1,3]$；$f(1)=0$、$f(2.5)=-0.75$ 都落在區間內 ✓。

**變式提示**：若範圍改成 $3\le x\le 5$，頂點 $x=2$ 就不在範圍內，此時函數在該區間單調遞增，最小值在 $x=3$、最大值在 $x=5$——完全不看頂點值。

![區間極值三種情形：頂點在區間左側／區間內／區間右側，各自的最大最小落點](IMG-QUAD-03-interval)
*要你看到的是：只有中間那種情形頂點才是答案；另外兩種的最大最小都在端點，而且大小順序相反。*

### 【進階 1】含參數的區間最小值 `難度 4｜8 分鐘｜QF-PARAM-CASE`

**題目**：設 $f(x)=x^2-2ax+1$，求 $f$ 在 $0\le x\le 2$ 上的最小值 $m(a)$（以 $a$ 表示）。

**特徵辨識**：對稱軸含參數（$h=a$），區間固定。**動的東西和不動的東西各一個 → 一定是分類討論。**

**想法起點**：問自己「什麼東西的變化會改變答案的算法？」答案是頂點在不在區間裡、以及在區間的哪一側。所以以 $h=a$ 相對於 $[0,2]$ 的位置切三段：$a<0$、$0\le a\le 2$、$a>2$。**分類的切點不是憑感覺挑的，是「算法改變的那一刻」。**

**完整解**：配方 $f(x)=(x-a)^2+1-a^2$，開口向上，對稱軸 $x=a$。

- 若 $a<0$：區間在對稱軸右側，$f$ 在 $[0,2]$ 遞增，最小值 $f(0)=1$。
- 若 $0\le a\le 2$：頂點在區間內，最小值 $f(a)=1-a^2$。
- 若 $a>2$：區間在對稱軸左側，$f$ 遞減，最小值 $f(2)=4-4a+1=5-4a$。

$$m(a)=\begin{cases}1, & a<0\\ 1-a^2, & 0\le a\le 2\\ 5-4a, & a>2\end{cases}$$

**檢驗**：分界點要接得起來。$a=0$：$1-0=1$ ✓ 與上段一致。$a=2$：$1-4=-3$，而 $5-8=-3$ ✓ 一致。**分段函數在切點不連續，八成是算錯了。**

**變式提示**：若改問**最大值**，分類切點會變成 $a=1$（區間中點），因為開口向上時最大值在離對稱軸較遠的端點。切點不同，是因為「算法改變的時刻」不同。

### 【進階 2】根的分佈 `難度 4｜8 分鐘｜QF-ROOTLOC`

**題目**：$f(x)=x^2+bx+c$ 的兩實根都落在 $0<x<2$ 之間，求 $(b,c)$ 需滿足的條件。

**特徵辨識**：「兩根都在某區間內」——不要試圖解出根。

**想法起點**：畫一條開口向上、與 $x$ 軸交兩點且兩交點都夾在 $0$ 與 $2$ 之間的曲線，然後問「這張圖必須滿足哪些事？」圖會直接告訴你三件事：(i) 真的有兩個交點；(ii) 曲線在 $x=0$ 與 $x=2$ 都在 $x$ 軸上方；(iii) 對稱軸夾在 $0$ 和 $2$ 之間。**這三件事缺一不可，而且合起來就充分**——這就是「三件套」的由來，不是口訣。

**完整解**：
$$\begin{cases} D=b^2-4c>0 &\text{(有兩相異實根)}\\ f(0)=c>0 &\text{(端點在軸上方)}\\ f(2)=4+2b+c>0 &\text{(端點在軸上方)}\\ 0<-\dfrac{b}{2}<2 \Rightarrow -4<b<0 &\text{(對稱軸在區間內)}\end{cases}$$

**檢驗**：取 $b=-2,c=0.5$：$D=4-2=2>0$ ✓，$c>0$ ✓，$4-4+0.5>0$ ✓，$-4<-2<0$ ✓。實際解 $x=\frac{2\pm\sqrt2}{2}\approx 0.29,\,1.71$，都在 $(0,2)$ 內 ✓。

**變式提示**：若改成「兩根一個大於 2、一個小於 0」，條件反而變簡單：只需 $f(0)<0$ 且 $f(2)<0$（開口向上時，端點在軸下方就保證兩根被端點分開）。判別式與對稱軸條件會自動成立——想想為什麼。

### 【跨章整合 1】換元後的二次函數 `難度 4｜7 分鐘｜QF-SUBST`

**題目**：求 $y=\sin^2\theta-\sin\theta+1$ 的最大值與最小值。

**特徵辨識**：出現「同一個東西的平方與一次方」（$\sin^2\theta$ 與 $\sin\theta$）——這是換元的訊號。

**想法起點**：看到 $A^2$ 與 $A$ 同時出現，就令 $t=A$，把式子變成 $t$ 的二次函數。**但換元的代價是：新變數的範圍要重新算。** $\theta$ 可以跑遍實數，$t=\sin\theta$ 卻只能在 $[-1,1]$。忘了這件事，題目就從「區間極值」被你做成「全實數極值」，答案必錯。

**完整解**：令 $t=\sin\theta$，則 $-1\le t\le 1$，且
$$y=t^2-t+1=\left(t-\frac12\right)^2+\frac34$$
對稱軸 $t=\frac12\in[-1,1]$，開口向上，故最小值 $\frac34$（此時 $\sin\theta=\frac12$，$\theta$ 有解）。
端點：$y(-1)=1+1+1=3$，$y(1)=1-1+1=1$。$t=-1$ 較遠，最大值 $3$。
最大值 $3$、最小值 $\frac34$。

**檢驗**：$\theta=-\frac{\pi}{2}$ 時 $\sin\theta=-1$，$y=1+1+1=3$ ✓ 最大值取得到。$\theta=\frac{\pi}{6}$ 時 $y=\frac14-\frac12+1=\frac34$ ✓。**每次換元都要回頭確認新變數的值真的取得到。**

**變式提示**：若改為 $y=\cos^2\theta+\sin\theta$，先用 $\cos^2=1-\sin^2$ 統一成同一個三角函數再換元。統一函數是換元的前置動作。

### 【跨章整合 2】應用最佳化 `難度 3｜6 分鐘｜QF-APPLIED-MAX`

**題目**：某商品定價 $200$ 元時每月賣出 $300$ 件。市場調查顯示，每漲價 $10$ 元，月銷量減少 $10$ 件。求每月收入最大時的售價。

**特徵辨識**：兩個量一升一降、且變化是等量的（線性）→ 乘積必為二次函數。

**想法起點**：**設變數要設「你能控制的那個動作的次數」**，而不是設售價。令漲價次數為 $x$（每次 10 元），售價與銷量都能用 $x$ 一次式表示，相乘自然得到二次函數。若直接設售價為 $p$，還要先把銷量寫成 $p$ 的函數，多一層轉換也多一次出錯機會。

**完整解**：設漲價 $x$ 次，售價 $200+10x$，銷量 $300-10x$，收入
$$R(x)=(200+10x)(300-10x)=-100x^2+1000x+60000$$
$$h=-\frac{1000}{2(-100)}=5$$
$a<0$ 開口向下，$x=5$ 時收入最大，售價 $200+50=250$ 元，銷量 $250$ 件，收入 $62500$ 元。

**檢驗**：$x=4 \Rightarrow 240\times 260=62400<62500$；$x=6\Rightarrow 260\times240=62400<62500$ ✓ 左右都比較小，確實是最大。
另可用對稱軸速算：$R(x)=0$ 的兩根為 $x=-20$ 與 $x=30$，中點 $\frac{-20+30}{2}=5$，與配方結果一致（S05 的「對稱軸 = 兩根中點」）。

**變式提示**：若加上「銷量不得低於 200 件」的限制，就變成區間極值題（$300-10x\ge200\Rightarrow x\le 10$，此處 $x=5$ 仍在範圍內，答案不變）；若改成「不得低於 280 件」（$x\le 2$），頂點就出界了，答案改在端點 $x=2$。
:::

## S08 常見錯誤與迷思概念 {#s08 layer=2}

**MC-QUAD-001｜區間題直接抄頂點**
> 錯誤示範：$f(x)=x^2-4x+3$，$3\le x\le 5$，最小值是 $-1$。
- 為什麼會這樣想：課本說「最小值在頂點」，這句話被記成無條件成立。
- 診斷：$f(3)=0$ 但答案寫 $-1$——比實際取得到的值還小，代表答案根本不在值域裡。
- 修正：頂點 $x=2$ 不在 $[3,5]$ 內，函數在此區間遞增，最小值為 $f(3)=0$。**看到範圍就先問「頂點在裡面嗎」。**

**MC-QUAD-002｜對稱軸公式漏負號**
> 錯誤示範：$f(x)=x^2-6x+1$，對稱軸 $x=\frac{-6}{2}=-3$。
- 為什麼會這樣想：把 $-\frac{b}{2a}$ 記成 $\frac{b}{2a}$，或忘記 $b$ 本身帶負號要再變一次號。
- 診斷：算出的 $h$ 和圖形直覺相反（$-6x$ 把圖形往右拉，軸應為正）。
- 修正：$h=-\frac{-6}{2\cdot1}=3$。**自檢法：$b$ 與 $h$ 永遠異號（$a>0$ 時）。**

**MC-QUAD-003｜換元忘記新變數範圍**
> 錯誤示範：$y=\sin^2\theta-\sin\theta+1$，令 $t=\sin\theta$，得 $y=(t-\frac12)^2+\frac34$，最大值無限大。
- 為什麼會這樣想：換元後只看到一個「普通的二次函數」，忘了 $t$ 的身分。
- 診斷：三角函數有界，答案卻出現無限大。
- 修正：$t\in[-1,1]$，變成區間極值題。**換元三步：換、寫新範圍、換回去驗證取得到。**

**MC-QUAD-004｜判別式用在「兩圖形交點」時忘記檢查是否為二次**
> 錯誤示範：求 $y=(m-1)x^2+2x+1$ 與 $x$ 軸恰有一個交點的 $m$，只解 $D=0$ 得 $m=2$。
- 為什麼會這樣想：一看到「一個交點」就等同於「相切」。
- 診斷：漏掉答案。
- 修正：$m=1$ 時式子退化為 $y=2x+1$，是直線，也恰有一個交點。故 $m=1$ 或 $m=2$。**係數含參數時，第一件事是問「它可能是 0 嗎」。**

**MC-QUAD-005｜交點式漏 $a$**
> 錯誤示範：拋物線過 $(1,0)$、$(5,0)$、$(3,8)$，寫 $f(x)=(x-1)(x-5)$。
- 診斷：代 $x=3$ 得 $-4\neq 8$。
- 修正：設 $f(x)=a(x-1)(x-5)$，代第三點得 $a(2)(-2)=8\Rightarrow a=-2$。

**MC-QUAD-006｜把「$a$ 大」讀成「圖形大」**
> 錯誤陳述：$a$ 越大開口越大。
- 修正：$|a|$ 越大開口越**窄**（同樣的 $x$ 位移，$y$ 衝得更快）；$a$ 的正負決定開口方向，$|a|$ 決定胖瘦。

## S09 變式與陷阱 {#s09 layer=2}

同一個考點的各種偽裝。左邊是題目表面長相，右邊是它其實在考什麼。

| 表面長相 | 實際考點 |
|---|---|
| 「求矩形面積最大」「圍籬能圍出的最大面積」 | 二次函數頂點（周長固定 → 邊長一升一降 → 乘積為二次） |
| 「利潤／收入最大的定價」 | 同上，且常附銷量下限 → 變成區間極值 |
| 「點 $P$ 在直線上，求 $\overline{PA}$ 最短」 | 距離平方是二次函數（開根號是遞增函數，最小化平方即可） |
| 「$y=\sin^2x+\cos x$ 的值域」 | 換元後的區間極值（且範圍必須重算） |
| 「數列 $a_n=n^2-9n+5$ 的最小項」 | 二次函數，但 $n$ 是正整數 → 對稱軸 $4.5$ 不可取，要比較 $a_4$ 與 $a_5$ |
| 「$x^2-4x+m>0$ 對所有實數 $x$ 成立」 | 判別式 $D<0$（恆正 = 圖形完全在軸上方） |
| 「方程式 $x^2+bx+c=0$ 一根大於 1、一根小於 1」 | 根的分佈 → $f(1)<0$（開口向上時） |
| 「二次函數圖形與 $y=2x+1$ 相切」 | 聯立後的新二次式判別式為 0 |
| 「拋物線在 $x=1$ 與 $x=5$ 有相同函數值」 | 對稱軸 = 兩點中點 = 3，不必解方程式 |
| 「拋體運動最高點的時間與高度」 | 物理題殼、二次函數核（見 S11） |

**最常見的三個陷阱**：(1) 附了定義域範圍；(2) 二次項係數含參數可能為 0；(3) 變數其實是整數。這三件事都不會寫在題目的顯眼處。

## S11 跨科連結 {#s11 layer=3}

**物理｜等加速度運動**
鉛直上拋的位移 $y=v_0t-\frac12 gt^2$，就是以時間 $t$ 為變數的二次函數，且 $a=-\frac{g}{2}<0$（開口向下）。「最高點」= 頂點，發生在 $t=\frac{v_0}{g}$——與物理課用 $v=v_0-gt=0$ 求出的結果相同。**符號差異**：物理用 $a$ 表加速度，數學用 $a$ 表二次項係數，兩者不同；物理題的定義域天然受限（$t\ge 0$，落地即停），所以物理版的最值題幾乎都是區間極值。

**物理／地科｜拋物面的聚焦**
碟型天線、車頭燈反射罩、太陽能聚光器都是拋物線繞軸旋轉而成。S05 的 L3 段落證明了 $y=ax^2$ 的焦點在 $\left(0,\frac{1}{4a}\right)$；平行入射光全部反射通過焦點，這是幾何定義（等距）的直接結果。

**經濟／公民｜邊際與最適**
收入 = 價格 × 數量，需求曲線為線性時收入必為二次函數，最大收入出現在需求曲線的中點——這正是公民課「價格彈性等於 1 的點」。跨章整合 2 做的就是這件事的數字版。

**生物／統計｜最小平方法**
配適一條直線使誤差平方和最小，誤差和是斜率的二次函數，令其頂點即得迴歸線公式。你在生物實驗課畫的趨勢線，背後就是一次配方。

## S12 課外延伸 {#s12 layer=3}

- `[應用]` **懸索橋的纜繩是拋物線還是懸鏈線？** 兩者長得很像但不同。自由懸掛、只承受自身重量的鏈子是**懸鏈線** $y=\cosh x$；而懸索橋的主纜承載的是均勻分布在**水平方向**的橋面重量，此時形狀才是拋物線。這是一個「看起來一樣但推導不同」的經典案例。
- `[科普]` **伽利略的斜面實驗**：在沒有精確計時器的年代，他把落體「稀釋」成斜面滾球以放慢速度，用水鐘計時，發現距離與時間平方成正比。這是「二次關係」第一次被實驗確立。
- `[時事]` 每年颱風季的降雨強度－時間曲線、疫情的單波感染曲線，常被媒體描述為「拋物線型」。閱讀時要注意：**形狀像不代表函數是二次的**，真實資料通常更接近高斯或對數常態。這是資料識讀的好練習。
- `[閱讀]` 3Blue1Brown〈Why is the derivative of $x^2$ equal to $2x$?〉——用面積的方式看二次函數的變化率，可以先建立微分的圖像直覺。

**定性觀察**（作者撰寫，須附題號佐證）：
1. 本單元極少單獨成題，多半是**其他單元題目的最後一步**——三角、數列、機率、指對數的最值問題最後都收斂到二次函數。因此練習重點不是「算二次函數」，而是「認出眼前的東西是二次函數」。
2. 混合題與非選題偏好情境最佳化（QF-APPLIED-MAX），且幾乎必定附帶範圍限制，同時考 QF-RANGE-INTERVAL。
3. 單選題偏好判別式與參數討論，因為容易設計出「漏掉 $a=0$」的誘答選項。

## S14 速記卡與一頁總結 {#s14 layer=1}

**速記卡**

| 正面 | 反面 |
|---|---|
| 對稱軸公式？ | $x=-\dfrac{b}{2a}$；$b$ 與 $h$ 異號（$a>0$ 時） |
| 頂點的 $y$ 值怎麼求最快？ | 不背公式，直接算 $f(h)$ |
| 看到定義域範圍，第一個動作？ | 問「頂點在範圍內嗎」，再決定看頂點還是看端點 |
| $D>0/=0/<0$ 各代表？ | 兩交點／相切／不相交 |
| 給頂點、給兩根、給三點，各用什麼式？ | 頂點式／交點式／一般式 |
| 換元後一定要做的一件事？ | 寫下新變數的範圍 |
| 二次項係數含參數時要先問？ | 它可以是 0 嗎（會退化成直線） |
| 兩根都在 $(m,n)$ 內的三件套？ | $D>0$、$f(m)$ 與 $f(n)$ 同號為正（$a>0$）、對稱軸在 $(m,n)$ 內 |

**一頁總結**

$$f(x)=ax^2+bx+c=a(x-h)^2+k,\quad h=-\frac{b}{2a},\ k=f(h)$$

- $a$ 的正負 = 開口方向 = 有最小值還是最大值；$|a|$ 越大越窄。
- $D=b^2-4ac$ 管交點個數，和 $a$ 的正負合起來管圖形位置。
- **對稱軸 = 兩根中點**，這條比公式好用。
- **限制定義域，一切重來**：頂點在區間內才用頂點，否則看端點。
- 一切最佳化問題的終點站：設變數 → 化成二次 → 配方 → 檢查範圍。

## S01 一句話定位 {#s01 layer=1}

虛詞是文言文的螺絲：它們本身沒有畫面，卻決定了句子的零件怎麼組裝。

在知識地圖上，它的上游是詞性與主謂賓結構（你要先能看出句子的骨架）；下游接文言句式（判斷句、被動句、倒裝句）、斷句標點，以及最終的文言文閱讀理解。

**為什麼要學**：會考的文言文題組，不論問翻譯、問文意、還是問「下列文句中『之』字用法相同的是」，都在同一個能力上——**你能不能看出這個虛詞在句中扮演什麼角色**。這四個字（之、其、而、以）合計占了文言虛詞題的絕大多數。

## S03 直覺建立 {#s03 layer=1}

::: L1
白話文靠標點和語序告訴你句子怎麼組裝，文言文沒有標點，靠的是虛詞。所以：**「之、其、而、以」不是要背意思，是要判斷位置。** 同一個「之」放在名詞和名詞中間是「的」，放在動詞後面是「他／它」，放在主語和謂語中間則根本不用翻。
:::

::: L2
### 一個類比：虛詞是接頭，不是零件

想像組裝家具。實詞（山、水、行、高）是木板，虛詞是螺絲和卡榫。木板決定家具有什麼，螺絲決定它們怎麼接。

- **之**：最萬用的接頭。接名詞和名詞 → 「的」；接在動詞後 → 「它」；卡在主語謂語中間 → 只是把一個句子降級成一個片語，本身不翻。
- **其**：指向遠處的手指。指人 → 「他的」；指物 → 「那個」；有時候手指抬起來變成語氣 → 「大概」「難道」。
- **而**：兩個動作之間的接頭，而且**有方向**。同向（然後、而且）或反向（卻）。方向讀錯，整句意思會顛倒。
- **以**：拿東西的手。拿工具（用）、拿理由（因為）、朝向目的（來）。

### 為什麼白話文不需要這些

白話文說「我喜歡蓮花從汙泥裡長出來卻不被汙染」，用「從」「卻」「不被」等雙音節詞和語序把關係說清楚。文言文字少，只能用單字承擔這些功能，於是同一個字被迫身兼數職。

**這就是虛詞難的真正原因**：不是意思多，是一字多職。而判斷是哪一職，靠的是它站在哪裡。
:::

::: L3
### 一點語言史

古代書寫材料昂貴（竹簡、絹帛），文字必須極度壓縮，這是文言文虛詞發達的物質原因。而且古書原本**沒有標點**，讀書的第一件事叫「句讀」（ㄐㄩˋ ㄉㄡˋ）——自己斷句。虛詞就是斷句最重要的路標：「夫」「蓋」常在句首，「也」「矣」「焉」「乎」常在句末，看到它們就知道刀該落在哪裡。

系統整理漢語虛詞的第一部語法書是馬建忠的《馬氏文通》（1898），它借用西方語法框架來分析文言文，也是「實詞／虛詞」這組名稱普及的起點。你現在用的「代詞、介詞、連詞」這套詞彙，就是從那時候來的。
:::

![四個虛詞的位置判斷圖：以「前面是什麼詞、後面是什麼詞」為兩軸](IMG-FW-01-position)
*要你看到的是：判斷虛詞用法時，你的眼睛應該先往左右看詞性，而不是先想意思。*

## S04 正式定義與符號 {#s04 layer=2}

**虛詞**：本身不表示具體意義（人、事、物、動作、性質），主要用來表示語法關係或語氣的詞。相對於此，能單獨表意的叫**實詞**。

白話說就是：把它從句子裡拿掉，你不會少掉一個東西或一個動作，但句子會散掉。

以下四表為本單元的核心清單。**例句一律取自國中課內或會考常見篇章。**

### 「之」的六種用法 `FW-ZHI`

| # | 用法 | 位置特徵 | 例句 | 語譯 |
|---|---|---|---|---|
| 1 | 結構助詞「的」 | 名詞／形容詞 + 之 + 名詞 | 水陸草木**之**花 | 水裡陸上草木的花 |
| 2 | 代詞（他／她／它／這） | 動詞 + 之（句尾或賓語位置） | 學而時習**之** | 時常複習它 |
| 3 | 取消句子獨立性 | 主語 + 之 + 謂語 | 予獨愛蓮**之**出淤泥而不染 | 我喜愛蓮從汙泥中長出卻不沾染（「之」不翻） |
| 4 | 賓語前置的標誌 | 疑問／否定句中，賓語跑到動詞前 | 何陋**之**有 | 有什麼簡陋呢（原為「有何陋」） |
| 5 | 湊足音節 | 用在時間詞或動詞後，無義 | 久**之**，目似瞑 | 過了很久，眼睛好像閉上了 |
| 6 | 動詞「往、到」 | 之 + 地點名詞 | 輟耕**之**壟上 | 停止耕作走到田埂上 |

### 「其」的四種用法 `FW-QI`

| # | 用法 | 位置特徵 | 例句 | 語譯 |
|---|---|---|---|---|
| 1 | 第三人稱代詞（他的／它的） | 其 + 名詞 | **其**岸勢犬牙差互 | 那溪岸的形勢像狗牙般交錯 |
| 2 | 指示代詞（那、那些） | 其 + 名詞（可替換為「那」） | 專**其**利三世矣 | 獨占那利益三代了 |
| 3 | 「其中的」 | 其 + 數量／選擇 | 擇**其**善者而從之 | 選擇他們之中好的來跟隨 |
| 4 | 語氣詞（大概／難道／可要） | 通常在句首，句末多有「乎」「邪」 | **其**真無馬邪？**其**真不知馬也 | 難道真的沒有千里馬嗎？大概是真的不認識馬吧 |

### 「而」的六種用法 `FW-ER`

| # | 關係 | 可替換為 | 例句 |
|---|---|---|---|
| 1 | 並列 | 又／而且（或不譯） | 望之蔚然**而**深秀者 |
| 2 | 承接 | 就／然後 | 溫故**而**知新 |
| 3 | 轉折 | 卻／可是 | 人不知**而**不慍 |
| 4 | 修飾 | 地（連狀語與動詞） | 默**而**識之 |
| 5 | 遞進 | 並且／而且更 | 學**而**時習之（部分注家）／飲少輒醉，**而**年又最高 |
| 6 | 假設 | 如果 | 人**而**無信，不知其可也 |

### 「以」的用法 `FW-YI`

| # | 詞性 | 意思 | 例句 |
|---|---|---|---|
| 1 | 介詞 | 用、拿 | **以**刀劈狼首 |
| 2 | 介詞 | 憑藉、依靠 | **以**君之力 |
| 3 | 介詞 | 因為 | 不**以**物喜，不**以**己悲 |
| 4 | 介詞 | 按照 | 策之不**以**其道 |
| 5 | 連詞 | 來、用來（表目的） | 屬予作文**以**記之 |
| 6 | 連詞 | 以致（表結果） | 不宜妄自菲薄……**以**塞忠諫之路也 |
| 7 | 動詞 | 認為 | 皆**以**美於徐公 |
| 8 | 通假 | 通「已」，已經 | 固**以**怪之矣 |
| 9 | 固定詞組 | 是以／以是＝因此；所以＝用來、……的原因 | **是以**先帝簡拔以遺陛下 |

### 常見誤寫與誤讀

1. 把「之」的第 3 種用法硬翻成「的」：「予獨愛蓮之出淤泥」翻成「我喜愛蓮的長出汙泥」——不通。這種「之」不翻。
2. 「而」的修飾用法被翻成「而且」：「默而識之」翻成「沉默而且記住」——應為「默默地記住」。
3. 把「所以」直接當白話的「所以」：〈出師表〉「此臣所以報先帝……」的「所以」是「用來……的方法」，不是因果連接詞。
4. 「其」的語氣用法被當成代詞：「其真無馬邪」翻成「他真的沒有馬嗎」——「其」在此是語氣詞「難道」。

## S05 判準的推導 {#s05 layer=2}

> 語文科沒有數學意義上的證明，但判斷方法有理由。這一節說明**為什麼可以靠位置判斷**，而不是要你背判準。

### 必須懂（L2）

#### 為什麼「看左右詞性」有效

文言文的詞序基本固定：定語在名詞前、狀語在動詞前、賓語在動詞後。虛詞既然是接頭，它連接的兩端是什麼詞性，就決定了它只能扮演哪一種角色。

以「之」為例，把它左右兩邊的詞性列出來，可能性立刻被壓縮：

| 左邊 | 右邊 | 只可能是 |
|---|---|---|
| 名詞／形容詞 | 名詞 | 「的」（用法 1） |
| 動詞 | 句末／逗號 | 代詞（用法 2） |
| 名詞（主語） | 動詞／形容詞（謂語） | 取消獨立性（用法 3） |
| 動詞 | 地點名詞 | 動詞「往」（用法 6） |

**關鍵在於第 1 種與第 3 種的差別**：右邊是名詞就是「的」，右邊是動詞或形容詞（謂語）就是取消獨立性。

「水陸草木**之**花」——花是名詞 → 的。
「蓮**之**出淤泥」——出是動詞 → 取消獨立性，不翻。

#### 為什麼會有「取消句子獨立性」這種東西

「蓮出淤泥而不染」本身是一個完整句子，可以獨立說。但作者要說的是「我喜愛〔蓮出淤泥而不染〕這件事」——這個句子必須降級成一個名詞性的成分，才能當「愛」的賓語。

古人的做法就是在主語和謂語中間塞一個「之」，句子立刻失去獨立語氣，變成一個片語。功能上等同於英文的 `that` 或動名詞：`I love that the lotus rises from mud unstained.`

**所以這個「之」不翻，不是因為它沒作用，而是因為現代中文用語序就能做到同樣的事。**

#### 「而」的方向怎麼判

不看「而」本身，看**前後兩件事的關係**：

1. 兩邊是同一件事的兩個面向、詞性相同、可以互換位置 → 並列。
2. 後面是前面的結果、時間上有先後、不可互換 → 承接。
3. 後面出乎前面的意料 → 轉折。（自測法：中間塞得下「卻」而意思更順，就是轉折）
4. 前面是狀態、方式，不是獨立動作 → 修飾。（自測法：前面那個詞能不能加「地」）

「溫故**而**知新」：先溫故、後知新，有先後 → 承接。
「人不知**而**不慍」：別人不了解，照理該生氣，卻不生氣 → 轉折。
「默**而**識之」：「默」不是一個動作，是「識」的方式 → 修飾。

#### 「以」的分界：後面接名詞還是動詞

- **以 + 名詞** → 介詞（用、憑、因為、按照）。「以刀劈狼首」刀是名詞 → 用。
- **以 + 動詞** → 連詞（來、以致）。「以記之」記是動詞 → 表目的，來。

這條規則的例外只有「認為」（後接小句）與通假「已」，而這兩種在課內是可窮舉的固定句。

::: L3
### 知道就好（L3）

#### 虛詞的來源：實詞虛化

幾乎所有虛詞原本都是實詞，用久了意思被磨掉，只剩語法功能。這個過程叫**語法化**（grammaticalization）。

- 「之」本義是「往、到」（用法 6 是它的原始義，甲骨文字形是腳趾離開地面），後來虛化為代詞、助詞。
- 「以」本義是「用」（拿著東西），虛化出「憑藉」→「因為」→「來」。
- 「而」本義是「鬍鬚」（象形），因為讀音被借去當連詞，本義完全消失。

**知道這件事的用處**：你會發現同一個字的多種用法不是隨機的，而是從一個源頭延伸出來的一條線。「以」從「用」到「憑藉」到「因為」，其實是同一個動作在越來越抽象的層次上重複。

#### 虛詞與斷句

古書無標點，虛詞是斷句的路標：
- **句首**：夫、蓋、凡、且夫、若夫 → 前面斷開。
- **句末**：也、矣、焉、哉、乎、耳、耶 → 後面斷開。
- **句中**：之、而、以、於 → **不要**在這裡斷（這是最常見的斷句錯誤）。

這條在會考的斷句題與課外文言閱讀非常有用，見進階題。
:::

## S06 核心結論與必背清單 {#s06 layer=1}

| 內容 | 背還是推 | 若選推，第一步是 |
|---|---|---|
| 「之」的六類、「其」的四類 | **背**（封閉清單，就這麼多） | — |
| 「以」的固定詞組（是以、所以、以是） | **背** | — |
| 這一句中的「之」是哪一類 | **推** | 看右邊是名詞還是謂語 |
| 這一句中的「而」是哪一類 | **推** | 看前後兩件事的關係，試著塞「卻」或「地」 |
| 這一句中的「以」是介詞還是連詞 | **推** | 看後面接名詞還是動詞 |
| 「而」的六種關係名稱 | **背名稱**，用法用推 | — |
| 課內例句 | **背**（會考的比較題必考課內句當基準） | — |

**分界原則**：**清單要背，判斷要推。** 背清單是為了知道「可能的答案有哪幾個」，推判斷是為了在其中選一個。只背清單不會判斷，等於拿著一串鑰匙不知道開哪個門；只想靠語感不背清單，會漏掉自己沒想到的用法。

## S07 例題階梯 {#s07 layer=2}

### 【基礎 1】單句判斷「之」 `難度 1｜1 分鐘｜FW-ZHI`

**題目**：判斷下列各句「之」的用法：
(A) 忘路**之**遠近　(B) 漁人甚異**之**　(C) 兩狼**之**並驅如故

**特徵辨識**：只有單句、只問用法 → 純執行題，用位置判準。

**想法起點**：不要先想「這句在講什麼」，先看「之」的右邊是什麼詞。右邊是名詞就是「的」；右邊沒東西（句末）就是代詞；右邊是動詞而左邊是名詞主語，就是取消獨立性。**判斷順序固定，可以做到不理解句意也答對。**

**完整解**：
(A) 右邊「遠近」是名詞（形容詞作名詞用，指距離） → **結構助詞「的」**，路的遠近。
(B) 「之」在句末、前面是動詞「異」（意動：以……為異） → **代詞**，指桃花林的景象。
(C) 左邊「兩狼」是主語、右邊「並驅」是謂語 → **取消句子獨立性**，不翻。原句意為「兩隻狼像原來一樣一起追趕」。

**檢驗**：(C) 把「之」拿掉唸成「兩狼並驅如故」，意思完全不變，只是語氣變成獨立句 → 確認是取消獨立性。**「拿掉還通、而且意思不變」是這一類的特徵。**

**變式提示**：若把 (A) 改成「忘路之遠」，判斷不變；若改成「送杜少府之任蜀州」，「之」後接「任蜀州」（動詞短語表地點行為），是動詞「往」。

### 【基礎 2】單句判斷「而」 `難度 1｜1 分鐘｜FW-ER`

**題目**：判斷「而」的關係：
(A) 溫故**而**知新　(B) 人不知**而**不慍　(C) 康肅笑**而**遣之

**想法起點**：先問「後面那件事，是不是出乎前面的意料？」是 → 轉折。不是，再問「前面那個詞是動作還是方式？」方式 → 修飾。都不是，看有沒有先後 → 承接／並列。

**完整解**：
(A) 溫習舊的、然後領悟新的，有時間先後 → **承接**，可譯「就、然後」。
(B) 別人不了解，照常理會不高興，卻不生氣 → **轉折**，可譯「卻」。
(C) 「笑」不是獨立於「遣」之外的動作，是「遣」的樣子 → **修飾**，譯「笑著打發他走」。

**檢驗**：(C) 若譯成「笑了，然後打發他」也講得通，但原文要表達的是陳堯咨無話可說的神態，「笑著」更貼切。**修飾與承接的分界在於：前面那件事能不能單獨成立為一個事件。**

**變式提示**：「呼爾**而**與之」「執策**而**臨之」都屬修飾；「擇其善者**而**從之」屬承接。

### 【標準 1】會考經典題型：用法相同者 `難度 3｜2 分鐘｜FW-COMPARE`

**題目**：下列各組「之」字，用法**相同**的是：
(A) 水陸草木**之**花／予獨愛蓮**之**出淤泥而不染
(B) 何陋**之**有／宋何罪**之**有
(C) 久**之**，目似瞑／學而時習**之**
(D) 輟耕**之**壟上／馬**之**千里者

**特徵辨識**：兩兩比較題。**這是會考虛詞題最主流的形式。**

**想法起點**：**不要一組一組讀意思，先把八個「之」各自標上代號。** 標完再看哪一組兩個代號相同。這樣做的好處是：你只需要做八次單句判斷（基礎 1 的能力），不需要做四次「比較」這種模糊的事。把難題拆成已經會的小題，是這一類題目的通用策略。

**完整解**：
(A) 前：右接名詞「花」→ 助詞「的」；後：主語「蓮」+ 謂語「出淤泥」→ 取消獨立性。**不同。**
(B) 前：「何陋之有」= 有何陋，賓語「何陋」前置 → 賓語前置標誌；後：「宋何罪之有」= 宋有何罪，同樣是賓語前置。**相同。**
(C) 前：「久」是時間詞，「之」湊音節無義；後：動詞「習」後 → 代詞。**不同。**
(D) 前：「之」後接地點「壟上」→ 動詞「往」；後：「馬之千里者」= 千里之馬，定語後置的標誌。**不同。**

答案：**(B)**

**檢驗**：(B) 兩句還原後語序一致（有何陋／有何罪），且都是疑問代詞作賓語提前——條件完全相同 ✓。

**變式提示**：這題型的三種常見設計：同字不同用法（本題）、課內句配課外句（用課內句當已知基準去推課外句）、以及四個選項各換一個虛詞（考的是四張表都要熟）。

### 【標準 2】翻譯中的虛詞 `難度 3｜3 分鐘｜FW-TRANSLATE`

**題目**：語譯「不以物喜，不以己悲」與「屬予作文以記之」，並說明兩個「以」的差別。

**想法起點**：看「以」後面接什麼。「物」「己」是名詞 → 介詞；「記」是動詞 → 連詞。**這一步做完，兩句的差別就已經有答案了，翻譯只是把判斷寫成句子。**

**完整解**：
- 「不以物喜，不以己悲」：以 + 名詞（物、己）→ 介詞「因為」。語譯：不因外物（的好壞）而歡喜，不因自己（的得失）而悲傷。
- 「屬予作文以記之」：以 + 動詞（記）→ 連詞，表目的「來」。語譯：囑咐我寫一篇文章來記下這件事。
- 差別：前者是介詞，引出原因；後者是連詞，連接前後兩個動作並表示後者是前者的目的。

**檢驗**：把「以」替換掉再讀一次——「不因物喜」通順 ✓；「作文來記之」通順 ✓。若互換（「不來物喜」「作文因為記之」）立刻不通，確認判斷正確。**替換測試是虛詞翻譯最可靠的自我檢驗。**

**變式提示**：〈岳陽樓記〉同篇還有「屬予作文以記之」與「予嘗求古仁人之心」，後者的「之」是「的」。同一篇文章裡的不同虛詞常被拿來組合成比較題。

### 【進階 1】課外短文的虛詞與斷句 `難度 4｜5 分鐘｜FW-PUNCT`

**題目**：為下列短文斷句，並說明畫線「之」「以」的用法。

> 齊人有馮諼者貧乏不能自存使人屬孟嘗君願寄食門下孟嘗君曰客何好曰客無好也

**特徵辨識**：課外、無標點、有對話。

**想法起點**：斷句不要從頭硬讀，先**找路標**。三種路標：(1) 對話標記「曰」——「曰」後面必斷；(2) 句末語氣詞「也、矣、乎、焉」——後面必斷；(3) 人名、專名出現處常是主語，前面可斷。**先用路標切出大塊，剩下的小塊再靠語感。** 同時記住：「之、而、以、於」是句中字，不要在它們前後亂斷。

**完整解**：
> 齊人有馮諼者，貧乏不能自存，使人屬孟嘗君，願寄食門下。孟嘗君曰：「客何好？」曰：「客無好也。」

判斷依據：「者」提示前面是一個名詞性短語（有……者），斷；「不能自存」語意完整，斷；「孟嘗君曰」是對話標記，「曰」後加冒號引號；「客無好也」的「也」是句末語氣詞，斷。

**檢驗**：斷完後每一小句都應該能單獨翻譯得通。「齊人有馮諼者」= 齊國有個叫馮諼的人 ✓；「客何好」= 客人喜歡什麼 ✓。若某一段翻不通，刀就切錯了。

**變式提示**：若題目改為「下列斷句何者正確」的選擇題，先掃四個選項的差異點（通常只差一兩刀），只判斷那一兩刀即可，不必逐字比對。

### 【進階 2】同字四義的辨析 `難度 4｜4 分鐘｜FW-QI`

**題目**：說明下列「其」的用法：
(A) 擇**其**善者而從之
(B) **其**如土石何
(C) **其**真無馬邪？**其**真不知馬也
(D) 安陵君**其**許寡人

**想法起點**：「其」的判斷順序和其他三個字不同：**先看它在不在句首。** 在句首而後面不是名詞 → 幾乎一定是語氣詞（推測、反詰、祈使）；在句中且後接名詞 → 代詞或指示代詞；後接數量或選擇 → 「其中」。

**完整解**：
(A) 後接「善者」，且語意為「他們之中好的」 → **其中的**。
(B) 句首，「如……何」是固定句式（把……怎麼樣），「其」在此加強反問語氣 → **語氣詞，難道**。（〈愚公移山〉智叟語）
(C) 兩個「其」都在句首：前者配句末「邪」表反詰 → **難道**；後者配句末「也」表推測 → **大概、恐怕**。
(D) 句首、後接動詞「許」、對象是安陵君（要求對方） → **語氣詞，表祈使：可要、希望**。

**檢驗**：把語氣詞的「其」拿掉，句子仍然通順但語氣變平（「真無馬邪」「安陵君許寡人」）→ 確認它只負責語氣 ✓。這與代詞的「其」不同：拿掉「其岸勢犬牙差互」的「其」，句子會缺少指稱。

**變式提示**：語氣詞的「其」在課內出現頻率不高但辨識度高，通常配合句末的「邪、乎、也」出現。**看到句首「其」，先往句末找語氣詞。**

### 【跨章整合 1】虛詞 × 文意理解 `難度 4｜6 分鐘｜FW-COMPARE, FW-TRANSLATE`

**題目**：閱讀〈愛蓮說〉節錄，回答問題。

> 予獨愛蓮**之**出淤泥**而**不染，濯清漣**而**不妖，中通外直，不蔓不枝，香遠益清，亭亭淨植，可遠觀**而**不可褻玩焉。

(1) 文中三個「而」的用法是否相同？
(2) 「蓮之出淤泥」的「之」若改成「的」，句子會出什麼問題？
(3) 作者用這一連串描述，實際上在說什麼？

**特徵辨識**：會考題組的典型結構——**先問虛詞（送分），再問文意（拉分），而文意的答案往往就藏在虛詞裡。**

**想法起點**：第 (3) 題看似跟虛詞無關，但三個「而」都是轉折，這件事本身就是答案的骨架：作者反覆使用「處於 X 卻不 Y」的句型，說的是「身處濁世而保持節操」。**虛詞不只是考點，它是作者思路的骨架。** 這是本單元最重要的一個觀念。

**完整解**：
(1) 三個都是**轉折**（卻）。「出淤泥」照理應該髒，卻不染；「濯清漣」照理會顯得妖豔，卻不妖；「可遠觀」照理親近也無妨，卻不可褻玩。三處都是「照理應該 A，實際卻 B」。
(2) 「蓮之出淤泥」的「之」是取消句子獨立性，作用是把「蓮出淤泥而不染」整個句子變成「愛」的賓語。若翻成「的」，會變成「我喜愛蓮的長出汙泥」，「的」後面必須接名詞，而「出淤泥」是動詞短語，語法上就不成立。
(3) 藉由三次「處於某種環境卻不受影響」的對比，塑造蓮「潔身自好、不同流合汙」的形象，並以此自喻，表達作者在世俗中保持節操的人格追求。

**檢驗**：第 (1) 題可用替換法逐一驗證——三處都能塞進「卻」且更順 ✓。第 (3) 題的答案應該能在原文找到直接對應（三個轉折句），不能是憑空的道德感想 ✓。

**變式提示**：〈陋室銘〉的「斯是陋室，惟吾德馨」與本文結構相同（陋卻不覺陋），常被拿來與本文組成比較題組。

## S08 常見錯誤與迷思概念 {#s08 layer=2}

**MC-FW-001｜見「之」就翻「的」**
> 錯誤示範：「予獨愛蓮之出淤泥而不染」→「我唯獨喜愛蓮的長出淤泥卻不沾染」
- 為什麼會這樣想：最先學到的用法是「的」，而且它出現頻率最高，於是變成預設值。
- 診斷：翻出來的句子「的」後面接了動詞，讀起來卡住。
- 修正：「的」後面必須是名詞。右邊是動詞或形容詞時，這個「之」是取消句子獨立性，**不翻**。

**MC-FW-002｜「而」的方向讀反**
> 錯誤示範：「人不知而不慍」→「別人不了解，所以不生氣」
- 為什麼會這樣想：把「而」預設為承接（然後、所以）。
- 診斷：翻出來的因果關係不合常理（不被了解怎麼會因此不生氣？）。
- 修正：語意上出乎意料就是轉折。**自測法：塞「卻」進去，若比「然後」順，就是轉折。**

**MC-FW-003｜「所以」照白話讀**
> 錯誤示範：〈出師表〉「此臣所以報先帝而忠陛下之職分也」→「這就是我所以報答先帝……」（當成因果連接詞）
- 為什麼會這樣想：字形與白話完全相同。
- 診斷：句中已有「此……也」的判斷句式，塞一個因果連接詞在中間，語法上多餘。
- 修正：文言的「所以」是「用來……的（方法／緣故）」。此句意為「這是我用來報答先帝、效忠陛下的職責本分」。**同類還有「是以」「以是」＝因此，方向與「所以」相反，別記混。**

**MC-FW-004｜把語氣詞的「其」當代詞**
> 錯誤示範：「其真無馬邪」→「他真的沒有馬嗎」
- 為什麼會這樣想：「其」的代詞用法最常見。
- 診斷：上下文找不到「他」是誰。**代詞一定有指涉對象，找不到對象就不是代詞。**
- 修正：句首的「其」配上句末「邪」，是反詰語氣：「難道真的沒有千里馬嗎？」

**MC-FW-005｜比較題用「感覺很像」作答**
> 錯誤示範：看到兩句都有「之」而且都很文言，就選相同。
- 為什麼會這樣想：沒有把比較題拆成單句判斷。
- 診斷：說不出兩個「之」各自是第幾類。
- 修正：**先為每個虛詞標上用法代號，再比對代號。** 說不出代號就不能作答。

## S09 變式與陷阱 {#s09 layer=2}

| 表面長相 | 實際考點 |
|---|---|
| 「下列『之』字用法相同的是」 | 六類清單 + 單句判斷（標準 1） |
| 「下列文句『而』字前後關係與例句相同的是」 | 而的六種關係，且例句通常取自課內 |
| 課外短文＋「請語譯畫線句」 | 虛詞判斷（翻錯虛詞，整句就錯） |
| 「下列文句斷句正確的是」 | 句首／句末虛詞路標（進階 1） |
| 「作者藉此表達的態度是」 | 常靠轉折詞「而」「然」定位作者真正想說的那一半 |
| 兩篇文言文比較閱讀 | 用同一個虛詞在兩篇中的不同用法設題 |
| 「『之』字在此可省略而文意不變者」 | 專考「取消獨立性」與「湊音節」兩類（這兩類拿掉都不影響語意） |
| 課內句配課外句 | 用你熟的課內句當基準，去推課外句——不是要你讀懂課外文 |

**三個最常見的陷阱**：
1. **同形不同義**：課內見過的字組，在課外文中換了用法（如「之」在「馬之千里者」是定語後置標誌）。
2. **語氣詞被忽略**：句末的「邪、乎、也、矣」會反過來決定句首「其」的用法。
3. **翻譯題不扣虛詞**：語譯時只翻實詞，把虛詞的關係漏掉，句意就散了。

## S10 判斷決策樹 {#s10 layer=1}

![四虛詞判斷決策樹](IMG-FW-02-tree)

```
【之】看右邊
├── 名詞          → 「的」
├── 動詞／形容詞（且左邊是主語） → 取消句子獨立性，不翻
├── 地點名詞      → 動詞「往、到」
├── 什麼都沒有（句末）或作賓語 → 代詞（他／它／這）
├── 疑問／否定句中賓語跑到動詞前 → 賓語前置標誌，不翻
└── 前面是時間詞或單音動詞，拿掉無影響 → 湊音節，不翻

【其】看在不在句首
├── 句首 + 句末有 邪/乎/也 → 語氣詞（難道／大概／可要）
├── 句中 + 名詞     → 他的／它的／那
├── + 善者/一/二等選擇 → 其中的
└── 其餘             → 代詞

【而】看前後兩件事的關係
├── 後者出乎意料 → 轉折（卻）
├── 前者是方式、狀態，不能獨立成事件 → 修飾（地）
├── 有時間先後、不可互換 → 承接（就、然後）
├── 可互換、詞性相同 → 並列（又、而且）
├── 前句是條件 → 假設（如果）
└── 後者程度更進 → 遞進

【以】看後面接什麼
├── 名詞 → 介詞
│   ├── 具體器物 → 用、拿
│   ├── 抽象憑據 → 憑藉、按照
│   └── 事件原因 → 因為
├── 動詞 → 連詞
│   ├── 後者是前者的目的 → 來、用來
│   └── 後者是前者的壞結果 → 以致
├── 接小句、意為判斷 → 動詞「認為」
└── 是以／以是／所以 → 固定詞組，另記
```

## S11 跨科連結 {#s11 layer=3}

**英文｜功能詞的對應**
文言虛詞的角色，在英文裡由功能詞承擔：
- 「之」（的）≈ `of` / `'s`；「之」（取消獨立性）≈ `that` 引導的名詞子句或動名詞。
- 「而」（轉折）≈ `but` / `yet`；「而」（承接）≈ `and then`；「而」（修飾）≈ `-ly` 副詞或分詞構句。
- 「以」（用）≈ `with` / `by`；「以」（因為）≈ `because of`；「以」（來）≈ `in order to`。
**差異提醒**：英文靠不同的字分工，文言靠同一個字兼職。所以英文是「認字」，文言是「認位置」。

**歷史｜史料閱讀**
歷史科的史料題常出現文言原文（詔書、奏議、方志）。看懂虛詞，你才讀得出史料裡的轉折與因果——而「因果」正是歷史題最愛問的東西。例如史料中的「以」若是「因為」，那句話就是在陳述動機；若是「用來」，那是在陳述手段。

**公民／法律文字**
現行法條仍保留大量文言結構：「前項所稱……者，指……」「非有正當理由，不得……」。習慣文言的條件句與否定句式，讀法條會輕鬆很多。

## S12 課外延伸 {#s12 layer=3}

- `[閱讀]` **《古文觀止》的短篇**：〈陋室銘〉〈愛蓮說〉之外，可讀〈鄒忌諷齊王納諫〉——全篇是對話，虛詞密度高，且故事本身好看。
- `[科普]` **語法化現象在現代還在發生**：白話文的「了」原本是動詞「終了」，現在只剩語法功能；網路語言的「的說」「而已啦」也在經歷同樣的磨損過程。你正在目睹虛詞的誕生。
- `[時事]` **AI 斷句與古籍數位化**：中研院、哈佛的古籍資料庫都在用機器學習自動標點古文，模型判斷的依據，正是本單元教的虛詞路標。
- `[閱讀]` **王力《古代漢語》常用詞部分**：高中之後想深入的人可以看，國中階段翻翻虛詞條目即可，會發現本單元的清單只是入口。

## S14 速記卡與一頁總結 {#s14 layer=1}

**速記卡**

| 正面 | 反面 |
|---|---|
| 「之」右邊是名詞 → ？ | 「的」 |
| 「之」左主語、右謂語 → ？ | 取消句子獨立性，不翻 |
| 「之」後接地點 → ？ | 動詞「往、到」 |
| 「何陋之有」的「之」→ ？ | 賓語前置標誌（原為「有何陋」） |
| 「其」在句首、句末有「邪／乎」→ ？ | 語氣詞（難道／大概） |
| 「而」怎麼判轉折？ | 塞「卻」進去比「然後」順，就是轉折 |
| 「默而識之」的「而」→ ？ | 修飾（默默地記住） |
| 「以」後接名詞／動詞 → ？ | 名詞＝介詞（用、因為）／動詞＝連詞（來、以致） |
| 文言「所以」＝？「是以」＝？ | 所以＝用來……的／是以＝因此 |
| 比較題的第一個動作？ | 為每個虛詞標用法代號，再比代號 |

**一頁總結**

> **虛詞不背意思，背清單、推位置。**

- **之**（六類）：的／代詞／取消獨立性／賓語前置／湊音節／往。**看右邊。**
- **其**（四類）：他的／那／其中／語氣。**看在不在句首、句末有沒有語氣詞。**
- **而**（六種關係）：並列／承接／轉折／修飾／遞進／假設。**看前後兩件事的關係，塞「卻」或「地」測試。**
- **以**：後接名詞是介詞（用、憑、因為、按照），後接動詞是連詞（來、以致），另有動詞「認為」與固定詞組。**看後面接什麼。**
- 三個自我檢驗法：**替換測試**（換成白話詞順不順）、**刪除測試**（拿掉還通就是不翻的那幾類）、**還原測試**（倒裝句還原後語序是否一致）。
- 最後一句：**虛詞是作者思路的骨架**。三個「而」都是轉折，就代表作者講了三次「處於 X 卻不 Y」——文意題的答案通常就在這裡。

## pitfalls
[
 "把「詳細」做成「更長」。字數上限跟下限一樣重要——S14 超過 300 字就不再是考前 3 分鐘能用的東西，S03 寫到 2000 字讀者會在建立直覺前就放棄。每個區塊的字數區間是規格，不是建議。",
 "三層深度用三份檔案維護。第一次改內容時三份還會同步，第三次修訂之後速覽版就開始說著跟深挖版不一樣的話，而使用者最常看的恰好是速覽版。必須從第一天就是單一原始檔 + 投影。",
 "「想法起點」寫成解題步驟的複述。「第一步先配方」不是想法起點，「看到要求最值而式子是二次的，就配方，因為配方是唯一能把兩個 x 併成一個的動作」才是。這一欄若寫壞，整份規格最大的差異點就消失了，而它壞掉時看起來完全正常。",
 "手寫歷屆考題的頻率統計。作者憑印象寫「近十年考過 7 次」，兩年後過期、被使用者抓錯、且無法追溯依據。所有數字綁題庫查詢，查不到就顯示「資料建置中」。",

 "口吻校正過度而變成裝熟。為了不學究就加語尾助詞和顏文字，13–18 歲的讀者對這個特別敏感，會直接降低對內容的信任。正確的親近感來自「直說這裡很難、這裡最多人錯」，不是來自語氣詞。",
