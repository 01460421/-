# 甩蔥影片 / Leek-spinning loop

一段 24 秒、無縫循環的甩蔥動畫短片：Q 版初音風格角色一邊跟著節拍搖擺，一邊轉手上的蔥。
畫面與配樂**全部由程式生成**，沒有用到任何外部素材、圖片或錄音。

![預覽](preview.gif)

成品：`out/miku-negi.mp4`（1280×720, 30fps, H.264 + AAC）。
上面的 `preview.gif` 是同一支影片的縮小版（GitHub 上可以直接播）。

## 怎麼跑

```bash
pip install -r requirements.txt
python3 build.py                       # 預設 720p / 30fps -> out/miku-negi.mp4
python3 build.py --height 1080 --gif   # 1080p，順便輸出 GIF
python3 build.py --height 360 --ss 1   # 快速預覽用
```

`build.py` 會把每一格分散到所有 CPU 核心上畫，再以 raw RGB 直接串進 ffmpeg，
中途不落地成圖檔。ffmpeg 由 `imageio-ffmpeg` 附帶的靜態執行檔提供，不必另外安裝。

## 檔案

| 檔案 | 內容 |
| --- | --- |
| `vector.py` | 極簡向量繪圖層：Catmull-Rom 平滑曲線、緞帶（沿中心線加寬度）、旋轉橢圓、超取樣抗鋸齒 |
| `scene.py` | 角色本身 — 頭髮、瀏海、眼睛、衣服、靴子、蔥，以及背景放射線與飄浮音符 |
| `music.py` | 用 numpy 合成的 chiptune 波爾卡：方波主旋律、oom-pah 貝斯、合成鼓組 |
| `build.py` | 多核算圖 + ffmpeg 封裝 |

## 設計上的幾個重點

**一切都對齊節拍。** 音樂是 130 BPM 的 2/4 波爾卡，26 小節，剛好 24.000 秒。
動畫的每個週期都是節拍的整數分之一 —— 蔥每拍轉一圈、身體每拍彈一次、
頭每兩拍左右擺一次、每四拍眨一次眼。24 秒正好是 52 拍，所以循環點完全接得起來。

**背景也必須循環。** 放射線每 20° 重複一次，因此一個循環必須剛好轉 20° 的整數倍
（這裡是 200°），否則接點會跳一下。飄浮粒子的週期則取 `loop/4`、`loop/6`。
實測首尾兩格只有 1 個像素有差（抗鋸齒的浮點誤差），肉眼看不出來。

**座標與解析度無關。** 所有圖形都畫在一個「高 1000 單位」的虛擬空間裡，
輸出時才換算成實際像素，所以同一份程式碼可以直接出 360p 或 1080p。
16:9 的作法是把 x 的可用範圍往兩側延伸（約 -389…1389），角色構圖不受影響。

**Pillow 的 `ImageDraw` 在 RGBA 圖層上是覆寫、不是混色。** 任何 alpha < 255 的顏色
直接畫下去會把底下的像素連同 alpha 一起換掉，畫面會出現「破洞」。
`vector.Pen` 因此把半透明的繪製轉到一塊裁切到外接矩形的暫存圖層上，再 alpha 合成回去。

## 關於素材來源

- **角色**：以初音未來的設定（青綠雙馬尾、灰黑無袖上衣配青綠飾邊、過膝靴）為靈感，
  用程式一筆一筆畫出來的原創 Q 版造型，沒有描摹或引用任何既有圖片。
- **配樂**：為這支短片寫的原創旋律，不是任何既有錄音（也不是 Ievan Polkka 的採譜）。
